## 一、為什麼會出現「解纜起步時石頭垂直下落」

先前驗收只檢查船上相對落點

`Δx = x石頭 − x桅杆 = −½at²`

卻沒有同時檢查三件必須彼此一致的事：

1. 岸上看到的石頭軌跡；
2. 岸上看到的船與桅杆軌跡；
3. 介面中的「解纜起步」是否正確映射到放手時已有的向前速度。

錯誤版本把解纜起步的放手初速設成 `v0 = 0`。這不會破壞上面的相對落點公式，所以局部測試仍可通過；但岸上視角會把石頭畫成垂直下落，違反本章要建立的「石頭離手時已經和船一起向前」。

這不是玩家理解問題，而是驗收邊界設得太窄。往後航船模擬不得只驗終點，必須同時驗岸紙、船紙與參數映射。

## 二、正式物理矩陣

設石頭放手時船速為 `v0`、船在放手後的加速度為 `a`、放手額外擾動為 `δv`：

- `x石頭(t) = (v0 + δv)t`
- `x桅杆(t) = v0t + ½at²`
- `x相對桅杆(t) = δv·t − ½at²`

| 船況 | 初速 `v0` | 加速度 `a` | 岸上所見 | 相對桅杆落點 |
|---|---:|---:|---|---|
| 停泊 | 0 | 0 | 石頭直落、船不動 | 桅腳附近 |
| 出港平駛 | `> 0` | 0 | 石頭與船共同向前，石頭呈拋物線 | 桅腳附近 |
| 解纜起步 | `> 0` | `> 0` | 石頭保留放手時速度；船繼續加速超前 | 桅後 |
| 收槳減速 | `> 0` | `< 0` | 石頭保留放手時速度；船減速落後 | 桅前 |

補充邊界：

- 徒手或細繩造成的放手擾動只進入 `δv·t`，不能假裝成船況效應。
- 船速高低改變岸上軌跡與斷言適用範圍，不改變理想條件下相對桅杆的落點。
- 加減槳力與桅高改變偏移量大小，不改變偏移方向。
- 不適用的船速、槳力、鼓拍設定必須立即歸零，不能讓隱藏舊值污染下一趟。

## 三、劇情與實驗任務鏈

第三章實驗順序固定為：

1. **重做舊紙**：重現「解纜後第一段、落在桅後」，補上舊紙缺少的船速欄。
2. **走穩三回**：在門閂放手、岸紙可判讀船速的條件下，取得走穩時落在桅腳附近的原紙。
3. **比較起步與走穩**：確認「起步偏後」不能代表所有向前船況。
4. **封閉船艙**：關窗隔開甲板風，比較停泊與走穩的局部機械結果；岸紙仍負責證明哪幾趟走穩。
5. **雙視角原紙**：同一顆石頭、同一高度、同一中拍鼓，同時留下岸紙與船紙。
6. **自由補強**：才開放徒手放手、收槳與跨船範圍等選配問題。

任務頁只顯示本輪可成立的斷言：

- 走穩 → A1
- 起步／走穩比較 → A3
- 船艙 → A2
- 重做舊紙、雙視角 → 不顯示無關斷言
- 自由補強 → S1、S4

S4 必須具備 A1、A3 與實際收槳原紙，不得拿 A2 代替減速資料。

## 四、第三柱資料閘門

碼頭第三柱只能接受同時滿足下列條件的原紙：

- 已簽名收卷；
- 船況為出港平駛且船速已由當趟原紙分類；
- 門閂放手；
- 中拍鼓；
- 同一顆石頭、同一高度；
- 同一趟同時留下岸紙與船紙；
- 對時與逐拍換尺尚未被事先代做。

UI、引擎與存檔淨化必須共用同一個正式閘門；不得讓畫面說不能用、匯入存檔卻能偷渡。

跨船範圍進度也只能使用正式合格原紙，不得以未分類、條件不一致或不足三回的資料點亮。
