## 正向路徑

```text
舊紙出現
→ 旅人先提議補記船怎麼走，船長要求做出來再說
→ 玩家忍住未來答案，指出紙面缺口
→ 伽桑狄確認旅人守得住資料邊界
→ 船主人情中立性再補第二個理由
→ 旅人取得安排原紙與分工的權限
→ 玩家親手做實驗
```

## 失準與修復路徑

```text
玩家先說出正確但未經此紙支持的答案
→ 伽桑狄追問「哪一欄寫了走穩」
→ 信譽 −1
→ 玩家返回同題，把話收回到「一次、船速未記」
→ 信譽 +1
→ 權限仍可取得，但事件簿保留曾經搶答與補正
```

這不是「選錯物理答案扣分」；兩個物理句子都可能正確，差別是當下是否有權把它當成結論。
