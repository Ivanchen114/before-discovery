# 發現之前｜CH3-CR-027｜實驗系列資料包與敘事鷹架

**日期**：2026-07-30  
**狀態**：已裁施工（依總監第三章真機試玩）  
**範圍**：第三章航船卷宗工作台、旅人筆記、證據取得演出；不改物理結論、不改辯論柱數、不改存檔 schema

## 一、試玩病灶

第三章目前的物理與證據鏈成立，但玩家連續按三次相同按鈕，才取得同條件的三張原紙；每次點擊之間沒有新判斷。這不是「親手做實驗」，而是把重複性誤寫成滑鼠耐力。

同時，解纜起步、走穩、封閉船艙、雙視角四段雖有任務卡，彼此缺少角色提出疑問、玩家選擇排除方式、實驗回答疑問的戲劇接縫。斷言成立後也只有系統訊息，沒有旅人公開說出有限斷言、NPC 核對原紙的支付。

旅人筆記雖已有證據圖，第三章的原始實驗紀錄仍顯示空白；玩家完成實驗後也無法重看較快的動畫。

## 二、本輪裁決

### 2.1 重複實驗的操作單位

1. **沒有新決策的重複，不得要求玩家重按。**
2. 同一條件需要三回重現時，玩家按一次「執行三回」，系統依序完成三回，消耗三回原有的時間成本。
3. 三回必須留下三張可追溯原紙；不得只存平均值、總結值或「成功三次」布林值。
4. 工作台與斷言介面以「資料組」為主要選取單位，但資料組可展開查看三張原紙及每回結果。
5. 若每回之間存在新預測、新控制選擇或不同操作，仍應分開操作；本裁決不是把所有重複一律自動化。
6. 雙視角不是三次重複：它是一個同步事件，同時產生岸紙與船紙各一張。
7. 舊存檔若同一組只完成一或兩回，再按一次只補足到三回，不重做已存在的回數。

### 2.2 實驗鏈的敘事鷹架

每次主要實驗轉換必須有下列四拍，並以有立繪的對話框演出：

1. **上一張紙留下缺口**：角色指出現有資料不能排除什麼。
2. **玩家選擇下一個可操作問題**：不是 NPC 代玩家診斷。
3. **NPC 確認實作安排**：誰在岸、誰在船、固定與改變什麼。
4. **玩家執行實驗**：結果只回答剛才承諾的範圍。

第三章最低接縫：

- 解纜起步 → 走穩：同一套條件，只改「船速是否仍在增加」。
- 甲板 → 封閉船艙：玩家先判斷甲板風是可能的混淆，再選「關艙隔開甲板風；岸上另記船況」。錯項不得靠荒謬取勝，而要暴露「沒量風卻說風永遠無關」等越界。
- 船艙 → 雙視角：玩家先判斷要比較兩把尺，必須同一事件、同一號鼓點、兩位觀察者，不能用兩次不同落石或一人奔跑補記。

### 2.3 斷言成立的戲劇支付

工作台斷言成功不得只顯示 `✓` 或 `◆`。必須依序：

1. 旅人把所選資料組與有限斷言完整說出口；
2. 最相關的 NPC 指名核對其中一個條件、範圍或缺口；
3. 證據取得圖出現，並寫明已收入旅人筆記。

NPC 回應必須針對玩家剛引用的紙，不得使用可套用任何章節的泛稱讚。

### 2.4 旅人筆記與重播

1. 第三章旅人筆記必須同時呈現：
   - 已取得證據圖；
   - 實驗資料組；
   - 每組所含原紙與原始結果；
   - 已成立斷言及引用來源。
2. 玩家可在當次結果旁立即重播，也可從旅人筆記重播已完成的實驗。
3. 重播只重演既有資料，**不得改變**天數、信譽、證據、斷言、事件帳、原紙數或存檔游標。
4. 重播畫面必須標示「重播既有紀錄」，避免誤認為新增實驗。

### 2.5 證據取得圖排版

證據圖的標題、圖像與 caption 必須全部包含在 focus 卡片邊界內；低高度橫屏也不得讓 caption 掉出卡片或與對話框重疊。

## 三、工程邊界

- 保留既有單回 engine action，供舊測試與舊存檔相容；runtime 主流程改呼叫系列 action。
- 系列 action 直接追加三張既有格式的原紙，不新增持久化欄位，因此不升 schema。
- UI 可用純表現層保存「最近一組」與重播狀態；任何重播不得呼叫會改 state 的 lab action。
- `greybox/data/scenes3.json` 仍是節點台詞 canonical；本輪動態工作台回應屬工作台演出層，不得反向改寫已收卷資料。

## 四、驗收條件

1. 同條件按一次得到三張不同編號原紙，天數增加三天；借船成本只算一次。
2. 舊存檔已有一／兩張同組原紙時，只補到三張。
3. 船艙停泊與平駛各按一次，各得到三張；兩組仍需玩家分別決定。
4. 雙視角按一次只得到一個同步事件及一對岸／船紙。
5. 斷言勾選以資料組為單位，展開後三張原紙仍逐張可讀。
6. A1、A3、A2 與補強斷言成功時，都有「旅人說出 → NPC 核紙 → 證據圖」。
7. 船艙與雙視角開始前各有一個可錯的設計選擇；錯誤不產生實驗資料。
8. 筆記不再顯示「尚無實驗紀錄」，並能看到第三章的資料組與原紙。
9. 即時重播與筆記重播前後，持久化 state 深度相等。
10. focus caption 在桌機與 844×390 低高度規則下仍位於卡片內。
11. 全套 `npm test` 維持全綠；新增契約必須有會反向轉紅的測試。
