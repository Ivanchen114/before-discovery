# 一、試玩病灶

1. 第一章按「回標題」會先同步存檔，但標題仍顯示「旅程起點」，使玩家誤以為沒有存檔。
2. 第一、二章辯論有「辯論備忘」；第三章辯論嵌在卷宗系統內，沒有章別備忘入口。
3. 第三章證據卡同時顯示原紙編號、船況、觀察位置、固定與改變的變因、支持範圍，五張並排時認知負荷過高。
4. 三柱普通路徑約需十五次選擇；其中多題只是重考玩家在實驗簿已完成的分類，沒有新增反例、干擾變因或主張邊界。
5. 艦長的若干提問在形式上是推論題，在功能上只負責銜接下一步；橋接句被做成計分選項，造成冗長與假難度。
6. 三柱目的沒有在畫面上先說清楚，玩家容易把「岸上紙／船上紙」理解為又一組資料，而不是同一事件的兩個座標原點。

# 二、三柱各自只支付一次認知責任

## 2.1 第一柱｜共同前行

**要回答的問題**：船近似走穩時，石頭鬆手後為什麼仍落在桅腳附近？  
**必要支付**：

1. 玩家出示 A1「走穩三回岸紙」，並在玩家台詞中完成「鬆手前石頭已與船共同前行」的推論。
2. 對手提出「可能是甲板風推回去」後，玩家出示 A2「封閉船艙六回對照」，把主張限制為「隔開甲板風後，停泊與平駛結果仍相近」。

原本的「石頭追桅杆／風一直推」概念題與風界線題不再各收一次點擊；其內容改由證據出示台詞與 NPC 回應承擔。

## 2.2 第二柱｜前進不等於正在變速

**要回答的問題**：舊紙只記到落點後偏，能否據此判定當趟船正在變快？  
**必要支付**：

1. 玩家出示 A3「走穩與解纜起步對照」。
2. 玩家選擇證據邊界：舊紙與今天變快組相像，但缺當趟船速，只能保留為未分類。
3. 玩家決定今天資料最多能支持到哪些實際做過的船與操法；若過度外推，必須診斷仍同時改變的船、操船者與槳法。

實驗簿中已完成的「走穩／正在變快／未分類」三張紙分類，不在辯論中逐張重考。

## 2.3 第三柱｜同一事件、兩個參考原點

**要回答的問題**：岸上與船上為何會畫出不同路徑，卻仍能記錄同一次落石？  
**必要支付**：

1. 玩家出示同一趟、共用鼓點的岸紙與船紙。
2. 玩家按同一鼓點對齊兩紙。
3. 玩家逐拍扣除桅杆位置，把岸紙換算成船紙。

「先確定同一時刻」與「兩張紙的起點不同」不另做概念選擇題；玩家在選紙台詞與實際對齊／換算操作中證明理解。

# 三、必按動作的資格

每個必按動作必須至少完成一項不可由系統代做的認知工作：

1. **選證據**：從目前可用材料中指名回答此問的紙；
2. **做推論**：從可見資料推出尚未支付的新關係；
3. **限主張**：判斷證據最多能說到哪裡；
4. **做轉換**：親自對齊、換算、作圖、核帳或封存。

已在前一層完成的分類，若沒有新增反例、干擾變因或適用範圍，不得再做成計分題。

提問施工前必須標記其功能：

- `optional_probe`：可選的「問到底」，用來拆穿隱藏前提；
- `inference`：答案會改變後續證據選擇或主張邊界；
- `bridge`：只負責承接劇情，不得做成計分選項。

# 四、證據卡採漸進揭露

辯論桌上的卡面只顯示：

1. 證據圖與短標題；
2. 一行船況／觀察位置；
3. 一句「最多能支持什麼」。

「固定了什麼、改了什麼、缺什麼、所含原紙編號」放在同卡的「查看條件與原紙」展開區。所有可用證據仍須同時攤開，但不等於把每張完整規格同時塞進視野。

# 五、章別備忘

- 第一、二章可沿用「問到底／以證據回擊」的辯論備忘。
- 第三章必須有自己的碼頭辯論備忘，先說清三柱目的、每柱支付方式、證據邊界與失敗後可回船補做。
- 第四章是工作台與出版校樣，不得為介面對稱硬塞三柱辯論備忘；若需要說明，使用「出版校樣備忘」。
- 第五章使用自己的兩輪帳目辯論備忘。

章別不必共用同一段文字或同一按鈕位置，但玩家必須在進入高負荷操作前與操作中都能重新叫出當章規則。
