# 發現之前｜CH4-CR-015｜K1 三紙兩問單變因證據鏈

## 一、問題

現行 K1 讓玩家一次勾三張紙，提示卻同時要求「繞得住／跑偏」與「至少一組只改一項」。既有 `assertK1` audit 為相容舊 claim／舊存檔，採較寬門檻：兩張近圓紙加一張離帶紙，而離帶紙只須和其中一張近圓紙形成單變因比較；它不保證第二條比較也成立。新 UI 因此有意比既有 audit 更嚴，把三張紙限制成共享一張離帶紙的兩次單變因比較。舊介面既沒有拆開兩次問題，又把「仍可閉合成橢圓」和「留在原半徑窄帶」混成同一種成功語彙，玩家因此看不出問題、變因與觀察量。

本段要建立的不是「只要繞得住就算成功」，也不是由三個離散設定證明精確函數。它只支持有限主張：月亮保留原有前進；若原有速度改變，每拍向內改向量也必須跟著改變，路徑才會留在原半徑近圓窄帶。

## 二、兩問證據鏈

K0 無作用切線紙固定顯示為已引用來源，不占玩家三紙選取名額。三張試跑紙以一張離開窄帶的紙為共同中間紙，依序完成：

1. **第一問，固定向內扳量，只改原有速度。**玩家選兩張向內扳量相同、速度不同的紙；其中一張須留在原半徑窄帶，另一張須離開窄帶。這一問確認：原來配得上的向內扳量，換了速度便未必仍配得上。
2. **第二問，固定中間紙的速度，只改向內扳量。**保留第一問的離帶紙，再選第三張同速度、不同向內扳量且回到窄帶的紙。這一問確認：同一速度下，改變向內扳量可以使路徑重新落回窄帶。
3. **綜合斷言。**兩問都成立後，玩家才從三句主張中選出「原有前進保留，向內扳量必須和速度相配」。`assertK1` 仍一次封存 K0 切線紙與三張試跑紙，證據、引擎、sanitizer、存檔 schema 均不變。

這是新局 UI 的認知門檻收緊，不是宣稱既有 audit 與兩問鏈等價；較寬的底層 audit 保留，只用來維持既有 claim 與存檔相容。

第一問與第二問各有獨立確認動作；每次點擊都完成新的比較判斷，不是把原本一題拆成兩次形式點擊。玩家可退回重選第一問；重選時第二問與結論草稿一併清除。

第一問成立後不得立刻露出第二問。旅人先把「箭頭相同、只換速度」及一張留帶／一張離帶的觀察說出口，牛頓再把主張收窄為「速度一變，路也變」；玩家親手收掉這兩拍對話後，第二問才解鎖。這是 UI session 內的對話確認，不新增證據、engine state 或存檔欄位；錯 token、舊 embed、重選後遲到的確認都不得開門。

## 三、玩家可見語彙

- 主要觀察量一律寫「留在原半徑窄帶／偏離原半徑窄帶」。
- 橢圓可以仍然閉合，但在本題若離開近圓窄帶，就屬「偏離窄帶」，不得以「仍繞得住」混淆本題判準。
- 速度與向內扳量是玩家改變的兩個變因；初始半徑、每拍時間與每拍指向當下地心維持不變；觀察量是路徑是否留在原半徑窄帶。
- 不顯示內部形狀代號，也不宣稱三張紙已證明平方定律或真實天體作用大小。

## 四、錯誤回饋

選紙失敗只作操作層短診斷，不由人物代替玩家作答：

- 第一問分別指出：數量不是兩張、向內扳量未固定、速度沒有改變、或兩張沒有形成「一張窄帶／一張離帶」。
- 第二問分別指出：未選第三張、速度未固定、向內扳量未改變、或第三張仍未回到窄帶。
- 只有兩問已成立、玩家選錯綜合主張時，才進牛頓的主張邊界回應；不得再假稱三張紙尚未形成對照。

## 八、2026-08-14 總監試玩增補：單一資料表與第二次換手

現行流程固定為：

1. **第一問**：「在朝地心箭頭長度相同時，原本速度會怎麼影響軌道？」玩家在同一張試跑表的首欄勾兩張紙；確認後由旅人指出一張留帶、一張離帶，牛頓只收窄為速度確實改變軌道。
2. **第二問**：「在原本速度相同時，朝地心箭頭長度又會怎麼影響軌道？」第一問兩張保持勾選且鎖定；玩家仍在同一張表再勾一張。確認後由旅人說出只改箭頭而回到窄帶，牛頓把兩次比較並列。
3. **綜合斷言**：「把兩次比較合起來：要讓軌道留在原半徑窄帶，原本速度和朝地心箭頭長度之間必須有什麼關係？」只有第二段人物對話由玩家收掉後才開放。

資料數值只在表格出現一次；第一問、第二問與總結區只顯問題、短摘要、確認／重選與斷言，不再重抄資料卡。兩問都使用 checkbox＋確認時數量驗證；沒有任何紙因接近正解而預先失效。

第二問新增獨立 UI-only `yieldToken`。它同時綁定 embed 與當前三紙鏈；錯 token、舊 embed、重選後遲到的 token 都不能開綜合斷言。人物對話框缺失時 fail closed。兩層選紙與對話確認仍只存在 `orbit4ClaimDraft`，不寫 engine／save；`assertK1`、物理 fixture、schema、sanitizer、migration 與既有證據格式維持不變。
