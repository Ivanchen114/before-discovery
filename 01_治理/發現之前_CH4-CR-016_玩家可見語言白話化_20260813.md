# 發現之前｜CH4-CR-016｜玩家可見語言白話化

**日期**：2026-08-13
**狀態**：IMPLEMENTED／AUTOMATED CONFORMANCE PASS
**上游**：GB-ADR-005、GB-ADR-050、《互動敘事總綱》、《角色聲線與情感弧線設計》、《跨章角色聲線與章間呼吸設計》
**總監授權**：總監實玩第四章後指出「封口、作保、猜中猜偏」等詞抽象且不自然，要求對照前三章後直接修改。

## 一、問題

第四章的物理任務本身清楚，但玩家可見文字同時疊用三套比喻：封蠟（封口、封存）、法庭（作保、聽證、資格）與帳房（過帳、對帳、借條）。同一句若同時出現兩套以上比喻，玩家必須先把修辭翻譯成操作，才知道自己要「先寫預測、再看資料、最後比較」。這種負擔不是物理推理，也不是戲劇張力。

前三章的主要語氣較接近日常動作：看、量、寫、拿紙來比、讓船或數據回答。第四章應保留自身的出版與帳本物質感，但把抽象延伸收回到看得見的物件與動作。

## 二、語言規則

1. **先寫玩家眼前能做的事。**優先使用「寫下預測、封好紙、拆開資料、核對數字、比較兩套說法」。
2. **物件可留，抽象轉喻刪除。**實際蠟封可寫「蠟封／封好／拆封」；不得把整個預測、資料或程序統稱為「封口」。
3. **結果直說。**「猜中／猜偏」改為「預測對上／沒有對上」；「替天空作保」改為「代表／支持／證明到什麼範圍」。
4. **一次只用一套比喻。**K4 的帳本、章與實體借條是玩家看得見且親手操作的章節母題，可以保留；在它們正式出場前，或不涉及帳本時，不用「過帳／開帳／整桌帳作廢」代替「核對／開始比較／比較不公平」。
5. **術語必須先由白話托住。**「事前預測」「殘差」「模型」等必要概念可保留；「盲驗」「聽證」「判讀留痕」等非必要標籤改成玩家當下要做的事。
6. **角色仍是人，不是介面說明。**牛頓短、冷、精確；哈雷用信件、資料、印刷期限和公開責任推動行動，但不代替系統朗讀規則。

## 三、代表性替換

| AS-IS | TO-BE 原則 |
|---|---|
| 觀測仍在封口裡 | 觀測資料還封著 |
| 封口在先，觀測在後 | 先把預測寫下來，再拆開觀測資料核對 |
| 直覺可以猜中，也可以猜偏 | 直覺偶爾也會對上，但不能只靠碰巧 |
| 還不能替整片天空作保 | 還不能代表整片天空 |
| 哪一條才構成盲驗 | 哪一種做法真的先預測、後核對 |
| 聽證第 1 步 | 第 1 步｜先定下怎麼比才公平 |
| 把彗星過帳 | 核對彗星資料 |
| 判讀留痕 | 寫下判斷 |

## 五、驗收

1. CH4 active 場景、工作台、筆記、證據 caption 中不再以「封口／猜中／猜偏／作保／聽證／盲驗／判讀留痕／過帳／開印窗口」作為玩家必須翻譯的操作語。
2. 實際蠟封與拆封仍清楚可見；K4 的「對帳／拉力帳／漩渦帳／借條」只在帳本物件已出場後使用，且首次指令先以白話說明用途。
3. 截圖所在 D3-1 段能直接讀出因果：先寫預測 → 封好 → 拆資料 → 核對 → 火星與木星對上，但證據範圍仍有限。
