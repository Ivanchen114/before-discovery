# CH4-CR-018｜哈雷來訪後：對話式科學高潮與出版收束

- 日期：2026-08-14
- 狀態：`IMPLEMENTED / AUTOMATED CONFORMANCE PASS / DIRECTOR PLAYTEST PENDING`（總監於實玩後明確授權第四章後半整體重構；2026-08-14 已完成最終試玩候選）
- 範圍：D4-1「兩套說法，同看三份資料」至 D4-2「印刷台」
- 原則：保留玩家判斷與可追溯後果，移除同屏資訊牆與例行總複習；牛頓、哈雷、旅人共同做事，而非工作台代替戲劇。

## 一、AS-IS 問題

1. K4 引擎雖逐列開放，畫面同時顯示三列、兩套模型、完成表與「借條」，玩家仍像在填審核表。
2. 正確蓋章多由綠色提示結束，牛頓與哈雷只在錯誤時出現；玩家做了判斷，人物沒有接住。
3. 「借條」未先由具體動作定義，玩家必須先猜作者隱喻，才有資格理解事後補假設的代價。
4. K5 把已取得的五份證據、四種功勞、作者欄與出版窗口全部做成必填工作台；球殼定理反而在進工作台前由牛頓直接講完，沒有第二個發現高潮。
5. 後半最重要的物理命題被出版管理稀釋：同一套平方反比規則能否不逐案改參數，跨過月亮、行星與彗星；以及為什麼球形天體可以從球心量距離。

## 二、TO-BE 戲劇骨架

### 2.1 K4：三次小揭曉，最後一次尤里卡

固定順序為月亮 → 行星 → 彗星；一次只顯示一份資料、一道判斷。

1. 月亮：平方反比交出可核對數字；簡化渦旋只有定性說法。牛頓不宣判渦旋「錯」，哈雷指出「沒有數字」只代表這輪無法檢驗。
2. 行星：同一距離律跨過火星與木星；固定流速簡化模型推得 6.4 年，觀測為 11.86 年。玩家可事後補「木星那層另有流速」，但補充紙永久留下。
3. 彗星：高傾角逆行路徑與固定流面／流向衝突；玩家可補「彗星能穿流」，同樣必須標成未獨立量過的事後補充。
4. 旅人最後自己說出有限結論：比較的不是哪個故事比較順耳，而是哪套固定規則不等看完結果就能跨過三份資料。仍不得聲稱所有渦旋模型都錯，也不得聲稱已解釋引力如何隔空作用。

「借條」只在第一次以可見物件定義：看過結果後才新增的假設，另寫在黃色補充紙上，不能擦掉原結果；桌上俗稱「借條」。後續玩家層一律稱「補充紙／事後補充假設」。

### 2.2 K5：球殼定理成為第二高潮，出版降為尾聲

1. 牛頓與旅人先共同攤開已取得的五張證據，不再逐張考玩家一次。
2. 版框只留下「憑什麼從地心量？」。牛頓提出球殼內一點的近側與遠側難題，玩家判斷：近側較近但涵蓋面積較小；遠側較遠但涵蓋面積較大，對應細錐中的作用恰能抵消。
3. 玩家答對後，牛頓完成外部球殼與同心薄殼相加的數學橋；玩家親手把球殼頁放入第六格。這一拍補回二十年前的假設。
4. 虎克貢獻範圍保留為一個真正有爭點的判斷；四人功勞改成一次完整分工方案，不再四次輪流填名。
5. 旅人退出作者欄、選擇證明邊界、親手送印仍保留。這些是短出版尾聲，不再壓過物理高潮。

## 三、角色分工

- 旅人：操作、蓋章、選擇是否留下事後補充、說出有限結論、解球殼幾何、決定出版邊界。
- 牛頓：交出計算、承認機制仍未知、在玩家判斷後完成數學推導；他不是答案播報器。
- 哈雷：維持公平程序、保留錯誤與補充紙、把玩家每次判斷接回下一個更難的問題。

每個關鍵循環必為：`玩家操作 → 引擎留痕 → 人物回應 → 下一問解鎖`。純 UI 自報不得冒充操作。
