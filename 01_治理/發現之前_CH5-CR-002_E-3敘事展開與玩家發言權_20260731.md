## 一、試玩病灶

第五章原 runtime 共 12 場，但只有約 20 個角色台詞節點；四場為 `embed + goto` 空殼。玩家只在工作台與辯論操作，缺少「為何做下一步」與「由誰公開承擔主張」的戲劇支付。

## 二、DESIGN GATE：PASS

本批逐場依 Claude E-3 展開稿施工，不自行改寫物理結論。三名角色的動機分別為：

- 杜夏特萊要讓《原理》在法文裡也能算，並查明碰撞留下的缺口。
- 杜佩院士守住三十年沒有出錯的動量帳；他的帳是真的，但不是唯一能記的帳。
- 旅人知道未來答案，卻只能用當下桌上的資料公開說話。

## 三、玩家發言與認知支付

主線配置十個 choice 節點，含既有問句選擇。新增選擇只負責四類支付：

1. 關係與自我揭露。
2. 調查順序。
3. 主張範圍。
4. 公開承諾。

純敘事選擇只寫入章內旗標，不新增證據、信譽或物理結果。`E2-3/c_scale` 的兩個過度宣稱會回到同一選擇，只有「這把尺只量到油灰」能留下範圍承諾。

## 四、相容與不變量

- 既有 scene id 與 node id 全數保留。
- `E2-3/n1` 保留為 `legacyOnly`，新主線改走 `n1a`，舊存檔游標仍可讀。
- J1–J4 證據 id、J4 的信譽事件、工作台判定、辯論資料與存檔 schema 不變。
- 新增心聲全部帶 CR-031 白名單內的 `osPurpose`。
- 1740 年可見資料只寫「兩顆球摸起來的溫度」，不宣稱短少已被證明變成熱。

## 五、敘事接縫

四個原空殼場都補上人物動機與行動：

- 第一輪前由玩家選擇碰撞順序。
- 第二輪前由杜夏特萊要求重用同一批六張紀錄，避免換資料才得到想要的結果。
- 黏土輪由玩家限定尺的適用範圍。
- 辯論前明示目標不是擊敗院士，而是讓兩本帳都留在桌上。

斷言與辯論成功後均有角色接住玩家成果，不以系統提示代替人物反應。

## 六、驗收

- 主線 choice 恰為 10 個。
- 主線不存在只有 `embed + goto` 的空殼場。
- 所有活躍心聲具合法 `osPurpose`。
- 活躍節點不得指向 `legacyOnly` 節點。
- 過度宣稱不寫入 `ch5ScaleBoundary`，縮限主張才寫入。
- 第五章黃金路徑取得 J1–J4、完成辯論、回顧與史實頁。
- 全套 runtime 測試必須全綠。
