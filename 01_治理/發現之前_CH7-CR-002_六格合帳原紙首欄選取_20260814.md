# 發現之前｜CH7-CR-002｜六格合帳原紙首欄選取

**狀態**：APPROVED／IMPLEMENTED／AUTOMATED CONFORMANCE PASS
**上游**：《工作台與辯論架構・一二章實證規格》§4-1、CH7-CR-001
**總監授權**：總監要求各章真正的「選數據」介面對齊第一章，不在題目下重複一組原紙卡。

## 問題與定案

第七章合帳頁原本把六張原紙各做成卡片與「把這張原紙放回同一頁」按鈕。現改為單一表格：六張原紙各占一列，第一欄 checkbox；玩家可勾選尚在場的紙，再以一個按鈕歸回合帳頁。

已歸頁的列保持勾選並停用；尚未取得或已被收走的紙不可選。確認時依 `MATRIX_KEYS` 的既定順序逐張送入，並跳過已歸頁的紙，避免重複追加 `board-placement` 留痕。

## 施工與保護線

選取存在 `em1BoardDraft`，不進存檔。每張正式歸頁仍呼叫既有 `placeMatrixTrace`；六張全齊後仍須玩家另按 `sealMatrixBoard`。engine7、matrix trace、withheld 後果、schema、sanitizer、場景與最終判讀不變。

## 驗收

1. 六張資料只在一張表出現一次；首欄有完整 `aria-label`。
2. 未勾紙不得送出；已歸頁、未取得與被收走的紙不得重送。
3. 批次確認只追加尚未歸頁的 trace，順序固定且失敗時不提交部分 UI state。
4. 未滿六張不能封存；既有 CH7 全章測試與存檔負向契約維持綠燈。

- 批次確認依 `MATRIX_KEYS` 順序處理且跳過已歸頁紙；`placeMatrixTrace`、`sealMatrixBoard`、engine7、schema、sanitizer 與場景零修改。
