## 先修一個接口缺口

現行 `stage-ui.js` 已讀 `speakerDialoguePortrait[speaker]`，但它只能做到「每位角色固定一張」。正式圖有伽利略 26／39、辛普里奧 58／72，且同角色依場景要換表情；只補 `entries` 不足以使用這批圖。

請新增一層純表現映射，名稱可自選，建議：

```js
sceneDialoguePortrait[sceneId][speaker] -> assetId
speakerDialoguePortrait[speaker]       -> default assetId
speakerPortrait[speaker]               -> old notebook fallback
```

解析優先序：場景覆寫 → 對話預設 → 舊筆記頭像。`stage-ui.js` 已有 `curSceneId`，不必碰引擎或存檔；`chapter.html` 灰盒殼可維持原狀。

## 驗收

1. `assets.js`／`assets.json` 鏡像一致；不使用 `git add -A`。
2. `npm test` 全綠；新增契約：所有 scene/portrait map 指向存在 entry；所有有 path entry 對應檔案存在。
3. 1280×720：肖像高 170–220 CSS px，人物頭頂不被切，對話至少保有約 3 行。
4. 844×390 橫屏：肖像高 110–150 px，不蓋姓名、本文、選項與下一頁提示。
5. 200% 字級：筆記內容仍可捲動／分頁，背景不影響文字對比。
6. 旅人台詞維持第一人稱：不換上玩家肖像，只把當前對手壓暗；若啟用剪影 A/B，必須能一鍵撤回。旁白／system 不強制換掉當前對手肖像。
7. 年代檢查：1590 不得出現 39 歲伽利略或 72 歲辛普里奧；1603/1604 不得回用青年肖像。
