# NARRATIVE-CR-035｜第四章共同計算與 K2 真實幾何

**日期**：2026-08-05
**狀態**：active／2026-08-05 總監畫面驗收再校正；取代 GB-ADR-039 的 K2 發現順序與固定數值來源，沿用其雙紙、錯誤留痕與無 schema 升版邊界
**範圍**：`D1-1`、`D1-2`、K2 引擎／UI／匯入相容、可見重建標示

## 一、總監裁決

採單場教學重建案。物理與敘事兩層一起修：K2 必須從天文距離、地球半徑與月球週期真正算出一秒正矢；`60 秒` 只在玩家完成 `60R ↔ 約3600` 連結後，用來放大極小偏折，不再冒充發現起點。新局不再先猜尚未算過的月球量級；第一個玩家承諾改為指認「弧長」或「兩端點之間朝地球的正矢」，由這個程序判斷開啟共同計算。

## 二、完整節點與認知順序

1. `D1-1/n1–c1`：牛頓提供觀測弧段與「拿掉拉扯」問題；玩家封存切線預測。
2. `D1-1/ok1–ok2`：旅人畫切線；同時顯示同一秒後的實際月球端點。旅人指出兩端點之間、朝地球的差距就是向內偏折，牛頓以幾何圖核對。
3. `D1-2/n1–n8`：場內明載現代教學重建；地表紙與月球天文紙分開。牛頓提供地表一秒估算；月球紙只提供 `60R` 與 `27.3 日`，不得烤入一秒答案。
4. K2 主工作台：旅人先指出應量哪一段，牛頓依週期與月距重算；以正矢 `r(1-cos θ)`（或等價半角式）從 fixture 計算一秒偏折約 `1.36 mm`。三角函數只在可略過選讀層；主線呈現切線端點、實際端點與弓高幾何，不另插入量級猜題。
5. 玩家比較 `4.9 m` 與 `1.36 mm`，判為約 `3600`；再把月距 `60R` 與倍率配對，親手決定是 `60×60`。
6. 旅人先接出 `60×60`。牛頓獨立重算比值與平方，再把「月距約為六十個地球半徑」與「月球一秒偏折約為地表一秒落距的三千六百分之一」明確接起來，並說這還不是證明。
7. 成功後才顯示 `1.36 mm × 60² ≈ 4.88 m`，說明六十秒只是視覺放大尺。
8. `D1-2/n13` 以火星、木星與彗星提出下一個未決問題；地心等效問題照舊保留。

## 三、fixture、算法與有效位數

- `earthRadiusKm = 6371`
- `moonDistanceEarthRadii = 60`
- `moonPeriodDays = 27.3`
- `surfaceOneSecondFallM = 4.9`
- 一秒正矢約 `1.356 mm`，顯示 `1.36 mm`
- 六十秒正矢約 `4.882 m`，顯示 `4.88 m` 或「約 4.9 m」
- `4.9 m ÷ 1.356 mm ≈ 3613`，判讀與文案只能說「約 3600」

引擎不得直接保存或引用 `moonSixtySecondSagM: 4.9` 作為答案。比率判定使用由 fixture 推得的期望值與公開容差，不硬吃 `value === 3600`。

## 四、存檔與歷史邊界

- schema 維持 2。舊存檔中的 `moonOneSecondSagMm = 1.4` 與既有完成旗標，在能由可信 action log／K2 完成狀態重建時正規化為新精度，不阻斷進度。
- 舊存檔既有 `scalePrediction`／`predictionAttempts` 只作歷史相容；新局的 `convertMoonTime` 不再要求量級封紙，新 UI 也不得自動或隱藏代替玩家封存。第一個可見 action 是正矢／弧長判讀，仍寫入 `conversionAttempts`，所以不需升 schema。
- 對玩家可見的兩張來源紙皆標「教學重建」；場景系統說明保留。`historyTag` 不是唯一告知方式。
- 生成影像不得承載精確數字、公式或判決；人物、紙張與光線可由 raster 承擔，物理圖線由 SVG／HTML 繪製。
- 舊 K2 烤字重建圖不再作主推理答案；若保留檔案，只能作歷史資產，不得在新主線揭題前顯示。

## 五、驗收

1. 改變週期或月距 fixture 時，一秒與六十秒正矢會隨之改變；不得仍固定 1.4 mm／4.9 m。
2. 玩家未完成一秒比較與 `60R ↔ 約3600` 配對前，UI、旁白、NPC 與成功訊息不得出現 `60×60` 或距離平方結論。
3. 舊完成存檔可載入；偽造 K2 或未知精度值仍被拒絕。
4. K1／K2 可交換順序、正矢錯讀留痕、舊量級封紙相容、觸控尺寸與重建標示照舊通過。
5. 桌機與 844×390 人工確認：切線—實際端點—正矢看得懂，差距箭確實接在兩端點之間；選讀可略過，合作場景圖不遮操作。
6. K2 右頁維持章內同一種米白紙面；藍、金、綠只可作邊線與狀態提示，不得把幾何圖、步驟卡或完成卡改成灰黑色面板。
