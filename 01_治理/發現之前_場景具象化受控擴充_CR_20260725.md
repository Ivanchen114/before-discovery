# CR｜場景具象化受控擴充（lineFocusVisual 放寬）

**日期**：2026-07-25
**提案**：Claude（劇本／程式線）
**授權**：待總監裁決；核准後交 Sol 施工，落地時由 Sol 轉為 GB-ADR
**範圍**：第一至第四章
**一句話**：把「對話提到想像或具體的東西時，畫面跳一張圖」做成 GB-ADR-017 `lineFocusVisual` 的**受控擴充**，不是新系統。

---

## 一、定位與理由

總監構想：遊戲對話／敘事提到某個想像或具體的東西時，讓畫面跳出一張圖具象化，讓場景更豐富。

- **本質**：`lineFocusVisual`（GB-ADR-017）本來就是「角色實際拿起／指向／比較某圖像或器材時自動入鏡，同場景保留、換場清除」。本 CR 只把**觸發範圍**謹慎放寬到：具名的具體物件／場所／信件、章末 payoff 鏡頭、以及**明確標為預測的思想實驗（只畫預測、不畫結果）**。機制、程式路徑、fallback 全部沿用，不新造系統。
- **為何走 CR**：綁定第一至第三章**凍結劇本**台詞的新規則＝更動凍結基線，依鐵律「先文件後程式」。第四章劇本未凍結，列為一般增補。
- **成本**：資料驅動。加一筆 `assets.json` 條目（可先 `path=null`）＋一條 `lineFocusVisual` 規則即生效，程式零改動；圖未到時 UI 全面 fallback，灰盒不變、不跳空圖。

## 二、三條紅線（不可交易）

1. **承載物理的一律不畫成圖**：數據、幾何、軌道、力向量、光路、圖表、以及「哪個預測才對」一律 HTML/SVG；點陣圖只當材質與氛圍底，**絕不洩漏玩家該自己推出的答案**（設計原則 15、GB-ADR-019）。
2. **綁真正看到該句的時刻**：以台詞子字串 `match` 觸發，不在事件排隊時搶跑（原則 46）；未建圖一律 `path=null`，UI fallback、不跳空圖。
3. **憲章四**：只對「史料／器材／道具／場所／明確標為預測的思想實驗」開放；思想實驗**只畫預測、不畫結果**（比照船桅特寫不畫落點、第四章 D1-1「無作用預測紙」）；`caption` 沿用劇本既有的史實邊界字樣。

## 五、明確不要做（會洩答或畫蛇添足）

- **第一章**：A1-1「輕的反而搶先」、高塔落地 — 運動／數據語意，且易畫錯物理踩憲章四。A2-3 想像的大部頭 — 純喜劇節拍，具象化削弱笑點。
- **第二章**：B2-1「倒掛的鏈子」 — 本章刻意尚未命名「拋物線」，懸鏈≠拋物線，畫出恐誤導或提前洩形。
- **第三章**：C2-3 雙紙帶做成點陣圖 — 直接違原則 15，等於把 G4 參考系謎底畫出來（現為程式 SVG，維持）。奔馬比喻 — 會強化錯誤直覺，除非明標「艦長的錯想法」（比照砲術圖是反方的圖）。
- **第四章**：彗星入向／出向星圖接合（洩「同一顆非兩顆」）、字盒碰撞結果（洩第五章動量／活力謎底，只可畫兩本並排的帳＝開放問句）、倍率天平／60 秒落點（洩 ÷3600）、繩球鬆手切線飛出（K1 鎖定前先講切線答案）。這些全屬 `embed system:"orbit"` 程式原生盤，維持 HTML/SVG。

## 六、旗艦項完整施工規格：第一章 E-2 月球鎚羽

給 Sol 可直接照做（ch1 美術已解凍，可一路做到真圖）：

**(1) 資產（`greybox/data/assets.json` 加一筆）**
```
{
  "id": "ch01_focus_moon_hammer_feather_v01",
  "label": "E-2 月球鎚羽（阿波羅 15 致敬伽利略・章末史實尾鏡）",
  "path": null,                       // ch1 已解凍，可直接轉真圖填上；未填則走 fallback
  "w": 2560, "h": 1440,               // 敘事 CG 母版長邊 ≥2560，出 WebP
  "sourceMaster": "art/source/production/ch01/transitions/ch01_focus_moon_hammer_feather_master_v01.png"
}
```
runtime 路徑建議 `ch01/transitions/ch01_focus_moon_hammer_feather_v01.webp`。
**美術內容**：灰塵原、黑天、白甲太空人左手一柄鎚、右手一根羽毛，同時放手，鎚與羽並肩觸地。**畫面內不得出現任何數據、箭頭、公式或文字**；寫實歷史插畫，對齊 Style Lock。

**(2) 規則（第一章 scenes 資料，`lineFocusVisual` 加一筆）**
```
{
  "scene": "E-2",                     // 章末尾鏡場景鍵，Sol 以 scenes.js 實際鍵為準
  "match": "灰色的塵原",               // 影像浮現那句（劇本正文「灰色的塵原。黑色的天。」）
  "items": [{ "asset": "ch01_focus_moon_hammer_feather_v01",
              "alt": "月面上，太空人左手鎚、右手羽毛同時放手，並肩落地" }],
  "caption": "1971，阿波羅 15 號，亞平寧山麓；向比薩人致敬（其公開說詞意譯）。"
}
```
- `match` 用「灰色的塵原」＝影像浮現時入鏡；劇本後句「鎚羽影像消失」隨換場自動 `clearFocusVisual`。
- **不得覆寫既有 E-1 運河弧線 focus**（下一頁石子弧仍從紙背透出）。

**(3) 邊界**：E-2 是全章解謎結束後的致敬鏡頭，零洩答；`caption` 史實字樣沿用劇本史實頁「1971 阿波羅 15 號，D. Scott 的鎚子與羽毛；『向比薩人致敬』為其公開說詞意譯」。憲章四：明標 1971 致敬，非 1590 當場完成。

## 七、驗收（Sol 實作後）

- **path=null 期**：灰盒不跳空圖、既有測試不變；填 path 後該句入鏡、換場清除。
- **新規則**：進資料雙載體（`.js`/`.json` 深等）＋ `match` 觸發契約＋不搶跑既有 focus。
- **凍結章（一至三章）**：綁凍結台詞的規則以本 CR 為法源；ch2/ch3 未建資產一律 path=null 先行，待美術解凍。
- **第四章**：新增資產走一般增補；D2-1／D0-2 若採納，須通過「幾何 HTML/SVG＋思想實驗不畫結果」檢查。
