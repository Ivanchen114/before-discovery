## 本夾規則

1. **結論被收編即歸檔**。前期思考稿的結論一旦被裁決紀錄／CR／更高階文件吸收，原稿即移 `archive/`（勿引用）。
2. **同名版號必須連資料夾與作者一起寫**。
   ⚠ 現存衝突：`02_設計/第三章完整劇本架構_**v0.5**_Sol` 與 `04_劇本/第三章劇本_**v0.5**_辯論終局_Claude`——**同日、同版號、不同文件**。
3. **本夾是設計層，不是法源層的全部**。凍結規格在 `03_規格/`，變更紀錄在 `01_治理/`，審查在 `05_審核/`，劇本在 `04_劇本/`。
4. **canonical 依真相模式決定**：AS-IS 以 runtime 現況為主；TO-BE 以指定的核准
   劇本、CR 或規格為主；CONFORMANCE 同時固定目標與成品，任何一方都不得越權
   取代另一方。
