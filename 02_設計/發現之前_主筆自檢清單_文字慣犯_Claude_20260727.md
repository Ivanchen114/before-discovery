# 主筆自檢清單:我的文字慣犯(Claude 自陳,2026-07-27)

**性質**:自我診斷。總監一日內連抓十餘處同型問題,以下是根因與可機械檢查的清單。**寫任何台詞前先過一遍,交稿前再過一遍。**
**用法**:每條都給「症狀→為什麼我會犯→怎麼檢查」。檢查欄是可以拿去 grep 或朗讀驗證的動作,不是心法。

---

## 一、根因:我在寫「規格」,不是在寫「人說話」

工作流是「設計定案 → 節點級台詞稿 → 轉 runtime」。寫節點時我腦中是資料結構(一節點=一功能),所以句子自動壓縮成最短的功能句;寫得越熟練,壓得越乾。**產出因此資訊完整、場面不完整。**四個症狀(第四章「好乾」、「突然進工作坊」、「合不合怎麼知道」、第三章「什麼抽屜」)全部同源。

---

## 二、七個慣犯

### 1. 把「證據邊界」寫成短促的詩
- **症狀**:「兩張紙才會相認」「它只回答了月亮」——每次要講「這條證據管到哪」,我就寫成四到六字的漂亮句。
- **為什麼**:邊界是本作的核心價值,我下意識想給它金句待遇。
- **檢查**:凡出現「只/才/不過是」+抽象受詞的短句,一律改寫成「**誰、量過什麼、還沒量什麼**」。

### 2. 擬人化代替因果
- **症狀**:紙會「相認」「回答」、資料會「說話」、證據會「站住」。
- **為什麼**:擬人省字又有溫度。
- **檢查**:grep「相認/說話/回答/站住/替它作證」——主詞若是物,重寫成人做了什麼、數字是多少。(例外:角色刻意的比喻,且下一句有人接住。)

### 3. 規格詞漏進角色嘴裡
- **症狀**:「未揭露資料」「允許帶內」「適用範圍」「解析度」「在……條件下」。
- **為什麼**:同一份腦袋同時寫規格與台詞,詞彙互相污染。
- **檢查**:規格詞黑名單(見 05_審核 白話化原則檔),台詞層零容忍;內部模型名(「簡單共轉渦旋」)只准進史實頁。

### 4. 旅人講話像古人
- **症狀**:旅人一開口就變成冷靜精準的答題機:「所以蘋果和月亮,是同一件事。」
- **為什麼**:我把「克制」誤讀成「精簡」。克制是**不爆雷**,不是不把話講完。
- **檢查**:旅人每句都問「一個現代人會這樣講嗎」;單詞斷句、文言縮寫一律展開。**古人可以短,旅人不行**(原則 66-bis)。

### 5. 金句成癖與對仗上癮
- **症狀**:「不是補在紙上,是補在我說出口的話裡」——排比、對仗、三段式,一場出現好幾次。
- **為什麼**:對仗讀起來有力,寫起來也快。
- **檢查**:每場至多一句對仗;辛普里奧豁免(修辭學辯士=職業病)。其餘拆成人話。

### 6. 角色只講自己的功能句
- **症狀**:六個角色像六個 UI 元件,依序報完各自的欄位。
- **為什麼**:節點設計時我是按「資訊點」分配台詞,不是按「人」。
- **檢查**:每場問「誰回應了誰」;至少一次角色對別人的工作有反應(戲劇完整度四律・原則 65)。

### 7-bis. 跨章引用他章證據時,不回頭讀那一章的 canonical(2026-07-28 新增,A 級事故)
- **症狀**:第四章把「一秒落下 4.9 公尺」寫成「旅人的第一章證據」。第一章 canonical 白紙黑字:「斜面沒有直接量到垂直落下」——而且那正是第一章高潮辛普里奧逼問「垂直,你量過嗎?」、玩家必須誠實說「沒有」的那一課。**我把玩家親口承認沒量到的數字,當成他的證據發給他。**
- **為什麼**:寫新章時憑印象引用舊章;教學換算值(4.9)在我腦中與「第一章落體」黏在一起。
- **檢查**:凡台詞出現「你的第 N 章證據」「你量過的」,**一律回去 grep 那一章的 `scenes*.json`**,確認該數值/該說法真的在玩家手上;跨章投影的限制條款(如 `vertical-not-directly-measured`)要一起帶過來。

### 7. 沒查證就寫「課本說」「大家都知道」
- **症狀**:「課本裡他只有一小段」(伽桑狄)——聽起來合理,查了才知道台灣教材根本沒有他。
- **為什麼**:寫得順手時,把常識感當成事實。
- **檢查**:凡宣稱外部事實(課本、教科書、大家都、史上第一),一律查證或改成不確定語氣。

## 三、交稿前的六道機械檢查

1. **朗讀**:每句念出口。卡牙齒=改。
2. **黑名單 grep**:規格詞、內部模型名、擬人化動詞。
3. **旅人句掃描**:他的每一句話,一個現代人會這樣講嗎?
4. **對仗計數**:每場 ≤1。
5. **「誰回應了誰」**:每場至少一次角色互動,不是各報各的。
6. **事實宣稱標記**:外部事實有沒有查證?未查證的改語氣或刪。
