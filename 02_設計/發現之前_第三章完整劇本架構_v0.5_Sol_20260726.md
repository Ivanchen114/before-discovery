# 一、案件核心

## 1. 一句話案件

> 船已經向前走，桅杆上的石頭一鬆手，為什麼沒有被船丟在後面？

## 2. 戲劇衝突

艦長不是反科學，也不是故意阻撓。他有三個合理理由不信：

1. 他親眼看過石頭落在桅後，而且留下了一張舊紙。
2. 學者借他的船，若結果含糊，最後承擔名聲的是他。
3. 他知道真船有風、手推、搖晃、加減速；一次漂亮落點不足以讓他改口。

因此，他同意借船，但立下條件：

> **「船和人借你們。我不登船，也不碰你們的紙。回來以後，當著碼頭上願意聽的人，用原始紀錄告訴我：我那一筆究竟代表什麼。結果沒說到的地方，別拿我的名字補上去。」**

艦長刻意留在岸上有三個功能：

- 他沒有在實驗途中被慢慢說服，終局仍是真正的對手。
- 玩家不能以「你自己也看見了」跳過證據。
- 船員留下的紀錄成為獨立見證，而不是學者自說自話。

## 3. 玩家在這一章真正要證明什麼

玩家不是直接證明地球在動，也不是建立完整的現代慣性定律。玩家要建立三層有限結論：

1. **近似直線穩速時**，石頭鬆手後仍保留原先與船共有的前行，因此相對船落在桅腳附近。
2. **船速改變時**，相對落點會出現方向性的偏移：加速偏後、減速偏前。
3. 岸上看見向前彎曲、船上看見近乎直落，是同一事件相對不同參考物的兩份正確紀錄。

最後只能說：

> **這組實驗排除了「地球若運動，落石必落後」這項反對；它沒有單獨證明地球正在運動。**

# 二、角色重新分工

| 角色 | 戲劇功能 | 實驗中的工作 | 聲線與限制 |
|---|---|---|---|
| 旅人（玩家） | 認知主體 | 設計、預測、判讀、辯論 | 知道方向，但不能拿未來答案代替當時證據 |
| 伽桑狄 | 同行研究者 | 把問題拆成可驗條件；在船上核對卷宗 | 短、冷靜；只問「這張紙能說到哪裡」 |
| 艦長 | 出題者、終局對手 | **不登船、不操作、不記錄** | 務實；接受哪一點就明說哪一點，不突然投降 |
| 舵手 | 船況執行者 | 依封存方案維持穩速、加速或減速 | 不下物理結論 |
| 馬蒂厄 | 獨立操作員 | 依固定訊號抽門閂；保存原始船上紙 | 只報哪一拍放手、原紙在哪裡 |
| 水手 | 計時 | 固定間隔敲鼓 | 不判讀船速 |
| 艾蒂安 | 岸上觀測員 | 每一聲鼓記船與桅杆相對岸標的位置 | 只報間距變化，不替玩家解釋 |
| 港口官員 | 結論誘惑 | 無 | 要一句能印在告示上的大標題，不是反派 |
| 碼頭群眾 | 公開壓力 | 無 | 只提出生活化追問，不各自成為一根支柱 |

### 分工原則

玩家不需要替五個人逐格選職位。只要玩家選定實驗方案，伽桑狄便依需要安排人手；畫面用一張簡單配置圖交代誰在哪裡。

真正的設計判斷是：

- 改什麼？
- 哪些條件不能一起改？
- 沒有哪一張紀錄，就回答不了原來的問題？

# 三、全章知識與證據

## 1. 三個待建立觀念

| 觀念 ID | 玩家用語 | 現代整理詞僅供製作 |
|---|---|---|
| K1 | 鬆手不會把石頭原先與船共有的前行抹掉 | 共同運動／慣性前行 |
| K2 | 「船正在向前」與「船速正在改變」不是同一件事 | 勻速與加速度區分 |
| K3 | 軌跡怎麼寫，取決於拿誰當不動的尺 | 參考系／座標轉換 |

## 2. 六份終局證據

證據名稱刻意採中性描述，不在卡名上直接寫答案。

| 證據 ID | 玩家看到的名稱 | 內容 | 能支持 | 不能支持 |
|---|---|---|---|---|
| E1 | 穩速三次落點 | 同石、同高、門閂放手；岸標確認近似穩速；三回皆集中桅腳附近 | 排除手推、一次巧合與船速未穩；反駁「只要船向前就必定落後」 | 單獨排除甲板風的影響；宣稱每次完全同點 |
| E2 | 兩次封窗紀錄 | 一次停船、一次近似穩速；同一顆小石由艙梁門閂放下，另做直上拋接；兩次結果近乎相同；岸上封條事後揭示船況 | 沒有甲板風時，普通局部機械現象仍不一定能分出停船與近似穩速 | 任何內部實驗永遠測不到運動、加速或旋轉 |
| E3 | 三種船況落點圖 | 加速偏後、穩速近桅腳、減速偏前；其他條件一致 | 相對偏移跟船速變化有系統關係 | 石頭受到一股維持前進的隱形力 |
| E4 | 艦長的舊紙 | 「解纜後第一段，落在桅後」；沒有當趟船速、放手方式、重複次數 | 舊觀察可能真實；圖樣與加速組相似 | 反向證明舊航次一定在加速；代表所有向前船況 |
| E5 | 同號鼓點原紙 | 岸上與船上兩張原紙，共用 0–3 號鼓點；記錄同一顆石頭 | 兩張紙記的是同一事件與同一時刻 | 單靠紙張外觀說明兩條路徑為何不同 |
| E6 | 逐拍移動的透明尺 | 每一拍把桅杆當作 0，計算／操作 `石頭位置－桅杆當拍位置`；岸上彎線轉成船上近乎直落 | 兩份軌跡可由改變參考物互相轉換 | 只要旋轉紙張或平移一次就能完成轉換 |

## 3. 證據取得順序

順序不是「把六張卡撿齊」，而是每一輪新證據回答上一輪留下的合理疑問：

1. **舊紙只知道落後，不知道船況。**
2. 做穩速落石後，得到桅腳附近落點；但仍有人可質疑甲板風。
3. 關上艙窗比較停船與穩速：沒有甲板風，同一顆小石由門閂放下、軟球直上拋接，仍近乎落回原處。玩家因此只能說風不是保留共同前行的必要解釋，不能說風在所有戶外落石中毫無作用。
4. 比較加速、穩速、減速，才解釋「為何有時落後、有時不落後」。
5. 同一顆石頭留下岸上／船上兩張紙，玩家親手把其中一張換成另一張。

## 序幕｜一本書欠下的實驗

### C0-1｜紙頁走了三十年

**地點／時間**：1609 帕多瓦 → 1632《對話》出版 → 1640 馬賽  
**功能**：承接第二章「沒有東西繼續推，球為什麼仍向前」，交代旅人不老與伽利略離場。

關鍵畫面：

- 第二章末頁的小白球仍向前。
- 1632 年，《對話》翻到第二日的船艙論證。
- 1640 年，伽桑狄在馬賽海風中按住書頁。

伽桑狄的立場：

> 「書上說得通。我想知道，真的船會不會照它說的走。」

本場不進工作台，只用一個短選項確認玩家知道案件尚未完成。

#### 選擇 C0-1.q1｜這一頁還欠什麼？

- A「一個更漂亮的說法。」
  - 伽桑狄：「說法已經夠多了。我缺的是一張別人能重做的紀錄。」
- B「一艘真的船，和不替書護短的紀錄。」✓
  - 伽桑狄：「正是。書先留在桌上，條件搬到船上。」
- C「一個能證明地球運動的標題。」
  - 伽桑狄：「那是結果出來以後也未必能說的話。」

**設計目的**：第一個選擇在章首約第 8–10 個節點出現；直接建立「思想實驗不等於證據」。

**地點**：馬賽港踏板旁  
**功能**：建立艦長的舊紙、動機、獨立性與終局約定。

場面：

- 艦長正在核對裝貨單，被伽桑狄的桅杆手勢打斷。
- 伽桑狄提出借船。
- 艦長拿出舊紙：「解纜後第一段，石頭落在桅後。」
- 伽桑狄說明，類似說法曾被用來反對地球運動；他只想先檢查這個反對放到船上是否站得住。
- 一旁的港口官員要在借船單上填用途，先寫下「落石試驗」，又問結果欄該填什麼。伽桑狄請他先留白；官員因此在終局再出現時，不會像突然被擺進來的誘惑路牌。

艦長：

> 「船和人借你們。我不登船，也不碰你們的紙。這是我的船，也是我的舊紀錄；我若在場，最後誰都能說我替自己作證。」

> 「回來以後，當著碼頭上願意聽的人告訴我：我那一筆究竟代表什麼。結果沒說到的地方，別拿我的名字補。」

艦長把封蠟交給馬蒂厄：

> 「每一趟的原紙，下船就封。明天以前，不必先來告訴我哪一邊贏。」

#### 選擇 C0-2.q1｜今天真正能回答哪一題？

- A「地球到底有沒有動。」
  - 伽桑狄：「船上的落石答不了整個天空。」
- B「穩定前進的船，是否必把石頭丟在後面。」✓
  - 艦長：「這題夠小，也正好咬住我的舊紙。」
- C「重石和輕石誰先落地。」
  - 伽桑狄：「那是上一頁的問題。今天要改的是船況。」

【系統】案件問題封存。這不是猜答案，而是限定證據的射程。

### C1-2｜設計單：只讓一件事改變

**唯一主實驗工作台**。玩家完成三個判斷，畫面同步生成實驗配置，不再另外填人員位置。

#### 選擇 C1-2.q1｜這組實驗要主動改變什麼？

- A 石頭重量
- B 放手高度
- C 船的運動狀態：穩速／加速／減速 ✓

錯答回應：

> 「改重量或高度，會回答另一個問題。艦長的主張差在船怎麼走。」

#### 選擇 C1-2.q2｜其他條件怎麼處理？

- A 每趟換不同石頭，讓結果更豐富
- B 同石、同高、同一門閂放手；每種情況自動重複三回 ✓
- C 交給不同水手用手放，取平均

錯答會生成一張可見的「不可判讀設計單」：

- 換石頭：標出「船況與石頭一起改，無法知道差異來自誰」。
- 手放：標出「放手同時可能多了一推」。

錯紙留在工作台角落；玩家修改一欄，不必整頁重來。

#### 選擇 C1-2.q3｜沒有哪組紀錄，就無法證明船真的走穩？

- A 只記最後落點
- B 固定節拍＋岸上每拍船位，並記落點相對桅腳 ✓
- C 由舵手事後回憶「我覺得已經走穩」

正解後自動分工：

- 舵手執行船況。
- 水手固定間隔敲鼓。
- 艾蒂安岸上記每拍船位。
- 馬蒂厄依訊號抽門閂、保存原紙。
- 伽桑狄記落點相對桅腳的位置。

伽桑狄：

> 「你只決定問題需要什麼。人站哪裡，由問題決定。」

【系統】實驗方案封存。之後若改設定，舊結果失效並要求重新封存。

### C1-3｜走穩再放

**功能**：第一次正式結果；一次動畫自動完成三回，不讓玩家連按三次。

航行條件：

- 近似穩速
- 同石、同高、門閂
- 三回
- 固定鼓點＋岸標

結果：

- 每拍岸標間距近乎相等。
- 三個落點集中在桅腳附近。
- 船仍明確向前。

#### 選擇 C1-3.q1｜這一組資料最直接排除了哪個說法？

- A「船其實沒有前進。」
  - 岸標紙直接反駁；但這不是完整結論。
- B「只要船向前，石頭就必定落在桅後。」✓
- C「風完全不會影響落石。」
  - 伽桑狄：「甲板上的風還在。這三回沒有資格替風說完。」

正解不立刻發完整證據。伽桑狄主動留下下一個疑問：

> 「門閂排除了手推，岸標證明船走穩，三回排除了單次巧合。還剩風。」

【系統】取得 E1「穩速三次落點」。

證據卡只記錄方法、船速與落點，不替尚未排除的風下結論。

## 第二幕｜看不出來，也是結果

### C2-1｜關上艙窗

**功能**：短場景，不進第二個大型工作台。它回應上一場留下的風疑問，是共同運動的體感轉折，也是章名來源。

伽桑狄安排兩次封窗測試：

- 一次船繫在岸邊。
- 一次船近似穩速前進。
- 次序由舵手封存，玩家事前不知道。
- 艙門與窗關閉；艙內只做兩件普通局部機械操作：同一顆小石由艙梁門閂放下、直上拋接軟球。
- 岸上紙事後才揭示兩次船況。

#### 選擇 C2-1.q1｜只看這顆落石與這顆軟球，能可靠分出哪一次在動嗎？

- A 小石較偏後的那次在動
- B 球較難接住的那次在動
- C 不能可靠分出；兩次都近乎落回原處 ✓

錯答先揭示兩次艙內紀錄幾乎相同，再讓玩家重選；不扣資源。

正解後揭示：

- 第一輪停船。
- 第二輪近似穩速。
- 艙內結果近乎相同。
- 岸標證明第二輪確實在前進。

【系統】取得 E2「兩次封窗紀錄」。

風的限定結論與物理邊界當場寫進伽桑狄台詞：

> 「沒有甲板風，它們仍跟著船一起走。所以風不是這種共同前行的必要解釋。」

> 「只能說，光憑這些普通的局部現象，我們分不出停船與近似穩速。船若加速、轉彎，或換別的問題，別拿這句話擋。」

### C2-2｜讓舊紙找到自己的位置

**功能**：解釋艦長的舊觀察；先設計反向情境，再封存預測。

#### 選擇 C2-2.q1｜要判斷「落後」跟什麼有關，下一組最有力的比較是？

- A 只把加速航次多做幾回
- B 保持其他條件不變，比較加速、穩速與減速 ✓
- C 換更輕的石頭，看看會不會被船追過

正解後，穩速資料沿用 C1；只需新增加速與減速兩組，每組自動三回。

#### 選擇 C2-2.q2｜結果揭曉前：船在石頭離手後減速，石頭相對桅杆會落在哪裡？

- A 桅後
- B 桅腳
- C 桅前 ✓

【系統】把玩家的選擇寫進卷宗並封存；錯誤預測不扣分，結果揭曉後原字保留。

結果：

- 加速：落點偏桅後。
- 穩速：落點集中桅腳附近。
- 減速：落點偏桅前。

#### 選擇 C2-2.q3｜三組資料共同支持哪一句？

- A 石頭離手後會慢慢失去前行
- B 船的速度若改變，船與石頭的相對位置會朝相反方向偏移 ✓
- C 船越快，石頭一定落得越後

【系統】取得：

- E3「三種船況落點圖」
- K2「船在前進」與「船速正在改變」不是同一件事

伽桑狄把 E3 放在 E4 旁邊，但不替舊紙補上不存在的船速：

> 「今天的加速組和舊紙長得相似。只能說相似；舊紙沒有船速，不能因為今天的結果，就突然變完整。」

### C2-3｜同一顆石頭，兩張紙

**唯一第二工作台**：雙紙帶。只保留兩個真正需要玩家判斷的操作。

素材來自同一次穩速落石：

- 岸上紙：每一拍記桅杆與石頭相對碼頭的位置。
- 船上紙：每一拍記石頭相對桅杆的位置。
- 兩張原紙上下排列，不先疊圖。

#### 選擇 C2-3.q1｜兩張紙上哪些點代表同一時刻？

- A 各自的終點
- B 相同高度的點
- C 同一編號的鼓點 ✓

錯答必須先演出可見後果：

- 對終點：顯示 2 號岸上點被錯配到 3 號船上點，時間線交叉。
- 對同高：顯示事件順序被打亂。

錯紙保留在旁邊，玩家回到選擇，不顯示單純紅叉。

#### 選擇 C2-3.q2｜要把岸上的記錄改寫成以桅杆為 0，應該怎麼做？

- A 全張紙只往左平移一次
- B 每一拍都扣掉那一拍桅杆相對岸的位置 ✓
- C 把紙旋轉到看起來近乎垂直

正解後，透明尺逐拍追著桅杆移動：

> `石頭相對桅杆的位置(t) = 石頭相對岸的位置(t) − 桅杆相對岸的位置(t)`

畫面結果：

- 岸上：石頭一面向前、一面向下。
- 船上：石頭相對桅杆近乎直落。
- 垂直分量不因換參考物而被改寫。

【系統】取得：

- E5「同號鼓點原紙」
- E6「逐拍移動的透明尺」
- K3「拿誰當不動的尺，會改變軌跡的寫法」

伽桑狄：

> 「兩張紙沒有互相否定。它們只是各自說清楚，自己拿誰當不動。」

### C3-2｜第一支柱：船向前，石頭就該落後

**支柱原文**：

> 「石頭離手後只剩下落；船還在向前，所以船會把它留在後面。」

#### 追問 C3-2.q1｜哪一句能把主張變成可檢驗的預測？

- A「你有幾年航海經驗？」
- B「如果鬆手會抹掉前行，經確認的穩速船上，它應該落在哪裡？」✓
- C「《對話》是誰寫的？」

艦長被追問後把話說滿：

> 「若離手後真的只剩下落，只要船向前，不管哪一趟，它都該落在桅後。」

群眾追問：

> 「可你們的手會推，風也會推。落到桅腳，怎麼知道不是被推回去？」

#### 觀念 C3-2.q2｜這一柱真正要處理哪個觀念？

- A 鬆手後，石頭原先與船共有的前行不會自動消失 ✓
- B 石頭會主動追著桅杆
- C 風會替石頭補上一股向前的力

#### 證據配對 C3-2.q3｜哪兩份合起來，既回答落點，也回答替代解釋？

**正解**：

- E1「穩速三次落點」
- E2「兩次封窗紀錄」

正解論證由玩家選定內容自動組成，不由伽桑狄搶答：

> 「岸標確認船在穩速，門閂、同石同高與三回重複排除了手推和單次巧合；三次都落在桅腳附近。封窗後，沒有甲板風，同一顆石頭由門閂放下、軟球直上拋接，仍近乎落回原處。風不是保留共同前行的必要解釋；鬆手也沒有把原先共有的前行抹掉。」

艦長接受的範圍：

> 「我接受穩速那一組沒有落後，也接受你們沒有拿手替結果補洞。至於戶外的風，你們沒有說它永遠無效；你們只證明，不靠甲板風也會留下共同前行。」

【視覺】第一支柱不是碎掉，而是被改寫：

> ~~只要船向前，石頭就會落後~~  
> **近似穩速時，石頭仍保留原先與船共有的前行。**

# 六、介面與操作預算

## 1. 只保留三種主要介面

1. **實驗設計單**：C1-2 至 C2-2 共用同一張，不重複進出不同工作台。
2. **雙紙帶**：C2-3，兩個判斷。
3. **碼頭辯論**：C3-1 至 C3-5，重用第一、二章的辯論語法。

船艙場景直接在敘事畫面完成，不另開大型工作台。

## 2. 操作原則

- 每種船況三回由系統自動執行，不要求玩家按三次。
- 玩家每次只做會影響推論的決定。
- 不做器材尋物。
- 不做角色分工下拉選單。
- 不做「讀完四個鼓點才解鎖」式點擊。
- 錯誤先演出可見後果，再說明；不只顯示紅叉。
- 錯誤結果與錯紙保留，但不污染成功證據。
- 改動已封存的實驗設定，會使依賴它的舊結果失效並要求重做。

## 3. 黃金路徑操作估算

- 章首 framing：2 次
- 舊紙與實驗設計：4 次
- 穩速判讀、船艙、變速預測與判讀：5 次
- 雙紙帶：2 次
- 三柱辯論：每柱 3 次，共 9 次
- 第二柱邊界＋官員誘惑：2 次

**合計約 24 次認知操作。**

這個數字高於「只算按鈕」的極簡版本，但每一次都在做推理；不再包含五人排班、逐拍點讀、重複跑三回、八個相位切換等程序點擊。正式實作時應另外統計「繼續」鍵，若單場連續繼續超過 6 次，需合併台詞或加入選擇。

# 七、三柱為什麼不是證據填空

即使形式沿用第一、二章，也要避免第三次變成「看卡名配支柱」：

1. **證據名稱不寫結論**：只叫「三次落點」「兩次封窗」「三種船況圖」。
2. **先追問，再選觀念**：沒有把對手主張問成可測預測，卡片不會自動變成答案。
3. **兩張證據必須互補**：
   - 一張回答發生什麼。
   - 另一張排除替代解釋或建立轉換規則。
4. **錯配保留在桌上**：艦長說清它回答了哪一題、漏了哪一題；玩家只換錯的那一張。
5. **第二柱強制證據邊界**：即使配對正確，若說成「舊航次一定加速」仍不能過關。
6. **第三柱重演轉換**：不是把 E5、E6 放上去就自動破柱；玩家已完成的同拍對齊與逐拍扣除會在眾人面前重播。
7. **對手逐柱改口**：支柱不是爆炸特效，而是保留原觀察、改寫過度推論。

# 八、物理與史實護欄

## 1. 物理不可破

- 穩速必須由固定時間間隔下的岸上位置近乎等距證明；不能只靠鼓點規律或舵手口述。
- 加速時：船追到石頭前方，石頭相對落後。
- 減速時：石頭保留較大的前行速度，相對落到前方。
- 封窗對照只足以說甲板風不是共同前行的必要解釋；不宣稱戶外風永遠無效或完全不影響散布。
- 船艙結論限定於普通局部機械現象、短時間、近似直線穩速。
- 不得把船艙結論寫成「任何實驗永遠測不到地球運動」；加速、旋轉與其他效應可被偵測。
- 岸上紙轉船上紙必須逐拍扣除桅杆當拍位置，固定平移一次不成立。
- 兩份軌跡都保留；不要求刪除其中一張。
- 不用完整牛頓第一定律的現代語句倒灌角色。
- 不新增「維持運動的力」。

## 2. 史實不可破

- 伽桑狄是實驗與思想工作的歷史主體；旅人只促成玩家可操作的證據鏈。
- 1640／1641 日期歧異留在史實頁，不在戲內假裝精確無疑。
- 艦長、馬蒂厄、艾蒂安與碼頭辯論為戲劇複合／虛構。
- 加速／減速三船況對照與封窗盲測是為了讓玩家檢驗條件而設計的教學重構，不宣稱伽桑狄在歷史現場逐項做過同一套流程；船艙共同運動的思想來源應明確連回伽利略《對話》。
- 「落石反對地球運動」可低溫提及；不虛構羅馬威脅或現場政治迫害。
- 官員追求大標題的動機來自告示與城市名聲，不寫成知道自己在誘惑學者的壞人。

# 九、刪台詞測試與玩家不可替代性

把伽桑狄所有解釋性台詞刪掉後，玩家仍必須能從操作推出：

- 穩速由岸標等距判定。
- 在沒有甲板風的封閉船艙內，同一顆小石與軟球在停船、近似穩速時仍近乎落回原處。
- 加速／穩速／減速對應後／中／前。
- 同號鼓點代表同時刻。
- 逐拍扣桅杆位置可把岸上紙改寫成船上紙。
- 舊紙因缺少船速而不能代表所有船況。
- 排除一項反對不等於直接證明地球運動。

若任何一項只能靠 NPC 說出，實作時視為不合格。

# 十、給 Claude 的對抗審查題目

請不要只修句子，先判斷結構是否成立：

1. **人物動機**：艦長借船卻不登船的理由是否自然？他到終局仍有足夠理由反對嗎？
2. **破案感**：六份證據是否真的是上一輪疑問逼出的，而不是依序領卡？
3. **實驗設計感**：玩家是否真的決定變因、控制與測量？有沒有哪個選擇只是正解長得比較像正解？
4. **點擊負擔**：是否還有可刪除的程序操作？三回自動執行是否損失必要的玩家承諾？
5. **三柱差異**：
   - 第一柱是否為排除替代解釋？
   - 第二柱是否為分類與證據邊界？
   - 第三柱是否為參考物轉換？
   三柱若可用同一種思路通過，請判失敗。
6. **一對一配卡風險**：六份中性證據與「追問→觀念→配對」是否足以避免填空感？若不足，請提出不增加介面數的改法。
7. **艦長聲線**：是否始終像熟悉船務、保護名字的實作者，而不是替物理課本出題？
8. **伽桑狄聲線**：是否有替玩家說答案或重複畫面已表達之處？
9. **物理誠實**：特別檢查風、舊紙、船艙、加減速與逐拍轉換五處。
10. **高潮**：官員的過度宣稱是否自然承接三柱，而不是突然冒出的第四題？
11. **章間接縫**：C0-1 是否接住第二章的前行問題；CE-2 是否只把問題交給月亮，不偷答第四章？
12. **可施工性**：場景、選項、證據與狀態是否足以轉成 JSON；若需拆節點，請標明但不要改回八個工作台。
