# 〇、這次真正找回第一、二章的核心

第三章不要求玩家依固定順序收齊完整證據。

正確的主迴圈是：

> **自由設計實驗 → 取得原始數據 → 特定數據組合解鎖「可提出的斷言」 → 玩家決定是否正式提出 → 帶現有卷宗去辯論 → 證據不足時被指出具體缺口 → 回船上補實驗**

這個改動代表：

1. **實驗台不是關卡清單**。玩家可搭配船況、放手、測量與重複次數，得到品質不同的紀錄。
2. **跑出數據不等於自動取得證據**。只有資料達到條件，斷言才會浮出；玩家還要點擊、選定適用範圍，才正式收入卷宗。
3. **辯論不是「證據收齊」才解鎖**。取得第一條由實驗數據成立的斷言後，玩家隨時可以回碼頭挑戰艦長。
4. **辯論可以失敗，也可以主動撤回**。所有原始數據、已成立斷言與已改寫支柱都保留。
5. **失敗不是重玩**。艦長的駁斥會變成卷宗上的「質疑釘」，帶回實驗台，告訴玩家缺的是哪一種判斷，不直接告訴正確設定。
6. **聰明玩家可以少做**。預先想到關鍵控制與記錄的人，可以用較少航次建立足以獲勝的論證；好奇的玩家則能做更多比較，取得更強或更完整的斷言。

木籌正式退場。所有「先承諾」都寫進實驗卷宗，不另造賭注道具。

# 一、案件與人物

## 1. 一句話案件

> 艦長有一張「船向前時，石頭落在桅後」的舊紀錄。這一筆代表所有向前的船，還是只代表某一種船況？

## 2. 玩家最後必須建立的三個觀念

| 觀念 | 玩家能說的話 | 現代整理詞僅供製作 |
|---|---|---|
| K1 | 鬆手不會把石頭原先與船共有的前行抹掉 | 共同運動／慣性前行 |
| K2 | 「船正在向前」與「船速正在改變」不是同一件事 | 勻速與加速度區分 |
| K3 | 軌跡怎麼寫，取決於拿誰當不動的尺 | 參考系／座標轉換 |

## 3. 艦長為什麼借船卻不參與實驗

艦長有一張真實但不完整的舊紙，也必須保護自己的名字。他因此提出：

> 「船和人借你們。我不登船，也不碰你們的紙。這是我的船，也是我的舊紀錄；我若在場，最後誰都能說我替自己作證。」

> 「你們想做幾趟就做幾趟。覺得手上的東西夠了，就回碼頭找我。可別等我問到一半，才說還少一張紙。」

他把封蠟交給馬蒂厄：

> 「每一趟的原紙，下船就封。辯論以前，不必先來告訴我哪一邊贏。」

角色分工：

| 角色 | 功能 |
|---|---|
| 旅人（玩家） | 設計、預測、判讀、提出斷言、決定何時辯論 |
| 伽桑狄 | 同行研究者；把玩家的問題轉成可操作條件，不代替玩家下斷言 |
| 艦長 | 出題者與終局對手；全程留岸，不操作、不看中途結果 |
| 舵手 | 依方案執行停泊、近似穩速、加速、減速 |
| 馬蒂厄 | 依訊號抽門閂，保管船上原紙 |
| 水手 | 固定間隔敲鼓 |
| 艾蒂安 | 岸上每拍記船與桅杆位置 |
| 港口官員 | 借船單與終局告示；想要一句夠響亮的結論 |

玩家不做五人排班。分工由選定的測量方案自動推導。

# 二、狀態模型：數據、斷言、質疑釘

## 1. 原始數據

每一次實驗都永久留下紀錄，不論設計好壞。

一筆航船落石紀錄至少顯示：

- 船況設定：停泊／近似穩速／加速／減速
- 放手方式：手放／門閂
- 是否有固定鼓點與岸上船位
- 是否有船上、岸上同步位置
- 重複次數：一回／三回
- 落點相對桅腳的位置與散布
- 哪些欄位未記錄

紀錄可能是：

- **可分類**：船況有當趟測量，能用於斷言。
- **未分類**：只有落點，沒有船速紀錄。
- **受混淆**：手放或同時改了多個條件。
- **可比較**：與另一組只有一項設定不同。

壞紀錄不刪除。它可能無法支持原本的斷言，卻能教玩家看見混淆因子。

## 2. 可提出的斷言

系統不在跑完實驗後自動發證據卡。

當資料達到某組條件時，卷宗側邊浮出：

> **「有一句話現在可以接受檢驗。」**

玩家點開後會看到：

1. 這句斷言候選。
2. 它引用的原始資料列。
3. 三種適用範圍，其中只有一種與資料相符。

玩家選對範圍，斷言才正式成立；選了過強版本，紙上留下刪改痕跡，再回選。

### 例：穩速三回完成

候選斷言：

> 「近似穩速時，石頭相對船落在桅腳附近。」

範圍選項：

- A「所有向前的船，任何條件下都完全落在同一點。」
- B「在同石、同高、門閂放手，且岸標確認近似穩速的三回中，落點集中在桅腳附近。」✓
- C「這證明風永遠不影響落石。」

只有 B 會成為正式斷言。

## 3. 質疑釘

辯論中每個具體缺口都會帶回實驗台，例如：

- 「你說走穩，可紙上沒有當趟船位。」
- 「你只有一回，還分不出規律與巧合。」
- 「門閂沒用上，手推仍混在結果裡。」
- 「甲板上有風；你還沒證明風不是共同前行的必要解釋。」
- 「舊紙與今天的加速組很像，不等於舊航次已被證明在加速。」
- 「你說兩張軌跡都對，卻還不能把一張換成另一張。」

回到實驗台後，質疑釘會釘在相關欄位旁，但不替玩家把正解選好。

# 三、自由實驗台

## 1. 一張桌，不是八個工作台

主介面只有一張「航船實驗卷宗」，分成兩個裝置頁籤：

1. **桅杆／甲板落石**
2. **封閉船艙局部測試**

岸上／船上雙紀錄不是第三個裝置，而是落石實驗的一種記錄方式。

## 2. 桅杆／甲板落石設定

| 設定列 | 可選項 | 物理意義 |
|---|---|---|
| 船況 | 停泊／近似穩速／加速／減速 | 主要自變因 |
| 放手 | 手放／門閂 | 是否混入額外推力 |
| 船況記錄 | 不記／固定鼓點＋岸上每拍船位 | 能否證明「穩速／加速／減速」 |
| 位置記錄 | 只記相對桅腳／岸上＋船上同步紙 | 是否能比較參考物 |
| 重複 | 一回／三回 | 是否能看散布與重複性 |

同一顆石頭、同一高度預設保持不變。玩家若主動改動，系統允許，但紀錄會標示「同時改了第二項條件」，無法與前一組做單變因比較。

### 快速複製

每做完一組，可按：

> **「複製這組，只改一項」**

這是本章最重要的實驗設計便利：

- 想比較船況：複製後只改穩速→加速。
- 想檢查放手：只改手放→門閂。
- 想補重複：只改一回→三回。
- 想取得雙紙：只改位置記錄。

## 3. 封閉船艙設定

船艙頁只保留三個判斷：

| 設定列 | 可選項 |
|---|---|
| 船況 | 停泊／近似穩速 |
| 操作 | 艙梁門閂落下同一顆小石／直上拋接軟球 |
| 對照 | 單做一種／兩種船況並排 |

艙門與窗關閉。近似穩速仍由岸上船位紙封存證明；玩家只比較小石與軟球，不把槳聲或窗景當成這個測試的量測。

## 4. 數據生成規則

### 桅杆落石

| 設定 | 典型結果 | 可否直接下強斷言 |
|---|---|---|
| 手放 | 落點散布大，方向隨手勢改變 | 不可；可解鎖「手放混入推力」 |
| 門閂＋無船速紙 | 有落點，但船況未分類 | 不可宣稱穩速／加速／減速 |
| 穩速＋門閂＋船速紙，一回 | 一筆落在桅腳附近 | 可提出「這一回沒有落後」的弱斷言 |
| 穩速＋門閂＋船速紙，三回 | 三點集中桅腳附近 | 可提出可用於辯論的穩速斷言 |
| 加速＋門閂＋船速紙 | 偏桅後 | 可提出「加速組出現後偏」 |
| 減速＋門閂＋船速紙 | 偏桅前 | 可提出「減速組出現前偏」 |
| 同步岸／船紙 | 兩張路徑不同但同拍 | 解鎖雙紙判讀，不直接解鎖轉換斷言 |

### 船艙

| 資料組合 | 結果 |
|---|---|
| 只做停船 | 石與球近乎落回原處；不能比較 |
| 只做穩速 | 石與球近乎落回原處；若無岸上船速紙，船況未分類 |
| 停船＋已證穩速並排 | 兩組近乎相同；可提出限定的共同運動斷言 |

# 四、斷言解鎖矩陣

斷言不是全部必拿。它們分成「最小過關斷言」與「補強斷言」。

## 1. 最小過關斷言

| ID | 斷言 | 解鎖資料 | 適用辯論 |
|---|---|---|---|
| A1 | 在本次可確認的近似穩速三回中，石頭落在桅腳附近 | 穩速＋門閂＋船速紙＋三回 | 第一柱、第二柱 |
| A2 | 沒有甲板風時，停船與近似穩速的局部落石／拋接仍近乎相同 | 船艙停船與已證穩速兩組 | 第一柱 |
| A3 | 加速組出現後偏；因此「後偏」不能代表所有向前船況 | 加速＋門閂＋船速紙，並已有 A1 | 第二柱 |
| A4 | 同號鼓點把兩張紙鎖在同一事件與同一時刻 | 同步岸／船紙＋正確對齊鼓點 | 第三柱 |
| A5 | 每拍扣除當拍桅杆位置，可把岸上紙改寫成船上紙 | 已有 A4＋完成逐拍轉換 | 第三柱 |
| A6 | 舊紙缺少當趟船速，只能保留為未分類紀錄 | 玩家讀取艦長舊紙的欄位 | 第二柱 |

成功辯論最少需要 A1–A6，但玩家不必先取得才可上台。
A6 是文件判讀，不會單獨開啟辯論入口；玩家至少要先讓一條實驗數據斷言成立。

## 2. 補強斷言

| ID | 斷言 | 解鎖資料 | 功能 |
|---|---|---|---|
| S1 | 手放會混入方向不一的額外推動 | 相同船況下手放多回，或手放／門閂對照 | 第一柱可代替一部分口頭辯護 |
| S2 | 一回結果不足以判斷散布與重複性 | 任一單次結果後嘗試強斷言 | 教玩家補三回 |
| S3 | 減速組出現前偏 | 減速＋門閂＋船速紙 | 讓第二柱的因果更完整 |
| S4 | 加速後偏、穩速近中、減速前偏形成三種船況指紋 | A1＋A3＋S3 | 第二柱強路徑；艦長少一次追問 |
| S5 | 舊紙與加速組同型，但今天的資料不能反證舊航次一定在加速 | A3＋A6 | 第二柱證據邊界 |

### 為什麼減速不是必做

只要玩家已有：

- 穩速近桅腳（A1）
- 加速後偏（A3）
- 舊紙缺船速（A6）

就足以阻止艦長把舊紙推成所有船況。

減速組能讓「船況指紋」更完整、辯論更容易，但不是硬性收集物。這正是「不必取得完整證據」的實際落點。

# 五、雙紙帶的斷言流程

取得同步岸／船紙後，不自動發 A4、A5。

玩家必須完成兩個判斷：

## 1. 哪些點是同一時刻

- 各自終點
- 相同高度
- **同號鼓點** ✓

錯誤先演出：

- 終點配終點會把岸上 2 號點錯配到船上 3 號點。
- 相同高度會讓事件順序交叉。

錯紙保留，玩家可重試。

正確後，A4 候選浮出。玩家點擊並選定限定句：

> 「同號鼓點只證明兩張紙記的是同一事件與時刻；尚未說明如何互換位置。」

## 2. 如何換成以桅杆為 0

- 全紙平移一次
- **每拍扣掉當拍桅杆位置** ✓
- 把紙旋轉成直線

正解後透明尺逐拍追著桅杆走：

> `石頭相對桅杆(t) = 石頭相對岸(t) − 桅杆相對岸(t)`

A5 候選才浮出。

# 六、玩家何時能去辯論

## 1. 入口

取得第一條由實驗數據成立的正式斷言後，實驗台常駐按鈕：

> **「帶現有卷宗回碼頭」**

不寫「證據已齊」「開始終辯」。

按下前只顯示：

- 已取得幾條斷言。
- 哪些原始數據仍未分類。
- 艦長有三項主張等待回答。

系統不判定玩家是否「準備好」。

## 2. 辯論可反覆進出

- 三根支柱可由玩家自行選擇挑戰順序。
- 每完成一柱，改寫結果永久保留。
- 每柱之間都有「繼續辯／回船上補實驗」。
- 說服力歸零時，艦長中止本輪，但不撤銷已接受的支柱。
- 回實驗台後，說服力於下次辯論重置；數據、斷言、質疑釘、已破支柱全部保留。
- 再入場跳過完整開場，艦長只問：

> 「這回補了哪個缺口？」

## 3. 為什麼提早辯論有價值

玩家未必知道自己缺什麼。辯論把抽象的「資料不完整」變成一個人的具體反對：

- 艦長不接受「我設定成穩速」，只接受岸上每拍船位。
- 群眾不接受一次落點，追問是否巧合。
- 艦長不接受「兩張都對」，要求玩家真的轉換。

因此提早辯論不是錯誤路線，而是一種診斷工具。

# 七、三柱辯論

## 共通規則

每柱仍保留第一、二章熟悉的四拍：

1. **追問**：把對手主張逼成可測預測。
2. **觀念**：選出真正的物理區分。
3. **配對**：從卷宗選兩項（斷言或原紙）組成論證。
4. **回應**：艦長接受到哪裡，或指出哪個缺口。

錯配不清空桌面。艦長說明其中哪一項答錯題，玩家可替換或撤回補實驗。

---

## 第一柱｜船向前，石頭就該落後

艦長：

> 「石頭離手後只剩下落；船還在向前，所以船會把它留在後面。」

### 追問

- A「你有幾年航海經驗？」
- B「如果鬆手會抹掉前行，經確認的穩速船上，它應該落在哪裡？」✓
- C「《對話》是誰寫的？」

### 觀念

- A 鬆手不會自動抹掉石頭原先與船共有的前行 ✓
- B 石頭會主動追著桅杆
- C 風替石頭補上一股向前的力

### 最小成功配對

- A1「穩速三回落在桅腳附近」
- A2「沒有甲板風，停船／穩速局部結果仍近乎相同」

### 不完整時的分層反駁

| 玩家手上有什麼 | 艦長／群眾回應 | 帶回的質疑釘 |
|---|---|---|
| 只有一回穩速落點 | 「一回可以是巧合。」 | 重複性 |
| 沒有岸上船位 | 「你說走穩，紙上卻沒有船速。」 | 當趟船況 |
| 手放 | 「放手時多推了一下，誰分得出來？」 | 放手控制 |
| 有 A1，沒有 A2 | 「甲板上有風。你還沒證明它不是必要解釋。」 | 無甲板風的對照 |
| A1＋A2 | 第一柱改寫 | — |

補強斷言 S1 可讓艦長直接接受放手控制，但不能代替 A2。

### 支柱改寫

> ~~只要船向前，石頭就會落後~~  
> **近似穩速時，石頭仍保留原先與船共有的前行。**

## 第二柱｜我的舊紙證明所有向前船況

艦長：

> 「我的舊紙確實記到落後。觀察既然是真的，你們就不能把它當成例外。」

### 追問

- A「舊紙上的落點是不是船尾？」
- B「舊紙有沒有同時記放手時，船速是否仍在改變？」✓
- C「這張紙是不是你親手寫的？」

### 觀念

- A 「船正在前進」與「船速正在改變」不能混成一種 ✓
- B 沒有完整數字的舊紙一定是假的
- C 加速時石頭比較重

### 最小成功配對

- A3「加速組出現後偏」
- A6「舊紙缺少船速，屬未分類紀錄」

但若玩家沒有 A1，艦長仍會追問：

> 「你只證明加速會落後，還沒有證明走穩時不會。」

因此完整最小論證其實由三項內容構成：

- A1：穩速近桅腳
- A3：加速後偏
- A6：舊紙缺船速

介面仍只要求當下配兩項；A1 若已在第一柱被接受，視為桌上既有前提，不必重複出示。若先挑第二柱，玩家可把 A1 與 A3 配對，艦長再追問舊紙缺口，之後補 A6。

### 強路徑

若玩家已有 S4「三種船況指紋」＋S5「舊紙邊界」，可直接完成此柱，艦長少一次追問。

### 邊界選擇

- A「舊航次已證明當時一定在加速。」
- B「艦長的舊紙是錯的，應該丟掉。」
- C「舊紙與今天的加速組同型，但缺少當趟船速，只能保留為未分類紀錄，不能代表所有向前船況。」✓

### 支柱改寫

> ~~舊紙證明所有向前的船都會落後~~  
> **舊紙記到真實落後，但沒有船速，不能代表全部船況。**

艦長：

> 「所以我看見落後沒有錯。錯的是我替那一筆補上了它沒有記的船況。」

## 第三柱｜同一顆石頭不可能有兩張真軌跡

艦長：

> 「岸上畫成彎線，船上畫成直落。同一顆石頭不可能走兩條路。」

### 追問

- A「哪一張比較像肉眼看到的？」
- B「如果兩張都對，能不能用同一組時刻，把岸上紙轉成船上紙？」✓
- C「兩位記錄員誰比較可靠？」

### 觀念

- A 改變的是記錄位置時採用的參考物：碼頭或桅杆 ✓
- B 改變的是石頭受力方向
- C 改變的是紙張角度

### 成功配對

- A4「同號鼓點鎖定同一事件與時刻」
- A5「逐拍扣桅杆位置可互換兩張紙」

### 不完整時的反駁

| 玩家有什麼 | 艦長回應 | 質疑釘 |
|---|---|---|
| 只有兩張原紙 | 「兩張圖放在一起，不等於它們能互相說明。」 | 轉換規則 |
| 終點對終點 | 「你把不同時刻說成同一時刻。」 | 同拍對齊 |
| 全紙平移一次 | 「桅杆每一拍都在走，不是只走一次。」 | 逐拍扣除 |
| A4＋A5 | 第三柱改寫 | — |

### 支柱改寫

> ~~同一顆石頭只能有一張真軌跡~~  
> **同一事件可相對碼頭或桅杆留下不同而可互換的軌跡。**

# 八、辯論失敗與返回實驗

## 1. 主動撤回

每一個具體反駁後，玩家可選：

- 「我現在回答。」
- 「先把這個問題釘回卷宗。」

選後者不扣說服力。艦長：

> 「知道缺哪一張紙，比拿錯紙硬撐有用。去吧。」

## 2. 說服力歸零

艦長：

> 「你有紀錄，也有幾句站得住的話。可你現在拿它們回答錯了問題。」

伽桑狄回船上只說：

> 「不用重做已經做對的。先看他剛才問的是哪一欄。」

【系統】返回自由實驗台：

- 已破支柱保留。
- 說服力下次重置。
- 所有數據、斷言與錯紙保留。
- 最新質疑釘置頂。

## 3. 不允許的假失敗

- 不因選錯證據清空數據。
- 不強迫重做已經合格的實驗。
- 不用紅字直接說「你缺船艙測試」；只呈現「甲板風仍是替代解釋」。
- 不把辯論失敗寫成人物羞辱或遊戲結束。

# 十一、最短成功路徑與自由路徑

## 1. 聰明玩家的最短成功路徑

1. **穩速桅杆落石**：門閂、船速紙、同步岸／船紙、三回。
   - 一次取得 A1 所需數據與雙紙原始資料。
2. **封閉船艙對照**：停船＋已證穩速。
   - 取得 A2。
3. **加速桅杆落石**：複製第一組，只改船況為加速。
   - 取得 A3。
4. 完成雙紙同拍對齊與逐拍扣除。
   - 取得 A4、A5。
5. 讀舊紙提出 A6。
6. 進辯論，依序或自選完成三柱。

玩家不必做：

- 減速航次
- 手放對照
- 停泊桅杆落石
- 多種石重
- 所有可能風況

## 2. 探索玩家可能走的路

- 先用手放，從散布發現門閂的必要。
- 只記落點，進辯論後才發現「設定成穩速」不等於有船速證據。
- 只做一回，被群眾追問巧合後回來補三回。
- 先做加速／減速，取得完整三船況指紋，再去處理風。
- 很早進辯論，破不了任何柱，但帶回三枚清楚的質疑釘。
- 先破第二柱，再回來補第一柱與第三柱。

這些都不是死路。

# 十二、介面與點擊原則

1. 實驗台只是一張卷宗；切頁籤不換整套操作語法。
2. 每組三回自動演出，不讓玩家連按三次。
3. 可複製前一組，只改一項。
4. 特定數據達門檻時才浮出斷言，不顯示尚未滿足的灰色斷言清單。
5. 斷言必須由玩家點擊並選擇適用範圍，不自動頒發。
6. 辯論入口在第一條實驗斷言後常駐，不以「收集完成度」鎖門。
7. 辯論失敗返回實驗台時，鏡頭直接落在最新質疑釘，不重播序幕。
8. 原始數據、斷言、錯紙與支柱狀態皆可在手機橫屏下清楚讀取。
9. 最小可讀字級 16px；觸控目標至少 44px。
10. 不做五個位置下拉、不做器材尋物、不做逐拍點滿才能繼續。

# 十三、物理與證據邊界

- 近似穩速必須由固定時間間隔下的岸上船位近乎等距證明。
- 加速後偏、減速前偏；偏移來自船與石頭的速度變化不同，不新增維持運動的力。
- 手放資料可作混淆示範，不得拿來支持乾淨落點斷言。
- 一回可形成弱斷言，但不足以回答重複性追問。
- 封窗對照只能說甲板風不是共同前行的必要解釋；不宣稱戶外風永遠無效。
- 船艙結論限於普通局部機械現象、短時間、近似直線穩速；不得擴張成加速、旋轉或所有地球運動永遠不可測。
- 舊紙是真實但未分類的紀錄；今天的加速資料不能反證舊航次一定加速。
- 岸上紙轉船上紙必須逐拍扣掉桅杆當拍位置，不能固定平移一次或旋轉紙張。
- 兩張軌跡都保留。
- 最終只排除一項反地動論證，不直接證明地球運動。

# 十五、刪台詞測試

刪掉伽桑狄所有解釋性台詞後，玩家仍應能由操作與數據推出：

- 沒有岸上船位，就不能證明走穩。
- 門閂資料比手放更能排除額外推力。
- 一回與三回的斷言強度不同。
- 穩速近桅腳、加速偏後；若選做減速則偏前。
- 封閉船艙內沒有甲板風，普通局部結果仍近乎相同。
- 同號鼓點代表同一時刻。
- 每拍扣除桅杆位置能互換兩張紙。
- 舊紙因缺船速而不能代表所有船況。
- 排除反對不等於證明地球運動。

任一項若只能靠 NPC 說出，實作不合格。
