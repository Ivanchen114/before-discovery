## 〇、寫作自檢（先聲明，後列稿）

- 四把尺全過：**平行句型**（statements 三句同型；FR 四句同型）、**無插旗詞**（掃過：無「任何／一定／全都／絕對／已經證明」）、**同視覺權重**（無 primary 註記）、**無異形選項**（FR 二×二）。

- 失敗只打掉主張：`texts.wrong` 不刪資料。
- 台詞全部過了一次白話化（自然口語、無「若／如紙所寫／以及」、句子短）。

## 一、order

```json
"order": ["P2", "P1", "P3", "fr"]
```

**柱序刻意是 P2 → P1 → P3**：院士先亮自己最強的牌（我的帳從沒錯過）→ 再攻對方最弱處（你的帳會漏）→ 最後收攏成「所以只有一本」。強—攻—收，是辯士的自然順序，也讓玩家先處理「承認對手是對的」這個最難的動作。

## 二、pillars

### P2｜「我的帳，從來沒錯過」（正解出示 J1 動量帳）

```
title: "第一問：帳只能有一本"
```

**statements（院士的三句話，玩家逐句聽完）**：

1. 「這本帳，帶方向記。撞前多少，撞後就多少。」
2. 「彈開的、黏死的，我都記過。**它一次也沒有漏。**」
3. 「所以運動之量只有一個。再立一本，是不會算，不是新發現。」

**playerCorrect（玩家親口說）**：

> 「院士，這兩種碰法我都親手記過——鋼頭、油灰頭，帶方向加起來，**每一筆都平**。這本帳是對的。（把 J1 推到桌心）**我要說的不是它錯了。是有些事，它沒記。**」

**breakReply（院士退這一步）**：

> 「……你先認了我的帳。好。那你說，它沒記到什麼？」

**設計註**：本柱的「勝利」是玩家**承認對手正確**。出示錯誤證據（J2/J3）時依引擎慣例 `evidence-mismatch`，杜夏特萊只指卷宗：「他問的是他那本帳。你拿這張，回答得了嗎？」

### P1｜「會漏的帳，不配叫定律」（正解出示 J3 黏土深度）

```
title: "第二問：短少的那一截"
```

**statements**：

1. 「你們那本要自乘的帳，鋼頭那幾次，我認，是平的。」
2. 「可油灰一撞成團，**它就短少一截**。撞得越狠，少得越多。」
3. 「會憑空少掉東西的帳，記的就不是自然的定律。」

**playerCorrect**：

> 「（把黏土盤放上桌）同一顆球，速度加一倍，坑深大約四倍——壓出去的效果，跟著失去的活力走。短少的那截去了哪裡，我還沒對平；**可它走的時候留了量得出來的痕跡。會留痕跡的短少，不是帳記錯了。**」

**breakReply**：

> 「（盯著那排坑，很久）……坑，是量得出來的。去向你沒對平——**可這確實不像記錯帳的樣子。**」

### P3｜「兩本帳，其實是同一件事」（正解出示 J2 活力帳）

```
title: "第三問：一本帳的兩種寫法"
```

**statements**：

1. 「好。你的帳沒漏，我的帳沒錯。」
2. 「那它們記的就是**同一個東西**——不過一本多自乘了一次。」
3. 「同一件事寫兩遍，留一本就夠。」

**playerCorrect**：

> 「同一件事，會在**同一次碰撞**裡，一本對平、一本短少嗎？（把兩本帳並排壓在桌上，指油灰那幾列）同一次撞擊，這邊對平，這邊短少；**換了砝碼再撞，短少的份量還會變。** 記同一件事的兩本帳，不會這樣吵架。」

**breakReply**：

> 「（看著那一列，手指停在短少的數字上）……不會吵架。可它們吵了。」

**設計註**：本柱正是 FR 誘答 ▸C 的「對面版」——院士先把混淆說出口，玩家在此駁倒；FR 裡同一個混淆變成玩家自己可犯的選項。同一個盲點見兩次，第二次要負責（§三-3.2）。

## 三、fr（重寫題目）

**open（主人請旅人表態；院士已講完）**：

> （莊園主人敲了敲杯子。）「兩位的帳都攤在桌上了。旅人，你一路都在場——**這場架，誰贏？**」

**explore.steps（兩步，各三選一，答錯留痕回同步）**：

**step 1**：「先別急著判。同一次油灰碰撞，兩本帳各記到什麼？」

- ✓ 「動量帳對平；活力帳短少一截。」
- ✗ 「兩本都對平。」→ 杜夏特萊（指油灰那列）：「再看一次這一列。」
- ✗ 「兩本都短少。」→ 杜夏特萊（指動量那欄）：「這一欄，你自己結算過。」

**step 2**：「那短少的那截，追到哪裡了？」

- ✓ 「追到一把尺——壓陷的深淺，跟著速度的平方走。去向還沒對平。」
- ✗ 「找不到，它消失了。」→ 杜夏特萊：「消失，是句太滿的話。那盤黏土上的坑，怎麼說？」
- ✗ 「找齊了，在動量帳裡。」→ 杜夏特萊：「動量帳平得剛剛好，一截都沒多。」

**assertion（浮出的候選主張）**：

> 「『運動之量』這四個字，一直裝著兩本帳。」

**claim（誘答所在・四選一・二×二對稱）**：

**prompt**：

> 主人：「所以呢？這題到底怎麼收？」

**options**：

1. ✗ 「答案是動量那本：它到哪都平；活力會短少，就是它不夠格。」
   → **reason: "single-ledger"**・杜夏特萊（看著黏土盤）：「那這些坑，記在哪一本？」
2. ✗ 「答案是活力那本：黏土和回彈，只有它說得清。」
   → **reason: "single-ledger"**・杜夏特萊（指非彈性那列）:「短少的那截，你要跟院士怎麼交代？」
3. ✗ 「這題問錯了——兩本帳記的其實是同一件事，一本多自乘了一次。」
   → **reason: "same-thing"**・杜夏特萊（把兩本帳並排壓下）：「同一件事，會在同一次撞擊裡一本平、一本短少嗎？」
4. ✓ 「這題問錯了——兩本帳記的是**不同的事**，各有各的用處。」

**honestText（玩家答對後親口收尾）**：

> 「杜佩院士，你的帳記的是**方向上的多少**——它到哪都平。夫人這本記的是**做事的本錢**——彈開時守住，撞爛時從眼前的運動裡短少；短少多少，壓出來的痕跡量得出尺度，**去向的全帳，還沒有人對平**。（拿起筆，把「運動之量＝？」那行劃掉）**題目不該問誰贏。該問：哪本帳，記哪件事。**」

**closeReply**：

> 院士（沉默很久，拿起自己的帳簿，又放下）：「……我記了三十年的帳。今天才知道，我記的是哪一本。」
> 杜夏特萊（對旅人，聲音放輕）：「兩本都留著。往後的人用得上。」

## 五、給 Sol 的實作註記

1. **P3 不用 `useLegacy`**（ch1 的 P3 是舊機制殘留）；三柱統一用 statements＋playerCorrect。若引擎要求 P3 特殊結構，照 P1/P2 的形狀開新枝，**不要沿用 legacy**。
2. FR 的 `claim` 四選項需要 **reason 分流**（`single-ledger`／`same-thing`），比照 ch2 修正案的資料驅動判定（`correct`／`reason`／`reply`），**不要硬編碼 `id==="over"`**——那正是 ch2 正要修掉的坑。
3. **錯項不過濾、可重複提交**（依 B-1 裁決方向）；penalty 用既有 persuasion 機制。
4. 台詞若需截短以配合版面，**先動 statements，不動 playerCorrect**——玩家親口說的話是這一章的骨。
5. **P3 的「換了砝碼再撞，短少的份量還會變」依賴規格 §2-2b 追一筆**（4／8 油灰，短少三分之二）。該步是主線必經，資料保證存在。
6. **證據邊界（v0.1.1）**：全稿不得出現「找回來／跑進黏土／沒有離開世界／兩量都守恆」。本章只主張：動量帳兩種碰撞閉合；活力帳彈性閉合、非彈性從可見運動短少；壓陷效應隨 v² 可量；**短少的完整去向未對平（交棒 H1）**。
