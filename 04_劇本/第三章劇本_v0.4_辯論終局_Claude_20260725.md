# §0 一頁摘要

**主線一句話**：艦長手上有一筆真的「落後」紀錄。他借船、丟下這張紙，然後**刻意不看**——你得在碼頭上，當著全港的人，說服他。

**五幕**

| 幕 | 內容 | 互動 |
|---|---|---|
| 一 | 交棒 → 借船・舊紙・「我不看」 → 三枚木籌 ＋ **第一個決定** | 對話決定 ×1 |
| 二 | 航船實驗台：加速 → 走穩 → 往返（風） → 艙內（轉折） → **封存減速預測** → 減速 | 實驗台 |
| 三 | 兩張紙（逐拍扣桅杆） | 雙紙帶 |
| 四 | **碼頭辯論**：四根支柱 ＋ 官員的告示（拒絕過度宣稱才算贏） | 辯論（重用引擎） |
| 五 | 題名 → 兩本書・1642 → 末頁・月亮問題 | 對話決定 ×1 |

**工作台相位：2**（航船實驗台、雙紙帶）＋辯論（重用 ch1／ch2 引擎）
**必要操作：18**（實驗台 15、雙紙帶 3）；辯論屬玩法，不計入點擊成本
**玩家選擇節點：5 處**（§5 總表）
**證據**：S5《對話》船艙頁｜G1 判準與三回穩速｜G2 艙內不可分辨＋往返風向｜G3 三態指紋｜G4 雙參考物｜G5 由辯論終局產生

**這一章的辯論跟前兩章不同的地方**：ch1＝破除舊理論、ch2＝組裝獨立性並讀懂對手數據、**ch3＝拒絕把話說滿**。判準：「這一章的辯論，能不能用上一章的打法過關？」——不能，因為最後一步是**刪掉別人替你寫好的一句結論**。

# §1 人物與分工（艦長退出實驗）

| 角色 | 定位 | 是否參與實驗 |
|---|---|---|
| **艦長** | **出題者＋終局對手**。借船、給舊紙、立規矩，然後不看 | **不參與** |
| 伽桑狄 | 同行學者；船上記落點與放手那一拍的風向；劃邊界 | 參與 |

| 艾蒂安 | 固定守岸標，逐拍記桅杆離碼頭多遠 | 參與 |
| 水手長 | 依伽桑狄要求操船（船況由船員執行，艦長不在場） | 參與 |
| 水手 | 等節拍鼓，間隔不變 | 參與 |
| 旅人（玩家） | **設計實驗**：改什麼、控住什麼、取得什麼 | 參與 |
| 商人／槳手／岸上群眾／官員 | 辯論質疑者（無立繪，聲音角色；比照現行 `publicDemo` 既有作法） | 不參與 |

**「同一人不得分身」仍成立**；唯一合併是伽桑狄在**同一時刻、同一位置**記落點與風向旗。

# §3 逐場台詞

## 第一幕｜接手

### `C0-1` 馬賽港・頁面翻了三十來年

```
n1  stage（montage：1609 頁角問題 → 年月折進紙縫 → 1632《對話》覆上 → 1640 馬賽）
    「1609 年。頁角還留著旅人寫下的問題：沒有東西繼續推它，它為什麼還在走？
     年月折進紙縫。1632 年的《對話》覆上舊問題，把它換成另一個問法：船若向前，桅頂的石頭落在哪裡？
     1640 年秋，法國・馬賽。」
n2  旅人・心聲「他們老了三十來年。我沒有。」
n3  伽桑狄（按住又被海風吹起的書頁，抬眼）「伽利略在《對話》的第二日，寫到一艘正在前進的船。」
n4  伽桑狄（闔上書，抬手指向桅頂）「我想借一艘真的船，把書裡那個問題帶到海上試一次：那顆石頭從桅頂鬆手，船正在前進時，它會落在哪裡？」
```

### `C0-2` 借船・那張舊紙・我不看

```
n1  伽桑狄（走到踏板前；艦長正低頭核對裝貨單）「有人拿同樣的說法反對地球在動。我想借你的船看看：船真的向前時，石頭是不是一定落在後面。」
n2  艦長（把裝貨單捲起，擋在踏板前）「船可以借。人也借你五個。先說好：做出什麼，就寫什麼。別拿我的名字替沒弄清楚的事撐場面。」
n3  艦長（從裝貨箱底抽出一張皺紙，推過來）「那我先給你們一張。解纜後第一段，落在桅後。」
    （指著紙面）「只有落點。沒有鼓點，沒有岸標，也沒有第二次。」
n4  艦長「我不上船。你們做的時候，我在帳房。」（把木籌盒推過來）
    「我不想有人說我幫了你們，也不想有人說我攔了你們。」
n5  艦長「三天後，貨全上完，碼頭上都是人。」（停）「你們在那裡說服我。說不動，這張紙就照我原來的意思留著。」
```

> **這一拍是本版的樞紐**：艦長退出實驗、預告終局。他不參與，所以終局的質疑是乾淨的。

```
n1  stage「三枚木籌落定。艦長寫『船尾』，名字朝外；伽桑狄寫『桅腳』；旅人也寫『桅腳』。

c1  【choice ①】「解纜後第一段，你先控住哪一件？」

    ▸ speed  ：「先把船速記清楚——鼓點對岸標，逐拍記。」

    → 寫入 design，直接成為第一趟的控制項；不在實驗台重選。
```

## 第二幕｜航船實驗台

**實驗台每輪三件事**：**改什麼**（船況：停泊／走穩／解纜後加速／收槳減速；航向：去程／回程）｜**控住什麼**（門閂、鼓點＋岸標、風向記錄、重複三回）｜**取得什麼**（落點相對桅腳、鼓點間距、相對風向）→ 玩家選資料＋提出主張＝證據。

### `C1-1` 解纜後第一段

```
n1  stage「第二天。艦長在帳房，門關著。甲板上只有五個人和一顆石頭。」
n2  水手長「解纜後第一段？那我照原樣開——不快也不慢，就跟他那天一樣。」
e1  【實驗台】改什麼＝解纜後加速；控住＝玩家在 c1 選的那一項；取得＝落點＋該項紀錄
    hint「重做艦長那一段。你選的控制已經就位。」
```

**結果旁（依玩家控住的項目）**

| 控住了 | 回話 |
|---|---|
| 門閂 | 馬蒂厄「門閂是我抽的。從頭到尾沒有人碰過。」／伽桑狄「這樣他不能說有人多推。可我們還不知道那時船走多快。」 |
| 船速紀錄 | 艾蒂安「三段間距，一段比一段長。」／伽桑狄「這一段速度在增加。可放手的是誰、有沒有多推，紙上沒有。」 |
| 風向 | 伽桑狄「風記下了。可我們既不知道船速，也不知道有沒有人多推。」 |

```
n3  伽桑狄「一趟只顧一件，下一趟還是會漏。這次五個人全上，把該記的一次記完。」
【實驗台・確認分工】（1 次）
    馬蒂厄抽門閂｜水手敲等節拍鼓｜艾蒂安守岸標｜伽桑狄記落點與放手那一拍的風向｜水手長操船
n4  馬蒂厄（把記錄板夾到臂下）「照原樣記。船長不在，也不能替他改。」
```

> 單趟不得出現「散布」；只能說「這一項已受控」。

### `C1-2` 等它走穩

```
n1  stage「重新解纜。同一種操作階段，這次五個人各就各位。」
e1  【實驗台】解纜後加速・完整紀錄（**合格方案自動三回**）
```
**結果旁**：艾蒂安「三段間距，一段比一段長。」／伽桑狄「三回都偏後。這一段，速度確實在增加。」

```
n2  旅人「那艦長那張舊紙——」
n3  伽桑狄（把兩張紙並排）「今天我們重做的是同一種操作，不是同一趟。」（停）
    「能說的只有兩句：這個階段速度仍在增加；舊紙的落後，和今天的加速紀錄同型。舊紙上沒有船速，它不會因為今天就變成一份完整的紀錄。」
n4  水手長「要走穩嗎？出了防波堤就穩。」
e2  【實驗台】改船況＝走穩 → 執行（**自動三回**）
```
**結果旁**：艾蒂安「三段間距，幾乎一樣長。」／伽桑狄「三回都在桅腳附近。」

### `C1-3` 換個方向再走一次

```
n1  水手（把手按在鼓面上）「今天順風。石頭會不會是被風推回桅腳的？」
n2  伽桑狄「那就換個方向。同一段船速，回頭再走。」
e1  【實驗台】改航向＝回程（**兩航向各自動三回**）
```
**結果旁**：伽桑狄「去程時，風從船尾方向來；回程時，風從船頭方向來。」／伽桑狄「兩個方向各三回，落點都還在桅腳附近，沒有跟著風偏向同一邊。」

```
【實驗台・判讀】（1 次）玩家提出：風向明顯改變，落點偏移沒有跟著形成一致變化。
n3  伽桑狄「只能說到這裡：在今天的精度與散布裡，沒有看到風造成一致的偏移。」（停）「不是說風不存在。」
```

### `C1-4` 艙裡（轉折）

```
n1  伽桑狄「把岸標和風都關在門外，再試一次。進艙裡。」
n2  水手長「艙裡我照兩種開法各開一次。你們在裡面，不會知道是哪一種。」
```

```
n3  伽桑狄「這句話只到這裡：只憑這碗水、這顆球，分不出停泊和走得很穩。」（停）
    「不是任何實驗都測不到運動。」
n4  馬蒂厄（在記錄板上寫）「兩筆都寫『分不出來』。」（停）「這樣寫，比猜一個好聽的難。」
```

### `C1-5` 收槳之前，先把答案留下

```
n1  伽桑狄（把加速那一組與走穩那一組並排）「如果落後來自速度正在增加——」
n2  伽桑狄「那麼速度減下來的時候，石頭會落在哪裡？」

c1  【choice ②・封存預測】「收槳之前，先把你的答案留下。」
    ▸ fore：偏向船頭
    ▸ aft ：偏向船尾
    ▸ foot：還在桅腳
s1  system「預測已封存。收槳之前，誰都不能改。」

e1  【實驗台】改船況＝收槳減速 → 執行（**自動三回**）
```
**結果旁**：艾蒂安「間距，一段比一段短。」／伽桑狄「落點：偏前。三回都偏前。」

| 玩家封存 | 回話 |
|---|---|
| **fore（正解）** | 伽桑狄「你封的那一句，和紙上一樣。」／水手長「石頭沒有慢下來。是船慢下來了。」 |
| **aft** | 伽桑狄（把三張紙推回，沒有笑）「你封的是偏後。紙上是偏前。」／「先別改主張——先說：剛才是什麼在變慢？」→ 可重新斷言，不扣資源 |
| **foot** | 伽桑狄「桅腳是走穩那一組的樣子。這一趟，船在變慢。」／「再看一次間距，再說一次。」→ 可重新斷言，不扣資源 |

### `C1-6` 三張紙並排

```
n1  stage「加速、走穩、減速。三張紙並排壓在艙頂板上，落點一張偏後、一張在桅腳、一張偏前。」

n3  伽桑狄「明天把兩張尺一起帶上船——岸上的和船上的。碼頭那場，你會需要它。」
```
