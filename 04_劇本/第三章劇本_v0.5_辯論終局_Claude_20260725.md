### §0.1 為什麼刪木籌（我的判斷）

木籌來自 `CH3-CR-014`，當時的功能是「先承諾、防事後改口」。但在 v0.4／v0.5 的結構下它已經三重冗餘：

1. **機制上**：先承諾已由「收槳前封存減速預測」承接，而且那一刻才真的有承諾的意義（玩家手上已有指紋、正要外推）。
2. **戲劇上**：艦長的公開立場是他**親手寫在舊紙上的「解纜後第一段，落在桅後」**——那比一枚木頭更有份量，而且是真證據。
3. **主題上**：本章一路在講「難看的紀錄也留著」。結局讓艦長**把舊紙補完**（補上他當年沒記的船速），比翻一枚木籌更貼題：他沒有丟掉錯誤，他把它寫完整。

→ 治理：`CH3-CR-014` 的木籌約定由 **CH3-CR-019** 明文取消；美術也少一件道具。

# §1 一頁摘要

**主線**：艦長有一筆真的「落後」紀錄。他借船、丟下這張紙，**刻意不上船**——你得在碼頭上，當著全港的人說服他。

| 幕 | 內容 | 互動 |
|---|---|---|
| 一 | 交棒 → 借船・舊紙・「我不上船」 → 三種解釋 ＋ **第一個決定** | 對話決定 |
| 二 | **航船實驗台（自由）**：任意組合船況／航向／配置；**資料齊了斷言才亮** | 實驗台（可反覆進出） |
| 三 | 兩張紙（逐拍扣桅杆） | 雙紙帶 |
| 四 | **碼頭辯論**：四根支柱 ＋ 官員的告示；**隨時可上、可失敗、可回頭** | 辯論（重用引擎） |
| 五 | 題名 → 兩本書・1642 → 末頁・月亮問題 | 對話決定 |

**工作台相位 2**（實驗台、雙紙帶）＋辯論（重用）｜**必要操作 17**（現行 runtime 約 45–47）
**證據**：S5《對話》船艙頁｜G1 走穩三回與判準｜G2 艙內不可分辨＋往返風向｜G3 三態指紋｜G4 雙參考物｜**G5 由辯論 FR 的 trap 選誠實產生**

**與前兩章的差別**：ch1＝破除舊理論、ch2＝組裝獨立性並讀懂對手數據、**ch3＝拒絕把話說滿**。判準「能不能用上一章的打法過關」——不能，最後一步是**刪掉別人替你寫好、群眾正在等的那句結論**。

# §3 第二幕：自由實驗台

## §3.1 每輪三件事

| 玩家決定 | 選項 |
|---|---|
| **改什麼** | 船況：停泊／走穩／解纜後加速／收槳減速　　航向：去程／回程 |
| **控住什麼** | 門閂（馬蒂厄）／鼓點＋岸標（水手＋艾蒂安）／風向記錄（伽桑狄）／重複三回 |
| **取得什麼** | 落點相對桅腳、鼓點間距、相對風向 |

**配置（互斥）**：A 桅頂落石（預設）｜B 艙內盲測（不放桅頂石）｜C 雙紀錄（岸紙＋船紙）
**合格方案自動三回**；未達三回不得使用「散布」「系統偏移」等措辭。
玩家可以任意順序、任意次數地跑，也可以中途上碼頭。

## §3.2 斷言亮牌條件表（核心）

**斷言按鈕只有在資料條件成立時才出現**，規則以引擎 `assertStage` 為單一事實源（GB-ADR-011：UI 不自帶平行邏輯）。

| 已取得的資料 | 亮出的斷言（玩家點擊） | 產生 |
|---|---|---|
| 走穩・三回（門閂＋岸標） | 「近似穩速前進時，落點在桅腳附近。」 | **G1** |
| 加速・三回 ＋ 走穩・三回 | （尚不亮完整斷言）伽桑狄：「兩組不同。可你還沒說清楚是什麼在變。」 | — |
| 加速 ＋ 走穩 ＋ **減速** 三組（減速須先封存預測） | 「加速偏後、走穩桅腳、減速偏前——運動在改變時，會留下方向相反的偏移。」 | **G3** |
| 走穩・**兩航向**各三回（含放手拍風向） | 「風向明顯改變，落點沒有跟著偏向同一邊。」（限定：本次精度與散布內） | **G2 之一** |
| 艙內盲測・兩筆未知船況 | 「只憑這碗水、這顆球，分不出停泊和走得很穩。」 | **G2 之二** |
| 雙紀錄 ＋ 滑桿完成 | 「兩張紙可以互相換算，差別在把什麼當作不動的。」 | **G4** |
| — | G5 不在實驗台產生；由**辯論 FR 的 trap 選誠實**產生 | **G5** |

**資料條件驅動的插話**（顯示於實驗台結果旁，不另開場景）：
- 只有走穩資料時 → 伽桑狄：「他那一趟不是走穩的。你還沒回答他。」
- 加速＋走穩齊備時 → **伽桑狄提出減速問題並要求封存預測**（見 §4 `C1-3`）
- 只跑同一航向多次時 → 水手：「風還是那個方向。你想問風，就得換邊。」
- 沒有岸標紀錄時 → 馬蒂厄：「這一筆我只能寫『未分類』。」

## §3.3 出口

實驗台常駐兩個出口：**「再跑一趟」**與**「上碼頭」**。上碼頭不需要證據齊全——不齊就會被問倒，然後回來。
