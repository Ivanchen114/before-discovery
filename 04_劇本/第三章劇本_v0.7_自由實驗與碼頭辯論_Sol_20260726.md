# 〇、本版定案

1. **玩家自由設計實驗**，不強迫先做一趟注定不完整的航次。
2. 原始數據不自動變成證據；資料達門檻後只浮出**候選斷言**，玩家仍須選對適用範圍。
3. 第一條實驗斷言成立後，玩家即可帶現有卷宗上碼頭試辯；若想一次完成，最低私下斷言為 A1／A2／A3／A6，第三柱另須兩張同步原紙。
4. 辯論可失敗、可主動撤回；數據、斷言、錯紙、質疑釘與已改寫支柱全部保留。
5. 艦長借船與船員，但不參與實驗、不看中途結果；他是終局主要對手。
6. 辯論只有三柱：**共同前行、前進與變速、參考物**。商人、槳手與群眾只穿插質疑，不另立支柱。
7. 不設木籌。
8. 不做往返風向實驗；封閉船艙只排除「甲板風是共同前行的必要原因」，不宣稱戶外風永遠無效。
9. 減速是補強路徑，不是過關必做。
10. 私下只取得兩張原始紙；**A4／A5 只在碼頭第三柱，當著群眾完成同拍對齊與逐拍換尺後成立。**
11. 艦長的舊紙不得補寫「加速中」；終局只補寫「船速未記；船況不能分類」。
12. 程式應服務劇本，不以現行辯論引擎只能出示單一證據為理由降階。

# 一、一頁總覽

## 案件

艦長有一張舊紙：

> **「解纜後第一段，石頭落在桅後。」**

這個觀察是真的。但它能不能代表所有正在前進的船？

## 三個最終觀念

| ID | 玩家最後能說的話 | 製作整理詞 |
|---|---|---|
| K1 | 石頭鬆手時，不會失去原先與船共有的前行 | 共同運動／慣性前行 |
| K2 | 船正在前進，與船速正在改變，不是同一件事 | 穩速與變速 |
| K3 | 同一事件可以相對碼頭或桅杆留下不同、但可互換的軌跡 | 參考物／座標轉換 |

## 主迴圈

> **設計實驗 → 取得原始數據 → 候選斷言浮出 → 選定適用範圍 → 收入卷宗 → 自選時機上碼頭 → 被指出缺口 → 帶質疑釘回船補實驗**

## 最短成功路徑

1. 走穩落石：門閂、船速紙、岸／船同步紙、三回。
2. 船艙：停泊與已證走穩並排。
3. 複製走穩方案，只改操作階段為解纜起步。
4. 讀懂艦長舊紙的射程。
5. 上碼頭完成三柱；第三柱現場對齊與換尺。

聰明玩家不必做減速、手放對照、停泊桅頂落石、不同重量或風向往返。

```text
n1  伽桑狄

n5  艦長（從裝貨箱底抽出一張皺紙）
```

## `C0-3` 先把舊紙說到剛好

**畫面**：舊紙特寫。可讀欄位只有「操作階段：解纜後第一段」「落點：桅後」；船速、放手、重複皆空白。

```text
n1  伽桑狄（把舊紙攤平）
    「先別替它補字。它現在到底能說到哪裡？」

c1  【choice ①｜舊紙的射程】
    A「它證明所有正在向前的船，都會把石頭留在後面。」
    B「它記到某一次落後；但沒有當趟船速，還不能代表所有船況。」 ✓
    C「缺了幾欄，所以這張紙是假的。」
```

**A 回應**

```text
伽桑狄（指船速空欄）
「『所有船況』是你添上去的。紙上沒有。」
→ 紙面留下刪線，回選。
```

**C 回應**

```text
馬蒂厄
「落在後面，是原來就寫著的。」

伽桑狄
「不完整，不等於沒有發生。」
→ 回選。
```

**B 成立 A6**

> **A6｜艦長的舊紙記到真實落後，但缺少當趟船速，只能保留為未分類紀錄。**

```text
n2  伽桑狄
    「船、放手、船速、記錄位置、做幾回。怎麼配，你決定。」

e1  【開放｜航船實驗卷宗】
```

> A6 是文件判讀，不單獨開放碼頭辯論。玩家至少須成立一條由自己實驗數據支持的斷言。

# 四、第二幕｜航船實驗卷宗

## `C1-LAB` 一張桌，不是八個工作台

主介面只有一張卷宗，兩個頁籤：

1. **桅杆落石**
2. **封閉船艙**

岸上紙／船上紙是桅杆落石的記錄方式，不另開第三個工作台。

## 桅杆落石設定

| 設定列 | 選項 |
|---|---|
| 操作階段 | 停泊／出港平駛／解纜起步／收槳 |
| 放手 | 手放／門閂 |
| 船況紀錄 | 不記／固定鼓點＋岸上逐拍船位 |
| 位置紀錄 | 只記相對桅腳／岸上＋船上同步紙 |
| 重複 | 一回／三回 |

同一顆石頭、同一高度預設鎖定。玩家可主動解鎖改動，但卷宗會標：

> **「同時改了第二項條件；不能與上一組作單變因比較。」**

每組完成後常駐：

> **「複製這組，只改一項」**

三回由系統連續演出，不要求玩家按三次。

## 封閉船艙設定

| 設定列 | 選項 |
|---|---|
| 船況 | 封存盲測：停泊／出港平駛由舵手抽籤，玩家事前不知 |
| 操作 | 艙梁門閂落下小石＋直上拋接軟球 |
| 對照 | 兩趟同操作；岸紙與船況結果拆封前不可見 |

艙門、窗關閉。舵手執行一趟停泊、一趟出港平駛，順序保密；艾蒂安照常在岸上依等拍記船位，馬蒂厄將船況紙與岸紙當場封蠟。玩家須先判讀艙內兩筆能否可靠分辨，再拆封驗證其中一趟確實走穩。不能用「聽起來很穩」替代岸紙。

## 每趟結果必須顯示

- 實際採用的設定。
- 原始落點與散布。
- 有記錄與未記錄欄位。
- 船況能否由當趟紙面分類。
- 與上一組相比改了幾項。
- 可否支持候選斷言；不能時，只說缺口，不顯示灰色答案清單。

壞紀錄不刪除。

# 五、數據結果與候選斷言

## `C1-R1` 手放資料

**條件**：任一船況，手放三回。

**典型結果**：散布較大，方向隨手勢改變。

```text
馬蒂厄（看三個落點）
「三次不是同一邊。」
```

候選 S1 浮出：

> 「手放混入了方向不一的額外推動。」

**適用範圍**

- A「所有手放都一定把石頭推向船尾。」
- B「在本組三次手放中，落點散布隨手勢改變；它不適合作為乾淨放手資料。」✓
- C「只要改用門閂，其他控制都不必記。」

選對成立：

> **S1｜本組手放資料混入額外推動，不能代替門閂資料。**

## `C1-R2` 沒有船速紙

**條件**：選了某種船況，但船況紀錄為「不記」。

```text
馬蒂厄（在欄位蓋章）
「這一筆只能寫『未分類』。」
```

卷宗不浮出穩速／變速斷言。玩家仍可把它帶去辯論，但艦長會釘回：

> 「你把旋鈕放在『走穩』，不等於紙上證明船走穩。」

## `C1-R3` 一回乾淨穩速

**條件**：走穩＋門閂＋船速紙＋一回。

候選只允許弱句：

> 「這一回，石頭落在桅腳附近。」

若玩家企圖擴張成規律：

```text
商人質疑釘
「一回可以是巧合。」
```

不另生成 S2。

## `C1-R4` 三回乾淨穩速

**條件**：走穩＋門閂＋船速紙＋三回。

**結果旁回話**

```text
艾蒂安（從岸上回報）
「桅杆每一拍走的距離，差不多一樣。」

水手
「鼓我照同一拍敲。」

馬蒂厄
「門閂是我抽的。三次都沒有人碰石頭。」
```

候選 A1：

> 「走穩時，石頭相對船落在桅腳附近。」

**適用範圍**

- A「所有向前的船，不論怎麼放手、怎麼變速，都落在完全同一點。」
- B「在同石、同高、門閂放手，且岸標確認走穩的三回中，落點集中在桅腳附近。」✓
- C「這證明地球正在運動。」

選對成立：

> **A1｜在本次可確認的走穩三回中，石頭落在桅腳附近。**

**第一次成立任何實驗斷言時**

```text
伽桑狄（把原始數據與斷言分放上下兩層）
「下面是發生過的事。上面是你準備拿它說的話。」
```

開放常駐按鈕：

> **「帶現有卷宗回碼頭」**

如果 A1 已成立但 A2 尚未成立：

```text
伽桑狄（點過門閂、岸標與三回標記）
「門閂、岸標、三回。」
（望向甲板上被風吹動的繩頭）
「甲板上的風還在。」
```

船艙頁籤亮起，但不自動切換。

## `C1-R5` 解纜起步・完整紀錄

**條件**：解纜起步＋門閂＋船速紙；已有 A1。設定畫面只顯示操作名；「正在變快」須由岸標紙判讀後才出現。

**結果**

```text
艾蒂安
「每一拍，桅杆走得比上一拍遠。」

馬蒂厄
「落點在桅後。」
```

候選 A3：

> 「解纜起步組由岸紙判為正在變快，並出現後偏；因此後偏不能代表所有向前船況。」

**適用範圍**

- A「艦長當年的船已經被證明一定在加速。」
- B「今天的加速組後偏，而走穩組近桅腳；後偏不能代表所有向前船況。」✓
- C「只要看到後偏，就能知道任何一次航程的完整船速。」

選對成立：

> **A3｜今天的加速組後偏；因此『後偏』不能代表所有向前船況。**

**條件短場景：舊紙找到鄰居**

```text
stage
「系統把今天的加速紙放在艦長舊紙旁。
 兩張紙方向相同；一張有船速，一張沒有。」

system
「可以比較，不能合併。」
```

## `C1-R6` 收槳補強

**開放條件**：A1、A3 已成立。玩家選做，不強制。

執行前封存預測：

```text
伽桑狄（把走穩與加速兩組並排）
「如果偏後和船正在變快有關，那船慢下來時，石頭會落在哪裡？」

c1  【choice ②｜減速預測】
    A 偏向船頭 ✓
    B 偏向船尾
    C 仍在桅腳

system
「預測已封存。收槳以前不能改。」
```

**結果**：船位逐拍縮短；落點偏船頭。

錯答不扣資源，預測原紙保留。

三種船況齊備後浮出候選 S4：

> 「加速後偏、走穩近中、減速前偏，形成三種船況指紋。」

**適用範圍**

- A「三種船況能反推艦長舊航次一定是哪一種。」
- B「本次三組只改船況，落點依序後偏、近中、前偏；可用來區分今天的三種船況。」✓
- C「所有船在任何風浪下都會留下完全相同的三點。」

選對成立：

> **S4｜本次加速、走穩、減速形成方向不同的船況指紋。**

## `C1-R7` 封閉船艙・封存盲測

**條件**：玩家選擇封存盲測；舵手秘密安排一趟停泊、一趟出港平駛，順序不公開。艾蒂安照常記岸紙，馬蒂厄封存船況與岸紙。

```text
stage
「艙門與窗關上。第一趟，小石從艙梁落下，軟球向上拋起；
 第二趟，兩個動作照原樣再做一次。船況紙在蠟封裡。」

旅人
「第一筆，石頭落在門閂正下方。球回到手邊。」

旅人（看第二筆）
「……一樣。」

c1  【choice｜只看艙內兩筆，能可靠分出哪一趟在走嗎？】
    A「第一趟在走。」
    B「第二趟在走。」
    C「只憑這兩筆，分不出來。」 ✓
```

選 A／B，兩張艙內紙留在桌上；伽桑狄只問：

```text
伽桑狄
「你用哪一個差異分的？」

system
「兩筆局部結果沒有提供足以辨認船況的差異。」
→ 回選，不拆封。
```

選 C：

```text
馬蒂厄（在兩筆結果旁寫）
「近乎相同。」
（停）
```

### P3-公開操作一｜同一時刻

兩張原紙在木板上同時展開。玩家選擇對齊方式：

- 各自終點
- 相同高度
- **同號鼓點** ✓

錯誤不立刻重置：

- 終點配終點：中間鼓號錯位。
- 相同高度：事件順序交叉。

錯誤透明紙留在木板側邊。群眾可看見錯在哪裡。

```text
艦長
「你把不同時刻說成同一時刻。」
```

第一次嘗試一種新規則不扣說服力；錯紙就是診斷。若玩家在錯誤已被指出後，仍重複使用同一規則，說服力 −1，並可選擇撤回。

正確後，A4 當眾成立：

> **A4｜同號鼓點把兩張紙鎖在同一事件與同一時刻。**

**中途離場與再入規則**：A4、A5 分開永久保存。若 A4 已成立而 A5 尚未成立，玩家再進第三柱時不重做對齊；兩張已對齊原紙與所有錯誤透明紙仍留在木板上。

```text
艦長
「鼓號已經對上了。剩下換尺。」
```

### P3-公開操作二｜把桅杆當作 0

玩家選擇：

- 全紙平移一次
- **每拍扣掉當拍桅杆的位置** ✓
- 旋轉紙張，直到彎線看起來垂直

錯誤：

- 固定平移：桅杆後續各拍仍偏離 0。
- 旋轉：鼓點順序與距離比例一起失真。

正確後，透明尺一拍一拍追著桅杆前移：

> `石頭相對桅杆(t) = 石頭相對岸(t) − 桅杆相對岸(t)`

岸上彎線逐拍換成船上近乎直落；垂直分量不被改動。

A5 當眾成立：

> **A5｜逐拍扣掉桅杆當拍位置，可把岸上紙改寫成船上紙。**

本段沿用同一失敗原則：新的錯誤規則先完整演出並留下紙痕；重複已被否證的規則才扣說服力。

```text
「原來不是誰看錯。是量的位置不一樣。」
```

> ~~同一顆石頭只能有一張真軌跡~~
>
> **同一事件可相對碼頭或桅杆留下不同、但可互換的軌跡。**

# 十四、點擊與手機原則

1. 實驗台一張卷宗、兩頁籤。
2. 每組三回自動演出。
3. 變更設定後，新方案處於「尚未執行」，不能沿用上一組結果成立新斷言；上一組原紙與既有斷言仍永久保留。
4. 「複製這組，只改一項」常駐。
5. 不顯示尚未解鎖的灰色斷言清單。
6. 候選斷言浮出後，由玩家點開並選範圍。
7. 辯論三柱順序自由；每柱之間可撤回。
8. P3 的兩個判斷連續呈現，但各自保留一次真正選擇；不增加「確認已確認」按鈕。
9. 最小可讀字級 16px；觸控目標至少 44px。
10. 不做五人下拉排班、不做器材尋物、不做逐拍點滿。
11. 手機橫屏須同時讀得到：當前質疑、可選原紙、斷言範圍與返回按鈕。

# 十五、物理與證據硬邊界

1. 走穩必須由固定時間間隔下、岸上每拍船位近乎等距證明。
2. 加速後偏、減速前偏；不得新增「維持前進的力」。
3. 手放資料不能支持乾淨落點斷言。
4. 一回只能描述這一回，不能支持重複性。
5. 船艙只回答普通、局部、短時間、近似直線穩速機械現象。
6. 船艙只排除甲板風是共同前行的必要原因；不得說戶外風永遠不影響落石。
7. 不以「船換向」推論相對風船首尾分量必然反向。
8. 舊紙是真實但未分類；今天的加速資料不能反證舊航次一定加速。
9. 岸紙轉船紙必須逐拍扣桅杆當拍位置；不能固定平移一次或旋轉。
10. 兩張原紙都保留。
11. 最終只排除一項反地動論證，不直接證明地球運動。
12. 不得由船艙結果擴張成「任何實驗永遠測不到運動」。

# 十六、歷史與戲劇邊界

1. 伽桑狄是歷史工作的主體；旅人協助設計與判讀，但不取代伽桑狄成為歷史發現者。
2. 1640／1641 的實驗日期歧異留在史實頁，不以戲劇日期消除歧異。
3. 加速、減速、封閉船艙與碼頭三柱是教學重構；不得聲稱歷史上的伽桑狄逐項依本流程完成。
4. 《對話》的船艙思想、伽桑狄的船上實驗與 1642 年出版關係須由史實頁分層標示，不偽造逐字史料。
5. 艦長、馬蒂厄、艾蒂安、官員與碼頭群眾為虛構或複合角色。
6. 港口官員追求清楚告示，不演成刻意誘惑學者的反派。
