  前兩句正是 `assets.json` 中 `evidenceVisual.GRID_BIMETAL.accessibleText` 的原文——**即被扣原紙的配置與觀測本身**。

- **檔案／函式**：`greybox/src/stage/03-focus-visual.part.js:231-236` 的 `resolveEvidenceVisual`——
  ```js
  var accessible = (rule.accessibleText || []).concat(
    variant && variant.accessibleText || []).concat(
    withheld && disposition.reason ? [disposition.reason] : []);
  ```
  `items` 有 `withheld ? [] : …` 的保護（`:241`），**`accessibleText` 沒有**；withheld 只做「追加一句理由」，不做「移除原內容」。
  消費端：`greybox/src/stage/09-notebook.part.js:124-130`（`evidenceReaderText` 逐句寫入 `<li>`，`:130` 只在清單為空時隱藏 transcript）。

- **玩家可見後果**：標題寫「內容暫扣」、圖片區空白，**下方文字版把被扣原紙的配置與觀測完整列出**。對使用讀屏的玩家更嚴重——他們拿到的是**全部內容**，而視覺玩家看到的是空白模板。**保護方向對依賴文字版的使用者是反過來的。**

- **修法（最小）**：在 `resolveEvidenceVisual` 讓 `accessibleText` 與 `items` 受同一個 `withheld` 閘門控制：
  ```js
  var accessible = withheld
    ? [disposition.reason]
    : (rule.accessibleText || []).concat(variant && variant.accessibleText || []);
  ```
  （若要保留可及性，可另加一句中性說明，例如「這張原紙目前不可讀；修復後恢復」。）

- **驗收條件**：以上述控制 state 取得 `GRID_BIMETAL` → 暫扣 → 斷言**四個入口都不含** `rule.accessibleText` 的任一原句；修復後四處同時恢復；`integrity.incidents` 與 integrity 類 records 仍在。**測試須斷言渲染輸出，不得只比對 disposition 欄位。**

- **狀態**：**已實攻**。

### 初審 B-1｜縮圖的暫扣保護由 `projectionOnly/neutralBase` 決定，不由 disposition 決定
