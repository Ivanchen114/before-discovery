## 一、這輪修的是什麼

使用者試玩指出六個同源問題：

1. 證據圖下方文字溢出、像卡在畫面中間。
2. 同一條件的三次重複要按三次，只有手指重複、沒有新決策。
3. 實驗與斷言之間缺少人物回應，像工作表完成後直接跳題。
4. 甲板落球、封閉船艙、岸上／船上雙視角之間缺少「為什麼下一步非做不可」。
5. 已做過的實驗不能重播；玩家看太快便無法回看。
6. 旅人筆記雖有證據圖，卻顯示「尚無實驗紀錄」；辯論也應把所有可用原紙攤開。

本輪採用的底層判準是：**重複測量保留三張原紙，但不要求玩家重複三次沒有新決策的點擊。**  
因此介面以「資料組」供玩家勾選，組內仍能展開逐張核對，沒有把三次平均成一個不可追溯的數字。

## 三、Runtime 行為

### 3.1 一鍵三回，三張原紙

- 解纜起步：一次操作產生 R1–R3。
- 出港平駛：一次操作產生 R4–R6。
- 封閉船艙：停泊與平駛各一次操作，各產生三張 C 紙。
- 每張紙仍保有 ID、船況、觀察位置、控制條件與結果；資料組可展開逐張查看。
- 天數依實際新增原紙增加；舊存檔只補欠缺張數。

### 3.2 同步雙視角只有一個事件

- 玩家先回答如何確保岸紙與船紙描述同一件事。
- 錯誤安排不產生資料、不增加天數。
- 正確安排要求同一趟落石、同號鼓點、岸船各一位觀察者。
- 執行後只新增一個同步事件 R7，內含岸紙與船紙兩個視角；天數只增加 1。

### 3.3 敘事鷹架

- A3 成立後：人物先質疑甲板風，再由玩家選擇如何隔離變因。
- 錯誤隔風安排不產生資料；正確安排後才出現船艙工作台。
- A2 成立後：人物指出兩張紙若不是同一事件便不能對帳，再由玩家設計同步雙視角。
- 斷言成功均由旅人公開說出有限範圍主張，相關 NPC 逐項核對條件，再顯示證據圖。
- 可見說話人仍統一為「旅人（你）」；讀屏依既有法源區分「旅人說」與「旅人心裡想」。

### 3.4 重播與筆記

- 工作台收卷後可立即重播個別原紙／同步事件。
- 旅人筆記列出資料組、原紙明細、證據圖、斷言與引用 ID。
- 筆記可重播已完成實驗；重播不呼叫實驗 action，不改天數、原紙、證據、斷言、信譽或事件帳。
- 真機驗收時曾發現：進入下一任務後，筆記重播會關閉筆記但看不到重播層。已把重播移到工作台共用層修正，並補契約測試。

### 3.5 辯論攤牌

- 每柱開始時，卷宗內所有可用原紙組都攤開。
- 每張卡含：證據縮圖、船況、觀察位置、固定／改變條件、能支持的範圍、所含原紙。
- 柱數沿劇情決定，不把「三柱」寫成通則。

### 3.6 圖像

- 本輪沒有新增生圖。
- 原因：既有 G1–G4／舊紙／船艙／雙視角圖已能準確承載本輪語意；本輪把它們補接到辯論卡與旅人筆記，避免為了「每張卡不同圖」另造不具新證據功能的美術。

## 六、請 Claude 對抗審

### A 面｜任一破壞即退回

1. 三回是否被任何一層平均、合併或失去原紙 ID？
2. 是否能用一張單次資料冒充三回資料組？
3. 錯誤隔風／雙視角安排是否可能產生資料或花天數？
4. R7 是否被算成三回，或岸紙／船紙變成兩個不同事件？
5. 重播是否能增加天數、原紙、證據、斷言、信譽或事件帳？
6. 舊存檔已有 1–2 張時，是否會重做成 4–5 張？
7. 斷言成功是否仍可能由 NPC 代玩家先說出結論？
8. 筆記或辯論是否存在「有 state.evidence、畫面卻看不到圖／原紙」的路徑？

### B 面｜契約與呈現

1. 資料組的條件、範圍與原紙明細是否一致？
2. 船艙兩組能否單獨誤成立 A2？
3. 轉場對白是否真的造成下一個玩家決策，而非只加一句解說？
4. 斷言回應是否由真正負責該觀察的 NPC 核紙？
5. 筆記重播是否在切到下一個任務後仍可見？
6. 辯論是否把所有可用材料攤開，且每張都有圖、船況、觀察位置、變因與能支持的範圍？
7. caption containment 是否同時守住證據焦點與工作台圖卡？

### C 面｜請獨立給判斷

1. 「一鍵三回」是否太快，需不需要短蒙太奇／逐張落紙節奏，但仍不增加點擊？
2. 筆記中的原紙密度是否應預設收合？
3. 現有圖是否已足夠；若判定要補圖，請指出它必須承載哪個現有圖無法表達的新證據功能。
