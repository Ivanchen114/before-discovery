# 二、獨立診斷

## 2.1 第一章不是沒存，是回饋失真

`回標題` 原本就同步執行 `save()` 再 reload。瀏覽器實測可續入原局；問題是首頁仍顯示「旅程起點」，沒有告知玩家「這是一份未完成存檔」。

修正後同時顯示：

- `旅程進度・第一章有未完成進度`
- `繼續第一章`
- `已自動儲存｜探索模式・第 N 天`

## 2.2 第三章的問題不是物理太難，而是每個銜接都被做成題目

舊流程把「共同運動、船況分類、缺少船速、同時刻、參考原點」分別再問一次。這些題有些是推論，有些只是橋接，但介面一律當成計分選擇，造成約十五次必要點選。

本輪把每個必按動作限制為四種之一：

- 選證據；
- 做新推論；
- 限定主張；
- 親手轉換。

只負責承接下一段的 bridge 改成台詞，不再偽裝成題目。

## 2.3 三柱的主要觀念

1. **共同前行**：船走穩時，石頭放手前已和船一起前進；封閉船艙對照用來排除甲板風。
2. **前進與變速**：有前進不等於正在變速；缺少船速記錄的舊紙只能標成船況不明，不能硬塞進走穩或變速。
3. **同石兩紙**：岸紙與船紙記的是同一事件、不同參考原點；先對齊同號鼓點，再把岸紙扣掉同拍桅杆位置。

岸紙與船紙的比較不是「再做一個實驗」，而是讓玩家親手發現：不同觀察者可以留下不同路徑，但經參考系轉換後仍描述同一事件。

# 三、施工內容

## 3.1 三柱由約十五步收斂為八步

| 柱 | 新的必要動作 | 認知支付 |
|---|---|---|
| 第一柱 | 選走穩紙 → 選封閉船艙對照 | 選證據、排除風的干擾 |
| 第二柱 | 選變速紙 → 收舊紙邊界 → 限主張 | 選證據、限主張 |
| 第三柱 | 選同步雙紙 → 對齊鼓點 → 改用桅杆原點 | 選證據、做轉換 |

已從 active UI 移除的重複小考包括：

- 石頭是否自己追桅杆；
- 是否只有風持續推才會前進；
- 逐張重做走穩／變速／舊紙分類；
- 兩張紙比較前先選「同一時刻」；
- 再選一次「兩張紙的起點不同」。

舊 API 與 flags 保留給舊存檔；新 UI 不再呼叫。

## 3.2 證據卡漸進揭露

第一層只顯示：

- 證據圖與短標題；
- 船況／觀察位置；
- 最多能支持什麼。

`查看條件與原紙` 才展開固定、改變、缺口與原紙編號。所有可用材料仍同時攤開，沒有藏掉選項。

## 3.3 章別備忘

- Ch1／Ch2：保留既有辯論備忘與可選的「問到底」。
- Ch3：新增「碼頭辯論備忘」，明說三問不是三次小考。
- Ch4：保留「軌道與出版備忘」；不是三柱辯論，不硬套。
- Ch5：保留「兩本帳辯論備忘」。

「問到底」不是全系列強制按鈕；只有存在可拆的隱藏前提時才使用。Ch3 本輪的核心支付是選紙、收邊界與換算。
