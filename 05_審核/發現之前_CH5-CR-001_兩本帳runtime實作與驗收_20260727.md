## 二、對抗驗收後修正

### 1. 工作台焦點保留

瀏覽器實走發現：checkbox 狀態會保留，但下拉與 checkbox 在 DOM 重繪後會把焦點掉回 `body`。

已改為用 `data-c5-focus` 明確回復焦點。實測：

- 下拉重繪後：焦點仍在 `SELECT[data-c5-focus="clayHeight"]`；
- checkbox 重繪後：焦點仍在 `INPUT[data-c5-focus="record-8"]`；
- 十筆勾選狀態均保留。

### 2. 辯論柱軌順序

辯論引擎已依 P2→P1→P3 運作，但柱軌曾固定顯示 P1→P2→P3，造成介面與實際順序不一致。

已讓 `pillarSummary` 直接依 `chapter.order` 生成，並加回歸測試。

### 3. 未查證史實不得進 runtime

史實卡曾以「待查證／未採用」標籤顯示達朗貝爾未核定的版次措辭；即使是否定式展示，仍違反「不得寫進 runtime 文案」。

已整列移除，並把「達朗貝爾」「用詞之爭」加入第五章 runtime lint。's Gravesande 只保留黏土落球的歷史主線，不寫裝置規格。
