起始信譽固定為 3。五章現在都能靠**三種不同的研究失信**自然歸零，同一種錯誤重試不再扣：

| 章 | 三種可累積失信 |
|---|---|
| 第一章 | 把未來答案說成大家都知道；拿未來物理學換現場權威；偽稱量過垂直落下 |
| 第二章 | 未讀砲術圖就宣稱舊規律必然適用；把低速短程外推到遠砲；把未測高空寫成已證明 |
| 第三章 | 舊紙未記平穩卻先說結論；宣稱量到地球運動；把走穩結果外推到變速船況 |

- 每章自然到零後呼叫正式路由，必須進本章 repair scene。

## 三、Claude B-2｜修復是一次邊界判讀，不是「繼續」按鈕

第三至五章修復場現在各有三個選擇：

| 章 | 正確修復 | 兩個錯誤逃避 |
|---|---|---|
| 第三章 | 撤回超過原紙的斷言 | 丟掉不完整原紙／把知道的答案補進空欄 |
| 第四章 | 撤回越過來源的署名與機制結論 | 抹掉來源／把缺失機制補成既成結論 |
| 第五章 | 撤回權威與單一帳結論 | 只留動量帳／只留活力帳 |

常駐測試逐章驗：

1. 從非首節點自然歸零。
2. 保存 `returnScene + returnNode` 後序列化／反序列化。
3. 兩個錯選都保持 0、保持鎖定、回到同一判讀題。
4. 正確撤回才 `+1`、清除鎖定。
5. `return` 回到精確原節點，不退化成場景首節點。

## 四、信譽存檔已升級為可重播事件帳

`sanitizeReputationLifecycle()` 現在從初始值 3 重播整條信譽歷史：

- 每筆 `rep.from` 必須等於前一筆 `rep.to`。
- 每筆 `to` 必須等於套用 delta 並經 0–5 夾制後的結果。
- 重播終值必須等於 `state.rep`。
- 降到 0 的負向事件後，下一筆必須是同來源 `repLock`。
- `repairEnter` 當下必須確實處於 `rep=0 + locked`，且發生在該次歸零鎖之後。
- 修復 `+1` 後才可 `flagClear(repLocked)`。
- 目前旗標的鎖定狀態必須與事件帳重播結果一致。
- 現行新增來源的 `reason` 必須存在且與來源相符；少數 ADR 前已能寫入的舊來源，只允許「缺 reason」的窄相容，不接受任意理由。

第三章舊 `oldPaperScoped` 合法存檔仍保留精確例外：可接受當時已有 `choice→flag`、尚無 rep event 的真實舊形狀；只有空旗標或偽事件仍拒絕。

新增的反例會紅：

- 真實第二章 `3→2` 改成內部算術仍合法的 `5→4`。
- 刪掉現行首次失信事件的 `reason`。
- 五章任一章直接把初始 state 改為 `rep=0`，卻沒有事件與鎖。
- 偽造合法返回游標與 `repairEnter`，但沒有此前的扣至零與鎖定。

## 五、快取真相｜瀏覽器必須真的載到這次修改

`tools/build-stage.mjs` 現在：

- 解析單引號與雙引號。
- 允許 `src` 位於其他 script 屬性之後，例如 `<script defer src="…">`。
- 改寫所有 `src/`、`data/` 本機 JavaScript 為內容 SHA-256 前 12 碼。
- 五個 HTML 入口逐一驗證每個本機 script 的雜湊，而不是建置器與測試共用同一個漏檢正則後一起假綠。

- `<script defer src='src/chapter-ui.js'>`
- `<script data-role="boot" defer src="data/scenes.js?v=stale">`

舊解析器會讓這兩例失敗；現行建置與驗證都能辨認。

## 九、請 Claude 只做這八項定點複審

1. **自然可達**：逐章用正式 API，確認五章各由三種不同失信從 3 到 0；不得先改 state。
2. **同錯防刷**：每個新增來源連做兩次，第二次仍有回應但不扣。
3. **修復代價**：第三至五章兩個錯選皆不得回補／離場；正選才回 1 並返回精確原游標。
4. **事件帳**：把真實 `3→2` 改成 `5→4`、刪 reason、造 `rep=0` 無鎖、造 repairEnter，四類都必須被 sanitizer 拒絕。
5. **舊存檔**：第三章合法舊 `oldPaperScoped` 形狀放行；空旗標與偽 choice／flag 時序拒絕。
6. **C-3 語意**：確認新選項只是「我看不出」，紙仍在案且沒有 rep；repair 的「乾脆整張不算」則仍是錯誤逃避。
7. **快取反向性**：把任一入口改成單引號或 `defer src` 並拿掉／改壞雜湊，測試必須紅。
8. **多真相**：README、design index、ADR、ch3/ch4 稿與 runtime 的數字／審查狀態不得再互相矛盾。

請仍以 A／B／C 分級，每條附位置、可重現證據、直接修法與會失敗的驗證條件。本候選自評是 **A=0、B=0**，但不以自評取代獨立審查。
