## 結論

**完整第一章內部版成立，但不得凍結；做一次外科修正後再驗。** 主線已能由標題走到 end，存檔、實驗、E4、三支柱、最後反撲、修復迴路、章末回顧與史實頁均已接通；`npm test` 為 **40 通過、0 失敗**，完整探索模式瀏覽器路徑亦通過且主控台無 error／warning。

阻擋凍結的是兩個程式契約 A 級：探索模式沒有取得 E3.c 卻能用它完成終辯；禁詞白名單的 class 不是封閉列舉，任意字串可讓測試維持全綠。另有劇本審稿的物理條件與史實揭露 A 級已原樣進入 runtime，須與本輪一起修，但不在此重複計為新程式缺陷。

## 2. A 級問題

### A-1｜探索模式以未取得的 E3.c 通過最後反撲

**位置**：`data/debate.js:143-209,227`、`src/narrative.js:217-224,293-321`、`src/chapter-ui.js:293-317`。

**重現步驟**：

1. 開探索模式，完成第二幕必經實驗；合法狀態為 E3.a=true、E3.b=true、E3.c=false，畫面顯示 `E3:a●b●c○`。
2. 進辯論並破三根支柱。
3. 最後反撲仍問「傾角一路變陡，形狀變過嗎」，選「沒有」即可前進；收束宣稱「從最緩到最陡……一字未改」，最後授予 E5。
4. 辯論出示表單也無條件列出 E3.c，即使 c 尚未取得。

**因果**：玩家沒有做過變傾角複驗，卻被允許把 NPC 提供的前提當成自己的證據；違反憲章二、三，也破壞「狀態是唯一事實來源」。40/40 全綠反而證明目前黃金路徑把矛盾固化了。

**最小修補**：

- E3.c 改為兩模式共同必經；探索模式給預選配置＋一次引導複驗，學者保留自由配置。
- `debatePresent`／FR 的引擎入口在 E3.c=false 時拒絕使用跨傾角論證；UI 只列已取得的 E3 子項。
- 新增負向測試：E3.c=false 不得開啟或完成 FR；探索黃金路徑進辯論前須斷言 c=true。

### A-2｜R-NAR-05 白名單可用任意 class 名稱繞過拓撲守衛

**位置**：`tests/narrative-suite.js:62-95`、`data/scenes.js` 的 lint whitelist、GB-ADR-006。

**可驗證反例**：測試只在 `class === "post-reveal"` 時檢查 `afterPlayerNode`；任何其他字串（包含錯字）只要有 `reason` 就通過。現行 `pre-discovery` 也沒有被驗證為合法列舉，更沒有指向後續玩家反駁節點。

**因果**：「刪台詞機器化」無法證明受控例外真的受控；後續章節只要 class 拼錯，NPC 洩題仍會顯示 40/40 全綠。這是憲章核心防回歸工具，不宜以人工默契補洞。

**最小修補**：

- class 封閉為 `character-hypothesis`／`post-reveal`；未知值測試必敗。
- `character-hypothesis` 必填 `reason`、`refutedBy`，且 `refutedBy` 必須指向可達的玩家驗證／反駁節點；不得套用於 system 正典結論。
- `post-reveal` 必填存在且位於前方的 `afterPlayerNode`；把目前 `pre-discovery` 資料遷移到正式列舉。

## 3. B 級問題

### B-1｜引擎沒有完整驗證「玩家是否持有被出示的證據」

`debatePresent` 只對 E3.b 的正解查狀態，E1／E2／E4／S1／S2 主要依 UI 篩選；竄改存檔或未來另一個呼叫端可直接把未持有證據送入純函式邊界。最小修補是建立單一 `ownsEvidence(state, evidence, subitem)`，UI 與引擎共用語義；未持有時回錯且不改 state，並加負向測試。

### B-2｜高塔場地 q2 仍是假選擇

`site=wall/tower` 被寫入但後續未消費，兩條都演鐘樓。依劇本審稿 B-1，讓 site 至少改變場景文本／代價／見證可信度，或刪 q2 由敘事直接決定場地。

### B-3｜壞檔備份後沒有告知玩家

`src/chapter-ui.js:21-29` 會備份 `_corrupt` 並移除原存檔，但標題頁只像從未存檔。保留備份策略，增加一次性非阻塞提示；補 parse error 與 schema mismatch 測試。

### B-4｜兩處重複輸出破壞收束質感

- `data/debate.js:211` 的 trap prompt 已含「辛普里奧」，`src/narrative.js:259` 又以辛普里奧 speaker 包裝，實機顯示「辛普里奧：辛普里奧（逼近一步）……」。
- `data/scenes.js` 的終點節點已有「第一章 終」，`src/chapter-ui.js:426-429` 又追加一次。

移除資料內 speaker 前綴，並讓 end 只由一個來源輸出。

### B-5｜缺少 trap 雙重歸零的常駐測試

應固定一條：進 trap 前說服力=1、信譽=1，選 lied 後同時觸發辯論中止與 SC-R1；修復、離場、再入後須仍停在 FR，能選 honest 並完成。這條是兩個系統咬合的最高風險交界，不能只靠相鄰黃金路徑推定。
