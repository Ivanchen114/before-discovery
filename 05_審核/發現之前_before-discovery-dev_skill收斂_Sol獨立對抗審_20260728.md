## 二、B 級

### B-1｜canonical 仍是第二份規則正文，且已發生語意漂移

**位置**

- canonical 第 11–12、50–62、99–109 行。
- `01_治理/發現之前_雙人共用工作守則_v0.1.md` 第 5、130–132 行。
- `02_設計/發現之前_工作台與辯論架構_一二章實證規格_v0.1.md`「終局形式不限於三追問」。

**實際看到**

共用守則明定「skill 只保留索引與開工儀式，不再複述內容」，但 canonical 的 §三與 §4.6 仍完整複述 16 條跨章規則。漂移已經發生：§三流程把終局普遍寫成「辯論台（三追問）」，原法源卻明定第四章是出版校樣，終局不限三追問。

**為何是問題**

這正是本次收斂要消除的雙來源問題。即使每句最初都抄對，只要法源更新，skill 仍會再次落後。

**直接修法**

- §三改成「工作台／證據／終局」的法源索引與勾讀清單，不重述條文；明指該規格 §七的終局例外。
- §4.6 改指向《設計原則手冊》H 節 31–41、《第一至第四章收官與後續章節製作基線》§十、工作台規格與對話框化規格，不在 skill 複製數值與 CSS 做法。

**可驗證條件**

- skill 中不再把 `三個追問`、`state.evidence`、`max-width:900px`、`最小可讀字級`寫成第二份規則。
- 所有操作判準都能由「精確路徑＋節號」回到單一法源。

### B-2｜多條硬規則尚未落法源，另有一條與現行基線衝突

**位置**

- canonical 第 20 行：把「A=0、B=0 才放行」歸給共用守則 §3-2。
- 第 77–78 行：archive 絕對禁改、只插不刪／結構重排必 schema bump。
- 第 88 行：契約必須反向轉紅、行為正確但無測試一律 B。
- 第 108 行：全域最小可讀字級 16px。

**實際看到**

1. 共用守則 §3-2 只有 A／B／C 定義，且保留「有條件放行」；沒有 `A=0、B=0` 的全域數值門檻。該門檻目前只在本輪 CH3／CH4 交接與審查報告中成立。
2. schema 句來自 ch3 純增拍與 ch4 結構重排兩個個案，尚未成為跨章通則。
3. 反向轉紅是正確且有價值的教訓，但目前只有實作／審查紀錄，尚未落入共用測試法源。
4. 「archive 一律不改」未說清楚「歷史內容不可竄改」與「舊提案須加作廢 banner」的邊界。
5. 現行跨章基線 §十是「重要說明不得低於 12px、正文原則上 14–16px 以上」，skill 直接升成全域 16px，已成另一套門檻。

**為何是問題**

skill 正在替總監完成尚未作出的跨章裁決；日後可能誤擋合法施工，或把章別個案當成全系列 schema 規則。

**直接修法**

- 尚未裁決者先從 skill 移除規範語氣。
- 若總監要立為通則，將「反向轉紅」「何時必須 schema bump」「archive 的不可竄改邊界」寫入共用守則或專門測試／存檔法源，附事故來源；skill 只留索引。
- `A=0、B=0` 若只適用本輪，就留在本輪交接報告；若要全域化，先修改共用守則 §3-2。
- 字級只索引現行基線 §十，不在 skill 自訂第二組數值。

**可驗證條件**

每條規則旁的路徑與節號都能 grep 到同義明文；不能只指向程式範例、事後審查報告或 Claude 的經驗摘要。

### B-3｜本檔不能原封同步給 Codex：角色會被改寫成 Claude

**位置**

- canonical 標題與 frontmatter description。
- §4「Claude 專屬事項」、§4.1「我的角色」、§4.4「寫給 Sol」。
- Codex 現行生效版為角色中立的開發守門。

**實際看到**

新 canonical 同時宣告自己是全專案唯一 skill canonical，卻含「我的角色＝劇本主筆」「第一、二章出自我」「寫給 Sol」等 Claude 第一人稱指令。若直接覆蓋 Codex 生效版，Sol 會被要求把自己當成 Claude，破壞共用守則的分工與獨立對抗審。

**直接修法**

採兩層結構：

1. `SKILL.md` 保持 agent-neutral，只放共同開工儀式與精確法源索引。
2. Claude 專屬角色、轉達格式與個人慣犯另放 Claude overlay／帳號層；Codex 保留自己的角色層。

若堅持目前檔案只供 Claude 使用，則必須把它明確命名為 Claude-only canonical，並停止要求 Codex 生效版與它全文同步。

**可驗證條件**

- Codex 安裝候選全文不得含「我的角色＝劇本主筆」「第一、二章出自我」「寫給 Sol」。
- Claude 與 Codex 共用段落可由同一 repo 檔產生，但角色 overlay 不互相覆蓋。

## 三、C 級

**驗證**：把索引路徑抽出逐一 `test -f`，應為 23／23。

### C-2｜交付檔的正文 diff 驗證法少算兩行

交付寫「canonical 去前 4 行、鏡像去前 8 行」，實跑不相同；鏡像另有分隔線。正確比較是 canonical 自第 6 行、鏡像自第 12 行。

### C-3｜兩種 canonical 的語意混在一起，設計索引也尚未同步

canonical 第 9 行的意思是「本檔是 skill 套件的 canonical」；第 11–12 行的意思則是「各 repo 法源才是規則 canonical」。應把兩種層級寫清楚，並索引《第一至第四章收官與後續章節製作基線》§二的法源優先序。
