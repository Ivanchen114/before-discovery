# A 級

## A-1｜ch1 的三個候選主張重演語域不對稱（修訂稿 §1-3）

修訂稿的三個候選：

| | 文字 | 開頭／收尾 |
|---|---|---|
| ✓ | 「這一趟**只能說**木球落後；重量和材質一起換了，**還不能說**是哪一項造成。」 | **兩個限制詞** |
| ✗ | 「木球比較輕又落得慢，這一趟**已經證明**重量決定快慢。」 | 斷言＋「已經證明」 |
| ✗ | 「木球和鉛球的差別來自材質，重量**已經可以排除**。」 | 斷言＋「已經可以排除」 |

**正解對沖、錯項斷言——這正是三把尺的第一把要擋的東西**，也是 ch3 這一輪花了整輪修掉的缺陷。修訂稿 §1-3 結尾寫「正解不是靠『只／所有』等插旗詞」，但它的正解**開頭就是「只能說」**。

而且「已經證明」「已經可以排除」與 ch3 被判掉的 `height-causes-offset` 原句「這三艘船**已經證明**是高度造成的」是同一個詞。

**修法（比照 ch3 的平行句型，四句同一句型、只差範圍）**：

- ✓「這一趟寫在落點上：木球落後。至於是重量還是材質，這一趟分不出來。」
- ✗「這一趟寫在重量上：木球輕，落得慢，快慢由重量決定。」
- ✗「這一趟寫在材質上：差別出在木頭和鉛，跟重量無關。」

三句都是「這一趟寫在＿＿上」。正解的正確性**不在語氣謙虛，而在它明說了『分不出來』**——那是內容，不是姿態。

## A-2｜「旅人替玩家說正解」是共用程式路徑，不是 ch1 的個案（雙方都漏）

`narrative.js`：

```
:343   say(state, "旅人(你)", CH.fr.trap.honestText);    ← ch1 的 FR trap
:414   say(state, "旅人(你)", CH.fr.claim.honestText);   ← ch2 的 claim
```

三個後果：

1. **ch1 的 A 級範圍被低估。** 修訂稿把 ch1 的 A 級定在 `nB2–nB5`（場景層）。但 ch1 的 FR trap 在 `:343` **也**讓旅人自動說出誠實版本——同一個代理權缺陷，在同一章的另一個地方，而且在引擎層。修訂稿 §四-1 的定案句「`nB3` 只是其中一項」仍然漏了它。
2. **ch2 的病灶比修訂稿描述的更重。** 修訂稿寫「錯後由系統替玩家改口」。實際上不是系統旁白，是**掛在「旅人(你)」名下**——與 ch1 `nB3` 完全同型，應同級（A），不是「可信度不足」。
3. **治理結論要改。** 修訂稿 §〇 寫「一章一張 CR，不得包成跨章 CR」。這條對**內容**成立，但 `:343`／`:414` 是**共用引擎行為**，不屬於任何一章的凍結基線。

# B 級

## B-1｜錯答後錯項會消失，而且錯誤訊息自己講出方向（修訂稿未列）

`narrative.js`：

```
:406   if (d.fr.overTried) return { ... error: "誇大的回答已被駁回——只能回到證據邊界" };
:557   .filter(function (o) { return !(CH.fr.enemy && d.fr.overTried && o.id === "over"); })
```

- `:557`：答錯一次之後，**錯項從選單消失**。選單縮短本身就是答案——而且玩家再也無法重新提交。
- `:406`：錯誤訊息寫「只能回到**證據邊界**」，**把正解的方向講出來了**。

**這一項直接衝擊修訂稿 §2-3 的擴選項計畫**：兩個錯項若都照 `:557` 過濾，第二次作答時選單只剩正解一項。

**我建議的修法比修訂稿 §2-4 更省**：

> **不要過濾，讓玩家可以再次提交同一個錯誤主張。**

三個好處一次到手：
1. 洩答消失（選單長度不變）。
2. **不需要任何 per-option 狀態，因此不需要存檔 schema 遷移**——修訂稿擔心的那件事直接不存在。
3. 符合「玩家必須親自選擇縮窄或撤回」：反覆提交同一句話而對手每次都指回同一欄，比「不准你再說」更像辯論。

信譽代價由既有 penalty 承擔即可，不必用「移除選項」當懲罰。

## B-2｜ch1 兩個錯項是同一種錯誤，第二個接近裝飾

修訂稿的兩個錯項都是「多因共變卻歸給其中一項」——歸給重量、歸給材質。方向相反，**推理錯誤同型**。玩家只選一個，所以第二個錯項幾乎不承擔教學功能。

建議把其中一個換成**不同型**的錯誤，覆蓋率立刻變兩倍而成本不變。最自然的是從單趟外推：

- ✗「這一趟寫在所有輕的東西上：輕的落得慢。」（n=1 推全體）

這樣三個選項覆蓋：**混淆歸因／過度推廣／守住邊界**，而且過度推廣正是 ch2 `claim` 要考的東西——ch1 先遇到輕量版，ch2 才在辯論台上考，符合「要求升級」。

## B-3｜ch4 的空槽標籤本身就是洩答，刪文案救不了

修訂稿把「SVG 初始狀態」列為洩答之一，但沒解決一個內在張力：

**若 SVG 全程顯示一個標著「引力如何穿過空間」的空槽，那個標籤就是答案**——它告訴玩家這一格注定填不滿。刪掉 `chapter-ui.js:4667` 的那句話沒有用，因為圖還在說同一件事。

但反過來把槽整個藏起來，玩家會不知道版面還缺什麼。

**建議**：槽保留可見、**標籤中性化**（例如「末句」或「未定」），玩家提交後才把它命名為「引力如何作用｜未決」。**命名是獎勵，不是提示。**

請 Sol 確認該槽的標籤是寫在 SVG 生成碼裡還是文案裡——這決定它算 UI 文案還是視覺層工作。

## C-2｜ch2 三個候選有一個字的洩答

- ✓「這條規律**寫在**這批低速、短程的紀錄裡……」
- ✗「這條規律**寫到**砲彈的射程裡……」
- ✗「這條規律**寫到**星辰的路上……」

**「寫在」＝它住在這裡；「寫到」＝它伸到那裡。** 這個動詞差異本身就是答案。三句應統一同一個動詞。

# 四、逐項回答 Sol 的四個問題

## Q1｜ch1 三個候選是否都由眼前資料長出來？正解是否守住「觀察可留、因果未定」？

- **`nB2` 的修法我完全同意，而且它修的是物理誠實問題，不只是台詞。** 原句「這數據不能用」是錯的：這筆觀察能支持「這一趟木球比鉛球慢」。你的替換句「這一趟能記，但還不能回答是不是重量造成的」精確，建議直接採用。

- 「歸給材質」那一項有一個額外優點修訂稿沒寫出來：**它正是伽利略自己在 `nB4` 的立場**（「我會說是密度」）。所以玩家選它不是笨，是站在伽利略那一邊——**這是很好的時代盲點,值得在史實頁點出來。**

## Q2｜ch2 兩個錯項是否仍有真誘惑？「戰場」「星辰」是否踩史實或提前洩漏第四章？

**戰場：安全且誘惑充足。** 辛普里奧 `p1s3` 已經先嗆過「桌上實驗高不到一尺也敢比戰場」，玩家有動機反擊。彈道學也確實是當時真正的爭議應用。

**星辰：兩個問題，第二個必須寫進 CR。**

1. **史實歸類**：伽利略本人**沒有**把拋物線推到天上——他對天體仍持圓慣性。所以「桌緣到天上同一條數學」是**現代玩家的自然衝動，不是當代盲點**。依 §三新訂的邊界，它屬於「符合當時器材與知識的**教學重建**」，**可以做，但章末史實頁必須說明**這一點。不寫就違反自己的法源。
2. **這一項不會洩漏第四章，但駁回的措辭可能植入錯誤物理。** 第四章要建立的正是「同一條律管地上與天上」。所以 ch2 駁回這句話時：
   - ✅ 只能駁**證據**：「你手上只有桌緣到一丈的紀錄。星辰那一段，你量過嗎？」
   - ❌ 不能駁**內容**：不得出現「天上的事和桌上的事無關」「天體不遵守同一條規律」這類句子。
   → **這一條建議寫成 CR 的硬邊界**，因為它是四章之間最容易互相打臉的一處。

**附帶一個好處**：這樣安排之後，玩家在 ch2 被擋下的那句話，會在 ch4 被真正兌現。這是全系列到目前為止最漂亮的一條伏線，值得刻意保留。
