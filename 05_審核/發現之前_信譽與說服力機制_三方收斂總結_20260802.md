## 二、三方立即共識（可直接排入 P0，本輪不需總監裁決）

### 1. 「說服力」改名為「論證對位」，純文字改動，不動底層機制

- **問題**：三方一致認為「說服力」這個名字名不符實——它扣的是「證據配對是否咬住主張」，不是口才或角色魅力，但名字暗示後者，與本作「不評價物理對錯、只認證據」的核心主題錯位。
- **解法**：改名為**「論證對位」**（借用第二章 B3-F／n3 伽利略自己的台詞「剛剛亂的不是手，是對位」——非外加新詞）。UI 顯示為「論證對位｜4/5」，並在 tooltip 明確說明：「看證據有沒有咬住主張；配錯會退回，歸零先複盤。」
- **範圍**：只改 UI 標籤與 2–4 處 system 節點文字（ch1 A3-1／n4、ch2 B3-1／s1、ch5 E3-1 補述說明），底層 `persuasion` 欄位、`debate` effects 與 `debate5.json` 完全不動。
- **為何不做更大規模的改動**：codex 原提案主張連 ch1/2/5 都應換成敘事內物件（書籤頁／邊頁批註／聽證位置）取代說服力顯示；claude 反對，理由是（1）會與 ch3/ch4 真正的「守門人實物」概念層混淆——同一章不該同時存在兩種「對手手上的東西」；（2）ch1/2/5 已通過台詞審查（A=0），任何 UI 換皮都是一次不必要的回歸風險。**codex 最終同意此為合理的成本／風險取捨**，接受「論證對位」改名作為本輪唯一動作。

### 2. 章節之間不應被迫使用同一種壓力機制

- 有正式辯論的章（一、二、五）保留「論證對位」的局部攻防節奏。
- 沒有正式辯論的章（三、四）改用**已經寫在劇本裡、只是還沒接上機制**的守門人實物：
  - **第三章**：維達爾船長的簽名欄（台詞已有「沒弄清楚以前，別把我的名字寫上去」）。
  - **第四章**：哈雷的印刷空檔（台詞已有「這個月，只剩兩個能開印的空檔」）。
- 兩者都是 **UI only**（讀取既有 claim 狀態渲染成畫面元件），不需要新台詞、不需要新機制邏輯。

### 3. 拒絕 emoji 與抽象數值符號，一律用時代內材料呈現狀態

- 已錨定＝墨跡已乾；懸置＝未拆的蠟封／空欄／頁角問號；越界已撤回＝那一行被劃掉但仍留在紙上（不是刪除，錯誤要留痕，這是全作最重要的倫理，第三章木板掛滿退件、第四章錯稿釘牆、第五章空框不補數字都是同一原則的既有實例）。
- 三方一致否決 gemini 原提案的 🔒⚠️❌ emoji 標籤——本輪台詞審查花了大量篇幅清除現代術語，emoji 是更強烈的當代介面符號，會直接砸掉時代質感。

## 三、三方原則性共識，但需要總監裁決才能排入實作（範圍較大，會影響存檔／引擎）

### 裁決 1｜信譽是否應該從「數字」改為「可作證／暫停作證」兩態？

三方都認為現行信譽數字（3、+1、−1……）不夠精確：它把「一般推理錯誤」和「研究誠信違規（越界斷言、隱去反證、拿權威代證據）」混在同一個扣分池，但這兩者性質完全不同——前者是能力問題，後者才是本作真正在乎的倫理問題。

- **建議**：信譽收緊為單一條件——「是否留有未修復的越界主張」，只有兩種狀態：可作證／暫停作證。玩家一般答錯不扣信譽，只消耗當章的局部壓力（論證對位／簽名欄／校樣空檔）；只有越界斷言、隱匿反證、拿權威代替證據才會觸發信譽暫停，修復後立即恢復。
- **成本**：這會動到 `rep` 的顯示邏輯與既有 system 節點的扣分理由（目前有些節點是「一般答錯」卻同時扣 rep 和 persuasion，需要重新分類）。**不是純文字改動，需要總監確認是否值得做。**
- 若不做：現狀（信譽數字+說服力/對位數字並存）仍然可玩，只是精確度較低，錯誤類型沒有被清楚區分。

### 裁決 2｜要不要正式建立「主張帳本」（claim→evidence→status→repair）這個底層契約？

codex 提出、claude 部分採納的統一資料模型——把玩家每個重要主張都記錄「連結了什麼證據」「目前狀態（待查/已錨定/越界/已修復）」「這份證據不能證明什麼」「修復時劃掉了哪句、補了什麼」。

- **好處**：能一次解釋「懸置頁」（二→三、四內、五末的封存預測）、「錯誤留痕」（各章已有的木板/錯稿/空框機制）、「信譽暫停/恢復」三件事，不用三套各自為政的邏輯。
- **成本**：這是引擎層重構，且應該**延後到內容凍結之後**才做，不要在台詞還在修的階段動這個。
- **建議的做法**：先不重構引擎，只在最需要驗證複雜情況的**第五章**試作（因為它同時有兩本帳、三問辯論、雙重扣分與修復場，最容易暴露契約缺口），驗證後再決定要不要推廣到其他章。

### 裁決 3｜第三、四章要不要也加一個獨立的「局部失誤容限」數字？

三方一致建議**不要**。簽名欄與校樣空檔本身就是壓力來源，且性質跟論證對位不同（一個是「證據夠不夠」，一個是「攻防有沒有失手」）。再加一個數字只會把非辯論章硬改成辯論章，重演第三章曾經出現過的「清單感」問題。

## 五、討論過程中的重要更正（供總監參考，避免重蹈覆轍）

1. **「第三章起說服力消失」最初被三方各自解讀為「死碼」或「刻意簡化」，但都不完全準確。** 真正的原因是終局形式輪替，說服力附屬於「正式辯論」這個形式，不是逐章遞減的設計語意。這也提醒我們：日後遇到「某機制在某章消失」的疑問，應先查證是形式替換還是真正移除，不要只看某一章的資料就下結論。
2. codex 的原始提案（全系列拿掉說服力）在得知第五章數據後主動修正立場；claude 的原始提案（守門人實物取代說服力）也在同樣的資訊下修正為「守門人實物只補在沒有辯論的章節，說服力保留在有辯論的章節」。**兩次修正都是三方在取得更完整程式碼證據後主動調整，不是被說服，這個過程本身值得記錄，作為未來設計討論的參考範例。**
