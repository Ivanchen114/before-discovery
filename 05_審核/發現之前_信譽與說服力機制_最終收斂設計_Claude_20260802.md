# 《發現之前》信譽／說服力機制・最終收斂設計

**作者**：Claude（獨立評審，三方收斂版）
**日期**：2026-08-02
**性質**：設計提案，待總監裁決。基於五章台詞審查（全章 A=0）與三方獨立方案收斂。
**前提**：第一、二章已審定且評價良好，第五章終局形式剛以 A=0 通過——**任何方案不得以重寫這三章的終局為代價**。

---

## 一、對另兩案的批判

### Gemini「知識論帳本」

**該採納的：**

1. **「懸置」是本作真正缺的第三態。** 現行只有「取得證據／未取得」兩態，但劇本裡明明有大量**已封存、尚未驗證**的東西：第二章 F1 船桅待驗預測（明寫「它還不是實驗紀錄」）、第四章 D1-1 切線來源紙與 D1-2 抽屜裡那個問號、第五章 EE-2 的空框。這些目前只靠散文註記維持，玩家看不到它們「懸在那裡」。這是 gemini 最大的貢獻，**我採納**。
2. **「玩家親手劃掉越界的話」把懲罰變成動作。** 這與我的「守門人物件」、codex 的「repair」是同一個直覺：可感知的後果應該是物理動作，不是數字遞減。**我採納**，而且本作已經有現成範例（SC3-R1「把那句收回到紙上真的有的欄位」、SC4-R1「把超過來源的署名與機制結論劃掉」）——不是要發明，是要把它升為正式狀態轉移。

**行不通或有風險的：**

1. **🔒⚠️❌ 這三個 emoji 標籤必須否決。** 我們五章審查花了大量篇幅清除玩家可見的現代術語（run／勾選／配置／賭注／玩家／第X章）。emoji 是比那些更強烈的 21 世紀介面符號，會直接破壞本作最珍貴的資產——時代質感（蠟封、鉛字、夾籤、港務簿、版框）。**同樣的三態必須用時代內材料表達**：已錨定＝墨跡已乾／懸置＝蠟封未拆／越界＝被劃掉的那一行。
2. **廢除所有分數會抽掉全系列唯一的縱向連續量。** 信譽是唯一跨五章、跨 150 年的東西，也是「這個世界只為證據付費」有牙齒的原因。標籤描述的是**主張的狀態**，不是**旅人的處境**——一張卡被劃掉，什麼東西被帶到下一章？沒有。這會讓系列失去脊椎。
3. **廢除分數也一併廢掉了失敗閘門。** 現行 `信譽歸零 → SC-R1…SC5-R1` 修復場是全作最好的設計之一（「在這座城市，道歉不用嘴。用一次乾淨的紀錄。」）。沒有分數，什麼觸發它？「累積 N 個 ❌」就是換了皮的分數。
4. **與凍結章衝突。** 第一、二章有大量寫得很好的 rep 理由與 system 節點；拔掉信譽等於重寫它們。

### Codex「claim→evidence→status→repair 統一契約」

**該採納的：**

1. **契約框架本身是兩案中最強的單一想法。** claim → evidence → status → repair 把五章各自土法煉鋼的東西寫成一台狀態機，讓同一套引擎／UI 服務全章，是真正的實作紅利。**我採納它作為內部模型**（但不採納「統一 UI 呈現」，見風險 2）。
2. **把信譽嚴格限定為「研究誠信」是真正的收斂。** 現行 rep 被用來扣好幾種不同的罪；收緊成單一件事（你有沒有把話說得超過你的紙）才可教、可預期。**我獨立提出過同一收緊**（「從『別人多信你』收緊成『你說過的話有多少還查得到底』），兩案在此匯流，建議直接定案。
3. **每章「主張缺口」物件**與我的守門人物件是同一件事，方向一致。

**行不通或有風險的：**

1. **拿掉說服力現在已被證明是錯的——而且證據是 codex 自己找到的。** 第五章 E3-1 實際在跑 `debate:init` / `until:{debateWon:true}` / `debate:reenter`，`debate5.json` 存在（9,041 bytes），UI 有 `說服力：X/5` ＋ `●●●○○` ＋ 規則 tooltip。codex 發現了這個事實卻推出相反結論。**刪掉說服力＝重寫第五章終局形式，而它剛以 A=0 通過。** 這是不必要的高成本。正確的解讀是：說服力不是遺留血條，是**辯論形式的子機制**，隨形式輪替出現（辯論→辯論→公開驗證→印刷台→辯論）。
2. **單一統一契約有壓平終局形式輪替的風險。** 五章之所以不同，主要就靠終局形式不同（架構 §七 的輪替承諾）。若每章都用同一套 claim→status UI 呈現，第三章的碼頭公開驗證與第四章的印刷截止會失去各自的體感。**契約應該留在引擎層當內部模型，不要浮到 UI 層當統一介面。**
3. **「status」列舉值有可能取代現在寫得更好的散文。** 本作每張證據卡都用散文寫清界線（「它支持…；它不支持…」），這比任何 enum 都精確。status 只能當索引，不能取代那些句子。

## 二、最終收斂設計

### 核心原則

> **一條縱貫的誠信線、一個隨形式出現的當場計量、一件每章可被收回的實物、一種看得見的懸置狀態——全部用時代內材料呈現。**

四個層次各有唯一職責，互不重疊：

| 層 | 名稱 | 職責 | 範圍 | 呈現 |
|---|---|---|---|---|
| L1 | **信譽** | 研究誠信：你有沒有把話說得超過你的紙 | 全五章唯一縱向量 | 既有數值＋修復場 |
| L2 | **說服力** | 當場攻防氣勢 | **僅辯論形式章**（一、二、五） | 既有量表＋tooltip（已足夠） |
| L3 | **守門人實物** | 對手可以不給你的東西 | **僅非辯論章**（三、四） | 常駐的空欄／可消耗的格 |
| L4 | **懸置頁** | 已封存、尚未驗證的主張 | 跨章（二→三、四內、五末） | 未拆的蠟封／空欄／問號 |

**關鍵取捨**：L2 與 L3 **互補而非並存**——有辯論的章用 L2，沒有辯論的章用 L3。這正好填掉現行設計中三、四章「中段小失誤無手感」的洞，且不動任何已通過的章。

### 信譽（L1）語義收緊

扣分只留一種條件：**主張超出手上的紀錄**。其餘（答錯物理、實驗配置失敗、選了較差的研究策略）一律不扣。
- 這與五章現況大致相符（第一章 nA4「把沒有證據的未來答案說成大家都知道的事」、第三章「把還沒有原紙支持的答案當成事實」、第四章「說出了結論，卻拿不出…證據」、第五章「拿前輩的名聲替代可驗資料」）——**多數 rep 理由已經是這條，只需逐條校對用語**。
- 修復場維持不變（它們已經是 L1 的正確出口）。

### 各章具體設計

#### 第一章《重物的渴望》（1590–1604，終局＝三支柱辯論）
- **L1 信譽**：既有。僅校對 rep 理由用語（P0-2／nA4 等）。
- **L2 說服力**：既有（A3-1／n4 已說明規則）。**不動。**
- **L3 守門人實物**：辛普里奧臂彎裡那冊《物理學》。劇本已有完整動作語彙（夾書＝權威／翻夾籤＝引經據典／翻頁停半空＝被擊中／合上書＝不再躲進引文／把數據紙夾進書帶走＝新證據進了舊典籍）。**建議維持敘事層，不上 UI**——本章已有 L2，加 L3 會重複施壓。
- **L4 懸置**：E5 外推論證鏈附「垂直未直接量過」。可標懸置，但非必要。
- **淨改動：文字校對，零程式。**

#### 第二章《第一寸的弧線》（1608–1609，終局＝三支柱辯論＋FR）
- **L1／L2**：同第一章，不動。
- **L4 懸置（本章是關鍵）**：**F1 船桅待驗預測是全系列最標準的懸置件**——劇本明寫「它還不是實驗紀錄」、辛普里奧說「運河裡有的是船。做過，再來告訴老夫」。應在筆記中以**未拆的蠟封**呈現，並一路帶到第三章。
- **淨改動：F1 的筆記呈現（UI，一種視覺狀態）。**

#### 第三章《船艙裡的靜止》（1640，終局＝公開驗證，無辯論）
- **L2**：無（正確）。
- **L3 守門人實物＝維達爾船長的簽名欄**。劇本已完全寫好：C0-2／n7「沒弄清楚以前，別把我的名字寫上去」、C3-1／n2「我的船，只替今天真的量過的事作證」、n3 他只簽岸上核對過的欄。**做法**：畫面邊緣常駐一個空白簽名欄，全章可見；玩家每完成一項可核對的條件就填上一格；船長只在程序走完後落筆。**不需新台詞，台詞已存在。**
- **L4 懸置兌現**：第二章那個未拆蠟封在此被拆開驗證（C1-1 起）。另外本章自己的懸置件是**舊紙上那個空白的船速欄**——C3-1／n5 船長親手補寫「船速沒記，這一趟不能判斷船況」，這已經是 L4 的完美示範，只需讓它在 UI 上看得見。
- **淨改動：常駐簽名欄（UI）＋懸置狀態顯示（UI）。零引擎、零新台詞。**

#### 第四章《月亮的無盡墜落》（1665–1687，終局＝印刷台校樣，無辯論）
- **L2**：無（正確）。
- **L3 守門人實物＝哈雷的印刷空檔**。劇本已寫：D4-2／n2「這個月，只剩兩個能開印的空檔。稿子一旦進了版框，再改就得整頁重排」。**做法**：兩格可消耗的空檔常駐可見，用掉一格就劃掉一格，並保留「錯稿與延後紙全釘在牆上」（n17 已有）。**這是全作最自然的成本計量**——它可逆但有代價，與血條相反。
- **L4 懸置（本章是最長弧）**：D1-2 那個「憑什麼從地心量？」的問號進抽屜，**懸置二十年**，到 D4-2 才由球殼定理（命題 LXX／LXXI／LXXIV）解決。這條弧應該在筆記裡看得見整整二十年。
- **淨改動：兩格印刷空檔（UI）＋懸置頁（UI）。零引擎。**

#### 第五章《碰撞守恆》（1740，終局＝院士三問辯論）
- **L1／L2**：既有，**不動**（UI 的量表與 tooltip 已比一、二章更完整）。
- **L3**：**不加**。杜佩院士的帳本雖然有同樣的質感（他最後把帳本留在桌上不帶走），但本章已有 L2，再加會重複。
- **L4 懸置＝EE-2 的空框**，全系列最後一個懸置件，交棒給續作。
- **淨改動：零（除台詞審查已列的 B／C 項）。**

### 呈現規範（取代 emoji）

| 狀態 | 時代內呈現 | 禁止 |
|---|---|---|
| 已錨定 | 墨跡已乾、頁緣壓平 | 🔒 |
| 懸置 | **未拆的蠟封**／空欄／頁角問號 | ⚠️ |
| 越界並已撤回 | 那一行被劃掉，但仍留在紙上 | ❌ |

第三條特別重要：**越界的話必須留在紙上被看見，不能消失**——這是本作反覆建立的倫理（第三章木板掛滿退回與畫錯的紙、第四章錯稿全釘在牆上、第五章空框不補數字）。

## 三、需要總監裁決的問題

1. **信譽是否收緊為「僅主張超出紀錄」單一扣分條件？** 影響五章 rep 理由用語校對（純文字）。我建議：是。
2. **L3 守門人實物要不要上 UI，或維持敘事層？** 這是本案唯一的主要成本驅動因子。我建議：**只有第三、四章上 UI**（那正是缺回饋的兩章），第一、二、五章維持敘事層。
3. **L4 懸置狀態是否需要引擎欄位，或可由既有證據資料衍生顯示？** 我建議先試「顯示層衍生」，避免動 save schema（第四章已升 schema 2，再升成本高）。
4. **emoji 是否確認禁用於玩家可見文字？** 我建議：明文禁用，寫進文字四律。
5. **第一、二、五章的終局形式是否確認不動？** 我建議：確認不動（三章皆已通過審查，第五章剛 A=0）。

## 四、實作優先順序

| 階段 | 內容 | 成本 | 風險 |
|---|---|---|---|
| **P0** | 信譽 rep 理由用語校對；第五章 E3-1 補一句與 UI 呼應的場面話 | 純文字 | 極低 |
| **P1** | 第三章常駐簽名欄、第四章兩格印刷空檔（讀既有狀態，不新增狀態） | UI only | 低 |
| **P2** | 懸置頁視覺狀態（F1 蠟封、地心問號、空框） | UI only，若能衍生則零引擎 | 中（需確認可衍生） |
| **P3** | codex 的 claim→evidence→status→repair 契約**下沉為引擎內部模型**（不改 UI 呈現、不改各章體感） | 引擎重構 | 中高——**建議延後到五章內容凍結之後再做** |
| **不做** | 刪除說服力／廢除信譽／統一 UI 呈現／emoji 標籤 | — | 會破壞已通過的章 |

**建議先做 P0＋P1**：那已經足以補掉三、四章「中段沒有手感」的洞，且全部不動引擎、不動已通過的章。P2 視 UI 可衍生性再定，P3 留到內容凍結後。

## 五、一句話

**信譽留下並收緊、說服力留在有辯論的章、守門人實物補在沒有辯論的第三與第四章、懸置狀態用未拆的蠟封而不是 emoji——這四層本作大半已經寫在台詞裡，缺的只是把其中兩件接上 UI。**
