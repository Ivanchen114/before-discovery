# 《發現之前》信譽／說服力機制收斂方案

**提案者**：Codex
**日期**：2026-08-02
**狀態**：供總監裁決，可直接轉成機制規格

## 一、核心裁決

### 1. 不保留兩條抽象分數；保留兩種不同功能

- **信譽**不再是可加減、可累積、可拿高分的貨幣，改為「研究誠信資格」：只看玩家目前是否留有**未修復的越界主張**。
- **說服力**不再是跨章能力，也不再顯示成角色魅力血條；但第一、二、五章確實需要它目前承擔的功能：**正式辯論中的局部失誤容限與暫停節奏**。這個功能應保留，改由章內物件呈現。
- 全系列真正統一的不是 UI，而是資料契約：

```text
主張 claim
  → 連結證據 evidenceLinks
  → 狀態 status：待查／已錨定／越界／已修復
  → 邊界 boundary：這份證據不能證明什麼
  → 修復 repair：玩家親手刪改哪一句、補回哪份來源
```

### 2. 我修正原提案，但不因「活碼」就替現況背書

我撤回「全系列直接刪除說服力功能」的 blanket proposal。第五章已確認 `debate:init → persuasion:5 → penalty → debrief/reenter` 是可達流程，說明第一、二、五章的正式辯論確實需要一個局部壓力迴路。

但「它是活碼」只證明它不是遺留碼，**不證明「說服力 4/5」是最佳呈現**。我的修正是：

> 保留局部辯論失誤容限，移除抽象魅力分數語意；保留底層 `persuasion` 欄位作相容層，畫面改呈現對手手上的具體物件與被駁回的紙。

### 3. 三種錯誤必須分流，不能一律雙重扣分

| 玩家行為 | 主張狀態 | 章內壓力 | 全域信譽資格 |
|---|---|---:|---|
| 證據配錯、推理尚未接好 | 不變，留下失手紀錄 | −1 | 不變 |
| 誠實說「還不知道」 | 待查 | 不扣 | 不變 |
| 把證據說得過大 | 越界 | −1 | 暫停，直到修復 |
| 拿權威、名聲代替資料 | 越界 | −1 | 暫停，直到修復 |
| 親手劃掉越界句並重接證據 | 已修復 | 重入／重置 | 恢復 |

普通答錯不是人格污點；只有研究誠信違規才碰全域信譽。這是現行「同一錯項同時扣說服力與信譽」最需要拆開之處。

## 二、對另外兩案的取捨

## Gemini：「知識論帳本」

### 最值得採納

1. **把判定附著在主張，而不是附著在人格。**「這句話越界」比「你失去一點信譽」精確，也更符合全作證據倫理。
2. **修復要由玩家親手完成。**劃掉過滿句、保留錯誤痕跡、重新接回證據，能把失敗變成可讀的推理歷史。
3. **帳本可跨章累積。**它能自然回答「旅人到底學會了什麼」，而不必靠總分敘述成長。

### 行不通或有風險

1. **`❌` 容易把「證據不足」誤讀成「物理為假」。**本作最重要的差別正是「未證」不等於「錯」。建議用「越界」或「超出這份紙」，不要用紅叉當真假判決。
2. **全部廢除局部壓力，辯論會退化成無成本試配。**第一、二、五章需要對手真的能中止當日辯論，否則玩家只是在反覆點選直到成功。
3. **三種標籤若每一步都要求玩家操作，會重演第三章的清單病。**標籤應由行為結果自動落在紙上；只有修復越界時才要求玩家親手劃改。
4. **「已錨定」不能等於永遠正確。**它只代表「目前這句有指定證據支撐，且沒有超出邊界」，後續新資料仍可迫使改寫。

## Claude：「守門人手上的東西」

### 最值得採納

1. **把壓力變成世界內物件。**辛普里奧把書闔上、船長不簽名、哈雷失去校樣窗口，比抽象扣點更有戲，也讓五章各有手感。
2. **不同章型不必硬套辯論血條。**第三章是程序審查，第四章是出版與來源管理；兩章本來就不該顯示說服力。
3. **對手的利害仍在場。**守門人物件能避免 NPC 在實驗中段退化成提示者。

### 行不通或有風險

1. **「對手可以不給你」若成為規則來源，會把證據裁決退回權威裁決。**物件只能呈現已發生的 claim/evidence 判定，NPC 不能任意否決一份合格證據。
2. **每章自創一套資源會增加教學與程式成本。**五個物件若各有不同扣法、恢復法、存檔法，玩家每章都要重學，工程也會長出五組例外。
3. **在第一、二、五章同時保留說服力血條與守門人物件會重複計量。**應該是同一個局部壓力值的兩種表示，不是兩套規則。
4. **「活碼所以應保留」推論太快。**應保留的是辯論暫停／複盤／重入的節奏，不是「說服力」這個抽象名稱與雙重扣分。

## 三、最終收斂版：一套契約、兩種章型、五種物件

## 全系列共用層

### A. 主張帳本

每個重要主張都存：

```js
{
  id,
  text,
  status: "pending" | "anchored" | "overreach" | "repaired",
  evidenceLinks: [],
  boundaryText,
  repairText,
  history: []
}
```

畫面文字建議：

- `待查`：預測已留下，證據未到。
- `已錨定`：有指定資料支撐；可翻看「不能證明什麼」。
- `越界`：這句超出所附資料；不是宣告物理錯誤。
- `已修復`：原句保留刪線，旁邊顯示玩家改寫。

### B. 信譽資格

不再顯示 `信譽 3`、`+1`、`−1`。由主張帳本推導：

- **可作證**：沒有未修復的越界主張。
- **暫停作證**：至少一條越界未修；不能完成當前公開主張，但仍可實驗、閱讀、整理。
- 修復後立即恢復；錯誤歷史留在筆記，不永久懲罰後續章節。

低成本過渡期可保留 `state.rep`，但只作舊存檔相容與觸發 repair scene，不再當玩家可見分數；新規則的 source of truth 必須逐步移到 claim status。

### C. 章內壓力 encounter pressure

只有正式辯論章使用。底層可暫留現有 `state.debate.persuasion`，但 UI 不再寫「說服力 4/5」。

```js
{
  type: "debate" | "audit" | "publication",
  capacity: 5,
  remaining: 5,
  gateObject,
  rejectedClaims: [],
  resetOnRepair: true
}
```

正式辯論答錯：被駁回的紙留在桌上，章內物件關閉一格；歸零後暫停、複盤、重入，已站住的支柱不消失。

## 第一章：辛普里奧的《物理學》

- **章型**：正式辯論，保留局部失誤容限。
- **物件呈現**：辛普里奧的書頁有五枚頁籤。每次把不相干證據推給一項主張，他抽掉一枚頁籤；錯紙留在該主張旁。
- **越界處理**：旅人直接搬出未來答案或把單次結果說成普遍定律，該句進帳本標「越界」，信譽資格暫停。
- **歸零**：辛普里奧闔書，辯論暫停；玩家回到桌邊，親手劃掉過滿句、補上適用條件，再重開書。已破的論證支柱保留。
- **不可做**：不能因一般證據配錯就扣全域信譽。

## 第二章：辛普里奧的批註頁

- **章型**：正式辯論，沿用第一章同一組件，降低重學成本。
- **物件呈現**：不是另一條新血條，而是《物理學》邊頁的五個批註位置；證據咬不住主張時，辛普里奧在邊頁留下一筆反駁。
- **主張帳本**：軌跡、射程、同高落地各自顯示來源與限制；思想實驗引導不當作獨立證據。
- **歸零／修復**：批註滿頁後暫停；玩家把「知道的答案」退回可由墨跡、沙盤、落點支持的句子，再回場。
- **一致性**：程式仍可共用 ch1/ch2 現有 debate component，只換物件皮膚與文本。

## 第三章：船長的簽名欄

- **章型**：程序審查，**沒有說服力／capacity**。
- **物件呈現**：維達爾船長的簽名欄。風、船況、雙參考物紀錄三項尚未錨定時，欄位保持空白；不是 NPC 任性不簽，而是卷宗缺件一眼可見。
- **錯誤後果**：舊紙被說得過大時，過滿句留刪線；加速、減速、穩速的爛圖留在卷宗，玩家從圖上修正。
- **完成條件**：三項程序各自 `anchored`，且公開主張沒有 unresolved overreach，船長才簽名。
- **不可做**：不能把三項程序另做三點「說服力」，否則又回清單感。

## 第四章：來源袋與校樣窗口

- **章型**：證明／出版審查，**沒有說服力／capacity**。
- **物件呈現**：牛頓的來源袋承載 claim status；哈雷的校樣窗口保留為真正的生產資源。
- **邊界**：虎克來信、切線預測、月距重建、球殼命題各自帶來源與不能證明之處；作者欄與信用分配也是主張的一部分。
- **校樣窗口只因玩家主動送出／延後而消耗**，不能把一般答錯也算成出版時間流失；否則會把閱讀理解錯誤誤裝成世界內時間。
- **修復**：越過來源的署名或機制結論被劃掉，退件仍夾回檔案；修復後才能送完整校樣。

## 第五章：杜佩的兩本帳

- **章型**：正式辯論，保留現行三問、暫停、複盤、重入；這是說服力功能最有價值的一章。
- **物件呈現**：桌上五個「聽證位置」或五枚帳頁夾，取代 `說服力 5/5`。證據配錯時，該紙被杜佩退回並留在對應問題旁；位置少一格。
- **錯誤分流**：
  - `same-thing` 這類推理錯誤：只減章內位置，不扣信譽。
  - 抹掉黏土坑、隱去活力短少、拿名聲代資料：標為越界／壓掉不利證據，信譽資格暫停。
- **歸零**：杜佩闔帳，杜夏特萊主持複盤；玩家把被駁回說法與 J1–J3 重新配對，改寫後重入。三個已過問題保留。
- **終局**：J4 只在兩本帳都留下且完整去向仍懸置時錨定；不得用章末文字偷補成「變成坑與溫度」。

## 四、需要總監裁決的問題

### 裁決 1｜「說服力」名稱要不要留在 UI？

**建議：不留。**底層欄位可留作相容；玩家只看書頁籤／批註／聽證位置。名稱若保留，玩家會誤以為在練話術，而非讓證據咬住主張。

### 裁決 2｜全域信譽是否還要有數字？

**建議：不顯示數字，最終移除數值語意。**過渡期可保留 `rep` 供舊存檔與 repair gate；正式規格改為「可作證／暫停作證」兩態，來源是 unresolved overreach。

### 裁決 3｜一般答錯是否扣信譽？

**建議：絕不。**一般推理錯誤只消耗章內辯論容限；只有越界、隱去反證、權威代證據才碰研究誠信。

### 裁決 4｜`已錨定／待查／越界／已修復` 是否全部讓玩家操作？

**建議：不。**狀態隨行為自動落在紙上；只有「修復」要求玩家親手劃改。否則知識論帳本會變成新的表單。

### 裁決 5｜第三、四章要不要補一個局部失誤容限？

**建議：不要。**簽名欄與校樣窗口已提供足夠壓力，而且壓力來源不同；再加五格只會把非辯論章硬改成辯論章。

## 五、實作優先順序

## P0｜先定資料契約，不先重畫 UI

1. 定義 claim status、evidenceLinks、boundary、repair history。
2. 定義事件分類：`mismatch`、`overreach`、`authority-substitution`、`repair`。
3. 寫測試鎖：
   - 一般配錯只減 local pressure，不改全域資格。
   - 越界必生成可修復 claim，未修前不能完成公開主張。
   - 修復保留原句刪線與歷史，不直接刪除錯誤。
   - 章內壓力歸零不刪證據、不重打已通過支柱。

## P1｜先改第五章，驗證最複雜情況

1. 保留現有 `persuasion`、三問、debrief/reenter 程式骨架。
2. 把扣分 reason 分成 mismatch 與 integrity breach，移除普通錯答的 `rep:-1`。
3. 將畫面 `說服力 X/5` 換成兩本帳旁的五個聽證位置。
4. 將 EE-2 越界章末改成懸置問題，驗證 claim repair 能貫穿到章末。

第五章同時有兩本帳、三問、雙重扣分與修復場，先做它最能暴露契約缺口。

## P2｜抽出共用辯論 adapter，套回第一、二章

1. 共用 local pressure、拒絕紙、暫停、重入、已破支柱保留。
2. ch1/ch2 只換 gateObject 皮膚與文字，不各自發明新狀態機。
3. 把現有錯項逐一分類；只有真正越界才影響信譽資格。

## P3｜第三、四章只接狀態，不重做玩法

1. ch3 簽名欄讀取三項 audit claim 是否 anchored。
2. ch4 來源袋／作者欄／校樣送出讀取 proof claim 狀態。
3. 不新增說服力 meter；現有簽名與校樣 UI 作為 adapter。

## P4｜存檔遷移與教學驗收

1. 舊 `rep` 映射：有鎖定修復場者→`suspended`，其餘→`clear`；不得用舊分數憑空授予已錨定主張。
2. 舊 `debate.persuasion` 保留到當前辯論結束，之後由 encounter adapter 接管。
3. 教師／測試輸出應能看見：主張原句、所附證據、越界原因、修復句、重試次數；不要只輸出最後信譽值。
4. 真人驗收問題：玩家能否說出「我錯的是哪一句超過哪張紙」，而不是只說「我掉了一點」。

## 六、最終一句話

> **全系列只共用「主張如何被證據錨定、越界後如何修復」；辯論章保留局部失誤容限，非辯論章用簽名與校樣承載壓力。信譽不是分數，說服力不是人格，兩者都只是證據流程的結果。**
