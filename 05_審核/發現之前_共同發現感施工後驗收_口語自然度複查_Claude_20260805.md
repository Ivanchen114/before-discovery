## 一、總裁決

# 有條件放行

**六個深讀場景裡，五個的核心目標達成了，而且第三、四章的施工品質很高。**沒有任何一項需要退回重寫。

但有 **1 項 A 級**必須在下一輪修掉，而且它正是本輪施工**引入**的：

> **第一章 `A2-2/n2` 刪掉了「押第五段」的指令，但工作台仍要求押記，後文 `qOdd` 又引用了「押記」。玩家會在工作台被要求做一件人物從沒交代過的事，然後聽伽利略談論一個他不知道自己下過的注。**

另有一個**跨章模式**值得單獨提出，因為它幾乎是本輪施工的簽名：**本輪新寫的句子系統性地帶進分號**，而唯一被刻意保留、一字未改的第五章，是六章裡**唯一分號與半形標點都為零**的一章。這不是巧合——分號是「一句話同時交代動作、理由與邊界」的症狀，而新句子都在試圖一次講完太多事。

**先確認一件大事**：我上一輪指出的 A 級缺陷（`engine4.js` 把月球 60 秒偏折寫死成等於地表 4.9 m）**已徹底修好**：

```js
var TEACHING = { earthRadiusRatio: 60, moonDistanceEarthRadii: 60,
                 earthRadiusKm: 6371, moonPeriodDays: 27.3, surfaceOneSecondFallM: 4.9 };
function moonSagM(seconds, fixture) { ...
  return radiusM * 2 * Math.pow(Math.sin(halfAngle), 2); }        // engine4.js:97-103
sc.moonOneSecondSagMm = round(moonSagM(1) * 1000, 2);             // engine4.js:1215
```

`2r·sin²(πt/T)` 是精確正矢式（數值上比 `1−cos` 更穩），週期真的進了計算。而 `D1-2/n12` 更進一步：把 60 秒放大寫成「約四點八八公尺」而**不是** 4.9——等於在台詞層公開承認月球 60 秒偏折不等於地表 1 秒落距。**這是本輪最誠實的一個數字，也是這條修法真正落地的證據。**

#### A-1｜`A2-2/n2` 刪掉押記指令，但工作台與後文都還在要求它

| | |
|---|---|
| **檔案／位置** | `greybox/data/scenes.json` → `A2-2` → `n2`（`speaker: 伽利略`） |
| **原句** | 「工具都在這了。球、槽面、傾角、計時——怎麼配，你決定。**先做出四段站得住的數字，第五段先蓋住。紙帶出來後，我們各讀一遍；哪裡不同，就把兩種讀法並排。**翻開後，才知道這條規矩能不能往前說中。」 |

| **為何更像伽利略** | 他的性格是「先動手、把賭注講明」（`A2-1/nb4`「滾多久、滾多遠,全寫在木槽上」）。原句把三件事（做四段、蓋第五段、各讀一遍）擠成一段，還承諾了一個不會發生的協作動作；替換句只留玩家馬上要做的兩件事，而且「壓在蠟下」與 `qOdd` 的「押記」對上了。 |

#### B-1｜`A2-2/n3`「逐段核水量」只在三個計時器中的一個成立

| | |
|---|---|
| **位置** | `scenes.json` → `A2-2` → `n3`（伽利略） |

### 第四章

**共同發現感六章最強**，但句子最密。

#### B-5｜`D1-1/ok1c` 旅人像在唸定義

| | |
|---|---|
| **位置** | `scenes4.json` → `D1-1` → `ok1c`（旅人） |
| **前一句** | `ok1b` stage：「牛頓在同一張圖上點出一秒後的實際月球位置。切線端點在外，實際端點略向地球偏；兩點之間留下一道極短的空隙。」 |
| **原句** | 「**切線端點**是沒有向內作用時會到的地方**；實際端點相對它**朝地球偏移。兩個**端點**之間的差距，才是這一秒裡向內作用留下的量。」 |
| **後一句** | `ok1d` 牛頓：「（把直尺貼上兩個端點，另畫一條短線）月亮一面向前，一面離開原來的直線。這個差距可以算。」 |
| **具體問題** | 三個「端點」、一個分號、「相對它朝地球偏移」是圖說語言不是說話語言。`ok1b` 剛剛才用同樣的詞把同一件事描述完，`ok1c` 等於把 stage 的文字換人再唸一次；`ok1d` 又用「一面向前，一面離開原來的直線」講第三次。**同一個概念在三個連續節點被講三遍，其中兩遍用術語、一遍用人話。**<br>另外 `n5` 旅人「所以，沒有拉扯時，月亮會照原來的方向走，不會自己沿圓弧」是第四遍。 |
| **最小替換句** | `ok1c`（旅人）：「**這裡是它不被拉的話會到的地方，這裡是它真的到的地方。**中間這一小段，就是這一秒被拉走的量。」<br>並把 `n5` 刪去或縮成一句反應（例：旅人「所以圓不是理所當然的。」）。 |

## 五、跨章共通問題

只列在三章以上重複出現的模式。

### 跨-1｜本輪新寫的句子系統性帶進分號，而唯一沒改的第五章是唯一乾淨的

角色台詞（不含 stage／system、不含 legacyOnly）的分號分布：

| 章 | 分號總數 | 本輪新句帶進的 |
|---|---:|---|
| 第一章 | 9 | `A2-2/n2`（改寫句） |
| 第二章 | 22 | `B2-3/p1`、`B1-2/na2`／`s1` |
| 第三章 | 13 | — |
| 第四章 | **39** | `D1-1/ok1c`（新增）、`D1-2/n10`（新增） |
| **第五章** | **0** | — （**本輪未改**） |
| 第六章 | 9 | `H3-1/a1b`（新增）、`H1-1/n4`（改寫）、`HE-1/joint`（新增） |

**這不是標點潔癖問題。**分號在這些句子裡都在做同一件事：把「動作＋理由＋邊界」壓進一口氣。`ok1c`、`n10`、`a1b`、`n4`、`n2` 五個本輪新句全部如此。而第五章之所以零分號，是因為它用**換手**取代了壓縮——杜夏特萊說「不要。」，動作交給 stage，理由留到下一句。

**這是本輪最值得帶進下一輪的一條方法**：新句子若出現分號，先問「這是不是兩個人該分說的兩句話」。

### 跨-2｜同一個結論在連續二到四個節點被反覆講

三章可證：

- 第二章 `B2-3`：邊界主張在 `p1`、`n4` 連說兩次（同一位說話者）；控制變因聲明在 `s3`、`p2`、`n6` 三次
- 第四章 `D1-1`：向內偏折的定義在 `ok1b`（stage）、`ok1c`（旅人）、`ok1d`（牛頓）、`n5`（旅人）四次
- 第二章 `B2-4`：`q4/a` 玩家剛選的判讀被 `n3` 伽利略整段重述

**成因是可辨識的**：施工為了確保「玩家有說出關鍵句」而新增旅人台詞，但沒有同步刪掉原本承擔同一功能的 NPC 或 stage 句。**下一輪的檢查動作很簡單：每加一句旅人的結論句，就去找那句話原本是誰說的，把它刪掉或改成反應。**

### 跨-3｜好的情緒拍被停用，缺拍集中在「玩家剛承擔責任之後」

三章可證，且模式一致——被停用的都是玩家承擔責任後的那一句心聲：

- `C3-1/x8`「……原來排順序也要簽名。」（署名歸屬之後）
- `D1-2/n14`「……他連一句『不錯』都沒有。」（發現之後）
- `B2-4/na1`「三種高度,飛出去那顆都沒有晚落到我們聽得出來。」（三列判讀之後）

前兩句是心聲、第三句是公開句，共同點是**它們都在玩家做完事之後給玩家一拍反應**。停用之後，場景直接進入下一個人物的動作，成就感沒有落地的地方。三句都建議恢復（`na1` 若與 `n3` 重複，改用第三節 C-2 的拆法）。

## 如果只准再修一輪，哪幾句最值得改？

**三句。**

**第一句：`scenes.json` `A2-2/n2`。** 因為它是唯一會讓玩家「不知道自己該做什麼」的地方——工作台要他押第五段，伽利略沒說過要押，`qOdd` 又談論那個押記。其他所有問題都是「說得不夠好」，只有這一句是「任務指令斷掉」。而且它是本輪施工新造成的，不是舊債。

**第二句：`scenes2.json` `B2-3/n4`。** 因為它是本輪施工邏輯的反例，改它同時帶走一個方法論。原本的問題是伽利略重述旅人，施工把那句改成旅人自己說——重複沒消失，只是換了嘴。留著它，下一輪很可能在別章重複同一個動作。刪掉它的前半句，就等於把「加一句玩家結論，就要刪掉原本承擔同一功能的那一句」寫進慣例。

**第三句：`scenes4.json` `D1-2/n10`。** 因為它是本輪最重要的修法（GB-ADR-040 ④ 要求的讀回句終於落地）卻穿了錯的衣服。牛頓的力量全在短——`n16`「蘋果離地三公尺。你憑什麼說它離地球一個地球半徑？」十九個字問垮玩家。而 `n10` 用了兩個分號、五個數字、三個並列動名詞去讀回玩家的成果，把整章最該讓人起雞皮疙瘩的一拍讀成了結案清單。**把它拆成短句，玩家在 `n11` 喊出「六十」的那一秒才會真的響。**
