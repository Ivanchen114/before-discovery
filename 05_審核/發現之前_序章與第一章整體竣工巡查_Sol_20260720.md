## 三、A 級阻斷（學生候選版前必修）

### A-1｜共享書信碼可形成儲存型 DOM 注入

**證據**：

- `greybox/src/narrative.js:511–525` 的 `deserialize/loadSave` 只驗 `schemaVersion` 與游標，沒有驗證／正規化 state 其餘欄位。
- `greybox/src/chapter-ui.js:619–651` 明確允許從任意機器貼入書信碼。
- `greybox/src/chapter-ui.js:249–275` 把匯入 state 的 `run.id`、`config`、`claim.id` 等值直接拼進 `tr.innerHTML` 與單引號屬性。
- 實測把 `id="x' autofocus onfocus='alert(1)"`、`ball="<img src=x onerror=alert(1)>"` 放進合法 schema／合法 cursor 的書信碼，`loadSave()` 回傳 `accepted:true`，惡意值原樣保留。

**影響**：書信碼的產品敘事就是讓學生互傳；任何來路不明的碼都能把 HTML／事件屬性帶入候選頁。即使以 `file://` 執行，也可能讀寫同頁資料、欺騙玩家或執行腳本。此項在學生版不可接受。

**修正門檻**：

1. 匯入前對整個 state 做深層白名單正規化：模式、cursor、flags、evidence、runs、claims、debate、review、eventLog 全部限制型別、enum、數值範圍、陣列長度與可接受鍵；未知鍵剔除或整包拒絕。
2. 動態表格改用 `createElement`＋`textContent`＋屬性 API，不得再以字串組 `innerHTML`。
3. 新增惡意 payload 負向測試：HTML、引號事件屬性、超長陣列、NaN／Infinity、錯誤 enum、錯誤巢狀型別皆必須拒絕且不得覆蓋本機存檔。

### A-2｜舞台主對話對讀屏者不可見

**證據**：

- `greybox/stage.html:545–550` 的視覺主對話 `#dlgText` 設為 `aria-hidden="true"`。
- 唯一 `aria-live` 對話紀錄位於 `#notebook` 內；`#notebook` 平時帶 `hidden`（`stage.html:553–578`），隱藏子樹不構成可靠的即時主敘事輸出。
- `browser-checklist.md` 的讀屏項與 G2–G5 全部未簽；DOM 契約測試不能替代 VoiceOver／NVDA。

**影響**：讀屏玩家能聽到部分狀態訊息，卻讀不到推進故事所需的主要人物台詞；這不是小瑕疵，而是主流程缺失。

**修正門檻**：新增獨立、永遠不在 `hidden` 子樹的 sr-only 對話 live region；每一「完整邏輯句」只播一次，內容為「講者：全文」，不可隨打字機逐字洗版。另以 VoiceOver 或 NVDA 抽查序章、一般對話、選項、實驗結果、辯論與史實頁。

**必驗**：Chrome/Chromium 與 Firefox 雙擊、1280×720、844×390 手機橫屏、200% 文字、純鍵盤完整通關、存檔中斷續玩、貼碼跨機、減少動態、VoiceOver/NVDA、Console 無紅字。這是「尚未證明」，不是判程式失敗；但未簽之前不得稱學生候選版完成。

### B-2｜實驗台仍是管理後台，不像本章的核心遊戲

總監實機截圖與靜態 CSS 一致：`#panelWrap` 是滿版大塊米白表單；兩張器材圖只有 72 px（手機 48 px，`stage.html:336–341`），而且在 `mountDecor()` 被標成純裝飾。畫面同時暴露「run→預測→認證」等內部語法、空表格與大片空虛線框。

**修正方向**：保持引擎不動，把呈現層重排為「左側可看的斜面工作桌／動畫、右側旅人實驗簿」；配置、紀錄、主張採漸進揭露或分頁；尚未取得的區塊先不展示空表。器材要變成 260–360 px 級的舞台構件或直接成為配置選擇的視覺，不要再當右上角郵票。

### B-3｜程序化 BGM 只以滑鼠 click 解鎖

`stage-ui.js:901–906` 的 AudioContext 解鎖只監聽 `document.click`。純鍵盤玩家可以用 Enter／Space 開局與推進，但沒有保證觸發 click；在瀏覽器自動播放限制下可能全程無聲。另未處理頁籤切到背景時的暫停／降音。

**修正**：用一次性的 `pointerdown`＋`keydown` 共同解鎖（維持同一聲音總開關），並於 `visibilitychange` 暫停／恢復；再做人耳 QA，因 54 項測試只能證明掛點，不能證明音樂不刺耳、不蓋字。

### B-4｜存檔失敗被靜默吞掉

`chapter-ui.js:30` 對 `localStorage.setItem` 的任何錯誤皆空 catch；玩家仍會以為已儲存。實驗紀錄按設計不可刪，長時間遊玩更應對 quota／禁用儲存顯示持續警示。

**修正**：`save()` 回傳成功與否，失敗時在 HUD／標題頁顯示不消失的「目前無法儲存，請先匯出書信碼」；加模擬 `setItem` 丟錯測試。

### B-5｜人工清單與現行成品互相矛盾

- G3 寫「旅人預設無肖像、`?travelerBust=1` 才開」；現行程式是預設有剪影、`?travelerBust=0` 才撤回。
- G5 仍寫「四連板」「當下時間」；現行是 v03 六板＋固定 `00:49`。
- README 仍寫序幕四連板、音訊尚待補，與目前六板＋BGM commit 不符；`最後更新` 仍為 7/18。

清單不先更新，簽核人會照錯規格驗錯東西。應先機械同步，再開始最後人工簽核。
