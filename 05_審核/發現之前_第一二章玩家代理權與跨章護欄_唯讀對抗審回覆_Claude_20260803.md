## 二、B-1｜`forbid` 與 `after-scene` 規則的 term 打錯一個字就靜默失效

**位置**：`greybox/tests/run-node.mjs:1918-1932`（`violations()`）與 `1940-1944`（自我檢驗段）。

**實際證據**——我做了這組變異：

1. 把第三章 `conclusionLint.rules[0].term` 從 `"參考系"` 改成 `"參考係"`（系→係，一個字）。
2. 同時把**真正的**「參考系」放進第三章第一個節點的台詞。

結果：**148 通過／0 失敗——完全不轉紅。**

**因果問題**在兩層同時失效：

```js
const hits = rows.filter((row) => row.value.includes(rule.term));   // term 打錯 → hits 為空
if (rule.kind === "forbid") bad.push(...hits.map(…));               // 空 → 無違規 → 通過
```

而內建的自我檢驗用的是**規則自己的 term**：

```js
const guarded = clone.conclusionLint.rules[0].term;   // ← 同一個錯字
first.text += " " + guarded;
if (!violations(clone).length) throw new Error(…);    // 錯字命中錯字 → 轉紅 → 自我檢驗「通過」
```

**自我檢驗被同一個錯字一起騙過去。** 它能證明「規則機制會動」，不能證明「規則的詞是對的」。

**受影響範圍**：ch3 三條 `forbid`、ch4 兩條 `forbid`、ch5 兩條 `after-scene`，**共 7 條規則的 term 正確性沒有任何機械保障**。唯一免疫的是 ch4 `rules[2]` 那條 `allow-only`（`平方反比`），因為白名單反查會在 term 打錯時 throw。

**玩家實際會看到的後果**：現在看不到——我確認內容乾淨、148/0 且無命中。風險在未來：任何人打錯一個字（或簡繁混用、全半角混用）就等於把那條護欄拆掉，而審查紀錄會寫「三至五章護欄已補齊」，下一位審查者不會再查。

**最小修法（兩個選項，建議第一個）**：

1. **盡量用 `allow-only` 取代 `forbid`。** 若該詞在該章有合法出現處（史實頁、章末揭曉、合理重建卡），就寫成 `allow-only` 並列出那些路徑——白名單反查會自動守住 term 正確性。第三章的「參考系」、第四章的「萬有引力」很可能都屬這類。

2. 真正全章不該出現的詞，另給一個**獨立書寫**的探針欄位，讓自我檢驗不共用 `term`：

```js
rules.forEach((rule) => {
  const probe = rule.probe;   // 例：「在這個參考系裡看，石頭沒有動」
  if (typeof probe !== "string" || !probe.includes(rule.term))
    throw new Error(data.chapter + " 規則缺獨立探針，或探針與 term 不一致：" + rule.term);
});
```

`probe` 是人手寫的完整句子，與 `term` 分開維護；兩者同時打成同一個錯字的機率遠低於單一欄位。

**可失敗的驗證條件**：把任一 `forbid`／`after-scene` 規則的 term 改動一個字元，測試**必須**轉紅（現況不會）。這一條可以直接用我上面那組變異當回歸樣本。

**代理權**：`A2-2/qOdd` 是 `type=choice`、`speaker=旅人(你)`——玩家自己判讀，不是伽利略代講。三個選項：

```
‧「一、三、五、七、九；每一段都比前一段多二。」          ← 正解
‧「一、四、九、十六、二十五；這就是每一段增加的距離。」   ← 誘答
‧「每一段都增加一樣多，所以速度沒有變。」                 ← 誘答
```

**第一個誘答值得特別記下來**：它用的是**真實而且正確的數列**（平方數），只是放錯位置——把「累加距離」當成「各段增量」。玩家不能靠「哪個數列看起來對」猜，必須真的分清增量與累加。這比「明顯錯得離譜的誘答」高一個層次。
