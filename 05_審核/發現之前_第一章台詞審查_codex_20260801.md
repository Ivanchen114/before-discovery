# 《發現之前》第一章台詞獨立審查

一句總裁決：**A=0；第一章的主線因果與 17 個 choice／36 條 options 分支大致成立，但有 8 項 B 級問題會讓玩家聽見不存在的前情、遇到沒有承接自己選項的回應，或被關鍵操作文案卡住；清掉 B 後才適合凍結台詞。**

## A 級

**無。** 未發現會直接阻斷主線理解或操作的台詞問題。

## B 級

### B1｜抵達後憑空辨認「義大利語」

**位置（場／節點）**：P0-1／n1a（scenes.json:36）

**原句**：「斜塔、義大利語……我掉進了剛才那篇文章?」

**因果問題**：就 canonical JSON 的可達文本而言，前一節點只交代石板與鐘聲，尚未有人開口；旅人此刻沒有材料辨認「義大利語」。若章節外另有前導語音，必須另驗；僅讀 startScene=P0-1 時，資訊是憑空出現的。

**建議修改句**：「斜塔、石板路……我掉進了剛才那篇文章？」

**是否動到節點結構**：否。

**驗證條件**：由 P0-1/n1 連讀到 n1a，旅人提到的每項線索都已在畫面或聲音中出現；若正式入口確有先播義大利語，則本項可降為 C。

### B2｜旅人回想了沒有發生的動作

**位置（場／節點）**：P0-1／m1a（scenes.json:110）

**原句**：「哇——伽利略欸。本人。剛剛還在滿地撿球。(頓)那個名字我知道——可課本只寫了他後來留下什麼,沒寫我現在該怎麼讓他相信。」

**因果問題**：P0-1/n3 明寫年輕人「不撿球」，後面也只寫他把小球拋給旅人；「滿地撿球」與剛演過的動作相反。

**建議修改句**：「哇——伽利略欸。本人。剛剛還在拿兩顆鉛球試聲音。（頓）那個名字我知道——可課本只寫了他後來留下什麼，沒寫我現在該怎麼讓他相信。」

**是否動到節點結構**：否。

**驗證條件**：連讀 n2→n3→m1→m1a，不再出現未演出的撿球動作。

### B3｜玩家選擇克制，NPC 卻回成「好大的口氣」

**位置（場／節點）**：P0-2／qB.option b1 → nB2（scenes.json:205、219）

**原句**：

- 玩家：「我不想用一句話蓋過你。先看證據能帶我們到哪裡。」
- 伽利略：「(大笑)好大的口氣。那就陪我找。醜話先說——在比薩,斷言不用錢,證據才值錢。我的話也一樣。」

**因果問題**：玩家剛承諾不搶答、先看證據，伽利略卻用「好大的口氣」回應，像沒有聽見選項內容。這是典型的分支入邊與回應不相接。

**建議修改句**：「（笑出聲）好，那就先別搶答案，陪我找。醜話先說——在比薩，斷言不用錢，證據才值錢；我的話也一樣。」

**是否動到節點結構**：否。

**驗證條件**：把 qB/b1 與 nB2 直接連讀，伽利略的第一句明確承接玩家的克制；b2 仍走 nA1，不受影響。

### B4｜「不找人」分支匯流後仍宣稱有見證人

**位置（場／節點）**：A1-3/q3.option c → A1-4/n1b（scenes.json:537）

**原句**：「鐘樓頂層。風。晨霧裡的比薩。(依你的選擇,見證人在塔下等著。)」

**因果問題**：q3/c 明寫「不找人」，但匯流後仍說「見證人在塔下等著」。括號中的「依你的選擇」不能消除後半句對見證人存在的斷言。

**建議修改句**：「鐘樓頂層。風。晨霧裡的比薩。塔下空曠得一覽無遺；你先前邀了誰、沒邀誰，現在都已成定局。」

**是否動到節點結構**：否。

**驗證條件**：分別由 q3 的 student／assistant／none 三條路進入 A1-4，這句都成立，尤其 none 路不得暗示場外有人。

### B5｜辛普里奧把不在塔上的學生說成親歷者

**位置（場／節點）**：A1-5／n6（scenes.json:630）

**原句**：「重的。(向學生頷首)亞里斯多德告訴我們自然傾向的方向;諸位今晨在塔上,親耳為他作證。至於快多少——比薩的空氣稠密,阻礙了傾向的完全展現——(拍了拍書皮)《物理學》,早有明論。」

**因果問題**：動作指向迴廊學生，「諸位今晨在塔上」便自然指向這群學生；但他們並未全體在場。不同 q3 見證分支也不能支持這個稱呼。

**建議修改句**：「重的。（朝旅人與伽利略一抬手）亞里斯多德告訴我們自然傾向的方向；你們今晨在塔上，親耳為他作證。至於快多少——比薩的空氣稠密，阻礙了這種傾向完全顯現。《物理學》早已有說明。」

**是否動到節點結構**：否。

**驗證條件**：以 w=student／assistant／none 三種狀態走到 n6，代名詞都只指向確實在塔上的旅人與伽利略；n7、n8 的 assistant 條件插話仍自然。

### B6｜三個關鍵實驗提示退化成操作手冊

**位置（場／節點）**：A2-2/e1、A2-3/e2、A2-3/e3c（scenes.json:1139、1264、1291）

**原句**：

- 「在實驗台取得一筆「成立」的主張(勾選同配置 run→預測第五段→認證規律),劇情才會繼續。」
- 「用「僅球不同」的兩筆成立主張(銅大×銅小,槽面/傾角/計時全同),執行斷言「與球重無關」。」
- 「用「僅傾角不同」的兩筆成立主張(如 緩×中,其餘全同),執行斷言「隨傾角形式不變」。」

**因果問題**：英文 run、乘號、斜線與「成立主張／執行斷言／認證規律」都要求玩家先懂介面內部術語，正好卡在核心操作入口。它不是時代感，而是開發規格直接露出。

**建議修改句**：

- e1：「先留下一組可靠紀錄，再猜第五段會走多遠；結果對得上，才能把規律寫進筆記。」
- e2：「找出兩筆只換了球大小、其他條件相同的可靠紀錄，比較那串規律有沒有改變。」
- e3c：「找出兩筆只換了坡度、其他條件相同的可靠紀錄，比較那串比例有沒有改變。」

**是否動到節點結構**：否。

**驗證條件**：第一次玩的玩家不需知道 run、主張、斷言等介面名詞，也能說出下一步要做什麼；until 條件與操作順序不變。

### B7｜失敗複盤句法斷裂，伽利略像在念規格

**位置（場／節點）**：A3-F／n2（scenes.json:1787）

**原句**：「(走出講堂,不惱)證據沒有少。少的是——你方才把哪一張紙,塞進了哪一句話裡。坐下,我們把失手的地方攤開。」

**因果問題**：「少的是——你把哪張紙塞進哪句話」語法接不起來；玩家剛失敗時最需要知道錯在證據與主張不相配，這句反而要重讀才懂。換角測試也會通過，缺少伽利略的動手感。

**建議修改句**：「（走出講堂，不惱）證據都還在。剛才失手，是把不相干的紙拿去撐那句話。坐下，我們一張一張攤開來對。」

**是否動到節點結構**：否。

**驗證條件**：失敗後首次朗讀即可回答「我錯在證據與主張不相配」；不需看 debrief 介面才理解。

### B8｜信譽修復場既露出遊戲分類，又宣稱「數據不會錯」

**位置（場／節點）**：SC-R1／n1、n2、n3（scenes.json:2018、2025、2042）

**原句**：

- stage：「(關鍵人物暫時拒絕與你交談。)伽利略把一張空白數據表拍在旅人面前。」
- 伽利略：「在這座城市,道歉不用嘴。(指實驗台)用一次乾淨的紀錄。挑一組配置,做完,拿來。」
- system：「信譽回復至 1。筆記:「話說錯了可以收回;數據不會。所以他們只信數據。」」

**因果問題**：「關鍵人物」「配置」是系統分類，不是場內世界；更嚴重的是「數據不會／只信數據」與本章前面反覆建立的觀念衝突：紀錄可能混變因、散亂、越界，必須檢查做法與邊界。修復場反而把數據寫成不會錯的權威。

**建議修改句**：

- n1：「伽利略不再接你的話，只把一張空白紀錄紙拍在你面前。」
- n2：「在這座城市，道歉不只靠嘴。球、木槽、坡度，你自己挑；做完，把紀錄拿來。」
- n3：「信譽回復至 1。筆記：『我收回了沒有證據的話，也補上一筆可檢查的紀錄。他願意再聽。』」

**是否動到節點結構**：否。

**驗證條件**：刪掉 UI 後仍能看懂修復方式；新句不能暗示任何紀錄天然正確，只能說它可被檢查。

## C 級

### C1｜「不是 Y，是 Z」警句共 7 次，超出本章配額

**位置（場／節點）**：A1-4/n2、A1-5/n11、A1-6/n5、A1-7/m1、A2-2/c1、A3-6/n8a、E-1/n2。

**原句與判斷**：本章共找到 7 個完整警句型；建議保留最有角色與場景辨識度的三句：

- A1-5/n11：「那你手裡的不是反例。是雜耍。」
- A1-7/m1：「那就不是石頭有問題——是前提自己撞上了自己。」
- E-1/n2：「不是落下……是拋出去的東西。」

其餘四句過量，讓伽利略、旅人與系統都像同一位作者在收金句。

**建議修改句**：

- A1-4/n2 原「聽好——不是看,是聽。眼睛會眨,耳朵不會。」→「聽好，別盯著球。兩個落地聲排在一起，比眼睛追得準。三——二——」
- A1-6/n5 原「不再是『誰先落地』——是落體,究竟怎麼落?」→「所以接下來別只問誰先落地。我要知道它一路是怎麼落的。」
- A2-2/c1 原「實驗失敗最常見的樣子,不是得到錯的答案,是什麼答案都得不到。」→「記下來。這幾次的點散成一團，什麼規律都讀不出來；實驗常常就是這樣失敗。」
- A3-6/n8a 原「那不是投降;是他答應繼續讀。」→「他仍信那本書，卻把我們的數據夾了進去。至少，他答應繼續讀。」

**是否動到節點結構**：否。

**驗證條件**：重掃 active nodes，完整「不是／不再是 Y，是 Z」警句不超過 3 次，且同場不超過 1 次。

### C2｜A1-3 的判讀選項與筆記太像研究方法講義

**位置（場／節點）**：A1-3／nB3.option mixed、nB5（scenes.json:431、464）

**原句**：

- 「這張紙記下木球落後;材質和重量同時不同,原因暫時不歸給其中一項。」
- 「紀錄保留:材質與重量同時改變,不能用來歸因。方法筆記:『一次只動一個變因。』」

**因果問題**：「原因暫時不歸給」「歸因」「變因」語意正確，但書面而像教室術語；玩家其實只需理解「一次換了兩樣，所以還不能怪其中一樣」。

**建議修改句**：

- option mixed：「先只記木球落後。材質和重量一起變了，還不能怪其中一個。」
- nB5：「紀錄留下：這回同時換了材質和重量，只能記木球落後，還不能判定原因。下一回，只換一樣。」

**是否動到節點結構**：否。

**驗證條件**：三個選項仍保持平行、正解不靠學術措辭辨認；高中生能用自己的話復述「一次只換一樣」。

### C3｜綁縛悖論筆記把擊破一項主張寫成擊倒整個權威

**位置（場／節點）**：A1-7／m3（scenes.json:873）

**原句**：「取得證據：綁縛悖論。筆記：『不用實驗，不用權威。亞里斯多德自己打倒了自己。』」

**因果問題**：玩家真正推出的是「重的必定落得更快」這項前提自相矛盾，不是亞里斯多德整套自然哲學被一次打倒。現句也有刻意收金句的作者感。

**建議修改句**：「取得證據：綁縛悖論。筆記：『「重的必定落得更快」從同一個前提出發，推出了兩個相反答案。』」

**是否動到節點結構**：否。

**驗證條件**：筆記只宣稱本次推理實際排除的命題，不擴大到整個人物或體系。

### C4｜父喪與離職突然落下，情緒轉場少一個承接動作

**位置（場／節點）**：A1-7／m4b（scenes.json:899）

**原句**：「父親過世了。家裡的債在我肩上,比薩的合約也不會續。」

**因果問題**：前一句仍在談悖論「刀能拆房子不能蓋房子」，雖有一個望雨幕的 stage，伽利略立刻報父喪、債務、合約，像作者一次投下三則背景資料。朗讀時轉折偏硬。

**建議修改句**：「（把鉛球放進行囊）我也正好得走了。父親過世，家裡的債落在我肩上；比薩的合約也不會續。」

**是否動到節點結構**：否。

**驗證條件**：m4a→m4b→m4c 連讀時，收球／行囊同時承接物理問題與人生離場，不需新增節點。

### C5｜角色說出介面欄位名稱，換角測試完全通過

**位置（場／節點）**：A2-2／n3（scenes.json:1159）

**原句**：「(盯著主張紀錄,手指微微發抖)把第一段當作一個單位——第二段接近三個,第三段五個,第四段七個。你預測的下一段,是九個。一、三、五、七、九……老天用奇數寫字。」

**因果問題**：「主張紀錄」正是介面欄位名稱；這個詞換給任何教學 NPC 都成立，削弱伽利略的工匠感。後半「老天用奇數寫字」反而很有角色聲音，應保留。

**建議修改句**：「（盯著那張紀錄紙，手指微微發抖）把第一段當作一份——第二段接近三份，第三段五份，第四段七份。你猜下一段是九份。一、三、五、七、九……老天用奇數寫字。」

**是否動到節點結構**：否。

**驗證條件**：角色台詞中不再出現 UI 欄位名；玩家此前確已做出第五段預測，數字順序不變。

### C6｜證據摘要精確但不適合朗讀

**位置（場／節點）**：A2-3／n6（scenes.json:1305）

**原句**：「取得證據：斜面奇數律（規律＋換球＋變傾角複驗）。筆記大字：『同介質、同形狀、同槽面下：等時距位移 1：3：5：7，形式不隨球重、不隨傾角改變。問號，劃掉了。』」

**因果問題**：「同介質、同形狀、同槽面」「等時距位移」「形式不隨」連續堆疊，像摘要表，不像旅人真的寫下來的句子；資訊邊界值得保留，但可拆成白話。

**建議修改句**：「取得證據：斜面奇數律（換球、換坡度都已複驗）。筆記：『在相同的空氣、球形和槽面下，每段同樣長的時間裡，球走過的距離是 1、3、5、7；換球重、換坡度，這串比例仍在。問號劃掉。』」

**是否動到節點結構**：否。

**驗證條件**：仍保留介質／形狀／槽面三個邊界、1:3:5:7、球重與傾角複驗；朗讀不需回頭找主詞。

### C7｜辯論入口仍使用「量表／支柱／擊破」的規格語言

**位置（場／節點）**：A3-1/n4、A3-D/e1.hint、A3-F/e1.hint（scenes.json:1730、1757、1795）

**原句**：

- 「說服力量表:5。錯誤出示 −1;歸零則辯論中止——你會與伽利略複盤,再從未破的支柱重返。」
- 「追問找線索,出示(證據×目標證詞)擊破支柱;三柱皆破後迎接最後反撲。」
- 「複盤剛才用錯的證據與證詞;證據與已破支柱完整保留。整理好就重返辯論會。」

**因果問題**：系統文案可以說操作，但「目標證詞／擊破支柱／已破支柱」仍像設計文件；去名去日期後，完全是現代教學遊戲術語。

**建議修改句**：

- n4：「說服力：5。拿錯一次證據 −1；歸零時先離場整理，但已說服對方的部分會保留。」
- e1：「先聽清辛普里奧哪一句站不住，再拿真正能回答它的紀錄反駁。三個主張都撐不住，他才會正面回應。」
- A3-F/e1：「把剛才用錯的紀錄和主張重新對照；整理好，就帶著原有進度回講堂。」

**是否動到節點結構**：否。

**驗證條件**：首次進辯論仍能理解扣分、保留進度與攻防方式；可見文字不再要求先懂「支柱」這個內部模型。
