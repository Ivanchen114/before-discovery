# 第三方台詞審(2026-07-27)・Claude 回應與白話化原則

**審源**:總監轉交之第三方台詞審(三病症+五重災區+三通用原則)。總監裁示:「我覺得這個方向比較好」=方向採納。
**總判**:**大部分接受**。三病症診斷成立;五例中三例照方向修(措辭由主筆定稿)、一例含事實錯誤修正後採、一例部分反駁。

## A 級(接受,立即生效)

1. **病症一「規格書倒灌」屬實**,且病原=主筆自己:設計詞彙(未揭露、允許帶、適用範圍、解析度、在……條件下)從規格直接漏進台詞。立**規格詞黑名單**(見下),台詞層一律替換;系統文可酌留但同樣優先人話。
2. **病症三「旅人開口變答題機」屬實**。修正雙聲域定義:「口=克制白話」的**克制指內容(不爆雷),不指節奏**——說出口的話也要有「等等」「說白了」「行吧」的頓挫與思考留白。
3. **通用原則三條全採**:砍歐化介詞與抽象名詞(邊界→管得到/管不到的地方)、加口語頓挫、旅人平民化(兩碼子事/硬槓等現代直覺白話,用來撞古人的嚴肅)。
4. **例 1(K3 斷言)與例 4(ch2 B3-5)病因診斷正確**——已修/入批次(見下)。
5. 新增**朗讀測試**入文字查核:每句台詞念出口,卡牙齒=改。

## B 級(方向對,修正後採)

1. **例 1 改寫含事實錯誤**:「我們連盒子的封條都沒碰過,預測就已經寫死在紙上了」——預測**有**蠟封(玩家親手滴的),沒碰過的是**觀測資料包**。定稿(已入 ch4 v0.6.7):「預測先滴了蠟,資料包後拆——匣子從頭到尾在哈雷手上。火星、木星,兩筆都對上。這不能再叫湊巧。」
2. **例 4 改寫兩處再酌**:「知之為知之」——現代旅人引《論語》成立且有味,保留為候選;「瞎吹」在 ch2 終辯高潮場偏輕,辛普里奧接著要行禮如儀,建議收半格:「沒量過的地方,我們不說。」措辭於 CH2-CR 定稿。
3. **例 5(辛普里奧)部分反駁**:排比是他的**職業病=角色特徵**(修辭學時代的辯士,ADR-005 老派書面語)——金句配額對他豁免,但同意「鬆一格」:採混合版「……老夫辯了一輩子,頭一回見人當場認了『量不到』。(頓)怪了。話收進界線裡,老夫反倒拿你沒辦法。」於 CH1-CR 定稿。

## C 級(補充與程序)

1. **書面句場合豁免**:要排成鉛字的行(虎克貢獻句)、封條、書信體(虎克/佛蘭斯蒂德)——書面文字書面化是**寫實**,不在整治範圍;判準=這句話在戲內是「說的」還是「寫的」。
2. 例 2(ch3 艦長「不是補在紙上」)之原句待與 v0.7/runtime 逐字核對後再修(該章 Sol 施工中);改寫方向採,入 CH3 批次。
3. 例 3(ch5 杜夏特萊)——ch5 為 v0.1 早期草稿,併入 ch5 自己的台詞 pass,不零星修。
4. **金句配額**:每場至多一句對仗/排比,高潮場優先保留;其餘拆成人話。
