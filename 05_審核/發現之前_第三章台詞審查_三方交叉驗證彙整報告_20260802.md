# 《發現之前》第三章台詞審查——三方交叉驗證彙整報告

**日期**：2026-08-02
**審查對象**：`greybox/data/scenes3.json`（第三章，11 場／194 個 active 節點／29 個 legacyOnly，馬賽航船場景）
**方法**：claude、codex、gemini 各自獨立審查，再交叉檢視彼此分歧，由 general（協調者）逐條核對 scenes3.json／narrative.js 引擎邏輯後整合。
**總裁決**：A=0、B=7、C=8。全部修法皆不新增或刪除節點。

本章是三章以來分歧最深、來回辯論最多的一輪，尤其 C0-3 那組重試句，三方一度各判不同節點洩題（gemini→a1；codex→f1+f2；claude→都合格）。最後訂出的判準：**先把正解拆成 2–3 個獨立主張，標出「反駁這個錯誤在邏輯上必須說的那一塊」（不算洩題），再看回饋是否額外多給了另一個獨立主張（算洩題）**。用這條規則重新過一遍才收斂出下方 B7、C1 的定案。

## B 級：明確錯誤，不阻斷理解

### B1｜C0-1/xcard（開場合理重建卡）— codex 單方發現

- **原句**：【合理重建】伽桑狄確實在 1640 年於馬賽的一艘槳帆船上做過這個實驗，結果也確實是「石頭落在桅腳」。但船是透過官方關係取得的；接下來借船的經過、船長其人與那張舊紙，是為了把「誰有權替一份證據作證」演出來而做的虛構。實驗做法、原紙欄位與結論，照史實與物理。
- **建議修改**：【合理重建】史料可確認的是：伽桑狄在 1640 年於馬賽的一艘槳帆船上做過落石實驗。接下來的借船過程、維達爾船長、舊紙與卷宗欄位，都是本作為了演出「誰有權替一份證據作證」所作的合理重建；實驗結果與史實邊界留到章末分開說明。
- **因果問題**：這張系統卡在玩家親自做實驗前，直接說出「落在桅腳」，讓之後的預測、量測與公開質詢全部失去未知性。同一句話還自相矛盾：先說「舊紙是虛構」，又說「原紙欄位與結論照史實」，會讓玩家誤以為存在一份可逐欄對照的真實史料原紙。
- **節點結構**：不動。
- **驗證條件**：玩家第一次親自完成穩速落石前，所有 active 系統卡不得出現「桅腳」或同義結果。

### B2｜C3-1/x19 — claude 單方發現，已核對前後節點確認全場無人提議撕紙

- **原句**：維達爾船長：不撕。留著。
- **建議修改**：維達爾船長：（把手按在那張舊紙上）錯的那張也不撕。留著。
- **因果問題**：claude 實走了 x14→x15→x17→x18→x16（心聲）→x19→n7 的完整順序，並調出兩個 legacyOnly 節點核對——全場沒有任何人提議撕掉那張舊紙，x19 是在回答一個不存在的提議。更糟的是它緊跟在心聲「八年。他把它壓在箱底八年……」之後，時序上讀起來像船長聽見了旅人沒說出口的念頭。
- **節點結構**：不動。
- **驗證條件**：x18→x16→x19→n7 連讀，不得讀成「船長回答了心聲」。

### B3｜C3-2/x4 — codex 發現，精確定位了 gemini 原本對 x5 匯流句的疑慮真正出在哪

- **原句**：（看了他一眼，沒有追問）那就更該是你。你不會回來替它辯護，所以你只能一次取對。
- **建議修改**：（看了他一眼，沒有追問）那就更該是你。你不會回來替它辯護，所以這個名字不能替卷宗說過頭。
- **因果問題**：gemini 原本質疑匯流句 x5「三個都不完整」讀起來像 NPC 沒看見玩家只選了一個名字；claude 核對後認為 x5 本身沒問題（三個候選各自只能講出侷限，匯流句對三條分支都成立，且題名機制靠 require 正確回收 ✓）。codex 進一步定位出真正矛盾其實在更早的 x4：它宣稱「只能一次取對」，把這一拍包裝成有唯一正解，但後面的匯流句與三個題名設計明明是「三個都可以、各自都不完整」——玩家選完才發現規則被偷換。
- **節點結構**：不動。
- **驗證條件**：三條分支最後一句與 x5 連讀都成立；題目前後不再暗示三個題名中有唯一正解。

### B4｜CE-1/x18 — codex 單方發現

- **原句**：他沒有看到這份卷宗。（把手稿和《對話》並排放好）不過他問的那句話，我們替他量完了。
- **建議修改**：他沒有看到這份卷宗。（把手稿和《對話》並排放好）不過他問的那句話，我們替他在這艘船上量了一回。
- **因果問題**：本章卷宗只排除了「落石必落後，所以地球不動」這一項反對，並沒有直接證明地球在動。「量完了」帶有完整結案的意味，削弱了伽桑狄一貫謹慎、守證據邊界的聲線，也越過了本章自己立下的界線。
- **節點結構**：不動。
- **驗證條件**：章末仍須明確保留「排除一項反對，不等於證明地球在動」。

### B5｜CE-1/x11、CE-2/x3-x5（憑空捏造的第一章回呼）— claude 與 codex 各自獨立發現同一問題，codex 找到更精準的原句對應

- **原句（CE-1/x11）**：他說：先別急著相信我。
- **建議修改**：他把空白冊子丟給我時說：送你，想在這座城市開口，先學會把看見的寫下來。
- **原句（CE-2/x4）**：「先別急著相信我。」
- **建議修改**：「這個世界只為證據付費。」
- **因果問題**：「先別急著相信我」這句話在全系列 grep 只出現在第三章這兩處，第一、二章從未出現過（已核實）。第一章真正的兩句是：P0-3/n2 伽利略給筆記本時說的「送你。想在這座城市開口,先學會把看見的寫下來。」，以及 P0-3/n3 筆記首頁題字「這個世界只為證據付費。」——codex 精確地把「他說」對應到給筆記本那一刻的**口說**引句、把「首頁題字」對應到**寫下**的題字，兩種媒介各自用對的原句。
- **節點結構**：不動（只替換四個節點文字）。
- **驗證條件**：全系列 grep「先別急著相信我」＝0 命中；回望引句與 scenes.json 逐字一致。

### B6｜CE-2/n2、n4 — gemini 發現 n2・codex 發現 n4，兩個獨立的心聲/書寫誤標

- **原句（n2，speaker: 旅人(你)）**：（把船上那張推到岸上那張下面）同一顆石頭，同一次落下。只是記它的人，站在兩個地方。
- **建議修改**：文字不變，speaker 改為心聲。
- **原句（n4，speaker: 旅人(你)，前一句 n3 明寫「他在弧線旁親手寫下：」）**：月亮也一直往前走。如果沒有東西讓它轉彎，為什麼它沒有沿直線離開？
- **建議修改（speaker: stage）**：「月亮也一直往前走。如果沒有東西讓它轉彎，為什麼它沒有沿直線離開？」
- **因果問題**：CE-2 全場沒有其他角色說話，旅人是獨自一人在整理筆記——n2 是獨處反思卻標成出聲台詞（違反心聲單向規則）。n4 的問題不同：n3 已經明確宣告「他在弧線旁親手寫下」，n4 卻標成出聲對話，會讓旁白、語音把「書寫」演成「說話」，這不是心聲規則問題，是媒介被弄錯了。
- **節點結構**：不動（只改 speaker 與引號）。

### B7｜C0-3/c1 重試句組 — gemini→codex→claude→codex 四輪交叉驗證收斂

- **原句（f2，伽桑狄）**：條件沒寫全，這張紙能說的就少；但它記下的落點還是真的。
- **建議修改（f2）**：落點這一欄有記錄，別丟。至於這張紙還能說到多遠——其他欄位，你自己再看一遍。
- **定案過程**：C0-3 的正解「bounded」可拆成三塊獨立主張：(1) 紙上真的記了「落在桅後」 (2) 那一趟船速沒記 (3) 所以不能代表別的船況。「fake」錯答本身已經自報 (2)；反駁「fake」在邏輯上必須說出 (1)——這就是 f1 的內容，必要，不算洩題，**原句保留**。但原本的 f2 前半「條件沒寫全，這張紙能說的就少」把 (3) 這個推論也代替玩家講完了——這才是真正多給的部分。

  這一輪辯論還連帶處理了另外兩個曾被提出、後來排除的懷疑：**a1**「你說的是答案,不是它留下的紀錄」一度被 codex 論證為候選空間窄化的洩題，但重新核對後 `fake` 選項本身就寫了「船速沒記」，候選並未被鎖到唯一項，該項最終**不成立**，改列為 C1 的措辭問題。
- **節點結構**：不動（f1 保持原樣，只改 f2）。
- **驗證條件**：讀完 f1+f2 之後，不重看原紙的空欄就無法組出 bounded 的第三塊「不能代表別的船況」。

## C 級：可改進

### C1｜C0-3/a1、SC3-R1/w2（「答案」措辭替旅人未來知識背書）— claude 定位出根本原因，統一兩處同類問題

- **原句（a1）**：（指著船速空欄）這張紙哪裡寫了「平穩」？你說的是答案，不是它留下的紀錄。
- **建議修改**：（指著船速空欄）這張紙哪裡寫了「平穩」？你說的是結論，不是它留下的紀錄。
- **原句（SC3-R1/w2）**：那還是在補寫。你知道的答案不能冒充那一趟真的記過的船況。
- **建議修改**：那還是在補寫。你以為知道的說法,不能冒充那一趟真的記過的船況。
- **因果問題**：對照本作自己的用詞（P0-2/nA4「把沒有證據的未來答案說成大家都知道的事」、C0-3/all 選項理由「把還沒有原紙支持的答案當成事實」），「答案」在本作詞彙裡等於「旅人手上那個正確的未來答案」。NPC 說「你說的是答案」，等於承認旅人講的物理是對的，只是來源不對——這跟全系列一貫做法（不評價旅人物理對錯，只認證據到不到）不一致。換成「結論」或「你以為知道的說法」，語氣節奏不變，但拿掉了背書、保留了指控。
- **驗證條件**：全章 NPC 台詞不得以「答案」指稱旅人未經證據的主張。

### C2｜C0-2/x3 — codex 單方發現

- **原句**：（還是沒抬頭）你知道我這艘船一天要多少錢嗎。
- **建議修改**：（還是沒抬頭）你知道我這艘船一天要多少錢嗎？
- **因果問題**：明確問句卻以句號收尾，朗讀時容易被念成陳述句；船長此處是在逼對方正視成本，問號更符合權威語氣。

### C3｜C0-3/n2（system）— codex 單方發現

- **原句**：◆ 舊紙已收入卷宗：它記下一次真實落後，但那一趟船速沒記，目前只能放在「船況不明」。
- **建議修改**：◆ 舊紙已收入卷宗：它確實記著一次「落在桅後」；但那一趟船速沒記，目前只能放在「船況不明」。
- **因果問題**：卷宗能確定的是紙上寫了「落在桅後」，不是未經條件約束的「真實落後」——原句正好跨過本場要教玩家守住的紀錄／主張邊界，與 C1 是同一類問題的系統文案版本。

### C4｜C1-1/e1（embed hint）— claude 判定合格且列為範本・codex 提出更進一步的語域精修

- **原句**：一次查一個問題：先設計並執行實驗，再從原紙寫出斷言。資料不夠也能去碼頭；被問倒後，可以帶著缺口回船補做。
- **建議修改**：一次只查一件事。先排好做法、跑一趟，再用原紙寫下一句不超過紀錄的判斷。紙還不夠，也能先回碼頭；哪裡被問住，就帶著那個缺口回船補做。
- **兩種判斷並存**：claude 對照第一、二章大量「勾選／配置／run／成立主張」等開發規格詞外洩後，認為本章這句是三章裡唯一乾淨的 hint，建議直接當範本套用到前兩章的修法。codex 進一步指出「設計並執行實驗」「寫出斷言」仍偏教案流程語感，不像船務語境下的提醒。兩者不衝突：本項不違反「禁止開發規格詞」的硬性標準，但若要精修到與船務語域完全貼合，可採 codex 版本。

### C5｜CE-1/n6 — claude 與 codex 各自發現，年份基準經核實後統一

- **原句**：五十年前，伽利略把第一本空白筆記塞進我手裡。現在他走了，我卻還是那天的模樣。
- **建議修改**：五十二年前，伽利略把第一本空白筆記塞進我手裡。現在他走了，我卻還是那天的模樣。
- **因果問題**：核實 P0-1/n1b「1590 年,義大利・比薩」為筆記本事件基準年，1642（本場）−1590＝52 年，「五十年前」聽起來像精確年份回指，會讓細心的玩家對不上帳。（codex 原先誤算基準年為 1589，經核對後採 claude 的 52 年精確版本。）
- **驗證條件**：1590→1642＝52 與台詞數字一致。

### C6｜CE-2/s1（system）— claude 單方發現，呼應第一、二章同款問題

- **原句**：第三章已封存。旅人筆記新增未解問題：「月亮為什麼沒有沿直線離開？」
- **建議修改**：這一份卷宗已封存。旅人筆記新增未解問題：「月亮為什麼沒有沿直線離開？」
- **因果問題**：「第三章」是製作端術語。第一章 E-2/n4、第二章 B2-5/q2 與 B1-3/n1 都已各列同款問題，這是第三例，三章應一併處理，否則像是刻意保留的漏網之魚。

### C7｜INT-C2/x7 — claude 單方發現

- **原句**：……八年前，好像也有人被這樣問過。而且問他的是他自己。
- **建議修改**：……八年前那本書裡，也有人被這樣一路問到底。而出題的，就是寫書的人自己。
- **因果問題**：年份錨點正確（呼應 C0-1/n5「八年前出版的《對話》」＝1632），但「問他的是他自己」要玩家自行推知《對話》是伽利略用對話體自我盤問——這一步對沒讀過該書結構的玩家偏遠，本章其他心聲都很好懂，只有這句需要外部知識。

## 本輪方法論成果（沿用至第四至五章）

**重試句洩題的「拆塊追蹤法」**：先把正解選項拆成 2–3 個獨立主張；標出「錯答本身已包含哪些」與「反駁該錯誤在邏輯上必須說出的那一塊」（這些都不算洩題）；只有當回饋額外交付了另一個獨立主張，使剩餘推論只剩同義改寫時，才升級為甲級（B）洩題。「候選選項空間被縮小」本身不能當作洩題的充分證據——必須確認候選真的被鎖到唯一項，且該窄化不是錯答選項自己已經暴露的資訊。

**「答案」措辭的背書問題**：NPC 台詞若用「答案」指稱旅人未經證據的未來知識主張，等於替其物理正確性背書，違反本作「不評價物理對錯，只認證據到不到」的一貫立場，應改用「結論」「說法」等中性詞。
