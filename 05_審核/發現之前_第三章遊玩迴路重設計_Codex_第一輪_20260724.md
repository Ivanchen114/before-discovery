**輪次**：第一輪獨立評審

## 1. 診斷回應

### 對「好玩不變量」的判斷

我同意這條不變量，但建議把「逼對手改變立場」說得更精確：

> 明確衝突 → 玩家先承諾 → 實驗製造意外 → 錯誤留下可讀後果 → **迫使對手為原立場付出代價並提出更難的新質疑** → 舊證據在高潮被拿去處理新情況。

理由是：對手一旦「承認你對」就退場，後半章仍會失壓。第一、二章真正有效的不是辛普里奧被說服，而是他會吸收新證據、改寫攻勢，再拿玩家教過他的證據規則反擊。第三章的艦長也應有三段轉變：

1. 「船動，石頭必落後。」
2. 「我承認加速與穩速不同，但你們兩張圖互相矛盾，碼頭憑什麼信？」
3. 「我不再替原主張護短，但公開程序也不准替你們護短。」

這樣才能抵達「共同審查者」，而不是在 C2-2 翻木籌後變成提示員。

### 對四鏡頭診斷的判斷

我同意四項診斷，且認為病灶不只在三個指定場，而在「每做完一件事，再跳出一次概念斷言」的整體節奏。

| 鏭頭 | 判斷 | 具體憑據 |
|---|---|---|
| ① 真決策或純操作 | **同意** | C0-2 封存木籌、C1-2 查搶跑、C2-2 預測加減速都會承擔判斷；C2-1 卻要求填滿停／穩 × 滴水／拋接四格，C2-3 逐拍點亮，C3-1 依序開五窗口，主要是在完成介面要求。 |
| ② 錯誤是否形成事件 | **同意** | C1-2 的「落在桅後＋岸標間距漸增」是一個能被艦長拿來攻擊的事故；相較之下，C2-3 錯配後只被告知同號鼓點才對，C3-1 搶跑也只是解釋後重選，錯誤沒有成為後續案件材料。 |
| ③ 對手是否施壓 | **同意，而且是主病根** | 艦長在 C0-2、C1-2、C2-2 很強；到了 C2-3 只說「我只查船況和木籌」，等於離開核心推理。C3-1 又主要是程序監督，沒有提出足以讓玩家重組證據的新難題。 |
| ④ 介面是否洩漏答案 | **同意** | C2-1 的正確選項幾乎是課本句；C2-3 先讓同號鼓點發亮，再明寫「石頭離岸 − 桅杆離岸」，玩家不是發現參考物，而是照著答案做座標轉換。C3-2 又把 G2/G3/G4 配給三個名稱幾乎相同的質詢。 |

### 我額外看到的兩個問題

**一、證據被過早「卡牌化」。**  
G1、G2、G3、G4 幾乎每一段都以「選一句正確概念」收尾。玩家真正看到的沙痕、岸標間距、滴水軌跡、紙帶，反而退化成解鎖概念卡的素材。第一、二章較好的地方，是壞數據、墨線、沙痕本身會被對手帶到下一場。第三章也應讓物證留在一張案件桌上，不要每場都另考一次文字題。

**二、高潮目前是「把舊卡放回同名插槽」。**  
C3-2 依次用 G2 回風、G3 回加速、G4 回雙圖，形式上正確，玩法上只是讀題配卡。高潮的證據重用應要求玩家處理一個先前沒見過的公開案件，例如從匿名的三組原始紀錄判斷哪一組是加速、穩速、減速，而不是重答三道已知問題。

## 2. 重設計的遊玩迴路

### 整章新骨架：「一艘船，兩份互相衝突的證詞」

整章不再是「建立 G1 → 建立 G2 → 建立 G3 → 建立 G4 → 逐卡答辯」，而是同一件事故被逐步重建：

1. 艦長與玩家先留下互斥預測。
2. 第一趟真的落後，艦長暫時勝出。
3. 玩家從鼓點與岸標找出「搶跑」這個隱藏條件。
4. 封艙與加減速實驗把「風」和「船只要在動」兩個說法拆開。
5. 岸上、船上兩名證人的圖互相矛盾，玩家必須親手重建同一事件。
6. 艦長在公開場合把三種船況匿名重演；玩家用前面留下的物證辨認，而不是再走一次清單。
7. 官員把結果誇大成「證明地球運動」，玩家刪掉證據沒有走過的那一步。

### 逐場處置

| 原場景 | 處置 | 重做後玩家的實際判斷、錯誤後果與壓力 |
|---|---|---|
| C0-1 交棒 | **保留** | 伽利略只以書與問題留下；伽桑狄接手。這段提供情感與史實定位，不需增加操作。 |
| C0-2 木籌預測 | **保留、加一個可見利害** | 玩家、伽桑狄、艦長把木籌釘在船尾／桅腳／船前。艦長另把「本船紀錄」銅牌掛上：若程序站不住，他不准用船名公開。木籌不是投票，而是防止事後改口。 |
| C0-3 條件卡＋C1-1 六項踏查 | **合併重做** | 取消六選三詞卡與六個亮點逐項點查。玩家直接在船的剖面上裝三件東西：無推力的門閂、桅腳沙盤、鼓點—岸標同步繩。若用手放、沙盤未對準或沒有同步繩，第一次停船試放就留下偏向散布、基準歪斜或無法對時的壞紀錄。艦長不說答案，只拒絕讓一張無法追查的紙掛上船名。這些壞紙保留在案件桌側欄。 |
| C1-2 搶跑的船 | **保留、升為案件起爆點** | 玩家在「看似已能出航」的時刻放手，石頭真落桅後。艦長把自己的船尾木籌立起來，要求原樣記錄。玩家不選 A/B/C 文字題，而是從三件現場物證中挑一件先查：沙痕、門閂、鼓點—岸標紙。只有第三件能顯示間距漸增；查錯不退回選單，而是得到一張「沒有解釋落後」的無效檢查紙，並聽見艦長指出它沒有碰到船況。 |
| C1-3 穩速重做 | **重做成「把放手釘在一拍上」** | 鼓點與岸標持續流動，玩家把一枚釋放釘插在自己判斷的拍點；插下後不能移，完整一趟才揭曉。插太早，沙盤再留下桅後點，且釋放釘與漸增間距同時被封在紙上；選到連續等距段，落點聚在桅腳基準附近。艦長承認「第一回的落後不能代表所有行船」，但仍保留風的質疑。 |
| C1-4 風的辯護＋C2-1 船艙四格 | **合併重做成「封艙的兩名證人」** | 停船基準時已留下滴水落點圈與布球接球圈。穩速封艙前，玩家必須先把接水碗與接球環放在自己預測的位置，放好才鎖艙。若照「船會把物體甩後」把器具放後方，水與球會在原位置留下濕痕／撞痕，錯誤預測成為可見物證；若放原位，兩種痕跡與停船的半透明基準圈近乎重疊。沒有四格表，也沒有二選一結論。艦長只能撤回「甲板風是唯一原因」，但立即提出新壓力：「船艙看來像沒動，岸旗卻一直退；哪一份紀錄在說謊？」 |
| C2-2 加速／減速 | **保留、取消文字斷言** | 玩家先在沙盤上放兩枚預測釘，再分別下令加槳、收槳。結果留下桅後／桅前兩道相反偏痕；原先搶跑的後方痕跡自動與加速痕跡並排。艦長公開翻木籌，承認自己的「只要向前就落後」說過頭；但他不退出，改成要求兩份觀測能被任何人重建。 |
| C2-2B 傳言分裂 | **保留** | 「落後」與「沒落後」兩句傳言貼在碼頭兩端。艦長指出兩邊都刪掉了船況，決定公開驗證。這是把私人更正推成公共風險的必要樞紐。 |
| C2-3 雙紙帶 | **完全重做** | 改為「兩名證人的事故重建桌」，詳見第 3 節。玩家不是按提示做減法，而是決定要固定碼頭還是桅杆，並以同一次鼓點的原始快照重排。錯誤會壓印成可讀的爛圖；正確方案會在無台詞下與另一名觀測者的紙逐拍重合。艦長全程追問：「你動了原點、時間，還是紙本身？」 |
| C2-4 主張範圍三選 | **取消獨立測驗，併入終局** | 官員可以提前留下「證明地球運動」的排字樣，但此時不要求玩家再選一次正確句。它成為終局的誘餌，避免 C2-4 與 C3-3 重複考證據邊界。 |
| C3-1 五窗口＋C3-2 三道質詢 | **合併重做成「艦長的封存盲驗」** | 艦長預先把「加槳／保持／收槳」三道命令各寫進封套，順序只有掌舵者知道；馬蒂厄、艾蒂安仍獨立記錄。三趟完成後，桌上只有匿名的鼓點—岸標紙、沙盤落點與兩名觀測者紙帶。玩家先封存三組判斷，再把三個船況銅牌放到三組物證上，最後才拆封艦長命令。錯配不扣信譽：命令、間距趨勢與落點方向會形成公開矛盾，錯誤配法釘在旁邊，玩家可重新重建。正確時，三組資料同時自洽。舊證據的功能是讓玩家讀懂新匿名紀錄，不是插入同名問答槽。 |
| C3-3 最後誘惑 | **保留物理邊界，改成實體刪稿** | 官員把兩句話排成印刷樣：①穩速船上落石不必落後；②因此地球已被直接證明在動。玩家只能用一道刪除線移除沒有證據承擔的句段，留下艦長願意簽名的版本。若保留第二句，印刷版會出現一段沒有任何物證連線的「懸空墨句」；不是扣信譽後選 B，而是讓玩家看見證據鏈斷在哪裡。 |
| C3-4／章尾 | **保留、精簡說明** | 艦長把原錯誤木籌、搶跑紙、三種船況與雙紙帶一併留在碼頭。章尾只揭露當代語境與現代整理詞，不再替玩家朗讀一次完整結論。 |

### 新迴路中的對手壓力

艦長不需要永遠反對物理結果，但每一幕都要握有一件玩家在乎的東西：

- 第一幕握有船與公開署名，要求壞資料也原樣留下。
- 第二幕承認自己局部錯誤，卻質疑兩名觀測者是否能同時為真。
- 第三幕掌握封套與船況原始命令，防止任何人事後配資料。
- 終局只替證據走到的句子簽名，也攔住官員替勝方誇大。

這使他從對手轉為共同審查者，仍然有戲劇壓力，而不是變成教學提示者。

### 證據在高潮如何重新使用

高潮不再逐張回答「風／加速／兩張圖」：

- C-F1 搶跑紙成為辨認匿名加速組的比對樣本。
- 停船與穩速船艙的濕痕／撞痕，證明局部現象不因穩速而整體向後漂。
- 加速／減速的相反沙痕，讓玩家辨認匿名船況。
- C2-3 生成的透明重建片，拿來檢查公開盲驗中的岸／船兩份紙。
- 最初木籌與所有壞圖留在同一張公開板上，使改變立場可追溯。

證據不是「正確答案卡」，而是玩家完成新重建工作時使用的工具。

## 3. C2-3「雙參考物對照」的具體互動

### 場景命題

艾蒂安說石頭向前彎落；馬蒂厄說石頭沿桅杆直落。艦長把兩張原紙分開壓住：

> 「不准燒掉任何一張，也不准把紙拉到剛好合。若你說是同一件事，就用原刻度、原鼓點，把它重做給我看。」

玩家面前不是公式，也沒有「配同號／扣桅杆」按鈕，只有原始快照、兩個固定釘與一塊可壓印的透明玻璃。

### 玩家親手做的事

1. **檢查原始物證**  
   岸上紀錄被切成四張等時快照。每張都保留同一次鼓點的穿孔、碼頭刻線、桅杆位置與石頭位置；船上紙保留同四拍的石頭相對桅杆位置。介面只說：「兩人都說自己照鼓聲落筆。」

2. **先承諾觀測立足點**  
   工作桌有兩枚可用的黃銅固定釘：「碼頭刻線」與「桅杆刻線」。玩家必須選一枚，將四張岸上快照逐張掛到同一條垂直基線；未固定前不能壓印。  
   - 固定碼頭：四張快照保持岸上視角，桅杆與石頭一同向前。  
   - 固定桅杆：每張快照都把當拍桅杆移回共同零線，石頭留下近似直落點列。

3. **用鼓點穿孔對時**  
   四條細線從船上紙的鼓點孔穿到岸上四張快照。玩家可自由接，但接線後才一次壓下玻璃。過程不亮綠燈，也不提示「同號才對」。

4. **壓印結果**  
   玩家扳下「壓印」桿，系統才把整套操作變成一張永久透明片：時間線、固定基線、四個石頭點、四個桅杆影與尺刻都留下。錯誤片掛到桌邊，可另取新片重做，舊錯誤不污染正確狀態。

5. **與獨立紀錄疊合**  
   玩家把透明片推到馬蒂厄的船上原紙上。沒有 NPC 宣布對錯；是否自證由圖形本身顯示。

### 正解如何不靠提示自證

正確重建必須同時滿足四個限制，缺一不可：

1. 四條鼓點線不交叉，時間順序一致。
2. 原尺刻度完全沒被拉伸、旋轉或改比例。
3. 四個桅杆影在共同零線上重合，表示現在量的是「離桅杆多遠」。
4. 轉換後的四個石頭點與馬蒂厄船上原紙逐拍落在同一散布範圍內。

玩家只要固定桅杆、保留同拍、保持原比例，兩名獨立觀測者的紀錄就會自動疊合。把 NPC 的結論台詞全部刪掉，畫面仍會顯示：

- 固定碼頭時：桅杆前進，石頭向前且下降。
- 固定桅杆時：桅杆不移，石頭近似直落。
- 原始點沒有增刪，只有量位置的起點改變。

成功後伽桑狄只需說：「兩張都留。」現代詞「參考系」仍留到章末史實頁。

### 三種典型錯誤與可讀爛圖

| 典型錯誤 | 玩家做法 | 留下的爛圖 | 玩家能自行讀出的問題 |
|---|---|---|---|
| **時間打結** | 只把兩張紙的起點、終點相接，或把不同鼓點互配 | 細線交叉；中間點出現回頭、突然跳躍，甚至像石頭先落下再升高 | 這不是軌跡之爭，而是把不同時刻當成同一刻。錯誤片標記為「時間打結」，但不直接給正解。 |
| **拉紙求合** | 縮放、旋轉或扭斜一張紙，硬讓首尾相合 | 首尾可能碰上，中間點逐拍漂開；上下兩把尺的等格長度不同，鼓點孔也無法全數對齊 | 形狀相似是被改比例做出來的，原量測尺度已遭破壞。 |
| **固定錯誤／只移一次** | 固定碼頭卻把結果當船上圖，或只用第一拍桅杆位置把全張平移一次 | 四個桅杆影展成斜列，石頭點仍向前漂；只能對上一拍，其餘三拍依序離開船上紙 | 參考點必須隨每一拍的桅杆位置重設；一次平移不能把移動中的桅杆變成共同零線。 |

艦長對三種錯誤只追問同一句的不同版本：

- 「你換的是時刻，還是位置？」
- 「你改的是參考點，還是偷偷改了尺？」
- 「若這是船上的圖，為什麼桅杆自己在紙上走？」

他不提供做法，只迫使玩家讀自己留下的爛圖。

## 4. 風險與取捨

### 設計代價

1. **從低成本表單互動改成高成本物證互動。**  
   拖快照、固定釘、鼓點穿線、透明壓印與疊圖，都比選項題昂貴。C2-3 應先做可丟棄 spike，只驗證「玩家能否不用台詞看懂兩張圖同時成立」，不要一開始就做完整美術。

2. **場景數變少，但單場狀態更深。**  
   C0-3/C1-1、C1-4/C2-1、C3-1/C3-2 合併後，點擊量下降；代價是每個合併場需要保存更多中間操作與錯誤片。這是值得的取捨：少而有後果，比多而無風險更接近前兩章。

3. **艦長可能被誤寫回反派。**  
   他施壓的對象應是「無法追查的程序」與「過度主張」，不是為了不認輸而否定結果。每次反駁都必須有船務專業依據：槳頻、岸標、放手機構、原紙保管、公開命令。

4. **需要防止偽精確。**  
   船在真實海況會搖晃，穩速只是近似；疊合應允許可見散布帶，不可畫成像素級完美直線。否則玩法反而教出「真實資料必須完全重合」的錯誤。

5. **現代教學代理必須誠實標注。**  
   同步快照、透明壓印桌是為了讓玩家操作參考物的教學代理，不應冒充伽桑狄留下的原始史料。章末史實頁需明確區分史實實驗、遊戲重構與現代整理詞。

### 對凍結章與既有測試的衝擊

這不是文案微調，而是第三章互動骨架變更，必須走 CR＋GB-ADR。至少會影響：

- C0-3、C1-1、C2-1、C2-3、C2-4、C3-1、C3-2 的場景資料與舊存檔節點。
- G2/G4 的取得條件，以及 G1–G4 從「斷言卡」改為「物證自證」後的狀態契約。
- 公開驗證的步驟順序、匿名三船況資料、封套揭曉與終局可進入條件。
- 雙紙帶的引擎、畫布／SVG、觸控命中、錯誤片持久化、重試不污染成功旗標。
- `scenes3.json` 與生成鏡像、sanitizer、舊存檔遷移、節點測試及瀏覽器逐場驗收。

建議分三刀，不要一次重寫全章：

1. **Spike A：C2-3 雙紙帶**  
   只做四張快照、兩種固定釘、三種爛圖、船上紙疊合；先做刪台詞測試。
2. **Spike B：C3 公開匿名三船況**  
   驗證玩家是否真的會用間距趨勢＋落點方向辨認，而不是靠位置記憶。
3. **通過後才合併 C2-1 與前段操作**  
   最後處理存檔遷移、證據狀態與整章節奏。

### 工程與可用性風險

- **工程量：高。** C2-3 與公開盲驗是新型互動，不是換按鈕文案；完整落地約等同兩個獨立互動元件加一次章節狀態遷移。
- **手機操作：中高風險。** 細線與小紙點不適合手指。需提供放大工作桌、44px 以上抓點、吸附、復原，以及「點選快照 → 點選固定釘」的非拖曳替代操作。
- **無障礙：需另做等價表徵。** 不可只用顏色判斷三船況；間距需有長短紋理／數值選讀，爛圖需有可朗讀的時間順序與尺度矛盾。
- **測試：不能只驗成功旗標。** 必須驗證三種錯誤先完整演出、錯誤片會保留、可自由重試、舊錯誤不會污染 G4，以及刪除 NPC 結論台詞後仍能從圖形辨認正解。

### 最終取捨

這版會犧牲一部分開發速度與「每場都有一題可考」的整齊性，換來三件更重要的事：

1. 玩家真的在重建事故，不是在勾科學方法清單。
2. 艦長從頭到尾都有立場、有權力、也會被證據迫使修正。
3. 參考物不是一句被選中的概念，而是玩家親手把同一批原始點變成兩份都成立的紀錄。

若 spike 只能做一個，優先做 C2-3。它是第三章最獨特的物理頓悟，也是目前答案洩漏最嚴重、最能用「爛圖自診斷」翻成破案感的一場。
