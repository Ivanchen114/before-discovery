# 第三章遊玩迴路重設計_第一輪獨立評審

## 1. 診斷回應
**同意** Claude 的核心診斷，特別是「對手消音」與「清單感」是破壞一、二章「破案感」的元兇。
*   **同意 C2-3 是核心病灶**：原腳本中，雙紙帶對照是在「工作桌」上由玩家與伽桑狄平靜地解謎，艦長完全不在場，沒有人質疑。這違反了「對手不消音」原則，玩家變成在玩毫無壓力的對位小遊戲。
*   **同意 C3-1 淪為清單**：五個公開驗證窗口流於形式，缺乏對立面的拉扯，讓高潮變成了純粹的操作展示。
*   **補充診斷**：C1-1（停船基準）與 C1-3（等船安靜）也存在病灶，操作繁瑣卻缺乏對手的直接挑戰。好玩不變量是「證明給對手看」，因此每一次實驗的啟動，都應該是對應對手的一個具體質疑。

## 2. 重設計的遊玩迴路
**核心策略**：把所有枯燥的量測轉為「回應艦長與群眾質疑」的戰鬥武器，並將高潮（C2-3）搬到辯論現場。

*   **C0-1 / C0-2 (保留)**：艦長押船尾，玩家與伽桑狄押桅腳。建立事前承諾。
*   **C0-3 (合併重做：直接出航與艦長的「我贏了」)**：不需要事前定合約。直接出航，抽門閂，石頭落在桅後。艦長高興宣告「船尾！」。玩家面臨失敗。
*   **C1-2 (保留並加壓)**：玩家尋找「石頭為何落後」的原因。查閱鼓點與岸標，發現船在「加速」。決策：要求「等鼓點穩了再抽」。第二次抽閂，石頭落在桅腳。艦長受到衝擊，但立刻拋出新質疑：「那是因為甲板上有風把它吹回去了吧？」
*   **C2-1 (重做：風的辯護與船艙盲測)**：為回應風的質疑，進入船艙。取消四格矩陣，改為**盲測**：艦長在甲板隨意切換「停船」或「穩速」，玩家在封閉船艙裡看滴水與拋接，必須判斷「現在船有沒有動」。玩家做出錯誤的判斷或承認「分不出來」，艦長親自進來看也分不出。證實「共同前行」，成功排除了風。
*   **C2-2 (保留)**：加速與減速的對照，艦長自我修正，保留翻面的木籌。
*   **C2-3 (重做：搬到公開驗證的最終高潮)**：見第 3 點。
*   **C3-1 / C3-2 (合併重做：碼頭對決)**：取消五窗口查驗，直接進入群眾質詢。
    *   質詢一（風）：用 C2-1 船艙盲測結果擊破。
    *   質詢二（加速減速）：用 C2-2 紀錄擊破。
    *   質詢三（最大的衝突）：岸上群眾說「石頭往前彎」，船上水手說「石頭直落」。雙方爭執。此時玩家介入，進行 C2-3 的雙參考物對照。
*   **C2-4 / C3-3 (合併保留：邊界的收束)**：官員要求宣告「證明地球轉動」，玩家拒絕，選擇誠實的邊界。

## 3. C2-3「雙參考物對照」那一場的具體互動
將此場景移至碼頭群眾與水手爭執的現場（對手施壓：兩派人馬各執一詞，互相指責對方作假）。
*   **玩家親手做什麼**：畫面上方是岸上視角的紙帶（彎曲軌跡），下方是船上視角的紙帶（直落軌跡）。玩家獲得一把「透明座標尺」，可以定義「誰是不動的零點」。
*   **正解怎麼自證**：玩家將透明尺的 0 刻度對準岸上紙帶的「碼頭」，岸上軌跡維持彎曲，此時系統依據這把尺自動重繪下方的船上紙帶，顯示出「相對於碼頭，石頭其實也在往前彎」。接著，玩家將 0 刻度切換對準「桅杆」，船上軌跡變回直落，同時上方的岸上軌跡也被重繪為「直落」。視覺直接證明：兩張圖只是基準點不同，沒有人說謊。
*   **三種錯誤留下的爛圖**：
    1.  **時間未對齊（錯亂圖）**：若玩家沒有先對齊兩張紙帶的「同號鼓點」就套用透明尺，重繪出的軌跡會變成折線或亂跳的點。
    2.  **堅持單一圖（矛盾圖）**：若玩家試圖把其中一張圖刪除或隱藏，艦長會施壓：「你要我捂住一半人的眼睛嗎？」
    3.  **強制變形（觀測偏離圖）**：若玩家試圖直接拖曳直落軌跡把它「拉彎」，軌跡點會脫離原本的觀測刻度，出現紅色的「觀測點偏離」警告。

## 4. 風險與取捨
*   **代價與對凍結章的衝擊**：將 C2-3 的核心解謎搬到 C3 的辯論高潮中，大幅改變了原先「先在幕後準備好證據，再上台」的節奏。這會讓 C3 的張力極大，但也要求 C3 的 UI 必須能流暢地在「對話質詢」與「紙帶對齊元件」之間切換。
*   **對既有測試的衝擊**：取消了 C0-3 的合約制定與 C3-1 的五窗口查驗，可能會讓「科學方法的嚴謹性」少了一些清單式的儀式感，換來的是更流暢的戲劇推動力。
*   **工程量**：中等偏高。「透明座標尺」的相對座標轉換 UI 是重頭戲，需要開發一個能夠根據玩家定義的「零點」，即時動態重繪另一個紙帶軌跡的元件。這比原先的靜態疊圖複雜，但能完美達成「不靠文字、視覺自證」的硬原則。
