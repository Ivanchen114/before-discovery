# 《發現之前》第二章 B2-4／B2-5 與終辯高潮重設計提案

**日期**：2026-08-02
**性質**：設計提案，不修改 runtime
**正本基線**：`greybox/data/scenes2.json`、`greybox/data/debate2.json`
**目標**：刪掉「連按三次＋考三題」的複習單感，保留物理證據鏈，讓辛普里奧自己的紙在高潮反過來改變他的立場。

---

## 0. 核心裁決

只改 B2-4／B2-5 的台詞，不足以解決模板重複。真正需要改的是三件事：

1. **B2-4**：三次相同門閂操作改成「先押判斷，再一次完成三高度比較」；重複仍存在於結果紙，不存在於三次相同按鍵。
2. **B2-5**：不再做證據邊界、平方、射程三題複習；改成玩家親手把唯一仍未驗證的「船桅預測」封存，其他紀錄只按時間排好，不提前排演終辯答案。
3. **B3 最後反撲**：三支柱的人物攻防可以保留，但 FR 必須從 slope→classify→claim→三步組鏈，改成**共同重排辛普里奧自己的批註紙**。否則前兩場再怎麼壓縮，終辯仍是第一章「拿三張自己的證據逐題作答」的換皮。

本案不是讓辛普里奧變笨或投降。相反，他帶來一份真的遠砲資料；玩家要承認它、保留它，並證明它畫的是規律邊界，不是桌上實驗的死刑判決。最後改變辛普里奧的，是他自己的紙被重新歸位。

## 2. B2-4：一拋一放改成「先押，再一次看三列結果」

### 2.1 保留的物理與敘事功能

- 同高、同形、低速短程。
- 一球水平推出、一球原地放下，同時離手。
- 三個高度的聲音都在裝置解析度內分不開。
- 玩家必須自己把結果收窄到「本裝置聽得出的範圍」。
- F3 仍是後續 P2／P3 的必要證據。

### 2.2 新流程

1. 伽利略把兩顆球放進門閂，先不讓玩家拉。
2. 玩家在三列空白紙旁壓一枚木籌，押「飛出的球會晚到／分不開／現在還不能說」。這只是預測，不亮對錯。
3. 預測落紙後門閂解鎖；玩家扳一次，畫面以短蒙太奇完成三個高度。每一輪仍有兩聲與一列紀錄，但不要求三次相同點擊。
4. 三列紙同時攤開，玩家判讀能說到哪裡。
5. 選「飛遠的晚一點」時，伽利略只把三列 `分不開` 推回，不講正解；錯誤留下的是「晚一點」批註與三列原紙衝突。

### 2.3 節點級手術

| 現行節點 | 處理 | 新功能 |
|---|---|---|
| `n1` | 改寫 | 裝置、三列空白紙、木籌預測位 |
| `n2` | 改寫 | 伽利略先鎖門閂，要求玩家把預判壓在紙邊 |
| `q1` | 改寫 options | 三個預測選項，全部匯到 `q2`；只記 prediction，不判分 |
| `np1` | 刪除 | 資訊併入 `np3` |
| `q2` | 改寫 | 單一實體動作：「扳下門閂，完成三個高度」 |
| `np2` | 刪除 | 資訊併入 `np3` |
| `q3` | 刪除 | 不再要求第三次相同操作 |
| `np3` | 改寫 | 三輪短蒙太奇＋三列結果紙一次攤開 |
| `q4` | 保留結構、改 prompt | 玩家根據三列結果收邊界 |
| `nb1` | 微改 | 只指出批註與原紙衝突，不代講原理 |
| `na1`、`n3`、`s1`、`g1` | 保留並壓字 | F3 限定式結論與授證 |

### 2.4 before / after

**Before：三次同按**

> system：「第一輪。」→（扳下門閂）
> system：「墊高。第二輪。」→（扳下門閂）
> system：「再墊高。第三輪。」→（扳下門閂）

**After：先承諾，再揭曉**

> 伽利略：「先別拉。三列紙還是空的——把你的木籌壓在你預想的那一列：飛出去的晚到、兩聲分不開，還是現在根本不能說。」
> system 選項：
> A「飛出去的球會晚到。」
> B「兩聲會近得分不開。」
> C「沒有紀錄，先不押結果。」
> system：「木籌壓下，門閂解鎖。」
> 玩家動作：「扳下門閂，依序完成三個高度。」
> stage：「第一列：兩聲貼在一起。沙盤墊高，第二列仍分不開。再墊高，第三列也是。三列紙一起被釘上牆；你剛才壓下的木籌還留在旁邊。」

**Before：錯答回饋**

> 伽利略：「你的耳朵記的是『分不開』，三輪都是。晚了一點——是聽見的，還是猜的？」

**After：保留可讀後果**

> 伽利略：（把你寫的「晚」壓在三列紙旁）「這個字是哪一列留下的？找得到，就圈給我看；找不到，就別替耳朵補聲音。」

這句只把玩家送回原紙，不交付「同時落地」或「離手即下墜」。

## 3. B2-5：從三題複習單改成「封存唯一未驗預測」

### 3.1 場景功能重寫

B2-5 不再替終辯排演答案。它只完成一件敘事上必要的事：**把已做紀錄與尚未做的船桅預測分開**。

玩家面前有四張紙：

- 墨跡板：第一寸已彎。
- 桌緣彈射：低速短程的平方根關係。
- 一拋一放：前行沒有造成可辨延後。
- 船桅落石：仍只是思想實驗／待驗預測。

玩家必須親手把其中一張放進未拆蠟封。這個動作直接替第三章留下未付的帳，不再用兩倍／四倍考記憶。

### 3.2 節點級手術

| 現行節點 | 處理 | 新功能 |
|---|---|---|
| `n1` | 改寫 | 四張紙並排，其中一只蠟封袋空著 |
| `n2` | 改寫 | 伽利略要求分開「做過」與「還欠著」 |
| `q1` | 改寫為三個平行選項 | 選哪張應放進未驗蠟封：船桅／F2／F3 |
| `w1b`,`w1c` | 改寫 | 指向紙上的實際量測戳記，不講正解 |
| `n3` | 改寫 | 玩家封存船桅預測；其他三張留在證據牆 |
| `q2`,`w2`,`n4`,`q3`,`w3` | **刪除** | 兩倍／四倍複習題全刪 |
| `n5` | 壓縮 | 玩家只說一次模型，不重算兩道算術 |
| `n6` | 改寫 | 伽利略警告明天不是背答案，辛普里奧會帶自己的紙 |
| `s1`,`g1` | 保留 | 明確標船桅仍待驗，三份紀錄已分開收存 |

### 3.3 before / after

**Before：三題複習單**

> 「這份紀錄能寫到哪裡？」
> 「下落高度四倍，飛行時間幾倍？」
> 「飛行時間兩倍，水平射程幾倍？」

**After：一個有後果的整理動作**

> stage：「牆上並排四張紙。前三張有沙痕、墨點或門閂日期；船桅圖只有伽利略畫下的桅杆和一個問號。桌上擺著一只空蠟封袋。」
> 伽利略：「明天以前，只做一件事。哪張紙還不能站進『做過』這一欄？你自己封。」
> 選項 A：「把船桅落石圖放進蠟封袋。」
> 選項 B：「把桌緣平方根紀錄放進蠟封袋。」
> 選項 C：「把一拋一放紀錄放進蠟封袋。」

錯選 B：

> 伽利略：（翻到紙背的四組沙痕編號）「這四趟是誰做的？既然有日期、有落點，你封的是未驗，還是你不想帶上台的結果？」

錯選 C：

> 伽利略：（敲敲三列聲響紀錄）「三個高度都在。這張缺的是結果，還是你不喜歡它的結果？」

正解後：

> 旅人(你)：（把船桅圖放進袋中，封蠟）「這張只到預測。其餘三張是紀錄，而且都有自己的範圍。」
> 伽利略：「好。明天別背給他聽。他會帶自己的數字；你得讓他的數字也留在桌上。」

這一拍把第三章的船桅實驗變成具體欠帳，也預告第二章高潮不是「否定對手資料」。

## 4. 新高潮：共同重排辛普里奧自己的批註紙

### 4.1 為何必須改 `debate2.json`

現行 FR 依序要求：

1. 讀末段／初段斜率。
2. 判定推翻或畫邊界。
3. 選適用範圍。
4. 再做三步組鏈。

這仍是「讀題→分類→答題→複習」；而且玩家第三次把自己的 F2/F3/F4 拿出來。若不改這一段，B2-5 刪掉的複習單只會在正式辯論重生。

提案：三支柱可保留，因為那裡的人物攻防是本章強項；只把**最後反撲 FR**換成一張可重排的批註紙。

### 4.2 批註紙內容

辛普里奧把三塊內容寫在同一張紙上：

| 紙塊 | 內容 | 正確位置 |
|---|---|---|
| A 桌緣批註 | 「你們只量到低速、短程；一丈內的墨跡與落點。」 | `這裡站得住` |
| B 遠砲抄錄 | 「初段斜率 1.3，末段 1.8；遠處偏離加重。」 | `這裡畫出邊界` |
| C 高空空欄 | 「星辰／高空：本場無測量。」 | `仍未有紙` |

紙上另有辛普里奧自己的總批註：

> 「既然遠砲不同，桌上的規律全錯。」

玩家不是把這句換成自己的口號，而是把 A/B/C 放回三個欄位。三塊歸位後，「全錯」會和紙本身衝突；辛普里奧必須親手劃掉它，改寫為：

> 「桌上規律只到低速短程；遠砲資料標出空氣不可忽略的邊界；高空仍未測。」

### 4.3 互動節拍

1. **先承認對手資料**：玩家先把 B 放到 `這裡畫出邊界`。若丟到垃圾區，辛普里奧拒絕：「你要贏，還是要記錄？」
2. **再保住自己的有限結果**：A 放到 `這裡站得住`。若放進 `仍未有紙`，F2/F3 的日期、沙痕、三列聲響會保持無處安放，形成可讀矛盾。
3. **最後留下空白**：C 放到 `仍未有紙`。若放成已證，卡片背面沒有來源戳記，空欄直接暴露越界。
4. **一次提交，不逐張亮綠燈**：三塊都放完才讓紙折回正面。錯誤版保留在桌上，玩家自己找哪一塊和來源欄衝突。
5. **人物高潮**：正解不是系統授證，而是辛普里奧沉默、拿回筆、劃掉自己那句「全錯」。

### 4.4 三種可讀的錯圖

| 錯法 | 紙面後果 | NPC 最小回應 |
|---|---|---|
| 丟掉遠砲資料 | 辛普里奧的 1.3／1.8 數字無欄可歸，紙角仍有來源 | 「這是老夫量到的。你若不要它，就不是在核對。」 |
| 把遠砲當成推翻全部 | A 的桌緣沙痕仍有效，卻被 B 一筆抹掉；兩張有效紙互相否定 | 「哪一張紙說另一張沒有發生？」 |
| 把星辰寫成已證 | 高空欄沒有日期、器具、來源戳記 | 「這一欄，誰量的？」 |

NPC 只把手指放到衝突處，不替玩家說出「適用範圍」四字。

### 4.5 高潮台詞草稿

**Before：**

> 辛普里奧：「桌緣的球，飛不過一丈。砲彈，三里。星辰，更遠。——你們量出的規律，也能解釋砲彈和星辰嗎？」
> 接著玩家依序答斜率、分類、範圍與三步組鏈。

**After：**

> 辛普里奧：（把批註紙轉向全場）「老夫不問你會不會背自己的結果。這三塊，都是今日桌上的東西。你若真守得住那句『量到哪裡，說到哪裡』——把它們放回各自該在的地方。」
> 旅人(你)：（把遠砲抄錄留在紙上）「這筆不丟。末段確實更陡。」
> 辛普里奧：「很好。那它殺死了桌上的規律，還是替它畫了界？」
> 玩家完成三紙歸位。
> stage：「紙翻回正面。『遠砲不同，所以桌上全錯』那行墨，正壓在兩份都有效的紀錄中間。」
> 辛普里奧：（看了很久，提筆劃掉自己的那一行）「桌上的，留在桌上。遠砲的，另記一欄。天上的——今日空著。」
> 伽利略：（沒有接話，只把自己的批註紙推過去）「換我。你也核。」

這樣 B3-6 的交換批註不再是勝利後附加的漂亮動作，而是高潮自然完成的契約。

## 5. 節點鎖定、工程影響與總監裁決

### 5.1 是否有節點總數鎖

目前未找到 `scenes2.json active===157` 的單一總數斷言；但存在多個**等效結構鎖**：

- `run-node.mjs` 的 GB-ADR-022 明確要求 B2-5 必有 `q1/q2/q3`，並鎖 `w1b→q1`、`n5` 的平方根文字。
- 誘答測試要求 B2-5/q1 有三個平行 `這句話寫到...` 選項。
- 自動走章測試特判 B2-4/q4 的錯答重試。
- `assets.json`／`run-node.mjs` 的 viewFocusVisual 明確把 B2-4 `q1/q2/q3` 綁到雙球機關，並把 `q4` 綁到 F3 結果圖。
- 背景映射鎖定 B2-4/B2-5 場景 ID；本提案保留場景 ID，背景可沿用。

因此這不是「只刪幾行 JSON」。**刪除 q3、q2 等節點會讓既有測試正確地失敗。**

### 5.2 裁決

本案會改節點總數與既有互動契約，標記：**需總監裁決**。

若總監不允許減少節點，可採低收益 fallback：保留所有 node ID，把被刪節點改為 `legacyOnly:true` 或短 goto。但這只滿足技術數目，不改善資料複雜度，且會留下更多退役節點；不推薦把它當正式版本。

### 5.3 施工影響檔案

| 檔案 | 必改內容 |
|---|---|
| `greybox/data/scenes2.json` | B2-4／B2-5 節點、路由、文字 |
| `greybox/data/scenes2.js` | 由 JSON 重建，不手改 |
| `greybox/data/debate2.json` | FR 改為批註紙歸位資料契約 |
| `greybox/data/debate2.js` | 由 JSON 重建 |
| `greybox/src/narrative.js` | 若新 FR widget 不沿用現有 enemy/classify/claim，需新增或分流 ch2 FR action；不可破壞 ch1/ch5 |
| `greybox/src/chapter-ui.js` | 新批註紙互動；一次提交、不逐張亮對錯 |
| `greybox/data/assets.json` | B2-4 viewFocusVisual nodeIds；B3 批註紙視覺資產規則 |
| `greybox/tests/run-node.mjs` | 用新契約取代 q1/q2/q3 複習單鎖；新增三種爛圖與資料不可丟測試 |

### 5.4 不可退讓的測試

1. B2-4 必須先記 prediction，再揭示三列結果。
2. 錯誤預測不扣信譽、不消失、不改結果。
3. F3 只支持本裝置解析度內的低速短程結論。
4. B2-5 船桅圖仍是 pending，不得因整理完成自動變證據。
5. 終辯遠砲資料不得被丟棄；丟棄不能通關。
6. 遠砲資料不能推翻桌上已發生的紀錄，也不能外推星辰。
7. 正解布局必須同時保留 A、B、C 三塊，不是排除式猜題。
8. 辛普里奧的立場改變由紙面矛盾觸發；刪掉 NPC 結論台詞後，布局本身仍能自證。

## 6. 最小與完整版選項

### A. 最小版（低工程，收益有限）

- B2-4 三次操作壓成一次蒙太奇。
- B2-5 三題改一題 pending/evidence 分類。
- B3 FR 不改。

代價：減少點擊，但第一章模板仍在；只治「拖」，不治「重複」。

### B. 完整版（本提案推薦）

- B2-4、B2-5 依本案壓縮。
- B3 三支柱保留人物攻防。
- B3 FR 改批註紙歸位，B3-6 直接承接交換批註。

這是最小一刀能同時做到：保留強對手、承認反方好資料、讓證據在高潮第二次使用、拆掉第一章終辯模板。

**推薦 B。** 若只做 A，玩家會覺得流程變短，但不會覺得第二章變成另一種戲。
