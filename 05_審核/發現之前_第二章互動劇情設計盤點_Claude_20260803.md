## 〇、先更正我自己的錯誤：**第二章的 lint 不是空的**

我在《第一章互動劇情設計盤點》裡寫「`scenes2.json` 有 lint 區塊但全空（0 禁詞 0 白名單）」，交辦也依此要求我「補齊二章禁詞表」。

**這個判斷是錯的。** 我當時用的檢查是找 `bannedWords` / `whitelist` 兩個鍵，回報 0/0——**但第二章根本不用那組鍵**。實際 schema 是：

| | 第一章 `scenes.json` | 第二章 `scenes2.json` |
|---|---|---|
| 鍵 | `bannedWords` / `classes` / `whitelist` | `note` / **`terms`** / **`entries`** |
| 受管詞 | 5 個平鋪字串 | **3 個詞群**（parabola／sqrt／simul，共 5 個字串） |
| 登錄筆數 | 4 | **22** |
| 類別 | `character-hypothesis` / `post-reveal` | `player-naming` / `player-hypothesis` / `revealed-after-player` / `resolution-qualified` / `historical-fact` |
| 守門機制 | `afterPlayerNode`（節點順序斷言） | **`revealKey` / `requiresReveal`（runtime 揭曉旗標依賴）** |

**第二章的 lint 不但不是空的，契約還比第一章強。** 第一章是「這個節點必須排在那個玩家節點之後」（靜態順序）；第二章是「這個詞只有在 `reveals.sqrt` 為真時才准出現」（**執行期狀態依賴**）——玩家沒有親手觸發揭曉，NPC 就不能說那個詞。

正確的五章狀態是：

| 章 | lint |
|---|---|
| 第一章 | ✅ schema A（5 禁詞 / 4 白名單） |
| **第二章** | ✅ **schema B（3 詞群 / 22 條目 / reveal 旗標）** |
| 三、四、五章 | ❌ 完全沒有 |

**所以「把 lint 移植到後三章」這個建議仍然成立，但要先裁決移植哪一套 schema。我建議 schema B**——理由見第二節末。

### 1.4 ⚠️ `player-naming` 類別**零條目**，而「拋物線」在第二章從未出現

規格 **R-NAR2-01** 定義：

| class | 詞 | 合法事件 | 必要欄位 |
|---|---|---|---|
| `player-naming` | **拋物線** | 指定**玩家命名節點**首次出現；effect 先寫 `reveals.parabola` | `nodeId, term, revealKey` |

而 R-NAR2-02 負向變異 #6：「命名前任一 UI／ARIA 出現「拋物線」→ fail」。

**實查**：
- `entries` 的 class 分布：`player-hypothesis` 2、`revealed-after-player` 17、`resolution-qualified` 3 — **`player-naming` 0 筆**
- 「拋物線」在 `scenes2.json`、`debate2.json`、第二章 UI **一次都沒有出現**

兩種讀法：

**(a) 刻意不命名**——第二章結束於伽利略「是拋出去的東西。它往前，又往下——兩件事，同時發生。」曲線始終沒有名字，留給後面的章節。這與 `B1-1/n5` 伽利略那句「**別說。四年前你就想直接說答案。這回，我們讓它自己畫給我們看。**」完全一致，也符合本作「不把詞先給玩家」的立場。**若是這樣，它是好設計。**

**(b) 命名拍被剪掉了**——規格既然指定了「玩家命名節點」，原本應該有一個玩家親手寫下那個詞的拍。

**無論哪一種，現況都需要一次裁決**：若採 (a)，`terms.parabola` 與 `player-naming` 類別應標註為「本章刻意不使用，保留給後章」，否則負向變異 #6 是在測一個不可能被違反的條件；若採 (b)，要補回那個命名節點。

### 1.5 🔴 跨章洩漏：**「拋物線」的首次出現在第四章的旁白**

既然第二章刻意守住這個詞，我掃了全 runtime：

| 位置 | 文字 |
|---|---|
| `scenes4.json` `D2-1/n33`（旁白） | 「牛頓把錯規則的紙逐張攤開：內捲、外張、**固定方向的拋物線**、繞錯墨點的彎路，以及什麼都不改時的切線直路。」 |
| `chapter-ui.js:6330`（ch4 觀摩區標籤） | 「固定向左的作用每拍累積，路徑成為**拋物線**。」 |

**第二章守了整章、連自己的 lint 都為它留了一個類別的詞，在第四章被一句舞台指示花掉了。** 而第四章**完全沒有 lint**，所以沒有任何機制擋得住。

這是本次盤點最具體的一條跨章行動項：**移植 lint 到第四章時，`拋物線` 必須列入受管詞**，並決定它的合法命名事件在哪一章、由誰命名。

### 1.6 ✅ 順帶確認：`R-LAB2-04` 的概念選擇有完整實作

```js

  var concepts = { sqrtScale: 1, linearScale: 1, constantRange: 1 };
  if (!concepts[conceptId]) return err(state0, "unknown-law-concept");
```

閉合列舉三選一（正解 `sqrtScale`＋兩個誘答 `linearScale`／`constantRange`），錯選回 `concept-mismatch` 且不改 state、不耗天。UI 端 `chapter-ui.js:1619-1633` 有對應的 `conceptSel` 下拉。

### 1.7 建議移植 schema B 而非 schema A

若要把 lint 補到三、四、五章，我建議採第二章的 schema：

1. **`revealKey`/`requiresReveal` 是執行期依賴**，比 `afterPlayerNode` 的靜態順序斷言強——它擋得住「節點順序對、但玩家其實沒觸發那個選項」的情況。
2. **詞群（`terms`）比平鋪字串好維護**——「平方根／開方／√」是同一個概念的三種寫法，應該一起管。
3. **`resolution-qualified` 這一類是三、四、五章最需要的**：它要求「同時落地」這種詞必須帶條件句（`conditionText`）。第四章的「近乎同時」「可測的延遲」、第五章的「短少」「對得平」都屬同型。

## 二、敘事因果鏈盤點

### 2.1 總評：**因果鏈是五章中最緊的一章**

每一場都明確回答上一場留下的問題，而且**驅動問題由對手提出**，不是系統交辦。

```
B0-2  辛普里奧：「你們的『時間平方』——管得到天上飛的東西嗎?」   ← 全章驅動問題
  ↓
B1-1  伽利略：「要贏這種錯，不能罵它瞎——得讓軌跡自己現形。」    ← 方法論目標
  ↓
B1-2  船桅思想實驗 → F1「待驗預測，還不是實驗紀錄」             ← 明確標記未驗
  ↓
B1-3  死路 A：辛普里奧「你們量的是『落』。老夫問的是『飛』。」    ← 舊證據被歸檔
  ↓
B1-4  伽利略：「所以問題變了……拋出去的東西，究竟走哪條路?走多遠?」← 問題升級＋定義第二幕兩個目標
  ↓
B2-1  圭多巴爾多十六年前的筆記：「看見了，沒算明白。現在補上。」  ← 走「哪條路」
  ↓
B2-2  墨跡曲線 → F4（玩家用尺判讀「從第一寸就彎」）
  ↓
B2-3  桌緣彈射 → F2（走「多遠」：押 H=25 → 揭曉 → 換球複驗）
  ↓
B2-4  一拋一放 → F3（前行會不會拖慢下墜）
  ↓
B2-5  分「做過」與「還欠著」，把 F1 封進蠟袋
  ↓
B3    辯論 → B3-6 交換批註 → BE-1 望遠鏡 → BE-2 月球高爾夫
```

`B1-4` 那一拍（「所以問題變了」）與第一章 `A1-6` 是同型設計，**而且第二章更進一步：它一次定義了兩個子目標（軌跡、射程），後面兩場各自回答一個。** 這是五章裡結構最清楚的一次分工。

### 2.2 ✅ F1 懸置是設計，不是斷裂

`B1-2` 產生 F1「船桅待驗預測」，`B1-2/s1` 明寫「**它還不是實驗紀錄**」；`B2-5` 讓玩家把它挑出來、封進蠟袋、在袋面寫「只到預測，尚未在船上實做」。**這一章從頭到尾不驗它——它是第三章伽桑狄借船的題目。**

我特別檢查這是不是「問了但下一場不回答」的斷裂：**不是。** 它被明確標記、被玩家親手歸類、還有兩個過度宣稱的誘答（「桌上實驗已經證明船上也會如此」「與三列門閂紀錄相同，已經做完」）被伽利略駁回。**這是五章裡把「跨章懸念」處理得最乾淨的一次**，比第四章 `D1-1/ok2` 那種懸空提問高一個層級。

### 2.3 🟡 唯一的前向引用：`B0-2/n1d` 的「時間平方」對無第一章存檔的玩家沒有來歷

> `B0-2/n1d` 辛普里奧：「（直視旅人）你們的『**時間平方**』——管得到天上飛的東西嗎？」

這是全章的驅動問題，而「時間平方」是**第一章的成果**（也正是第一章的禁詞之一）。

**但規格 R-XCH-01 明訂「第二章可直接開始」**，R-XCH-02 另有「第一章唯讀投影」。實查 `B0-2/n1d` **沒有任何 `require` 分支**——有無第一章存檔的玩家看到同一句台詞。

對沒玩過第一章的玩家，開場第八句話就是一個未經介紹的既有結論。

**值得對照的是：規格自己在別處有做雙路。** R-DEB2-07 的 F5 槽位表分「ch1 certified」與「無／未完 ch1」兩欄，措辭完全不同（「第一章：斜面各傾角形式不變」vs「本章 F3：水平推出與原地放下…同落」），而且明訂「無 ch1 路線不得顯示『你在第一章證過』」。

**辯論做了雙路，開場沒有。**

**建議（P2-A）**：在 `n1d` 之後補一句，讓兩種玩家都接得住——
> 旅人（新增）：「時間平方——同一段時間走的距離，一段比一段多，多得剛好照著時間自己乘自己。斜面上我們量過。」
> 辛普里奧：「斜面。（指圖）這張圖上沒有斜面。」

一句話同時交代了詞義、標明來源、並讓辛普里奧的追問更尖銳。無 ch1 存檔的玩家得到定義，有存檔的玩家得到回收。

### 2.4 🟡 章內不對稱：F2 的兩半，一半要選概念、一半由 NPC 講結論

| | 判斷形式 | 誰說出結論 |
|---|---|---|
| **F2a 射程律** | `assertLaw(seriesId, **conceptId**)`，三選一含兩個誘答 | **玩家選** ✅ |
| **F2b 換球** | `compareBalls` 只驗資料（一銅一木、五個 partId 全同、H 集合相同、偏差 ≤3%） | **伽利略講**：`B2-3/n6`「銅球這樣彎，木球也這樣彎。重量換了，路沒有換。」 |

規格 R-LAB2-05 確實只寫守衛條件、沒要求 `conceptId`，**所以合規**。而且守衛很嚴（五個維度全同才受理），玩家不可能靠亂選過關。

**但同一份證據 F2 的兩半用了兩種標準**，而且被 NPC 講掉的那一半（「重量換了，路沒有換」）正是第二章要駁倒的核心迷思。

**程度誠實標示**：這比第五章（三張斷言全部無概念選擇、結論寫死在 UI 陣列）輕得多——玩家真的做了換球實驗、守衛真的擋得住髒資料。**它是不對稱，不是繞過。**

**建議（P3-B）**：`compareBalls` 加一個 `conceptId`，沿用 `assertLaw` 的模式：
> ✓「換了球重，路沒有換。」
> ✗「木球比較輕，所以飛得比較遠。」
> ✗「兩顆球的路一樣，因為它們一樣重。」

### 2.5 🟡 `B2-5` 的清點時刻被停用了

`B2-5` 有 5 個 `legacyOnly` 節點，其中 `n2` 是：

> 伽利略：「船桅預測、墨跡、平方根、分不開的兩聲。（逐一點過去）四樣都在了——但預測和紀錄不能混成一疊。上辯論台以前，你把它們排成一條。」

**這是全章唯一一次把四張紙點過一遍的地方**，現在被停用，玩家直接進入 `q1`（「把『做過』和『還欠著』分開。哪張該進這只袋，你自己選。」）。

**與我在三、四章找到的「型態 C：好句被整段刪除、無替代」同型**——玩家失去了一個「我手上有什麼」的清點時刻，而那正好是進辯論前最需要的。

**建議（P3-C）**：把 `n2` 放回，或至少讓 `q1` 的 prompt 先列出四張紙的名字。

### 2.6 ✅ 沒有「核心判斷被代做」

### 2.7 ✅ 生活類比與方法論自陳

- `B2-4`「別替耳朵補聲音。」——不得把沒量到的寫成結果

## 三、可直接施工的清單
