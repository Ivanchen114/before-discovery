# 《發現之前》第二章台詞口語自然度審查（Codex）

**日期**：2026-08-03
**主審檔案**：`greybox/data/scenes2.json`
**範圍**：全部 active 角色台詞與玩家選項；`stage/system` 只作語境參考。`B3-D` 的實際辯論台詞由外部 embed 承載，不在本檔審查範圍。
**方法**：全新逐句人工朗讀，不參照舊審查報告；只判斷白話程度、朗讀自然度、角色聲線與全／半形標點，不重審因果、證據邊界或玩法。

## 分級

- **A**：阻斷理解、嚴重破壞角色聲線或無法順利朗讀。
- **B**：明顯翻譯腔、名詞化／規準腔或長句結構，出現在關鍵解釋與高潮台詞，建議正式版前修正。
- **C**：意思清楚，但搭配、代詞、標點或節奏仍可口語化。

**總裁決**：A=0、B=13、C=20，共 33 項。第二章可理解，但工作台後半的角色台詞常從人物語言滑成「研究規準摘要」；最主要的跨章問題是 P2、P5、P6b，不只是標點。

## 系統性模式

- **P1：9 項。** 分號集中在思想實驗、資料判讀與章末收束；多數改句號即可。
- **P2：13 項。** 問題不是禁用所有「它」，而是抽象說法、紙張、圖形或前句整體被代回，造成英文式承接或指涉飄移。
- **P3：1 項。** 集中於 B2-2/n2「被答案養壞的眼睛」。
- **P4：7 項。** 最常見於先塞滿實驗條件，再把真正動作放到句尾。
- **P5：9 項。** 第二章後段最嚴重：「待驗預測、自己的範圍、超出證據、失分、站錯欄、讓人核」概念正確，但角色說出口像審稿規準。
- **P6a：2 項。** 主要是白話角色突然使用「尚未／其餘」。B2-3/n5 的「妙哉／然／焉知」是伽利略刻意模仿辛普里奧，情境成立，不算錯。
- **P6b：13 項。** 集中於模型解釋與證據收束，常把動作改寫成「成為一筆預測／留下可測延遲／做一次紀錄」。

## 全形／半形標點

源稿確有高能見度混用：B0-1 至 B2-3 大量使用半形 `, : ? ( )`，B2-4、B2-5、B3-F、B3-6 的新稿則多為全形，B3-1 又回到半形。現行 runtime 的「中文顯示標點全形化」測試通過，因此玩家端可能被正規化；但 canonical JSON、劇本匯出與配音稿仍不一致。建議台詞定案後另做一次純標點正規化，不把它混入語句改寫逐條處理。

## 角色聲線

- **伽利略**：敏捷、好勝、幽默仍成立；問題集中在工作台後半突然轉成「規準講師」，應把抽象規則還原成眼前的紙、聲音與動作。
- **辛普里奧**：有尊嚴的老派書面語成立，不應一律現代化；只需移除「失分」等介面／規準詞。
- **旅人**：整體現代白話；B2-5/n5 明顯像報告摘要。
- **主持**：正式語域可保留，B3-1/n2 是標點問題，不是聲線問題。
