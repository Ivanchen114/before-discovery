# 二、B 級（兩項，均為文案／UI 層）

## B-1｜HUD 把內部代碼印上玩家畫面（原則 44／候選 69 **再犯**）

`chapter-ui.js:352`：`e3Val` 寫成 **「兩本帳：J1●J2○J3○」**。
`stage.html:2313` 有這顆 chip，`（:1240/:1271）`只在窄幅／低高度隱藏——**桌機舞台殼玩家看得到 J1/J2/J3**。

這正是 20260726 在 ch3 抓過（HUD 畫 `A1 A2 A3…`）、ch4 在 `eb297fc` 修過的同一類缺陷。J 碼是系統骨架，玩家賺到的名字是「動量帳／活力帳／黏土」。

**修法（一行）**：`「帳冊：動量●｜活力○｜黏土○」`。title 提示文可留。

## B-2｜工作台沒有目的卡，杜夏特萊在實驗桌旁消失了（違反現行法 §3-2c）

`collision5Mission` 每相位一句——但全是**程序**：「輪一｜鋼頭、油灰頭各三筆；勾同速紀錄，結算帶方向的 mv。」沒有一句回答**為什麼**；規格 2-1／2-2／2-2b／2-3 寫好的杜夏特萊引導台詞（「先把院士的帳親手做一遍——他說它從沒錯過，那我們就驗給自己看」「別再撞了。同樣那幾次，換這本帳重記一遍」「先別急著把『一半』寫成規矩」「這回換個問法：不問撞完剩下多少，問它花掉的力氣留下了什麼」）**在 scenes5 與 UI 均為 0 命中**；E1-2 更是無任何對話直接進 embed。

這正是總監昨天在 ch4 抓的同一件事（「每個實驗的開始都要有目的」），而 §3-2c 已在法源 v0.1.3 生效。**ch5 是法生效後第一個交付的章，不該一出生就欠它。**

**修法（零機制）**：`collision5Mission` 由一句擴為兩行——「這一輪要回答＿＿」＋杜夏特萊一句（規格現成台詞直接用）；或在 E1-2／E2-2／E2-3 embed 前補一至兩個 line 節點。
