## 一、總裁決

第五章的戲劇骨架是五章中相當成熟的一套：杜佩不是稻草人，他的帳先被玩家親手證實；杜夏特萊不是答案導師，而是逼玩家不能換資料、不能抹掉對手；印刷清樣把「今晚能寫到哪裡」變成期限；終局不是擊敗一本帳，而是讓兩本帳各自回答不同問題並留下「未決」。

但現行互動中有三個會直接削弱這套骨架的斷裂：

1. **兩本帳的揭示順序被工作台提前攤平。** 第一輪本應只建立杜佩的動量帳確實可靠，紀錄表卻從第一筆起就同時顯示動量與活力數值、甚至標出活力短少。第二輪「同一批資料換一本帳」因而不再是重新看見，而只是重新勾選已讀過的欄位。
2. **`E2-2/lab2` 的完成條件把兩個認知拍黏反了。** 玩家必須先取得 J2，再做完 4／8 油灰追一筆，才離開 embed；劇本此後才演旅人第一次看到短少、筆停住。人物反應晚於玩家操作一整拍，4／8 的結果反而沒有任何人物反應。
3. **核心斷言多次由系統代玩家說完。** J1、J2、J3 都是玩家勾紀錄後，由固定按鈕／引擎直接授予既定斷言；三柱辯論也只需配對證據與一句證詞，完整的 `playerCorrect` 便由系統替旅人說出口。玩家在 FR 才真正親自選擇兩本帳的關係。

所以第五章不是「因果鏈不存在」，而是**資料結果、人物反應與玩家判斷三者錯拍**。修正優先順序應是：先把 J2／4-8 拆回正確時序，再隱藏第一輪的活力欄，最後把工作台與三柱各補一個真正由玩家完成的判斷。這三件做完，兩本帳的張力就能從台詞設定進入玩法。

## 二、判準與方法

每一拍沿同一條鏈檢查：

> 上一題留下什麼缺口 → 玩家為何做這次判斷 → 玩家實際決定什麼 → 結果如何可見 → 哪個人因此改變或提出新反駁 → 下一次實驗為何非做不可

另做兩個第五章專項檢查：

| 專項 | 驗收問題 |
|---|---|
| 兩本帳 | 第二本帳是否真的用「同一批原紙」重新解讀，而不是從第一輪就同步揭露？ |
| 玩家代理權 | 玩家是否親自判斷數據模式、主張射程與兩帳關係，還是只勾資料後由系統講完？ |

本輪只判斷敘事與互動因果，不重查台詞口語、證據邊界、史實裝置或 fixture 算術；若這些因素影響「玩家為何做下一步」，才會在此提出。

## 四、最值得保留的設計

### 4.1 對手先被證明正確

J1 不是替玩家集火力，而是逼玩家承認杜佩的動量帳在兩種碰撞中都閉合。這讓後面的勝利不可能靠「老人守舊所以錯」，也讓第一柱 `P2` 的退讓有重量。這個順序應保留。

### 4.2 同一批原紙，不能換資料

`E2-2/x1-x5` 是全章最好的方法性衝突：旅人想再做，杜夏特萊按住六張紙，明說一換資料就會被質疑湊答案。這使「同一份資料可以記兩本帳」不只是教學概念，而是辯論中防止挑資料的必要手段。

### 4.3 P2 → P1 → P3 的對手升級

院士先說「我的帳從沒錯」，再攻「你的帳會漏」，最後把兩本收成「同一件事」。玩家依序必須承認、守住、拆開。這比三個平行問題有戲，而且每一柱都重新使用前面做出的不同證據。

### 4.4 FR 真正讓玩家重寫問題

FR 先問同一油灰碰撞兩本帳各記到什麼，再問短少追到哪裡，最後才讓玩家選「一本贏／另一本贏／同一件事／不同事情」。這是第五章少數沒有由固定斷言按鈕代理的核心判斷，應作為工作台與三柱改造的範本。

### 4.5 院士的失敗是改變研究位置，不是被羞辱

`E3-2` 讓他留下來嘗試固定換算，最後說「坑是真的，我只是不知道記在哪一欄」。這是實驗真正改變一個人的證據，也把下一章未決問題留在世界內。

## 五、主要問題與具體修法

## 問題 1｜開場把「短少」與「兩件事」說得太早

**位置**：`E0-2/n3-x8-s7`（`scenes5.json:263-306`）
**優先級**：P1

此時玩家只看過杜佩帳與萊頓坑深報告，尚未用同一批碰撞資料算出活力短少。杜夏特萊已說「那就是兩件事」，系統又寫「油灰上的坑讓我們量得出那一截短少」。問題有兩層：

1. 「那一截短少」尚未在故事中出現，指涉先於定義。
2. 全章 FR 才應由玩家下的「兩帳記不同事情」，開場已被夥伴用近義句預告。

萊頓報告本來就可以公開 `坑深 ∝ v²`；不能提前給的是「它就是活力短少的尺」與「兩帳必然不同物」。

**建議改寫 x8**：

> 杜夏特萊：也許是兩個問題，也許只是同一件事的兩種記法。現在還不能挑。先拿同一場碰撞，讓兩本帳各算一次。

**建議改寫 s7**：

> 取得 S7：黏土報告。坑深隨速度平方改變；它能否替碰撞留下另一把尺，尚待重做與對帳。

如此保留競爭模型，而不是提前宣布勝方。

## 問題 2｜第一輪表格已顯示第二本帳，破壞「同紙重算」的揭示

**位置**：`E1-2/lab1`；`chapter-ui.js:7288-7323`
**優先級**：P0

第一輪的敘事任務是只查杜佩的動量帳；但紀錄表從第一筆起固定顯示「動量帳」與「活力帳／坑深」，鋼頭／油灰每列的 `mv²` 及短少也同時可見。玩家在第二輪之前已知道：鋼頭活力閉合、油灰活力短少。

因此 E2-2「別再撞，同一批數字換一本帳重記」失去翻頁感。玩家不是拿同一張原紙重新看見另一種模式，只是回來勾選早已顯示的欄位。

**建議呈現**：

| 階段 | 紀錄表可見欄 |
|---|---|
| J1 前 | 配置、撞前／撞後速度、帶方向動量帳 |
| J1 成立後、J2 前 | 同一批列保留；新增一個仍被紙條遮住的「第二本帳」頁籤 |
| 玩家在 E2-2 承諾不換資料後 | 親手翻開第二頁，原列不動，只新增 mv² 欄 |
| J2 成立後 | 兩帳並排，對平／短少差異才同時可見 |

不要只用 CSS 隱藏數字後在成功瞬間跳出；應保留「同一列原紙」視覺位置，讓玩家看見真正變的是算法，不是資料。

## 問題 3｜J1 結果沒有成為人物事件

**位置**：`E1-2/x6 → E2-1/n1`
**優先級**：P1

J1 後只演「六張紀錄紙一字排開」，下一場直接由杜佩宣布動量帳到哪裡都平。玩家雖親手做了六筆，卻沒有人在現場逐欄看著結果改變語氣。

**建議橋接台詞**：

> 旅人：（把鋼頭與油灰兩列各自加完）彈開三筆，平；黏成一團三筆，也平。
> 杜佩院士：現在這本帳不是我三十年前寫的，是你剛剛親手寫的。
> 杜夏特萊：很好。先把這句簽下來。下一步不是推翻它，是看它有沒有漏掉別的問題。

這一拍會讓院士真正贏一輪，也自然推進 E2-1「既然每次都平，為何還要第二本」。

## 問題 4｜J1、J2、J3 都只驗證選紙，沒有讓玩家選下物理解讀

**位置**：工作台三輪；`chapter-ui.js:7270-7286`、`7470-7485`；`engine5.js:117-193`
**優先級**：P0

玩家確實要挑對原紙，但斷言內容固定：

- J1：勾六筆後按「提出斷言一」，系統直接寫「兩種碰法 mv 都閉合」。
- J2：勾同一批後按「重算活力帳」，系統直接寫「鋼頭閉合、油灰短少」。
- J3：勾三速度後按「提出斷言三」，系統直接寫「坑深與速度平方吻合」。

引擎判斷的是資料集條件，不是玩家如何解讀表格。這和第三章第一柱「選到 A1 就自動取得共同前行」同型，只是分散在三輪。

**低成本修法**：每輪保留選紙，成功後再出現一個「在帳頁邊緣補一句」的判斷，不新增 JSON choice 節點，放在 embed 內即可。

| 輪次 | 玩家應親自選下的句子 | 可信誘答 |
|---|---|---|
| J1 | 兩種碰法的帶方向 mv 都對平 | 只有彈開對平／黏住就短少 |
| J2 | 同一批資料中，鋼頭 mv² 對平、油灰 mv² 短少 | 兩帳都一起對平／兩帳都一起短少 |
| J3 | 三個坑深跟 v² 的比例一致 | 坑深跟 v 成正比／高度愈高但無固定尺度 |

錯項不要扣信譽；讓錯句留在頁邊，玩家對照數字自行劃掉。只有玩家選下正確資料關係後才取得 J1/J2/J3。

## 問題 5｜`lab2` 把 J2 發現與 4／8 追一筆塞在同一個完成閘，人物反應晚了一拍

**位置**：`E2-2/lab2-x12`（`scenes5.json:715-756`）
**優先級**：P0，最先修改

`lab2` 的 `until` 是 `collision: followup`，不是 `j2`。現行真實順序是：

1. 玩家用同一批原紙取得 J2。
2. 工作台立刻進 `followup`，系統預設油灰頭／高速／4-8。
3. 玩家按「4／8 油灰追一筆」，看到短少三分之二。
4. embed 才結束。
5. 劇本 x8-x11 才演「旅人第一次算到短少、筆停住；院士說這本帳不算；杜夏特萊猜可能去了別處」。

也就是人物還在討論第一個等重短少，玩家已經做完了下一個反例。更糟的是，真正推翻「總是少一半」的 4／8 結果沒有任何人回應。

**推薦重排**：

> lab2a：只到 J2
> → x8：旅人算到油灰列，筆停
> → x9：玩家親口指出「同一批資料，這本短少」
> → x10：院士宣布它不算
> → x11：杜夏特萊不先猜去向，只問短少比例是否固定
> → lab2b：4／8 油灰追一筆
> → 新反應：玩家比較二分之一與三分之二，撤回固定比例
> → 進 E2-3

第五章主線 choice 數目前被測試鎖為 10（`run-node.mjs:7610-7615`）。若在 `scenes5.json` 新增 choice 節點須由總監裁決並同步更新測試；較低風險做法是在 embed 內以兩個 phase 和人物對話橋完成，不新增主線 choice。

## 問題 6｜4／8 追一筆是「指定配置＋指定解讀」的一鍵程序

**位置**：`chapter-ui.js:7366-7368`、`7412-7418`；`engine5.js:136-154`
**優先級**：P1

取得 J2 後，引擎直接把碰撞頭、速度、砝碼設成唯一正解；畫面標題已寫「總是少一半？」；玩家按一次後，成功訊息直接給 `144 → 48，短少 96（三分之二）`，隨即自動進黏土。玩家沒有做的，是這一步真正應有的判斷：等重時的一半不能外推成固定規律。

**建議橋接與判斷**：

> 杜夏特萊：（在等重油灰列的「少一半」旁畫問號）這個「一半」是規矩，還是剛好兩邊一樣重？要分開它們，下一撞只准改哪一欄？

玩家先選「只改砝碼比例」，系統再鎖定其餘條件。結果後再選：

> 「短少比例不是固定一半」／「活力帳總會少三分之二」／「動量帳因此不守恆」。

正解只否定固定一半，不替後面黏土或能量去向先下結論。

## 問題 7｜從碰撞短少跳到落球黏土，缺少「為何這個實驗能回答下一問」

**位置**：`E2-3/x1-x4`、`lab3`
**優先級**：P1

現行過門是「現在可以量坑了。三個高度，各落一次」。玩家知道怎麼做，卻不一定知道：為什麼另一顆球落入黏土，能替兩顆滑車碰撞的爭議提供資訊？

必須白話交代它只在查一個較小問題：**可見形變的尺度是否跟 v² 同步**。它不是重做碰撞，也不直接對平短少去向。

**建議橋接台詞**：

> 旅人：剛才一換砝碼，「短少一半」就站不住了。下一步追什麼？
> 杜夏特萊：（把萊頓報告放到油灰盤旁）滑車那一撞，速度、兩邊重量和黏住全纏在一起。先把問題縮小：只用同一顆球、同一盤油灰，改落下速度。
> 杜佩院士：你最多只能證明坑怎麼變，不能說那一截都進了坑。
> 旅人：好。這一輪只找一把尺，不開收據。

這同時讓院士在量測現場繼續施壓，而不是等辯論才重新出現。

## 問題 8｜J3 已由系統寫出關係與邊界，`c_scale` 才來問同一題

**位置**：`E2-3/lab3-c_scale`；`chapter-ui.js:7456-7458`、`7481-7485`
**優先級**：P1

工作台任務先明說「檢查坑深跟速度平方」，J3 成功訊息又寫「坑深與速度平方吻合；完整去向仍未對平」。離開後，`c_scale` 才問「這盤油灰能說到哪裡？」正解正是剛才成功訊息的同義句。玩家不是根據結果判斷射程，而是重選系統剛說過的答案。

**修法**：

1. 實驗前只說「看坑深怎麼跟速度一起變」，不要先點名平方。
2. J3 的第一個玩家判斷只識別資料模式：線性、平方或沒有固定關係。
3. 成功訊息只回報玩家選下的可見關係，不加「完整去向未對平」。
4. `c_scale` 才負責第二層射程：這把尺只量到油灰，不能把碰撞短少全數入帳。

這樣「模式辨識」與「證據邊界」是兩個不同判斷，不會前題代答後題。

## 問題 9｜三柱的證據配對正確，但完整論證由 `playerCorrect` 自動代說

**位置**：`debate5.json` 三柱；`narrative.js:303-338`
**優先級**：P0

玩家在每柱做兩件事：點一張證詞、點一張證據。只要 `weakTo.evidence` 配對成功，系統便自動讓旅人說出整段 `playerCorrect`，其中包含本章最難的三個判斷：

| 柱 | 系統代說的核心判斷 |
|---|---|
| P2 | 「這本帳是對的；我要說的不是它錯，而是有些事它沒記」 |
| P1 | 「坑只給可量痕跡，短少去向仍未對平；短少不等於記帳錯」 |
| P3 | 「同一碰撞一本平一本短，且換砝碼短少比例會變，因此不是同一件事」 |

證據配對是必要判斷，但不足以等同上述論證。尤其 P1 的射程與 P3 的兩帳關係正是全章主題，不能只藏在資料稿。

**建議把每柱改成兩拍**：

1. 玩家先選證據咬住哪一句。
2. 對手追問一句，玩家再從三個「同樣承認資料、但推論不同」的回應中選擇。

範例：

**P2 追問**：「你既然承認每一筆都平，第二本還憑什麼留？」

| 回應 | 判定 |
|---|---|
| 這本帳沒錯；我要追的是它沒有設欄的現象 | 正解 |
| 三十年裡總有一頁其實算錯，只是還沒找到 | 逃避不利資料 |
| 因為萊布尼茲的名字比較可信 | 權威替代 |

**P1 追問**：「坑能量，是否等於短少已全數找到？」

| 回應 | 判定 |
|---|---|
| 只能說壓陷有 v² 尺度；完整去向仍未對平 | 正解 |
| 所有短少都進了坑 | 越界 |
| 坑只是黏土的事，跟帳完全無關 | 抹去不利痕跡 |

**P3 追問**：「同一批原紙，不就是同一件事嗎？」

| 回應 | 判定 |
|---|---|
| 要看兩個量是否在同一事件裡同進同退；油灰列證明沒有 | 正解 |
| 同一份數字算出的東西一定相同 | 混淆資料與物理量 |
| 公式長得不同，所以一定是不同東西 | 形式替代理由 |

答對後才播放可縮短版 `playerCorrect`，作為玩家已選判斷的戲劇化朗讀，而不是系統第一次替玩家提出觀點。

## 問題 10｜探索模式的「此句有隙」加上 insight，讓證據配對更像找標記

**位置**：`chapter-ui.js:936-945`、`1008-1018`
**優先級**：P2

探索模式在玩家追問後會對有 `weakTo` 的句子標「此句有隙」，而 `insight` 又常直接說出該柱應承認或限制什麼。這對讀寫弱學生有幫助，但跟固定證據摘要疊加後，容易把辯論變成「找被標記的句子，再配最像的卡」。

建議保留一次保護，但改標記內容：

- 不顯示「此句有隙」。
- 改顯示對手剛被逼出的**可檢查前提**，例如「他把『帳沒錯』推成『只能有一本』」。
- 證據卡只說自己量到什麼，不說能反駁哪一柱。

如此仍支援弱讀者，但玩家要自行連起前提與資料。

## 問題 11｜杜夏特萊在辯論前先說「讓兩本帳都留在桌上」，略微預告 FR

**位置**：`E3-1/x2-x4`
**優先級**：P2

這句作為角色目標很清楚，但 FR 的正解就是兩本都留、各記不同事情。與其把答案當任務，可把它改成可觀察的勝負條件：不是保證兩本都留下，而是不能讓任何一本靠權威或一個漂亮結果撕掉另一張。

**建議改寫**：

> 杜夏特萊：等一下別急著替我贏。逼他把每一本帳能記什麼、不能記什麼，親口說清楚。
> 旅人：如果其中一本真的站不住呢？
> 杜夏特萊：那就讓它倒在自己的數字上，不倒在我們的名聲上。

這保留她的方法立場，但不預告最後必須兩本全留。

## 問題 12｜`E3-2/c_j4` 是封存儀式，不應偽裝成選擇

**位置**：`E3-2/c_j4`
**優先級**：P3

畫面問「你要在卷宗上寫什麼？」卻只有一個選項。真正的判斷已在 FR 完成；此處單選不是錯，但 UI 語意會讓玩家期待還有取捨。

建議改成明確動作按鈕：

> 「把兩本帳與『未決』一起封進卷宗」

如此它是對前面判斷的簽署，不是假 choice。第五章主線 choice 數被測試鎖為 10，這項若將 choice 改為一般 action 需要同步調整契約，應與問題 5 的結構改動一起由總監裁決。

## 六、兩本帳戲劇張力專項評估

### 已經足夠強的部分

| 張力來源 | 為何有效 |
|---|---|
| 三十年帳本 | 對手的權威不是口頭，是可翻、可加、每頁都平的實物 |
| 玩家先替對手驗證 | 讓衝突從「誰算錯」升級為「一個正確量是否能壟斷所有問題」 |
| 同一批原紙 | 排除換資料湊答案；兩帳衝突發生在同一事件內 |
| 印刷清樣 | 「未決」不是課堂保留句，而是明早是否進書、往後是否承擔質問 |
| 院士留下帳本 | 對手不是被擊敗，而是承認自己的帳有範圍 |

### 現行最削弱張力的部分

| 問題 | 戲劇後果 |
|---|---|
| 第一輪已顯示活力欄 | 第二本帳沒有揭紙瞬間 |
| E0-2 已說兩件事／短少尺度 | P3 與 J3 像證明夥伴早已宣布的答案 |
| J2 與 4-8 黏在同一 embed | 第一次短少與第二次反例沒有各自的人物反應 |
| 三柱自動播放 playerCorrect | 院士是被系統論證擊敗，不是被玩家逼退 |
| `E3-1/x4` 先說兩本都留 | FR 的重寫較像完成指定結論 |

### 最重要的重建原則

兩本帳不該只在畫面上「並排常駐」，而要經歷三個不同狀態：

1. **第一本獨占桌面，而且真的對。**
2. **同一批原紙翻到第二本後，兩本第一次吵架。**
3. **玩家不是選贏家，而是替兩本各畫可用範圍與未決欄。**

現在狀態 1、2 在 UI 裡同時出現，狀態 3 又多由系統代說。修正後，兩本帳才會是劇情，而不只是兩欄表格。

## 七、建議的重設後完整因果鏈

> 清樣明早收件，「活力」欄今晚只能寫到證據所及
> → 杜佩攤開三十年都對平的動量帳
> → 萊頓報告只留下競爭假說：坑深隨 v²，但它跟碰撞帳有何關係仍未決
> → 玩家先封存兩本帳各自要回答的問題
> → 第一輪只看動量帳；鋼頭、油灰都閉合
> → 玩家親口承認杜佩這一本沒有錯，杜佩真正贏一輪
> → 油灰坑迫使眾人問：一本總和正確的帳，是否仍可能沒記到另一種效果
> → 玩家承諾不換任何原紙，只翻到第二本帳
> → 同一批資料第一次顯示：鋼頭活力閉合、油灰活力短少
> → 杜佩宣布第二本無效；杜夏特萊只問短少比例是不是固定
> → 玩家只改砝碼比例追一筆，發現二分之一變三分之二
> → 玩家撤回「總是少一半」，但不替去向下結論
> → 萊頓報告成為下一個可查問題：可見形變是否有 v² 尺度
> → 玩家用同球、同黏土、三速度辨認坑深尺度
> → 玩家親自把「量到尺度」與「對平去向」分開
> → 辯論第一柱承認動量帳正確，第二柱守住短少不是算錯，第三柱證明兩帳不同進退
> → FR 由玩家重寫：不問誰贏，問哪一本記哪件事
> → 院士嘗試換算失敗，留下自己的帳
> → 杜夏特萊在清樣寫「活力／未決」
> → 下一章追問機械過程與熱之間尚未量得的兌換率

這條鏈中，每個實驗都只因上一個角色反駁而發生；每個結果也都必須先改變一個人的立場，才解鎖下一個工作台。

## 九、驗收條件

修正後至少要通過：

1. 第一輪完成前，玩家看不到任何活力帳結果或油灰短少數值。
2. 玩家能用一句話說明第二輪為何不能換資料。
3. J2 成立當下，人物先對第一個短少作反應；4-8 尚未發生。
4. 4-8 完成後，玩家必須親自撤回「總是少一半」，且不被系統自動帶進黏土。
5. 進黏土前，玩家知道這一輪只查可見形變是否有 v² 尺度，不是對平碰撞短少。
6. J1、J2、J3 每項都包含「選資料」與「選資料支持的關係」兩個不同動作。
7. 三柱每柱都需玩家選下至少一個推論或邊界；正確證據不得直接觸發整段 `playerCorrect`。
8. 刪掉杜夏特萊的解釋台詞，玩家仍可由兩本同列原紙看出：一本在油灰列閉合、一本短少。
9. FR 仍保留四個對稱選項，且正解不能在 E3-1 開場被逐字預告。
10. 院士至少真贏 J1 一拍，並在 J2、J3、FR 後各有不同程度的立場移動。
11. `npm test` 維持全綠，舊存檔能在新 J2／followup 分段中落到可繼續的位置。
12. 自動測試通過後仍需真人完整遊玩，確認「翻第二本帳」與兩次人物反應有可感知停頓；不得把 contract green 當戲劇驗收。

## 結論

第五章的問題不是「兩本帳衝突不夠好」，而是**好衝突被介面提前攤開、被錯誤的完成閘打亂、又被固定台詞代玩家說完**。最值得先動的不是加更多實驗，而是恢復三個停頓：第一本帳先獨自獲勝；第二本帳在同一批原紙上第一次露出短少；4-8 另成一拍推翻固定比例。然後把每張證據後面那一句物理解讀還給玩家。做到這裡，兩本帳才不是一張六欄表，而是兩套都能說真話、卻不能互相取代的世界觀。
