## 一、跨全章系統性模式（claude 提出，本輪最高槓桿發現）

比逐條修改更有效率——先套用這五條規則再回頭挑漏網之魚：

| # | 模式 | 規則 |
|---|---|---|
| P1 | **口白裡的分號** | 分號是書面標點，人說話沒有分號。全部改破折號、句號、或「，可……」。 |
| P2 | **代詞「它」當主／賓語** | 中文口語會還原名詞或直接省略，「它」頂主語是英文語序殘留。 |
| P3 | **「被」字被動** | 中文口語慣用意義被動（「沒撕掉」而非「沒有被撕掉」）。 |
| P4 | **長定語前置** | 中文偏好後置展開，前置長定語要憋一口氣才到中心語。 |
| P5 | **審查／規準術語漏進角色嘴裡** | 「完整去向」「過大的結論」「可以量的尺」是評分規準詞彙，不是 1740 年桌邊講得出來的話。 |

**額外交付面觀察**：多處 runtime 台詞是劇本稿壓縮版，壓縮時把口語呼吸壓掉了（例：E0-2/n3、E1-1/n1、E0-2/n4 都能在劇本稿找到更口語但被砍掉的版本）。**建議日後劇本稿→runtime 轉譯時，逐句核對是否壓掉了停頓詞或緩衝句。**
