## 一、三方一開始就高度收斂的核心設定（無爭議）

- **案件核心**：1798 慕尼黑兵工廠，Rumford 鑽炮實驗；不是「一桶沸水處決熱質說」，而是**熱源追債案**——熱質論每次修補都必須留下新的可測債務，運動論每次得分都必須承認尚未量出機械功與熱的定量兌換率。
- **對手型態**：對稱者初階——與第五章杜佩的「各自為是（兩本帳並列）」明確不同，本章對手擁有**模型修補權**，但修補受限：新來源須事前登記、須有可見後果、失敗版本留痕不得抹除。
- **新動詞**：管理一個「不會自己停下來的持續過程」（工時、鈍鑽、水量、累積熱曲線）——前五章量的都是離散試次，本章第一次量連續累積量。新系統預算三方估計 15–30%，均在 30% 上限內，不需強制收斂到單一數字。
- **H2 交棒**：本章不解決「機械功與熱的定量兌換率」，把它當作明確的下一債留給 H2；**不點名焦耳、不顯示任何當代單位換算**。
- **禁止神話**（三方一致）：不得寫成「Rumford 一次實驗徹底殺死熱質說」；不得讓 Rumford 已經量出兌換率；不得虛構他與焦耳的私人書信往來。
- **對手命名**：採用虛構人物（claude 提議「凱斯勒院士」），**不掛真實歷史人物姓名**——gemini 原提議掛拉瓦節（Lavoisier）觀點已確認有史實風險（拉瓦節死於 1794 年，1798 年時人已不在），三方一致同意撤回，改用純虛構角色代表熱質框架的正統立場。

## 二、本輪交叉討論收斂的兩個關鍵分歧

### 分歧一：對手要不要真的贏一輪？——**答案：要，且用「潛熱卡片化」方式**

**討論過程**：
1. codex 原案讓評議員從頭到尾只轉移熱源、留下新債，從未真正贏過一輪。
2. claude 指出：架構文件明訂本章對手是「對稱者初階——兩套模型都能吃掉部分證據」，若對手只讓步不曾吃到證據，就退化成 ch3／ch4 已用過兩次的「守門人」型態，對手升級階梯會在第四級卡第三次。claude 原案讓評議員用「潛熱」（冰融化持續吸熱卻不升溫，1798 年運動說確實答不出來）真正擊潰玩家一輪。
3. codex 認同原則，但反對把潛熱做成新的一套冰塊實驗小遊戲（會拆案為二、拉高新系統比例、變成 NPC 空降課本知識）。提出**卡片化**方案：評議員在前段就把「相變吸熱但溫度不升」列進熱質模型「已能處理的現象簿」（不是高潮才突襲）；炮鑽實驗做完後，玩家把各項證據放進「已解釋／機制未決／與預測不合」三欄卡片；評議員把潛熱卡放上桌，玩家誠實地只能把它放進「未決」欄，不能放進運動論的「已解釋」欄。這張未決卡留到章末不被後續勝利洗掉。
4. claude 自己另外提出「你的帳跑在我的數字上」（凱斯勒質疑玩家反駁熱質說用的比熱常數，本身是熱質框架量出來的）。**gemini 投票選 codex 的潛熱卡片版**，理由是它是結結實實的物理現象攻防且能與 UI 機制、旅人收尾串成因果鏈，而「帳跑在我的數字上」偏向後設質疑。**claude 隨後自我檢驗後撤回**：比熱是「量出來的常數」，不依賴熱質說為真，運動論者一樣能照用——玩家一句「那是量出來的，不是你推出來的」就能擋掉，等於給了對手一句可被反駁的台詞，不符合本專案「NPC 反駁玩家必須是證據理由，不能是修辭」的規則，也會讓可敬對手的威嚴漏氣。

**最終定案（三方最後一輪合併版，取代上一版的「降級為質地」處理）**：對手的真勝局採**主擊＋補刀**兩層設計，而非兩次獨立勝負：

- **主擊（唯一計入勝負的動作）**：潛熱卡。玩家把「冰融化持續吸熱、溫度不升」歸進運動模型的「未決」欄——這是玩家本章唯一該記成敗局的動作，證明熱質框架此刻仍能處理一個運動說交不出帳的現象。
- **認識論補刀（條件觸發，不計第二次勝負）**：潛熱卡歸檔後，若玩家或朗福德想把熱質傳統整個劃成無用，評議員才追加一句——這正是「你的帳跑在我的數字上」精修後的版本，**命題已從「你用我的數字⇒我的理論為真」（可一句反駁的邏輯偷換）改成「錯誤的本體論仍可能留下可用的量測技術；你可以反對我們怎麼解釋熱，不能一面借這把尺、一面說這把尺從未做成過任何事」**（不可反駁，因為它不主張熱質說為真，只主張壞理論能產出好工具）。台詞建議：
  > 「你剛拿來比較碎屑和薄片的比熱，是照誰的規則量的？你可以反對我們怎麼解釋熱，不能一面借這把尺，一面說這把尺從未做成過任何事。」
  這句不要求玩家再做一次來源選擇，只是評議員護住自己傳統尊嚴的解讀，功能上等同本系列一貫的「你的否定超過你的紙」規則套用在否定句上，不是例外。

三方一致確認：這個合併解決了 claude 原本撤回「帳跑在我的數字上」的兩個理由——「可被反駁」（新命題本身為真，無法反駁）與「給可敬對手不合規的修辭」（現在是條件觸發的護欄，不是攻防論點）。

**claude 提出、待實作時採納的兩個提醒**：
1. 補刀是條件觸發（只在玩家/朗福德真的想全盤抹黑熱質傳統時才出現），代價是沒踩到那個坑的玩家學不到「壞理論也能留下好工具」這一課。建議在史實頁補一行零成本的說明，確保這一課不論是否觸發補刀都能送達玩家。
2. 「範圍未決」與「棄車保帥」（中段凱斯勒丟掉「分細改變容納能力」變體）呼應一致，應放在前；「兌換率未量得」應是章末**最後一句**、交棒 H2——順序顛倒會讓玩家帶走「這章沒定案」而非「下一章要量什麼」的錯誤印象，交棒指向性會鈍掉。

### 分歧二：旅人角色反轉——**答案：成立，但限定範圍**

**討論過程**：
1. claude 提出結構性主張：前五章都是 NPC 攔住旅人，本章應反轉——旅人必須攔住盟友（Rumford 想在論文寫「熱質說已被摧毀」，玩家親手劃掉）。
2. 交叉質疑指出兩個風險：(a) 會不會把 Rumford 從強勢表演者削弱成被管教的角色（claude 自己原案已列此風險）；(b) **更嚴重**——旅人憑什麼知道該劃掉？若理由是「我知道熱質說還會活五十年」，就是用未來知識壓過當代人，破壞全系列「旅人知道答案但不能用、用了要付代價」的核心規矩。
3. claude 自我修正為「不劃掉、改增列一欄（兌換率：未量得）」，但 codex 提出更精確的版本：**不動 Rumford 本人的論文**（史實上他的論文本來就寫得很強，予以保留），玩家拒絕的是**「共同驗證頁／聯署摘要」上要求在場者集體背書的過度宣稱**——Rumford 仍可照發他自己的強解讀，玩家只是不讓觀測者集體簽名超出證據的句子。
4. claude 完全採納 codex 版本，理由：(a) 史實保護更徹底，一個字都不用動 Rumford 的論文；(b) 與系列既有原則同構（第三章船長「只替今天真的量過的事作證」、第四章「功勞記在對的人名下」——簽名只能覆蓋你真的核對過的範圍）；(c) 這版本本身就包含了「增列未量得欄」的動作。

**最終定案**：旅人的最後操作是**拒絕在共同驗證頁上集體背書 Rumford 的越界宣稱**，不刪改 Rumford 個人論文的用詞與自信（他保留強解讀並自行署名）。旅人增列的不是一筆而是**兩筆未決，且有明確先後順序**：
1. **範圍未決**（先）：本次只使已登記的有限、可耗盡熱質版本失效，不代表所有熱質版本與所有熱現象皆已裁決——與中段凱斯勒「棄車保帥」丟掉的變體呼應。
2. **兌換率未量得**（後，章末最後一句）：機械作用與升溫之間的固定換法尚未建立——這是交棒給 H2 的帳單，順序不可顛倒，否則玩家帶走的印象會是「這章沒定案」而非「下一章要量什麼」。

四欄分工：炮匠簽「操作與觀測」；評議員簽「量熱來源、反例與保留」；Rumford 簽「運動說解讀」；旅人簽「證據邊界與下一筆債」（含上述兩筆未決）。

## 三、收斂後的因果鏈（本章高潮的最終形狀）

> 評議員用潛熱卡真贏一局（早段已種下伏筆，非高潮空降）→ 桌上留下一張「機制未決」卡 → （條件觸發）若玩家/朗福德想把熱質傳統全盤抹黑，評議員追加認識論補刀「你不能一面借這把尺，一面說這把尺從未做成過任何事」→ Rumford 想在共同驗證頁寫「熱質說已被摧毀」→ **玩家拿潛熱未決卡當理由**，拒絕讓在場者集體背書這句越界宣稱（不動 Rumford 自己的論文，他保留個人強解讀並自行署名）→ 旅人在共同驗證頁增列兩筆未決，**先範圍未決、後兌換率未量得（章末最後一句，交棒 H2）**→ 炮匠／朗福德／評議員／旅人四方在原紙上分欄署名。

三方一致認為這條因果鏈是本輪討論最重要的成果：**對手的真勝利不是一次挫傷，而是本章結局得以成立的前提**——玩家用來守住誠實邊界的那張未決卡，正是剛剛輸給對手才拿到的。「贏了也還不夠」這個教訓因此不是被告知，而是被結構逼出來的。

## 四、尚未強制收斂、留給下一階段（正式場次腳本）處理的細節

以下三方仍有些微差異，但不構成分歧、不阻擋定案，可在實際撰寫 scenes6.json 節點時依現場需要決定：

- **場次數與確切分場**：codex／claude 提案的四段式骨架（開場立約→第一輪供應者排除→第二輪隔絕來源→模型決鬥高潮→簽署收尾）高度一致，僅場次切分細節（11 場 vs 12–13 場）不同；gemini 的版本較精簡。建議以 codex 的 H0/H1/H2/H3/HE 分場標籤為基礎骨架，因為它與案件已有的形式指紋、四硬閘驗收綁得最緊。
- **兵工廠守門人角色**：codex 用「首席炮匠」（單一角色，守簽名背書），claude 用「史坦格・鑽炮長」並列出與第三章維達爾船長的區隔表（守的是「能否繼續」而非「背書」，代價是機會成本而非名譽）。claude 的區隔設計更精細，建議採用，但兩案在功能上可視為同一角色的不同命名，留給下一階段定案。
- **工時是否做成真實資源額度**：claude 在原提案第八節列為待三方定案的問題之一，尚未有人正面回應；建議下一階段先做「敘事壓力優先、資源額度為次要加強」的預設，除非有更多討論。

## 五、驗收方式（沿用五章故事精彩度審查已建立的判準）

修訂後本章應能通過：
1. 能寫出一句「實驗後，某人改變了什麼」——評議員把確定的熱質來源改成待驗補流；炮匠因可重演工序而肯署名；Rumford 因潛熱未決卡被迫接受「機制未決」留在共同驗證頁上。
2. 刪掉 NPC 結論台詞，玩家仍能從自己的三欄證據卡、溫度曲線看懂核心差異。
3. 高潮必須重用前段證據（碎屑熱容量紙、乾式紙帶、密封／浸水紙帶、長時段曲線、早段已埋的潛熱現象簿），不得空降新證據。
4. 開場即可指出：誰在等（兵工廠工時／評議員的截稿）、不滿意會怎樣（只剩奇觀無獨立原紙）、何時到期（炮尾突出件按工序拆除前）。
5. 無提示紙上試玩：新玩家能在不聽 NPC 總結下說出「水沸騰」本身為何不能裁決、哪份原紙讓哪個熱源欠債、Rumford 證據支持到哪裡、H2 為何要量機械作用與升溫比例。
