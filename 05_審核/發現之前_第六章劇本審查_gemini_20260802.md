# 第六章 H1 劇本草稿交叉審查報告 (Gemini)

## 1. 核心判準檢驗
*   **金句配額（「不是X是Y」）**：**【超標】**
    *   全章共出現 5 處「不是…是…」句型，超過單章 3 句的配額限制。
    *   H0-1/a2 (朗福德):「你先問的是尺，不是答案。」(保留)
    *   H0-2/w3 (史坦格):「我守的是轉床，不是伯爵的腦袋。」(保留)
    *   H1-1/a3 (凱斯勒):「你殺掉的是『碎屑改變容量』這一版，不是熱質。」(保留)
    *   **H3-1/a2 (凱斯勒)**:「不是因為你的炮紙是假的；是因為你們這套說法還沒有吃下所有熱現象。」 -> **建議修改**（例如改為：「你這局的炮紙是真的；但你們這套說法還吞不下宇宙裡所有的熱。」）
    *   **H3-2/w2a (旅人)**:「我該限制的是共同署名，不是你的作者權。」 -> **建議修改**（例如改為：「你的作者權歸你。我限制的只有共同署名的邊界。」）
*   **「答案」用字禁令**：**【邊緣/建議微調】**
    *   H0-1/a2:「你先問的是尺，不是答案。」（這句的「答案」意指尚未經過檢驗的現成結論，語境尚可接受）。
    *   H0-2/n9 (凱斯勒):「我還以為你今天會先準備一個答案。原來只準備了一門炮。」 -> **建議修改**：把「答案」改為「結論」或「說法」，如：「我還以為你今天會先準備一套完美的結論...」，以嚴格遵守物理真理不輕易被稱為「答案」的鐵律。
*   **心聲規則**：**【Pass】**
    *   H0-1/n2 旅人在跨越時空前獨處時使用心聲 (OS)，完全符合「獨處但出聲=錯」的規則（因此正確使用了 OS）。
*   **章號與開發黑話禁令**：**【Pass】**
    *   對話與玩家選項中未見 flag, embed 等字眼。選項中的「已解釋」、「機制未決」為遊戲世界觀的 UI 標籤，合法。
*   **三格填空法（立約）**：**【Pass，極度優秀】**
    *   H0-2 完美執行了三格測試：誰在等（史坦格把關簽名）、不滿意會怎樣（漏記就作廢、留壞紙）、何時到期（借到明晚，後天要切炮頭）。死線壓迫感與實證標準完美建立。

## 2. 劇本結構與三方收斂核對
*   **潛熱卡主擊**：成功落地。S8 在早段 H0-3 埋下，在 H3-1 成為凱斯勒贏下一局的武器，讓玩家親手把它拖進「未決」，沒有發生高潮空降概念的問題。
*   **認識論補刀**：精準無比。把 Claude 的建議做成了 H3-1/c2 的條件觸發 (ch6TraditionDismissed)。只有當玩家選擇全盤抹黑熱質傳統時，凱斯勒才會抽出 T1 反殺「你拿來比較碎屑的尺是我的」。
*   **兩筆未決順序**：順序正確。先在 H3-2 處理「範圍未決」，最後 HE-1 的 x_final 才寫下歷史的交棒點「兌換率未量得」。
*   **四方分欄署名**：H3-2/a1 旅人主動劃線，HE-1 四人各自認領責任範圍。完美解決了朗福德的傲慢與共同實證邊界的衝突。旅人的行動百分之百基於盤面證據。

## 3. 史實與人設細節查核
*   **拉瓦節除名**：完全乾淨。凱斯勒（Kessler）作為虛構的慕尼黑科學院保守派院士，完美撐起了熱質說防線，避開了時空錯置的危險。
*   **朗福德的傲慢**：寫得非常傳神（「沒有人能說我為一個實驗毀了一門炮」、「我的解讀我自己負責，不必替我相信」）。這讓他的角色從單調的「正確導師」變成了有血有肉、帶有攻擊性的實用主義者。
*   **未來知識防堵**：旅人反駁朗福德時，依靠的是桌面上「未決的潛熱卡」與「被撤回的三張封條」，字字句句都有當下的實證依據，無懈可擊。

## 4. 針對 Codex 附錄 C 的回覆
*   **Q1 (H1-2與H1-3合併?)**：不建議合併。H1-2 釐清的是「變數控制」（只有接觸+轉動才發熱），H1-3 建立的是「短時段連續不衰減」。在認知上這是兩個連續的科學步驟，拆開來能讓玩家深刻體驗實驗設計的嚴謹。
*   **Q2 (工時軟鎖?)**：目前用敘事期限（明晚切炮頭）＋原紙品質來施壓已經足夠。如果加上硬性的馬班時間條 UI，可能會讓玩家過度分心於資源管理，削弱核心的物理辯論。支持維持現狀。

## 總結
這份草稿的品質高得令人頭皮發麻，尤其在機制與敘事的融合上堪稱教科書級別。只需微調兩句超標的「不是X是Y」和替換一個「答案」字眼，即可直接交由總監核准進入下一階段。
