### A-4 ｜P5／學術詞漏進角色嘴裡：4 處，其中一處是**章內退步**

**A-4a（最值得改）** `H1-3/c1` 正解：「接觸轉動**伴隨**升溫」

「伴隨」是學術詞，不是玩家會說的話。而**同一章的 `H1-2/c1` 正解寫的是「接觸和轉動**同時出現**，溫度才持續升」** —— 完全相同的概念，前一場用了口語，後一場退回書面。這不是判準問題，是同一章內部自己已經示範過正確寫法卻沒沿用。

> 建議：「這張紙只記到：固定條件下，接觸和轉動一起來的時候溫度就一直升，這一班沒看到升溫線變弱。」

**A-4b** `HE-1/c3` 正解：「機械作用和升溫**能否**固定對上」→「機械作用和升溫是不是總能對上同一個數」

**A-4c** `H3-1/c2` 誘答：「**因**炮鑽已讓整套傳統失效」——「因」單字當連詞是文言 →「因為炮鑽已經讓整套傳統失效」

**A-4d** `H0-3/c1` 題幹：「這兩套模型**能否**只靠…」——system 題幹，可接受；若要統一 →「能不能」

### A-5 ｜P6b 名詞化堆疊：`H2-1/c1` 三個選項像 UI 標籤，不像人話

三個選項都是「封存 ＋ 〔低於／偏離／重合〕T2 的曲線 ＋ ：說明」的結構。「低於 T2 的曲線」「重合」「較慢」都是儀器語言，而選項有引號、是旅人**說出來的話**。

| 現況 | 建議 |
|---|---|
| 「封存低於 T2 的曲線：密合後升溫應較慢。」 | 「封起來：密合以後升溫會變慢，比 T2 那條低。」 |
| 「封存偏離 T2 的曲線：密合後任何改變都算。」 | 「封起來：密合以後只要跟 T2 不一樣就算。」 |
| 「封存重合 T2 的曲線：密合後不變就證明運動說。」 | 「封起來：密合以後跟 T2 一樣，就證明是運動。」 |

（凱斯勒緊接的駁回 `w1`「『任何改變』不是預測」在改寫後依然咬得住，因為「只要不一樣就算」保留了原意。）

### A-6 ｜P3 被字定語：實質乾淨

全章 5 處「被…的＋名詞」，其中 4 處在 `stage` 敘述（書面敘述語域，可接受）：「被丟掉的舊封條」「被劃掉的舊版本」「被劃線的三張來源封條」「被拿去替理論背書的印章」。

角色台詞只有 1 處：`H1-3/n2` 朗福德「一條不會**被「剛好」兩個字吞掉的**線」。被字子句短、比喻鮮活、讀起來順 —— **不建議改**。這是 P3 判準應該放過的那一類。

### A-7 ｜P4 長定語前置：10 處，但 7 處集中在凱斯勒身上，屬刻意聲線

凱斯勒的長定語（「一張仍放著潛熱未決卡的紙」「這種一口氣說遍所有情況的話」「你沒有讓共同結論越界的理由」）與他的規格「冷靜、精確」一致，是**角色化而非缺陷**，不建議一律改。

唯一需要動的是同時犯 P2 的 `H3-1/n2`（見 A-2）。

### A-8 ｜全形／半形標點：紀律很好，只有一個不一致

- 半形逗號／句號／問號／驚嘆號／括號／引號：**全部 0 處**。
- 破折號「——」2 處，用法正確（`H0-2/a4` 補述、`H1-3/n4` 被打斷）。
- **唯一不一致**：`HE-1/c1` 兩個選項寫「T1**–**T4」（半形連接號 en-dash），而全章敘述一律寫「T1 **到** T4」（`H3-1/n1`、`H3-2/w1`）。選項是角色說的話，更該用「到」。

> 建議：「送入 T1 到 T4 的操作和讀數」。

## B 類：正解／誘答對稱性（洩題）

**整體結論：18 個 choice 裡 13 個對稱良好，5 個仍有洩題傾向。** 三方審查後的改寫確實生效了，而且完整轉入 runtime；以下 5 項是殘留。

### B-1 ｜`H1-3/c1`：雙重洩題（最嚴重）

```
正解 (observed-range)  「這張紙只記到：固定條件下，接觸轉動伴隨升溫，這一班沒見升溫線變弱。」
誘答 (heat-is-motion)  「這張紙只記到：固定條件下，升溫證明熱就是運動，這一班已分出勝負。」
誘答 (body-source)     「這張紙只記到：固定條件下，升溫來自炮身熱質，這一班已找到來源。」
```

**兩層洩題疊在一起：**
1. **語域**：正解用「伴隨」（書面），兩個誘答用「證明」「來自」（口語）。**正解比誘答書面**，就是全案反覆出現的那個坑。
2. **語意自我矛盾**：兩個誘答都是「只記到……」卻接「已分出勝負／已找到來源」。對句子敏感的玩家不必碰物理，光靠「只記到」和「已分出勝負」打架，就能挑出剩下那個內部一致的選項。

> 修法：正解按 A-4a 改成口語；兩個誘答的前綴改掉，讓它們不再自我矛盾，例如「這張紙可以記到：……升溫證明熱就是運動，這一班已分出勝負。」——把「只」拿掉，三句就都成立了，玩家得真的判斷紙的範圍。

### B-2 ｜`HE-1/c3`：正解獨有兩個標記

```
正解 「換幾套不同裝置，逐次比較機械作用和升溫能否固定對上。」
誘答 「換一門更大的炮，繼續比較同一裝置能熱到哪裡。」
誘答 「換幾種熱的名字，繼續比較哪個名稱最能說明紙帶。」
```
正解獨佔「逐次」（誘答都是「繼續」）＋「能否」（誘答都是口語疑問詞）。兩個標記都指向同一個選項。

> 建議：「換幾套不同裝置，一次一次比：機械作用和升溫是不是總能對上同一個數。」

### B-3 ｜`SC6-R1/c1`：長度洩題

```
正解 「我收回越過原紙與署名範圍的話。封條、壞紙和未決都照原樣留著。」（2 句 / 26 字）
誘答 「把不利原紙收掉，再請大家重新簽一次。」（1 句 / 17 字）
誘答 「把那句話換個名稱，內容照舊一起簽。」（1 句 / 16 字）
```
正解句數與字數都明顯多一截。修復場只有三個選項，這種落差一眼可見。

> 建議：把正解的第二句移到後續的 `n3`（史坦格已經在講「印章還你」，正好可以接「封條、壞紙和未決都照原樣留著」），正解只留「我收回越過原紙與署名範圍的話。」

### B-4 ｜`H0-2/c1`：正解含「它」，兩個誘答都不含

```
正解 「把每個可能來源和它應留下的痕跡寫進馬班簿。」
誘答 「把兩套說法和最後的舉手票數寫進馬班簿。」
誘答 「把朗福德的判斷和他對機器的熟悉寫進馬班簿。」
```
「它」成了正解的辨識特徵。按 A-2 改寫時順手消掉，一次解決 A 與 B 兩類。

### B-5 ｜`HE-1/c1`：正解「不附熱的解釋」

「不附」是文書用語，兩個誘答（「一起交他簽名」「前面原紙全部收掉」）都是口語。

> 建議：「送入 T1 到 T4 的操作和讀數，熱怎麼解釋的不放進去。」

### 對稱良好的正面例子（建議當範本沿用）

- **`H3-1/c1`（全章最佳）**：三個選項僅換一個動詞片語 ——「現象成立，運動模型 **已說清 / 還沒說清 / 不可能說清** 升溫為何停住」。這是三方定案裡的潛熱主擊，也是本章最關鍵的判斷，卻做到了零語言線索。
- **`HE-1/c2`**：三選項各差一個詞（保留／移走、保留／恢復），差異純在語意。
- **`H3-2/c1`**：四選項全為「私稿……，共同頁……」同構。
- `H0-3/c1`、`H1-1/c1`、`H1-2/c1`、`H2-2/c1` 亦對稱良好。

### 附註：`-again` 重複選項不是資料錯誤

`give-future-again`、`trust-rumford-again`、`heat-is-motion-again`、`common-seal-again` 四組與前一個選項**文字完全相同**，但都有 `require` 守衛（`flagAbsent` ↔ `flag`），同一時間只顯示一個。這是「同一個坑第二次踩不再扣信譽」的機制，設計正確。

唯一可考慮的小改進：第二次出現時文字一模一樣，玩家沒有任何「我又來了」的訊號，全靠 `refutedBy` 那兩句駁回兼任提醒。若要加一點回饋，改動 `-again` 的文字即可，不涉及邏輯。

## C 類：角色聲線一致性

我拿劇本第 59–66 行自己寫的聲線規格逐條驗。

### C-1 ｜落實極好的兩條（不必動）

**凱斯勒院士**——規格：「冷靜、精確、熟悉量熱傳統；每次撤回都撤得乾脆，每次保留都留下可檢驗條件。不是拖延反派。」

三次撤回全部乾脆到位：`H1-1/a1`「這一版我撤回。碎屑沒有留下我寫的容量變化。」／`H2-1/a2`「我撤回『外界空氣是必要來源』。下一版：……」／`H3-1/n4`「這三筆，你們贏。」而且每次撤回都立刻掛下一張可檢驗的來源紙。`H2-1/w5`「不必替我擦。那是我簽過的版本，讓它留著。」尤其好——對手主動守住自己的失敗紀錄，威嚴完全立住。

**旅人・心聲**——規格：「只保留當下無法說出口的認知衝突，不代替玩家下結論。」
