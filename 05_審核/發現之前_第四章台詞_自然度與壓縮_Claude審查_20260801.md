# 第四章台詞｜自然度與壓縮審查

**審查**：Claude｜**日期**：2026-08-01｜**真相模式**：AS-IS（runtime `scenes4.json`）｜**lane**：R0
**主審**：13 場、226 個台詞節點
**判定：A=0、B=2、C=3。整章的戲立得住，兩條 B 都是機械語言混進人嘴裡與一個幕間被寫成年表。**

先講結論裡最重要的一句：**第四章沒有被壓縮過頭。** 平均 27.9 字／句，比第三章（26.0）還長，第一章 35.8 最長、第五章 22.0 最短。短句多的地方（D2-2、D3-1）是刻意的節奏，不是縮水——D2-2 那場沉默是本章最好的寫作。

真正的問題不在長度，在**誰在說話**。

## 一、B-1｜六處角色嘴裡念 UI 動詞

**位置**：`greybox/data/scenes4.json` — `D0-2/w1`、`D0-2/w2`、`D1-1/w1`、`D1-1/w3`、`DE-1/w1`、`DE-1/w2`。

**實際證據**：

| 位置 | 現行台詞 |
|---|---|
| D0-2/w1 | 牛頓：追上的東西會撞上桅杆，不會乖乖躺在腳邊。**重選。** |
| D0-2/w2 | 牛頓：（圈住三個落點）風有這麼準？每一趟，都吹回同一隻手掌大的地方？**重選。** |
| D1-1/w1 | 牛頓：（用指甲截住那段弧）你把要證明的圓，先塞進答案裡了。**重選。** |
| D1-1/w3 | 牛頓：這是替它多加了一次拉。題目說，什麼都不加。**重選。** |
| DE-1/w1 | 牛頓：別人就看不出我們排除了什麼，也看不出哪一步曾經失敗。**重收。** |
| DE-1/w2 | 哈雷：過幾年就只剩一句漂亮話。要讓每句話找得到它付過的紙。**重收。** |

**因果問題**：六句的前半都是好台詞——「不會乖乖躺在腳邊」「你把要證明的圓，先塞進答案裡了」是牛頓會說的話。**「重選」「重收」不是。** 沒有人在對話裡說「重選」，那是介面在說話，焊在角色句尾。

而且它是多餘的：選項仍在畫面上，玩家本來就知道要再選一次。這兩個字唯一的作用是把玩家從 1665 年的果園拉回 2026 年的瀏覽器。

**最小修法**：刪掉那兩個字。需要推一把時，用角色行為代替指令：

> 牛頓：（圈住三個落點）風有這麼準？每一趟，都吹回同一隻手掌大的地方？
> 牛頓：（把紙推回旅人面前）再看一次。

**可失敗的驗證條件**：新增契約——`scenes4.json` 中 `speaker` 非 `stage`／`system` 的 `text` 不得含「重選／重收／重來／請選擇／點選」；放回任一個必須轉紅。第一、二章的「誘答可信度」契約（`run-node.mjs:1502`）已有同類前例可循。

## 二、B-2｜D-INT-1「幕間十四年」被寫成年表

**位置**：`scenes4.json` 場 `D-INT-1`。

**實際證據**：全場結構是

```
stage ｜旅人翻頁。紙縫折進十四年。
system｜1667——瘟疫退了，牛頓回到劍橋。
system｜1669——二十六歲，盧卡斯數學教授。
system｜1672——他磨的鏡片做成望遠鏡，送進皇家學會；隨後為了光的顏色，跟人爭了很久。
system｜這些年——那個抽屜，沒有再開過。
心聲  ｜對他們是十四年。對我，又只是一頁。
▼ 親手翻到 1679
```

**因果問題**：十四年是本章最大的情感落差——果園裡那個二十三歲的年輕人，變成一個把抽屜關了十四年的盧卡斯教授。這一整段被交代成三行條列年表。

四句 system 裡只有最後一句「**這些年——那個抽屜，沒有再開過。**」在做戲，而它是系統文字，不是場面。前三行是百科詞條：讀者知道了 1669 年他當上教授，但**沒有看見任何東西**。

對照第一章 INT-1 的十一年跳躍——那一場讓辛普里奧七十二歲重逢、當面收掉舊帳，時間的重量是演出來的。這裡沒有。

這是全章唯一真正「被壓縮」的地方，而且壓的正好是最該慢下來的那一段。

**最小修法**：**不加心聲**——NARRATIVE-CR-032 已把全章心聲從 27 砍到 10、每場恰好一個，本場那一句（「對他們是十四年。對我，又只是一頁。」）是它的唯一配額，寫得也好，原封不動。要補的是**看得見的動作**：把 1667／1669 併成一句，保留 1672 的爭執（那是牛頓性格的伏筆），空出來的位置給 stage：

> stage｜旅人伸手去拉那個抽屜。鎖著。
> stage｜（維持原句）這些年——那個抽屜，沒有再開過。

一個動作就能把「沒有再開過」從陳述變成事件，而且**心聲數不變**。

**可失敗的驗證條件**：`D-INT-1` 須至少有一個旅人可見的實體動作節點；且修法後全章活躍心聲仍須為 **10**（現行契約已鎖此數，改動必須維持綠燈）。

## 三、C 級三條

**C-1｜D2-1 的「一拍」教學段是牛頓在念規程。** 位置：`D2-1`。牛頓連說 **5 句**（全章最長連說紀錄）解釋機制：切成一小段／叫一拍／一拍之內怎麼走／切得越細越接近。旅人全程不出聲。「我今天切得很粗——因為我只有一雙手」救回一半，但那仍是一段沒有對手的教學。修法：中間插一句旅人的錯猜讓牛頓糾正，把講解變成更正——同一份資訊，戲就回來了。

**C-2｜DE-1 結尾 92 字的 stage 指示是規格文字穿了舞台指示的外衣。** 位置：`DE-1/ok1`，全章最長一句：「旅人依次夾回『一直改向的路』…切線預測紙留在第一張證據前，標作來源紀錄，不冒充第六張證據。」這句話坐在全章情感最高點（書印出來了、墨還沒乾），內容卻是歸檔規則。修法：拆兩段——「旅人依次夾回…」留作動作；「不冒充第六張證據」移到 system 行，或整段刪掉（機制本來就會擋，不需要在戲裡再講一次）。

**C-3｜心聲減量已到位；剩下的問題是那 10 句裡有 2 句語域滑出時代。**

先確認減量結果：NARRATIVE-CR-032 把活躍心聲 27 → **10**，分佈是**每場恰好一個**，密度 6.1%（第三章 12.8%、第五章 13.5%、第一章 4.0%）。**第四章現在是全系列第二精簡的一章，減量做到了，不要再砍。**

正因為只剩 10 句、每一句都是「重要或真正有趣」篩過的，每句的重量就變大。CR-032 §五 自己把「保留笑點是否仍自然」列為待人工驗收——這是我的回答：

| 心聲 | 判定 |
|---|---|
| DE-2「……別又來。上一題我跟了二十二年，墨都還沒乾。好，撿。」 | **成立。** 口語，但二十二年是真的跟過來的，笑點是掙來的 |
| D2-2「課本只留一行。眼前這場沉默，就佔了那一行。」 | **全章最好的一句。** 不動 |
| D0-2「這題我們在船上整整量了一星期。太簡單了吧。」 | 偏弱。「太簡單了吧」是當代口語；且緊接著的公開台詞「量了幾趟」已說過同一件事，觸到 CR-032 §四自訂的冗餘判準邊緣 |
| D3-1「他把『你沒有老』跟沒算完的題目放在同一疊裡了。這人真的很會擱置。」 | 偏弱。前半很好——「放在同一疊裡」精準寫出牛頓的性格；**「這人真的很會擱置」是現代人物評語**，把前半的力道洩掉。建議刪後半句留前半句 |

兩句都是調語氣，不必動節點結構，心聲數維持 10。這是判斷題不是缺陷，供您裁。

## 四、寫得好的，我也點名

- **D2-2 全場。** 「他寫了……平方反比。」／「嗯。」／「你抽屜裡那兩張紙——」／「在抽屜裡。（沒有抬頭）」——四句話演完一場關於優先權的沉默。心聲收尾「課本只留一行。眼前這場沉默，就佔了那一行」是全章最好的一句。
- **D3-1 哈雷把封蠟推給旅人，不是推給牛頓。** 這個舞台調度本身就是論證。
- 「我信不過任何人的記性，包括我自己的。看過答案以後，人都會覺得自己早就知道。」
- 「你怕別人反駁？」／「我怕他們只讀序言。」
- 「封面會回答一種問題。你剛才接回去的那些紙，回答另一種。」
- **DE-2 用兩個撞在一起的字盒當第五章的鉤子**，牛頓走到門口回頭看一眼、不替下一章回答——收得漂亮。
- 敘述佔比 15–34%，最低的 D4-1（15%）與 D3-1（19%）正好是戲最密的兩場，比例是對的。
