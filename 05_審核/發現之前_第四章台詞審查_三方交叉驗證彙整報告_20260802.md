- **驗證條件**：獨處時的台詞不再顯示為對話框，且不觸發心聲配額測試失敗。

## C 級：可改進

### C1｜D1-2/n3、n8：用「第一章紀錄」指稱旅人手上的實地紀錄

- **原句（n3）**：下：旅人的第一章紀錄——等時段距離比為 1、3、5、7…
- **建議修改**：下：旅人在比薩斜面上的紀錄——等時段距離比為 1、3、5、7…
- **原句（n8）**：…旅人的第一章紀錄不包含垂直落下一秒的數值。
- **建議修改**：…旅人那疊斜面紀錄不包含垂直落下一秒的數值。
- **因果問題**：指的是世界裡真實存在的一疊紙，卻用製作端章號命名（與 B2 同源但較輕，屬 system 語氣）。旅人自己在 n6 講的「我們在斜面上量到的是比例」才是對的講法。

### C2｜章號使用規則（建議正式訂為判準，供全系列一次分流）

- **位置**：D4-2/n20「第四章《月亮的無盡墜落》」、DE-2/s1「第四章已封存」。
- **建議規則**：**章號只允許出現在章名卡與存檔提示，不得用於指稱世界內物件、不得由角色說出**——如此 C1、B2 要修，本項可留不動。
- **因果問題**：這兩處屬章名揭示與存檔確認的 UI 慣例，不主張刪；但一至四章各自零散列過類似的「第X章」問題，標準不一致，建議寫進判準後一次掃描分流。

### C3｜D4-1/n23：三種蓋章定義擠在一句，讀起來像規則圖例

- **原句**：每一格，先看依據，再蓋章。對上了——有數字而且對了；講得通——只有說法，沒數字可對；對不上——有數字，錯了。
- **建議修改**：每一格，先看依據，再蓋章。三種章:對上了——有數字，而且合;講得通——只有說法，沒有數字可核;對不上——有數字，但不合。
- **因果問題**：同句內「對上／對了」重複，三段定義並列無停頓；這是玩家理解整場操作的關鍵句。

### C4｜D0-1/n4a：唯一一處半形括號與逗號破壞朗讀節奏

- **原句**：(紙頁開始發燙)這次,我至少先把問題寫清楚了。
- **建議修改**：（紙頁開始發燙）這次，我至少先把問題寫清楚了。
- **因果問題**：全章其餘中文台詞使用全形標點；此句在畫面與語音切句都像未清稿。

### C5｜D4-1/n25：哈雷一句話的措辭不夠精準

- **原句**：你既不是規矩的作者，也不是出錢印書的人；這桌帳裡，你最沒有輸贏。
- **建議修改**：……這桌帳裡，只有你沒有輸贏。
- **因果問題**：「最沒有輸贏」口語不成立，像把「利害關係最少」硬翻成白話；哈雷此處應直接而精準。

### C6｜「不是 X，是 Y」警句配額：4 次超過上限（具體刪哪句待總監裁決）

- **位置**：D3-1／n33；D4-1／n26；D4-2／n16；SC4-R1／w1。
- **codex 建議**：只改 D4-1／n26：「帳房裡最值錢的，是那筆本來可以藏、最後仍照樣留下的數。」
- **gemini 建議**：只改 D4-2／n16：「所以必須寫清楚，別在那裡裝大方。接好證明，再寫一句他做過、也只寫到他做過的事。」
- **因果問題**：沿用前三章定案的折衷處理——「總量須降到 ≤3」為硬性規則，「刪哪一句」屬編輯裁量。兩位審查者各自提出不同候選，皆可用，留給總監挑選。
- **驗證條件**：全章 active 台詞「不是 X，是 Y」骨架不超過 3 次，同場不超過 1 次。

### C7｜D0-2/c0、DE-1/c1：兩題可靠「最謙抑／最完整」語域猜正解

- **位置**：D0-2/c0（正解為主動限縮範圍的選項）；DE-1/c1（正解為三項中最長、最完整的選項）。
- **因果問題**：兩題都不必真正判讀證據，只要選最自我設限、名詞最完整的一項即可，讓「守邊界」退化成辨認作者偏好的語氣。
- **建議修改句**：D0-2 錯項改為與正解等長、同樣有謹慎措辭但仍有可辨識缺口的版本；DE-1 三個選項改成平行長度，避免長度本身透露正解。
- **節點結構**：不動，只改 option 文字。

### C8｜D4-2/n5：應要求「證明」的地方用了泛稱「答案」

- **原句**：版框中央留著六處空位。最後一處仍寫著二十年前留下的問題：「憑什麼從地心量？」同尺紙不能替代答案。
