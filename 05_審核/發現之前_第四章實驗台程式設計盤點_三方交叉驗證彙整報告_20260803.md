# 《發現之前》第四章實驗台程式設計盤點——三方交叉驗證彙整報告

**日期**：2026-08-03
**性質**：唯讀程式與互動設計審查，均未修改 runtime。
**方法**：claude、codex 各自獨立通讀 `engine4.js`、`chapter-ui.js`、`ch4-migration.js` 及三個 CANONICAL spike 原型；gemini 從介面體感角度審查。

**總裁決（claude／codex 高度一致）**：第四章「狀態完整性強、遊戲性落差大」——引擎認真保留封存順序、錯誤嘗試、借條、錯稿邊界，但玩家實際操作對結果的影響力參差不齊。**兩座好系統被實作細節削弱（K1作圖、K3封存），兩座停在習題/清單層（K2、K5部分流程），只有K4對帳桌與K5送錯稿已接近完成形態。**

## 一、claude 與 codex 獨立找到、互相驗證的兩個嚴重程式 bug（最高信心）

### 🔴 P0-1：K1（D2-1 牛頓作圖法）——玩家三拍的操作被整條丟棄

**codex 用 Node 直接重跑引擎重現**：`continueOrbitRule()` 沒有從玩家第三拍留下的 `position`／`velocity`／`path` 接續，而是呼叫 `simulateOrbitRule(target, speed, strength)` 從標準起點重跑一次 canonical 軌道，`o.path` 被整筆覆蓋。

**claude 的表述完全一致**：「玩家轉了三次鍵，畫面長出來的路跟他轉的角度沒有因果關係」，並指出 CANONICAL 原型（`spike_ch4_D2-1_construction_v3_CANONICAL.html`）是做對的——從玩家終點接續、結果由實測軌跡判定。

**這直接違反本章分工承諾**：「規矩是你的，前三步你自己來；剩下的他接著畫。」玩家的三拍目前只是**資格門檻**，不是結果的一部分。

**修法**（codex 具體化）：新增 `continueOrbitFromPlayerState()`，以玩家第三拍狀態為續畫起點；`run.path` 保留玩家三拍作為 prefix；新 run 加 `continuationMode:"player-state"` 欄位，舊存檔走 legacy 相容分支避免毀損。

### 🔴 P0-2：K1 固定轉鍵捷徑——不用看月亮位置也能穩定過關

**codex 精確重現**：每次封存後，下一支箭固定設為「當下正確方向 + 0.6 rad（約 34.4°）」，UI 每次轉 6°、容差 18°，因此玩家固定按三次逆時針，每拍留下 16.4° 誤差、三拍全部通過（實測驗證，`manualComplete=true`）。**玩家不必看地球位置，只要記住按鍵次數。**

**修法**：抽出可重播的 `orbitAimOffset(attempt, step)`，讓三拍偏角方向與幅度不同（如正、負、正），且非 6° 整數倍；新增契約測試：連續同方向同次數轉鍵至少一拍不得通過。

### 🔴 K3（D3-1 火星木星封存）——「先封後揭」是假的，玩家不可能失敗

**兩方獨立確認**：`predictPlanet()` 在同一次函式呼叫內依序完成「算預測→記封存時間→記開獎時間→填入實際值」，UI 只有一顆「封存並揭露」按鈕。**codex 補充關鍵數據**：火星殘差 0.32%、木星 0.03%，門檻是 3%，結構上不可能失敗；玩家可以先開火星確認規則有效、再「預測」木星，承諾機制形同虛設。

**canonical spike 原本有的內容全部被壓縮掉**（codex 詳列）：火星先選快/慢/一樣、滴蠟與拆包是兩個分開動作、木星判斷誤差會更明顯或更藏得住、刻痕帶逐圈累積可見對齊或錯開。**哈雷「我信不過任何人的記性」是全章最好的動機台詞，但玩家從沒做過真正的承諾。**

**修法**：拆成 `sealPlanetPrediction()` 與 `openPlanetObservation()` 兩個動作；封存時只存 prediction 不存 actual；把 canonical spike 的刻痕帶移植為 SVG runtime。**codex 特別提醒：不要用「先播動畫延遲 500ms 再自動拆包」這種假修法，那只是把系統代做拖長，沒有增加玩家判斷。**

## 四、做對的地方（不要在重構時誤刪）

- K1：四項封存無預設值、慢×短/中×中/快×長都能形成近圓（不偷設唯一答案）、錯拍留下 `manualAttempts` 幽靈紙、每拍重設瞄準角（防肌肉記憶，是這站唯一真正的物理內容）、`matchedPreviousEarth` 幾何診斷（claude：「全章最聰明的一段程式」）
- K4：雙模型系統算、玩家判讀、彗星硬接留下可辨認折角（全站最好的物理失敗）、`removeTravelerFromAuthorField`（全章唯一帶 repDelta 的主動放棄）
