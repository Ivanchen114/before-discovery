# 第四章對話具象化審查

**日期**：2026-07-25
**審查者**：Codex
**基線**：第四章 runtime 與可操作小說重構稿 v0.4.2

## 結論

第四章適合補「角色此刻真正拿起、拆開或擺上桌的物件」，不適合把物理推理結果畫成插圖。此次新增四個低洩答風險的台詞特寫；軌道、尺度、距離律、行星預測與雙模型比較仍全部由 HTML／SVG 工作台承擔。

## 現有視覺盤點

- 專屬場景背景：7 張；另沿用第三章印刷室作章首銜接。
- 角色立繪：青年 Newton、成熟 Newton、Halley 共 3 張。
- 章首轉場：1642 問題打開、紙頁穿越、1665 Woolsthorpe 落地共 3 張。
- 既有台詞特寫：D1-1「無作用切線預測紙」1 張。
- 程式原生物理視覺：D1 軌道逐拍改向、D2 六十地球半徑與距離律、D2-3 行星預測、D3 雙模型比較。這些視覺不得改成點陣插圖。

## 明確不做

- 山頂大砲思想實驗：兩版劇本與 runtime 均未出現；不新增。若畫出成功繞地結果會洩漏 D1 軌道謎底，若只畫預測又會與既有切線紙重複。
- 蘋果與月亮的完整軌道類比：會提前替玩家說完案件。
- 六十倍尺度、平方縮弱、行星預測結果：承載數據與判讀，維持 SVG／HTML。
- 彗星完整路徑與雙模型勝負：屬反驗結論，不能先由插圖宣判。

## 實作護欄

1. 特寫只由玩家實際看見的台詞觸發，不搶跑。
2. 圖片 caption 明確標示道具重建、預測或尚未揭露的資料。
3. D3-3 特寫綁在署名操作完成後的節點，不提前暗示正確選項。
4. 所有物理幾何、數據與模型比較仍以可操作的向量／SVG 圖呈現。
