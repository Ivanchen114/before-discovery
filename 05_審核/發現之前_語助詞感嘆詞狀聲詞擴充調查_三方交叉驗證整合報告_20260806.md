# 中文語助詞／感嘆詞／狀聲詞完整地圖與「呃……」擴充提案——三方交叉驗證整合報告

**日期**：2026-08-06
**觸發原因**：總監希望在現行「思考聲紋」系統（等等/嗯…/喔/對/啊！）外，新增更生活化的猶疑聲詞（如「痾/呃」），讓對話更自然。總監要求三方先做語言地圖調查，再回到設計。
**方法**：claude以六章全部active節點做實測基準線調查；codex以教育部辭典與學術文獻為語言學根據；gemini經過兩輪修正（含一次糾正一個完全虛構的引用）後完成設計提案。我對所有關鍵runtime引用逐一核對。

## 一、總裁決：三方高度收斂——可以加，但範圍要遠比原提案窄，且字要用對

三方一致：
1. **正字問題**：一律用「呃」，不用「痾」——「痾」本義是疾病/排泄，是網路諧音借字，不適合印刷品，且不該宣稱是歷史人物原本使用的詞（codex查證教育部辭典確認）。
2. **這不是通用詞庫擴充，是新增一個受限的「話輪事故」功能**：codex的表述是「零預設配額，數量是保險絲不是配額」；claude的表述是「6次全案上限、只給旅人、動作優先排除」。兩人方向完全一致，只是措辭不同。
3. **不要為歷史人物發明假的古代語助詞**：牛頓、伽利略、辛普里奧等角色本來就不說中文，中文是翻譯慣例；他們的猶疑應該繼續靠句法與動作表現（辛普里奧的「但。」單字成句、「停了半拍」），不需要也不該給「唔……」這種假裝古意的替代詞。

## 二、⭐ 調查過程中發現的更急迫問題：「欸」已經在用、規範完全沒寫、沒有配額

**這是claude獨立發現、我已逐字核對三處引用全部屬實的重要發現，比原提案的「呃」更急迫。**

`欸`目前在runtime裡出現3次，全部是旅人（含心聲），但有**兩種完全不同的詞性**：
- 句尾（難以置信的強調）：`scenes.json P0-1/m1a`「哇——伽利略欸。本人。」；`scenes3.json C0-1/x7`「三十年欸。就這樣從我手上滑過去」
- 句首（喚起注意/輕鬆搭話）：`scenes.json A2-3/n2`「欸，你學得真像。」

**這三處用得語域正確、也自然，但規範一個字都沒提到「欸」——現在完全沒有上限、沒有功能定義、沒有角色限制。這正是「嗯」在被清理前的狀態（13處浮濫使用）。** claude的建議：不是禁止，是**先納管**——句首/句尾分開定義為兩個功能，都只給旅人（含心聲），各章至多1次，現行3處已在額度內不需回改，但要正式寫進規範。

## 三、四類地圖（三方彙整，去重，以codex的語言學分類為骨架、claude的runtime實測基準線為證據）

### 1. 語助詞/填詞/言談標記——這些其實混了四種不同的語言資源，不是同一袋「語助詞」（codex的關鍵分類）

1. **截斷話輪的功能句**：等等、且慢——不是填充詞，是動作指令
2. **可獨立成一個話輪的回應詞/感嘆詞**：嗯/喔/對/啊
3. **維持話輪、修補說法的言談標記**：那個、就是說、然後——**這類詞天生兼任指示代名詞或連接詞，機械檢查會大量假陽性**（claude實測「這個」在runtime裡21次幾乎全是「這個數字」「這個說法」，不是填詞，不建議納入規範）
4. **句尾調整立場/情緒的語氣詞**：齁/耶/啦/嘛/呢/囉——多帶強烈台灣當代地域色彩，不納入歷史人物聲線

### 2. 感嘆詞地圖

| 詞 | 情緒色彩 | 三方共識 |
|---|---|---|
| 啊！ | 關係接通、真正發現 | 維持現行：每章至多一次，只給旅人 |
| 啊， | 較小的自我糾正/察覺 | 已合規使用（`D1-1/ok2`「啊，不是整段圓弧」） |
| 咦？ | 意外、與預期不合 | 可考慮給旅人/年輕伽利略，但需緊接具體異常 |
| 哇 | 純粹驚嘆，缺乏推動科學探究的功能 | 心聲較安全，公開說會顯輕 |
| 唉 | 無力、認輸 | 不建議，容易讓角色顯得洩氣 |
| **嘖、哼** | 不耐、輕蔑 | **三方一致：永久禁用**——本作的對手都設計成「可敬的」（辛普里奧夾進數據、凱斯勒公開撤回、杜佩留下帳本），這兩個詞會把對手丑角化 |
| 唔…… | 遲疑、偏書面 | **不可拿來假裝17世紀語感**，若用只能給旅人當「嗯」的變體，不給古人 |

### 3. 狀聲詞——不屬於角色台詞，屬旁白層，且本作現行做法已經比純狀聲詞更好（三方一致，claude找到最強的設計論證）

三方一致：狀聲詞模擬的是「世界發出的聲音」而不是「角色的思考」，應歸`stage`旁白層。**claude的關鍵發現**：本作現行runtime已經用「可數的描述」或「名詞化的聲音」取代擬聲字，這不是隨意選擇，是有結構性理由——

```
A1-5     兩聲落地)幾乎同時——            ← 用「兩聲」而非「碰！碰！」
D0-2/n1  一顆蘋果掉在旅人腳邊。沒有音效，沒有光。它滾了半圈，停住。  ← 明文拒絕音效
H0-1     鐵輪的轟響從頁縫裡撞了出來      ← 「轟響」是名詞化，不是「轟！」
```

**這不是美學選擇，是機制需求**：第二章`B2-4`整場判讀就是靠「兩聲分不分得開」——**可數的聲音能被當成證據，擬聲字不能**。若當初寫成「碰！碰！」，這個實驗的判讀基礎就沒了。建議把這條寫進規範當正式原則，而不只是既成事實。

codex補充實務規則：真實發生的聲音放`stage`；角色刻意模仿或把聲音當證據時才可進台詞；不要同時由stage寫「砰」又讓角色立刻重念一次；聲音不得成為無障礙玩家唯一能取得的證據。

### 4. 時代/語域差異——三方一致的核心原則：不要製造假的「古代中文」

牛頓、伽利略、辛普里奧等角色本來就不說中文，中文是翻譯慣例，不是語言事實。**目標不是「歷史正確的中文語助詞」（這種東西不存在），是語域訊號**——讓玩家一讀就分得出「這人來自另一個年代」。三層轉譯策略（codex）：共同底層用現代台灣高中生可直讀的句法；歷史感由稱呼、禮貌、職業材料、權力關係與句子節奏承擔；猶疑差異不用假古語，用角色行動區分。

**claude的反直覺但有runtime證據支持的結論**：古人不需要語助詞替代品，句法本身就夠——

```
A3-6/n4  辛普里奧｜但。(抬眼,直視伽利略)老夫執教四十年,今日頭一回,在辯論裡輸給了一組數字。
B0-1/n4  辛普里奧｜(微一頷首,目光掠過旅人,停了半拍)還有你。
```

「但。」單字成句、「停了半拍」——這兩個比任何老派語助詞都更有力，而且沒有年代風險。

## 四、「呃」與「嗯……」的區分：三方定義高度一致，收斂成一個可審查的判準

三方最終收斂的判準（claude的表述最精確，codex獨立提出幾乎相同的判準，可互相驗證）：

| 功能 | 定義 | 判準（看前一個節點） |
|---|---|---|
| **疑**（嗯……） | 我握著發言權，正在處理自己的工作 | 前句是我自己的話，或是我在核對資料/畫面 |
| **卡**（呃……） | 發言權剛被塞到我手上，而我沒有東西可交 | 前句是別人對我的直接問句或要求，且我尚未準備好回答 |

codex補充後續內容限制：「呃……」後面只能接三類——承認不知道、暫定回答、要求釐清。若後面接的是完整、早已準備好的結論，這個「呃」必刪。

**驗證**：claude找到現行唯一正確的「嗯」用例`A2-1/nb`伽利略「（停住）落慢一點……嗯。」——前句是他自己說的話，符合「疑」不符合「卡」，定義區分成立。

## 六、頻率紀律：三方一致的核心精神——「保險絲」而非「配額」

彙整三方建議，去重後的最終版本：
1. **預設值為零，不是必須用滿的目標**
2. 全案上限（claude：6次，即每章至多1次；codex：每場全角色合計至多1次、每名角色每章至多1次、每章至多2次——兩人數字略有差異，但精神一致：極稀有）
3. **動作優先排除規則（claude提出，三方公認最重要的一條）**：若這個猶疑寫得成一個具體動作（停筆、張嘴又閉上、把話吞回去、愣住），一律寫動作，不用語助詞。**審查判準：問「這裡能不能改成一個動作？」能，就不該用「呃」。**
4. 疊加禁令：同一句已有括號動作或句首省略號時，不再加詞
5. 禁止出現在system、hint、選項標籤、書信、旁白（codex補充）
6. 機械檢查：`呃`+`痾`總數有上限且speaker必為旅人；出現`痾`一律轉紅

**claude的人工驗收四問（codex獨立提出幾乎相同的四問，互相驗證）**：①上一拍真的把未準備的話輪交給他了嗎？②後句真的還在組句/限縮/請求釐清嗎？③刪掉後會失去權力關係或臨場節奏嗎？④同一停頓是否已由動作/刪節號完成？任一答案為否就刪。

## 七、實際候選試點：兩個不同但都站得住的位置，供總監選擇

**claude提議｜`scenes4.json D3-1/n5`**
- 前句：牛頓「你沒有老。」→ 旅人（你）「這件事很難解釋。」
- 改為：旅人（你）「呃……這件事很難解釋。」
- 理由：牛頓的話是直接陳述兼質問，發言權硬塞過來，問的是旅人最不能答的事（穿越）；且旅人確實開口了（不是沉默），動作節拍不適用。**附帶價值**：這句跟`scenes5.json E0-1/intro_print_2`（「我知道。這件事很難解釋。」）共用同一個關鍵短句，加了「呃」後兩處不再完全相同，且差異有敘事理由（對牛頓是當場語塞，對杜夏特萊是「我知道」之後的坦承）。

**codex提議｜`scenes4.json D4-1/n3`**
- 前句：哈雷「你知道現在讀書人怎麼想天上的事嗎？」→ 旅人（你）「我大概知道他們怎麼說。」
- 改為：旅人（你）「呃……大概知道。」
- 理由：哈雷突然把「替對方立最強版本」的話輪交給旅人，旅人並未準備演講，讓玩家聽見臨場接題而非降低旅人的知識。

**兩個候選都經過我核對原始碼屬實。** codex額外建議：先只在其中一處做A/B朗讀測試（確認演員讀起來不是英文「uh」的翻譯腔），兩輪真人朗讀後若確實增加臨場感再考慮第二處，找不到效果就維持一處或零處——**不建立「每個角色都要有一個猶疑詞」的對稱表**。

### 三方一致的負向範本（不該套用，直接寫進規範當反例）

- `scenes4.json D0-2/n7`：stage已明說「他在想：名字要怎麼講」，換成「呃」會刪掉這個資訊
- `scenes3.json C1-1/x5`：已有「（愣住）……」雙層停頓，不能再疊「呃」
- `scenes5.json EE-1/emilie_promise_2`（codex提出）：旅人「……我不知道。」是撤回無證據安慰的倫理重量，不是找不到說法，換成「呃」會把一個艱難承認降成日常卡詞

## 八、文件施工建議

寫入`02_設計/發現之前_角色聲線與對話規範_v0.1.md`「口語習慣是思考聲紋」一節，三功能列表之後：

> - **卡**：`呃……`。發言權剛被交到自己手上，而手上沒有可交的東西；用在角色已經開口、話卻沒接上的時刻。與**疑**的差別在於發言權是誰交出去的：**疑**是自己停下來核對，**卡**是被別人問住。後面只能接承認不知道、暫定回答或請對方釐清；若下一句已是完整判決，或停頓已由動作呈現，刪除。
> - **使用限制**（比其他語助詞嚴）：全案上限約6次，只給旅人；動作優先排除；同句已有括號動作或省略號不疊加；一律寫「呃」不得用「痾」（後者本義為疾病，是網路諧音借字，不適合印刷品，也不得宣稱是歷史語氣）。
> - **同時納管「欸」**：句首（喚起注意）與句尾（難以置信的強調）是兩種不同功能，都只給旅人（含心聲），各章至多1次。
> - **感嘆詞永久禁用**：嘖、哼——本作對手設計為可敬，這兩詞會使其丑角化。
> - **狀聲詞歸屬**：屬旁白層（stage），不進角色台詞；優先用可數描述（如「兩聲落地」）或名詞化聲音（如「轟響」），因為可數的聲音能當證據，擬聲字不能。
