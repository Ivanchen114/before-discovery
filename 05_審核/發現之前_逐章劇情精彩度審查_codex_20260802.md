# 《發現之前》逐章劇情精彩度審查（Codex）

日期：2026-08-02
主審：`greybox/data/scenes.json` 至 `scenes5.json`，並核對 `debate.json`、`debate2.json`、`debate5.json` 中實際辯論內容。
範圍：只評敘事結構、節奏、實驗的戲劇功能與跨章弧線；不重做台詞校對。

## 總裁決

五章不是「沒有故事」，而是**精彩度分布不均**：第一章有最完整的破案弧，第二章有最強的對手進化，第三章有最好的利害關係設定卻把交鋒壓進一個大型介面，第四章有全作最成熟的長時段證據再利用但後半程序過密，第五章有最精準的思想衝突卻把人生代價放到高潮之後。

整體最值得保留的是「證據不只證明自然，也迫使一個人重新安排自己與世界的關係」。最需要修的不是再添史實或再加實驗，而是讓三件事重新咬在一起：**有人會因結果失去什麼、玩家親手留下的哪張紙會在高潮被重新使用、那張紙最後逼誰做了原本不肯做的事。**

## 五章速覽

## 第一章：重物的渴望

### 整體表現

第一章仍是全作最完整的「破案」範本。它先讓玩家帶著現代答案闖入，再由辛普里奧證明「知道答案」不等於有一條當代可接受的證據鏈。衝突、挫敗、改問、取證、回到對手面前，因果非常清楚。

### 亮點

1. **A1-5/n2–n12 是全作最強的第一次失敗。**「幾乎同時」被辛普里奧改讀成「重的仍先到」，玩家做出的結果沒有消失，而是成為對手的新武器。若把高塔實驗替換成一句「結果幾乎同時」，辛普里奧吞證據的羞辱仍少了玩家親手造成那兩聲落地的責任，因此通過一句話替代測試。
2. **A1-7/q1–m4d 同時推進物理、人物與代價。**綁縛悖論破壞舊前提，伽利略隨即指出「刀能拆房，不能蓋房」，再把家庭債務與離職壓進同一場。這不是補課，是人物被問題迫著離開。
3. **A3-6/n1–n8a 不要求對手投降。**辛普里奧仍信亞里斯多德，卻把數據夾進自己的書。改變的是他的審查方式，不是立場標籤；這比「辯論勝利」四字更有力。

### 不夠精彩之處

1. **A2-2 至 A2-4（全章約 55–78%）拖成方法清單。**A2-2 做穩定紀錄，A2-3 分別換球大小與坡度，A2-4 再做紙張形狀與介質對照。每一步都正確，但連續三段主要改變的是玩家知識，不是角色關係。尤其 A2-4/qP～qBc 兩組「操作→選變因→NPC確認」可濃縮成一句結果而不大改後續，未通過一句話替代測試。
2. **A2-2/n3–n4 的核心規律由角色立即說完。**玩家留下 1、3、5、7 的紀錄，這本可成為自己讀出規律的高潮；目前伽利略先解出奇數與平方，玩家只接一句總結。刪掉 NPC 結論後，介面紀錄仍可能支持頓悟，但劇本沒有把讀圖責任明確交給玩家。
3. **正式高潮落得太晚。**A3 辯論約在全章 82% 後才開始。前段有兩次強挫敗，因此尚能撐住，但 A2 方法走廊讓「回去找辛普里奧」的迫切性暫時消失。
4. **E-2 是知識預告，不是人物後果。**月面下落替第二章播種，功能成立；但它和後續章末「再開一頁未解問題」逐漸形成固定片尾格式。

### 建議

不重寫第一章骨架。只需把 A2-3 與 A2-4 壓成一場「辛普里奧會怎麼吃掉這張紙」的針對性壓力測試：每做一組控制，牆上就消掉一條他可用的反駁。如此操作不再是科學方法清單，而是在為一個具名對手封路。

## 第二章：第一寸的弧線

### 整體表現

第二章的**人物對抗很強，宏觀模板卻重複**。兩者並不矛盾：辛普里奧確實從第一章失敗中進化，但章節仍沿用「中段備齊證據→講堂三問→失手複盤→判定」的第一章外形。

### 亮點

1. **B0-1/n2–n6a 是合格的跨章升級。**辛普里奧把四年前那張數據紙保存、批註，再帶回來提出新問題。舊勝利不是獎盃，而是對手下一回合的武器。
2. **B1-3/n1–s1 明確打敗上一章的獲勝招式。**玩家拿落體同落反例回去，辛普里奧不再吞證據，而是把它歸檔：「你們量的是落，我問的是飛。」這符合「新章對手必須能打敗上一章勝招」。
3. **B3-6/n1–n5a 的關係改變比第一章再走一步。**第一章是他願意讀玩家的紙；第二章是他把自己的數據交出來核對。對手沒有消失，合作規則卻變了。
4. **高潮確實再用前證。**`debate2.json` 把桌緣彈射、一拋一放、遠砲偏離與第一章斜面邊界重新配對；不是取得證據就結束。

### 不夠精彩之處

1. **B2-4/q1–q3 是三次同手感按鍵。**三輪扳門閂讓結果可靠，物理上合理；敘事上第二、三次沒有新風險、新反應或新決策，屬於純重複操作。一次完整演出加一個可比較的三列記錄，比三次同動畫更有力。
2. **B2-5/q1–q3 是明顯的講堂前複習單。**玩家逐題答「證據邊界、平方關係、射程倍數」，它主要確認玩家是否記得，不改變辛普里奧、伽利略或任何利害關係。這是教科書三明治中間的「整理重點」層。
3. **B3-D 再度使用正式三段辯論，降低章節新鮮度。**本章最有特色的其實是辛普里奧帶來自己的圖與數據；若高潮仍由相同的三問血條承載，對手雖升級，玩家感受到的章節動詞沒有升級。
4. **BE-1／BE-2 再次用未來天文發現作片尾。**作為史實連接漂亮，但在第一章也有相似片尾後，容易變成「本章結案→看一眼下一課」的罐頭銜接。

### 建議

壓縮 B2-4 與 B2-5，讓高潮提前到 60–70% 左右，並把辯論改成**共同重排辛普里奧自己的批註紙**：玩家不是第三次出示自己的證據，而是必須指出他的哪一筆數據支持低速短程、哪一筆迫使他承認空氣邊界。這會保留強對手，拆掉第一章模板。

## 第三章：船艙裡的靜止

### 整體表現

第三章不是缺好戲，而是**把最好的一場戲藏進介面，外層劇本只留下前因與事後報告**。C0-2 的船長是很好的「持械對手」：他拿船期、名字、舊紙與簽名權下注；C3-1 的翻紙認錯也很強。中間本該是兩者相撞的公開破案，現在 C1-1 一個大型 `ship/dossier` 互動承擔全部量測、返工與三輪質詢，接著 INT-C2 直接從「第三輪最後一句」開始。

### 亮點

1. **C0-2/n1–n13 把三格 stakes 填得最完整。**船長在等一份能簽名的結果；做不好會浪費半天船期並污染他的名字；原紙一下船就封、港務簿等著填，期限與見證都在場。
2. **舊紙是全章真正的主角。**C0-3 先限制它能說到哪裡，C3-1/n4–x19 再讓船長親手補上「船速沒記」，最後保留錯紙。高潮再用測試通過，而且再用改變了紙的主人。
3. **船長不是被說服，而是改變審查者角色。**他從拒簽，到只簽自己核過的欄位，再承認舊紙出自自己；這條人物弧值得保留。

### 不夠精彩之處

1. **C1-1/e1 吞掉了全章主動衝突。**提示顯示玩家會「排做法、跑一趟、寫判斷、被問住再補做」，但外層劇本沒有逐拍呈現哪張錯紙如何被船長利用、哪一次返船改變他的壓力。C1-1 後立刻進 INT-C2「三輪質詢結束」，等於把審判剪掉，只播宣判。
2. **C3-1/n1 先替玩家說完結論。**場景開頭直接公告「排除了落後反對、沒有量到地球運動」。刪除 NPC／旁白結論後，玩家本來應能從船況紙、雙視角紙帶與落點看懂邊界；目前高潮先由公文摘要定義，降低自證感。
3. **玩家做出的新紙沒有像舊紙一樣獲得戲劇特寫。**C3-1 最有力的再利用幾乎全落在 1632 舊紙；新實驗的岸紙、船紙、雙參考物圖主要出現在簽名分工清單。玩家親手產生的「爛圖→修正圖」沒有一張在高潮反殺具名質疑。
4. **CE-1、CE-2 雙尾聲過長。**伽利略死訊與五十年不老是情感高點，應有空間；但再接卷宗末頁與下一章月亮問題，使結束感分成兩次，船長的轉變反而不是最後殘留的情緒。

### 建議

把 C1-1 與 C3-1 之間缺失的「公開質詢」還給玩家，但不新增更多程序：固定三張紙上桌——舊紙、一次加速爛圖、一次穩速雙視角圖。船長每輪只問一個會傷到自己舊紙的問題；玩家必須用同一張紙指出缺欄、重排參考物、最後才取得簽名。C3-1 不先公告結論，讓官員依玩家實際留下的欄位寫結果。如此刪掉所有 NPC 結論後，圖仍能自己說話。

## 第四章：月亮的無盡墜落

### 整體表現

第四章是五章中**長線結構最成熟**的一章。它把第三章末頁的問題帶入果園，讓 1665 的封存預測經過十四年，被虎克的信重新解讀；再由哈雷把私人作圖推向可公開檢查的書。認識論、人物、出版代價三線第一次真正合流。

### 亮點

1. **D1-2/n16–n25 留下的問號不是裝飾。**「憑什麼從地心量」使 1665 的量級相合保持懸置，直到 D4-2/n5–n10 球殼頁才清帳。這是合格的「未付帳」。
2. **D2-1/n8–n42 是全作最好的中段高潮。**十四年沒開的抽屜、切線紙、虎克兩箭、玩家畫出的錯路與帕多瓦彈射共同生成山頂大砲。證據不是重播，而是換了功能；高潮位置約在全章 35–50%，也讓後半仍有公共驗證可做。
3. **D3-1/n25–n40 把第三章方法升級成新權力關係。**哈雷扣住木匣、要求先封預測；旅人把馬賽船長的規矩帶進劍橋。這是少數真正把前章獲勝招式變成新章操作權的交棒。
4. **D4-2 的出版風險是真實後果。**只剩兩個印刷空檔、經費被魚書卡住、來源與作者欄會進入不可輕易修改的版框，終局不只是「答對」，而是決定什麼能公開。

### 不夠精彩之處

1. **後半三個大型互動連續堆疊。**D3-1 封週期、D4-1 三份資料過帳、D4-2 六槽證明鏈，各自都合理；連續使用「先封存／逐格核對／留下錯紙」的同一語法，會使 54–88% 從冒險轉成研究稽核。
2. **D4-1 的木章分類有程序化風險。**三種章「對上／講得通／對不上」很清楚，但若逐格判讀沒有牛頓或哈雷因某一枚章失去具體東西，就會退化成高級版分類題。場後主要由哈雷總結帳面，人物衝突弱於 D3-1。
3. **D4-2/n7–n10 在互動前先交付球殼解法。**玩家之後把球殼頁放進六槽，較像組裝已知正解。刪掉 NPC 結論後，這一段的核心證明目前不完全能由玩家所見物件自行得出。
4. **章內有兩個高潮競爭。**D2-1 是物理與情感揭示，D4-2 是出版與倫理揭示。雙峰本身不是錯，但 D3-1、D4-1 都做成完整關卡，使第二峰前的上坡太長。

### 建議

保留 D2-1、D3-1、D4-2；壓縮 D4-1。三份模型對帳只保留一個最冒犯牛頓、也最替漩渦辯護的資料，其他兩份以已完成帳面呈現。讓玩家蓋下關鍵一章後，立即決定是否附「借條」，其後果直接進 D4-2 的校樣。這能讓模型比較成為出版抉擇，而非另一座獨立工作台。

## 第五章：兩本帳

### 整體表現

第五章的概念最乾淨：對手不是無知者，而是拿著一套三十年來從未算錯的帳。E2-2「不准換資料，同一批數字換一本帳」是全作最成熟的探究命題；E3-2 也讓杜佩院士保有尊嚴。然而章節的外部 stakes 太弱，導致精彩主要停留在思想層。

### 亮點

1. **E0-2/n1–n4 讓反方可敬。**杜佩的 `mv` 帳三十年都閉合，杜夏特萊明說他不是笨蛋。這符合當時合理自洽的對手測試。
2. **E2-2/x1–x12 通過三個實驗測試。**同一批紀錄被第二本帳重算，若換成一句「活力短少」，就會失去「你不能換資料迎合結論」這個戲劇行動；結果也直接改變杜佩與杜夏特萊的對峙。
3. **E3-2/x2–x7 是克制而有效的人物改變。**杜佩不是承認自己三十年都錯，而是承認坑真的存在、自己的帳沒有欄位可記。這是本章應保留的終局。
4. **高潮位置合理。**E2-2、E2-3 在約 46–66%，E3 辯論在 66% 後，節奏比前兩章俐落。

### 不夠精彩之處

1. **三格 stakes 缺兩格。**誰在等有答案：杜夏特萊與杜佩。可是「不滿意會怎樣」與「何時到期」直到 EE-1 才出現翻譯工作與一生的投入；辯論輸贏沒有決定哪一頁能否出版、哪一本帳會被抹掉、或誰將帶走原紙。
2. **E1-2 的先做順序是風格選擇，不是真決策。**先做彈開或先做黏住只換幾句反應，之後仍完成六筆。若選擇不影響杜佩是否願意留下、哪組資料先取得他的承認，就沒有破案代價。
3. **E2-3 又回到「做三筆→選證據邊界」。**油灰實驗重要，但戲劇功能主要是替短少找尺；玩家做完後仍由三選一確認界線。若不把這把尺拿去逼杜佩在自己的帳上開欄，便接近教學關卡。
4. **杜夏特萊真正的人生代價在高潮後才揭露。**EE-1 才說翻譯要很久、她會繼續做。若這是第五章關係與代價線的頂點，它應在開場就成為有限的紙張、時間或出版承諾，而不是片尾人物誌。
5. **EE-2/x7 提前封死未解問題。**全章刻意維持「短少去哪裡尚未對平」，尾聲卻直接寫成坑與溫度。這不只是證據邊界問題，也讓「未付帳」失效：下一頁不再欠玩家一個真正未知，只欠一個已知答案的測量方法。

### 建議

把杜夏特萊的法文校樣與交稿期限移到 E0-1：桌上只剩一個空欄，杜佩若不接受兩本帳並存，她就只能在譯本中選一套寫法。玩家每次實驗不是拿一張知識卡，而是在爭取「第二欄能不能進書」。高潮時杜佩把自己的帳本留下，等同允許第二欄公開；EE-1 才成為代價的支付，而非遲到的 stakes 說明。

## 跨章整體弧線

### 對手升級：概念成立，體感不完全成立

升級階梯在紙面上很清楚：

- 第一章，辛普里奧**吞噬**反例。
- 第二章，他把舊反例**歸檔**，並用自己的數據出題。
- 第三章，船長握有船、舊紙與簽名權，屬於**持械審查者**。
- 第四章，哈雷握資料與印刷窗口，屬於**公開守門人**。
- 第五章，杜佩與杜夏特萊各有一套可成立的帳，形成**各自為是**。

真正斷裂處在第三、四章：對手雖握有權力，實際壓力常被介面接管。船長三輪質詢被摘要，哈雷的模型審查變成逐格蓋章；人物設定升級了，玩家當下感受到的對抗反而變弱。

### 三條長線

1. **認識論線最完整。**反例會被吸收 → 證據有適用邊界 → 來源與空欄同樣重要 → 模型要跨資料且留下借條 → 不同量各需自己的帳。這是五章真正的主題主幹。
2. **關係線前強後散。**伽利略—旅人—辛普里奧在前兩章持續變化；第三章以船長建立一次性強關係；第四、五章人物雖精彩，但多半很快接受旅人進入核心工作。筆記本與「你沒有老」維持連續性，卻不能完全取代一段持續受考驗的關係。
3. **代價線尚未成弧。**伽利略付家庭與職涯代價，船長押名字，哈雷押錢與印刷，杜夏特萊押時間；但多數代價只被說出，玩家很少做出會真的關閉一條路的選擇。全作最需要的不是扣更多分，而是讓某張紙若處理錯，就暫時失去一位證人、一個印刷空檔或一本帳的署名。

### 章際交棒

- 第一→二章：同一位對手帶回同一張紙，最強。
- 第二→三章：船桅思想實驗成為真船問題，因果清楚。
- 第三→四章：岸上彎線延長為月球為何不直走，物理交棒強。
- 第四→五章：印刷所字盒相撞很有畫面，但屬於章末偶發事件，不是第四章尚未支付的承諾，較像預告片。

建議未來判準：下一章不能只由「又看見一個新現象」啟動；它必須拿著上一章**已做出但不能兌現的主張或物件**進場。

## 如果只能改三處

### 1. 重做第三章 C1-1 至 C3-1 的公開質詢

最高優先。這一段擁有全作最好的 stakes 與人物翻轉，卻把最值得玩的攻防摘要掉。讓三張具體紙逐輪上桌、每張錯圖留下可讀後果、船長每問一次都更接近承認自己的 1632 舊紙，能同時修復清單感、NPC 結論與玩家證據再用。

### 2. 把第五章「譯本能不能留下第二本帳」提前成全章期限

目前第五章思想好、戲劇賭注小。讓實驗結果決定一個正在排寫的法文欄位，杜夏特萊的時間、杜佩的三十年聲望與玩家的兩本帳就會在同一場衝突。這也能讓第五章成為代價線真正的頂點。

### 3. 壓縮第二章 B2-4／B2-5，拆掉第二次正式辯論模板

保留一次一拋一放與完整紀錄，刪除重複扳桿和三題複習單；改用辛普里奧自己的批註紙作高潮介面。如此第二章仍保有全作最強對手，又不會像第一章換題重演。

## 驗收方式

修訂後每章至少通過以下檢查：

1. 能寫出一句「實驗後，某人改變了什麼」；不能只寫玩家知道了什麼。
2. 把實驗替換成「結果是 X」後，至少一個人物行動或權力分配必須無法成立。
3. 刪掉 NPC 的結論台詞，玩家仍能從自己留下的紙、圖、落點或帳看懂核心差異。
4. 高潮必須要求玩家再使用前半章的一份具體證據，而且用途與取得時不同。
5. 每章開場十五分鐘內能指出：誰在等、不滿意會失去什麼、何時到期。
