## 新協作者從這裡開始

1. 先讀 `tools/skill/before-discovery-dev/SKILL.md`，用其 router 依任務／章節／階段取得本輪最小法源集；不要從舊任務書猜現況。
2. 再讀 `decisions.md`（分工與 PENDING）及最新 `05_審核/` 交付包；憲章仍是 `02_設計/發現之前_架構計劃書_v0.3.md`。
3. 歷史任務書只用來追溯當時決策，不視為當期授權。
4. 玩候選版：雙擊 `greybox/stage.html`；內部 QA 才使用 `chapter.html`／`index.html`。在 `greybox/` 內跑 `npm test`（Node 18+、零依賴）或開 `greybox/tests/tests.html`。
