## 一、主線一句話（起承轉合的脊椎）

> **艦長手上有一筆真的「落後」紀錄。玩家用同一張設計桌做出加速、穩速、減速三種船況，證明那筆落後屬於「加速」，不屬於「船在動」；最後在碼頭公開重做一次自己的設計，並把告示改成只說證據支持的範圍。**

四幕對應：**承接問題（艦長的舊紙）→ 設計對照（三種船況）→ 換參考物（兩張紙）→ 公開與邊界（告示）**。
全章只有一條線：**那一筆落後到底屬於什麼**。目前版本沒有這條線，才會覺得亂。

**工作台一「設計這一趟」**（取代 `pilot-design` ＋ `protocol`）

- **唯一核心判斷：這一趟要在什麼船況下放手，並留下哪一種可以拿去比較的紀錄。**
- 玩家每輪只決定三件事（目標 4）：
  1. **怎麼放手**：門閂／人手直接放
  2. **何時放手**：離岸加速／走穩／收槳減速（＋回程同一段＝吸收「風」）
  3. **要記什麼**（可多選）：落點／鼓點＋岸標／艙內水碗與球
- **分工由「要記什麼」推導，沒有下拉選單**（目標 5）：選門閂→馬蒂厄就位；選鼓點＋岸標→水手敲鼓、艾蒂安守岸；選落點→船上要有人記（伽桑狄或旅人）；船況永遠是艦長。同一人不得分身這條**規則不消失，改成推導時的硬約束**：若玩家選的紀錄組合需要同一個人站兩處，設計桌當下就顯示「這一趟少一個人」，而不是等跑完才失敗。
- **漏選＝資料缺角，不是填表失敗**（目標 5）：沒有鼓點＋岸標 → 這趟只能標「未分類」，不能替艦長那筆定性；沒有門閂 → 落點散布明顯放大，艦長質疑有人偷推。**錯誤以缺失資料呈現。**
- 首輪操作：3 選 ＋ 1 執行 ＝ **4**

**工作台二「湊出可以比較的一組」**（同一張桌子，取代 `investigations`）

- **唯一核心判斷：讓兩趟之間只差一件事。**（這是第一章學過的動詞，第三章升級成「船況」）
- 第二、三趟**沿用上一趟設定，只改「何時放手」**→ 每趟 **2 次操作**。
- **船艙那趟＝把「要記什麼」改成只記艙內水碗與球**（目標 6）：艦長私下換船況；玩家判「分不出來」。**這不是失敗，是本章第一次誠實地說不知道**——戲劇轉折就落在這裡，而且不必另開相位。
- **風不另開相位**：以「回程同一段」被吸收進上述任一趟，**0 額外操作**。
- 操作：2 趟 × 2 ＋ 船艙 2 ＝ **6**

## 五、誠實標註：這一輪需要引擎工作

上一版我錯誤宣稱「引擎零改動」，這次逐條標明：

- **五 slot 指派 → 推導式分工**：`PROTOCOL_REQUIRED`（release／clock／shore／ship／vessel）改成由「要記什麼」推導，並把「同一人不得分身」變成設計時的即時約束。**改引擎＋UI。**
- **`chooseInvestigationOrder` 退場**：順序由玩家實際跑了哪一趟決定，不再是獨立步驟。**改引擎＋`sanitize.js:193` 白名單＋UI。**
- **三種船況共用一支執行 API**：現行 `runPilot`／`runDesignedProtocol`／`runSpeedChange`／`runCabinBlindPair`／`runWindAudit` 合成單一 `runVoyage(design)`；`design` 只有三個欄位（放手／船況／要記什麼）。**引擎重構。**
- **收斂重複資產**：`assertG1Designed`／`assertG1`、`assertG2Designed`／`assertG2` 兩套並存，重寫時一併清理。
- **雙紙帶**：`inspectRecordBeat`／`alignRecords`／逐拍扣除 → 單一「量測起點」參數（滑桿）。**引擎＋UI。**
- **公開複驗**：`sealPublicCriteria`／`screenPublicRecord`／`revealPublicResults` 三支收成「一條門檻＋重跑＋揭曉」。**引擎。**
- **G1–G5 內部化**：保留在 `evidence` 與存檔（目標 9），UI 改「旅人筆記多一張紙」。**UI。**
- **舊存檔遷移**：相位鍵與 `lab.design` 結構改變 → 需重導與淨化，沿用既有 baseline／cabin／public 舊 API 遷移先例。

**凍結不變（不可交易）**：G1–G5 的物理內容與證據邊界、船艙誠實邊界（近似穩速、局部、不得擴張成「任何實驗都測不到運動」）、公開複驗「先封標準後揭曉」、風只判「本次精度內未見系統偏移」、艦長人物轉向、章尾月亮交棒。

**治理**：屬 ch3 凍結基線的整章重構 → 需 **CH3-CR-018（結構重寫）＋ GB-ADR**，先文件後程式。前一份節點草稿（木籌／刪 C1-4）**併入本重構，不單獨施工**。

## 六、本輪要總監檢查的三個問題
