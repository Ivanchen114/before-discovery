## 一、四項必修

### 修正 1｜舊紙只能稱「同一種操作階段」

**v0.3 說得太滿**（「舊紙記的那一段，我們量到它在加速」——像今天測到了過去那一趟）。

**定案措辭**：

> 我們今天重做「解纜後第一段」，量到**這個階段**速度仍在增加。舊紙的落後與今天的加速紀錄**同型**，但舊紙本身**仍缺少當趟船速**。

**允許的主張**：①加速會產生落後 ②穩速前進不必然落後 ③舊紙**很可能**記到相同情況。
**禁止**：把舊紙事後升格成完整紀錄。
**這個邊界必須寫進艦長台詞**，不能只藏在證據卡（已落實於台詞稿 `C1-3`）。

### 修正 2｜固定順序（V4 成為高潮）

**V1 缺口 → V2 加速 → V3 穩速 → V5／V6 風 → V7 船艙 → 封存減速預測 → V4 減速 → V8 雙紀錄 → V9 公開**

理由鏈：V3 推翻「只要船動就落後」→ 艦長立刻提風 → 風被**當趟紀錄**排除 → 船艙帶出「局部普通機械現象分不出停泊與近似穩速」→ **玩家自己預測：若落後來自加速，減速該偏哪裡？** → V4 是玩家主動提出的新預測，不是第三次換船況按執行。

v0.3 的「艦長轉變表」與場景骨架順序不一致（表寫風在 V4 之前、骨架寫 V4 在風之前），此矛盾以本順序為準，全稿統一。

### 修正 3｜V2 艦長不得「看不懂自己的船速紀錄」

V2 已留下逐段拉開的岸標紙，他就知道這段仍在加速。**刪掉「他還不知道這一段在加速」。** 定案反應：承認落後與加速**同時出現**，並要求再做穩速對照。

### 修正 4｜風的措辭與「自動三回」

- 全稿「相對風向**翻轉**」→ **「相對風向明顯改變；沿船頭—船尾方向的分量反向」**（有側風時不必然反轉 180°）。
- 玩家要判讀的是：**風向改變了，落點偏移卻沒有跟著風向形成一致變化。**
- **V2、V3、V4 皆明寫「合格方案自動三回」**；未達三回不得使用「散布」「系統偏前／偏後」等措辭。
