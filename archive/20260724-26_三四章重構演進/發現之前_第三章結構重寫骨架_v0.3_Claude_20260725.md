## 一、固定分工（V2 起，補齊後不再變動）

| 人 | 唯一職責 |
|---|---|
| 馬蒂厄 | **只抽門閂**（不下來看落點） |
| 水手 | 維持等節拍鼓（間隔不變） |
| 艾蒂安 | **固定守岸標**（逐拍記桅杆離碼頭多遠） |
| 船上落點紀錄者（伽桑狄或旅人） | 記落點，**並在放手那一拍記下風向旗方向** |
| 艦長 | 只控制船況 |

- **「同一人不得分身」仍然成立**：唯一的合併是船上紀錄者在**同一時刻、同一位置**記落點與風向旗——不是站兩處，因此不違反該規則。
- 分工補齊之後，**每一趟桅頂落石都同時具備**：落點、鼓點、岸標（→船況可判定）、放手那一拍的相對風向。
- 因此「要記什麼」不再是勾選清單；**每趟的第三個決定改為「配置」**（互斥，見下），而互斥來自物理設定，不是人手：

| 配置 | 內容 | 互斥理由 |
|---|---|---|
| **A 桅頂落石** | 落點＋鼓點＋岸標＋風向 | 標準配置 |
| **B 船艙盲測** | **不放桅頂石**；只有艙內水碗與球；艦長私下設定兩筆未知船況 | 根本沒有落石，無法與 A 並存 |
| **C 雙紀錄** | 落點＋**岸上逐拍位置**＋**船上逐拍位置** | 同一事件要兩份獨立逐拍紀錄，艾蒂安守岸紙、船上另一人守船紙 |

## 五、舊紙的推論鏈與殘餘界線

**開場（節點 7）舊紙只寫**：「解纜後第一段，落在桅後。」——標明**哪一段操作**，但**不命名**加速。

推論鏈：

1. **V2** 量到：這艘船在「解纜後第一段」，鼓點對岸標的間距**逐段拉開** → 該段速度正在增加。
2. **V3／V4** 建立指紋：加速 → 落點偏後；穩速 → 桅腳；減速 → 偏前。
3. 因此舊紙的落後**與加速紀錄同型，且指向同一段航程**（段落名稱寫在舊紙上，是文件本身給的資訊，不是事後補的證詞）。

**允許的措辭**：「舊紙記的那一段，我們量到它在加速；它的落後與加速紀錄同型。」
**禁止的措辭**：「舊紙已證明當時在加速。」
**殘餘界線**（保留在證據卡／史實邊界）：舊紙本身沒有當趟船速紀錄；若那一趟另有異常操作，此重新解讀就要重議。**不得**因為結論好用就把它寫成定案。

## 六、一項我主動提出的補強（防止 V2–V4 變成三次同動作）

分工固定後，V2–V4 每趟只改「船況」一項——這是變因控制的正確樣貌，但手感上會接近「連續按三次同一個鍵」。

**建議沿用 ch4 已驗證有效的作法**：每趟執行完，由**艦長或伽桑狄依這一趟的實際結果**回一句（不是通用教學旁白）。例如加速趟由艦長得意、穩速趟他先辯風、減速趟他被迫改口。引擎已經知道每趟的船況與落點方向，UI 只要按結果取句，**不必改引擎**。
→ 三趟就不是三次同動作，而是三次對話推進；艦長的轉變也剛好卡在這三趟之間（§七）。

## 八、引擎工作與凍結界線（更新）

**需要的引擎工作**：
- `PROTOCOL_REQUIRED` 五 slot → **固定分工 ＋ 三配置（A／B／C）切換**；分工補齊為單一確認
- `chooseInvestigationOrder` 退場；`sanitize.js:193` 白名單同步
- `runPilot`／`runDesignedProtocol`／`runSpeedChange`／`runCabinBlindPair`／`runWindAudit` → 單一 **`runVoyage(design)`**，`design = {segment, release, config}`；**合格方案自動三回**寫進同一支
- **往返對照**：一次執行產生**兩航向 × 各三回**的真實資料（不可鏡像充數）
- **每趟必附**：岸標船速紀錄與放手拍的相對風向（資料結構需擴欄）
- 雙紙帶：`inspectRecordBeat`／`alignRecords` → **逐拍扣桅杆位置的單一參數**（滑桿 0→1，動畫表現尺隨船前移）
- 公開：`sealPublicCriteria`／`screenPublicRecord`／`revealPublicResults` → **沿用 V3 判準（顯示）＋確認＋重跑＋揭曉**
- 收斂 `assertG1Designed`／`assertG1`、`assertG2Designed`／`assertG2`
- G1–G5 留在 `evidence` 與存檔；UI 只說「旅人筆記多一張紙」
- 舊存檔遷移

**凍結不變**：G1–G5 物理內容與證據邊界；船艙結論只及於近似穩速、局部、普通機械現象；風只判「本次精度與散布內未見系統主因」；公開先封標準後揭曉；等節拍鼓間隔不變；馬蒂厄不得兼任抽閂與船上觀察；艦長人物轉向；章尾月亮交棒。

**新增凍結一條（本版產生）**：**每一筆桅頂落石紀錄都必須具備當趟船速紀錄**；任何結論不得以「同一套操法」替代當趟紀錄。

**治理**：**CH3-CR-018（結構重寫）＋ GB-ADR**，先文件後程式。
