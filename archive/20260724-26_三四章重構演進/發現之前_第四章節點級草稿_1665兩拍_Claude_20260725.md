# A. D1-2「牛頓當場回話」反應表

**問題**：現在牛頓在 `n8` 交代規則、然後玩家進 `e1` 工作台，牛頓整段缺席，直到 `n10` 才又出現。玩家在最需要對手的時候是獨自面對一台機器。

**落點（重要）**：這些台詞**不是 scenes 節點**，而是工作台內一個「牛頓回話」區的資料表。引擎**已經**回傳所需的一切（`commitDeflection` 的 `consequence.kind`、`runOrbitRule` 的 `run.outcome` 與 `run.predictionMatched`），所以 UI 只要按 key 取句即可，**`engine4.js` 不必改**。

## A1. 逐拍偏折的可讀後果（key＝`consequence.kind`）

| key | 引擎判定 | 牛頓當場回話 |
|---|---|---|
| `tangent` | 箭幾乎為零（<0.006） | 「這是沒有作用的那張紙。你又把它畫了一次。」 |
| `outward` | 角度 > 90°（往外） | 「往外推。那不是拉，是丟。」 |
| `impact` | 量 > 2.2 倍 | 「太多。它沒有繞，它撞上來了。」 |
| `unstable` | 1.25–2.2 倍，或偏角 >15°，或 < 0.75 倍 | 「不夠準。它每一圈都在換半徑。」 |

## A2. 整輪跑完的結果（key＝`run.outcome`）

| key | 引擎條件 | 牛頓當場回話 |
|---|---|---|
| `parabola` | `target = same-vector`（固定方向） | 「固定一個方向，就只折彎一次。它離開了，不是繞著走。」 |
| `wrong-center` | `target = ink-mark`（瞄紙上的墨點） | 「它繞了。繞的是紙上那個點，不是地球。」 |
| `outer-band` | 外張 | 「拉得太少，或它跑太快。它一圈比一圈遠。」 |
| `inner-band` | 內切／撞地 | 「拉得太多，或它跑太慢。它正在往裡栽。」 |
| `near-circle` | 成功 | 「留下來了。方向對，量也配上了速度。」 |

## A3. 封存預測的回收（key＝`run.predictionMatched`）★最關鍵

引擎早就在比「你事前封存的預測」與「它實際跑出來的結果」，但呈現層沒把它演出來。**這一句才是「先承諾再揭曉」在微觀層的兌現**，也是牛頓最像人的時刻。接在 A2 之後：

| 情況 | 牛頓當場回話 |
|---|---|
| 料中 ＋ 失敗 | 「你料中了它會失敗。那你已經知道下一個該改哪一項。」 |
| 沒料中 ＋ 失敗 | 「你連自己寫的規則會做什麼都沒料到。先別動箭長——先想清楚你剛才在期待什麼。」 |
| 料中 ＋ `near-circle` | 「你先寫下它會留下來，它就留下來了。這一張可以拿去比。」 |
| 沒料中 ＋ `near-circle` | 「成了，但不是你預期的那樣。記下來——這次是運氣還是規則，下一輪會告訴你。」 |

## A4. 撰寫紀律（給後續補句用）

- 牛頓**短、冷、講數量**；不用比喻、不用法庭語（「作證」一類請避開）、不說「錯」，只說**它做了什麼**。
- **不判卷、不給答案**：不說「你應該把箭長調小」，只說「它正在往裡栽」。診斷權留給玩家（憲章一）。
- 一次只回一句；失敗不加驚嘆號。

## B1. 為什麼三個選項是真決策

- 兩個死路各打中一種**真實的科學不誠實**：`fit`＝為結論挑資料；`announce`＝拿半個答案先卡位。錯選**不扣分、不軟鎖**，牛頓當場駁回並退回選擇（沿用 ch3 `C2-4/q1` 的 `r1`/`r2` → 回選項先例）。
- 正解不是「聰明」，是**把差距與不確定的來源寫清楚再擱下**——與 K5「能算到哪裡，也要停在哪裡」同一條脊椎，提前十九年埋下。

# D. 自檢

- **不洩 K2**：全場**不出現**指數、不出現「平方」、不出現 60 或 3600、不給任何數值。失敗原因掛在「借來的地球尺寸」，玩家仍必須在 `D2-2` 自己封存距離律。
- **史實邊界**：不把 1665 演成理論完成；不宣稱他因此棄置二十年；晚年「相當接近」的自述與後世對地球尺寸的指正**並列呈現**（`s0`）。
- **憲章四**：失敗被判讀為「量尺不可信」而非「規則被否證」——這是誠實的科學判讀，也不預先替玩家宣布規則是對的。
- **引擎相容**：反應表 key 全部對應 `engine4.js` 實際回傳（`tangent`／`outward`／`impact`／`unstable`；`parabola`／`wrong-center`／`inner-band`／`outer-band`／`near-circle`；`predictionMatched`）。新場景只用既有節點型別；`ch4FirstMoonCheck` flag 若採用，請一併加進存檔淨化白名單。
- **旅人定位**：`n9` 明說旅人知道未來、但**不交出數字**——共同驗證者，不是祕密發明者。
- **ch4 未凍結**：走一般增補；`scenes4.json` 為 canonical，改完自動生成 `.js`、跑測試，並回寫小說稿 v0.4.x 對應段落，避免 JSON 改了、`.md` 沒改。

**建議施工序**：先做 A（反應表，改動小、立刻改善「牛頓不在場」的體感）→ 再做 B（新增一場戲）→ C（一句回呼）。A 做完就該重測一次手感，再決定 B 要不要進。
