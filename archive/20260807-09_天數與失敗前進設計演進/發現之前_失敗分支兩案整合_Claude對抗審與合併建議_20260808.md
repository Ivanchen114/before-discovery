## 總裁決

**Codex 案的骨架比我的好，建議採用；我的案降級為增補件併入。**

兩案對問題的診斷相同（錯誤沒有後果壽命），開的藥方不同：我開的是「失敗段走到底→筆記回溯→壞紙保留」的迴圈；Codex 開的是「錯誤先被世界採用→玩家在後果裡修復→帶痕跡匯回」的失敗前進。對抗審後我改判支持 Codex，三個理由，每個都打在我案的實處：

1. **重量問題**：我案的回溯會清洗世界線（NPC 不記得），這在更長的時間尺度上複製了總監抱怨的原病——「世界沒有真的相信你說過的話」。失敗前進讓世界記住錯誤，重量是真的。
2. **重走問題**：我案 §八自承「最大風險是重走體感」，整套防痛機制（錨點後移、until 跳過、變化 OS）都在治這個自己製造的病。Codex 不回頭，病根本不發生。
3. **世界觀成本**：我用「筆記翻頁」的修辭想繞過穿越降格，但只要玩家能回到之前，就是給了旅人時間能力——修辭迴避不了設定變更。Codex 把回捲降為 F4 稀有事件並強制先動上游法源，是誠實的處理。

我案撤回的條款：筆記回溯作為普遍失敗機制（§三.3）、失敗段信譽一律 −1（§四）——後者經 F 分級檢驗屬 F1/F2 誤罰。我案保留為增補件的條款見 §整合。

## A 級必查（逐題）

### A1 「曖昧時間裂口」是否仍實質改變旅人世界觀？

**是，即使選 C 案，且要動的上游比 Codex §14.1 列的多一項。**

- 能力面：C 案雖不給玩家按鈕，但「世界回復而旅人記憶跨越回復」本身就是新設定——被動能力也是能力。聖經需補穿越能力邊界，Codex 已列，正確。
- **Codex 未列的**：聖經 line 43 與 §長線持有表——「終幕不解釋穿越（不降格為科幻設定）」，且「穿越之因」的線索露出計畫全系列只許 P0-0 埋設＋EM3、L4 各一行＋終幕收束。**ch4 時間裂口＝旅人異常的第二個親歷樣本，是持有計畫外的重大線索露出**。好消息是方向相容：裂口不解釋，與「不解釋穿越」同構；終幕「我為什麼在這裡」反而多一個可檢驗的資料點。但持有表必須先修，否則裂口就是計畫外洩答。
- 順帶核可：C3-2 x4「你不會回來替它辯護」安全——裂口限章內，旅人跨章仍是單向的。

### A2 F 分級是否有混類？

**分級乾淨，但有兩個邊界未收口：**

1. **與現行信譽事件的對表缺失**。現行 runtime 已在罰的行為（ch1 辯論 trap 雙重代價、C0-3 越界 rep −1、H3-2 common-seal rep −1）各屬哪級？trap「憑未來的物理學」按表是 F1（認知誤判）還是 F3（把未量得說成已證明）？答案影響它該不該扣信譽。**建議：施工前建立「現行信譽事件 → F 級」對照表**，逐筆歸級，發現 F1/F2 被現行規則扣分者列為待修正案。這張表 Codex 案沒有，是空缺。
2. **F4「反覆拒絕更正」需量化**。建議判準：同一 choice 第二次選擇強迫項即升 F4——**現行 H3-2 已是這個結構**（common-seal 首選 rep −1＋flag `ch6JointOverreachTried`，common-seal-again 以 flagPresent 解鎖，已回檔核實），直接沿用先例，不必發明。

### A3 回捲保留／回復表是否可能偷留？

**有一個洞：時序糾纏證據。**§8.2「錨點前合法證據保留」假設證據取得與錨點後事件無因果，但若玩家在錨點前**靠即將被回復的承諾**取得證據（例：以「我答應署名」換到一張紙，回捲後署名不曾發生），白名單制會漏留這張紙。**建議補不變量：「證據的取得條件若依賴被回復的事件，證據一併回復。」**這正是方向二（checkpoint envelope）天然處理、方向一（章別白名單）容易漏的案例——影響 B3 答案。

另對 §8.2「信譽不可草率決定」的未裁項，我給明確建議：**F4 裂口的信譽不回復**。信譽是旅人的跨章屬性，不是世界狀態——世界忘了，帳還在。這同時回應 Codex 自己的「回捲抹掉重量」風險：裂口有真代價，就不是免費讀檔。

### A4 六章候選是否違反既有契約？

**一條 A 級衝突，其餘通過：**

- **ch2 候選（B2-5 錯袋真封）與 GB-ADR-022 直接衝突**。ADR-022 驗證條款明寫「B2-5 三步『挑紙→寫界線→封蠟』與**錯選原地修正**」且進常駐測試（已回檔核實 decisions.md:158）。Codex 聲明「所有引用場景節點已對照現行 runtime 驗證」——對照了存在性，沒對照 ADR 保護（與我上輪被抓的錯同型，對抗審的價值就在這裡）。**修法：ch2 候選施工前必須先立 ADR-022 修正案**，或改為跨章投影版（Codex 已標 R4 另走）。
- ch3 候選：與剛完成的 C3-1/x1 三選項 CONFORMANCE 相容；「官員把錯的寫進卷宗」有 1633 審判後的史實張力，但**匯流時卷宗必須改回有限主張**，不得讓「已證明地球會動」的官方紀錄流出章外成 alternate canon——Codex 匯流點 C3-1/x2 可控，驗收加一條「卷宗終稿唯一」即可。
- ch4 K5：印刷波折在史實框架內（初版本就有出版危機）；錨點 K5 入口不重做 K1–K4，通過。
- ch5、ch6：與 debate5 P2「先認對方的帳」及 SC6-R1 語意銜接皆通過；ch6 現行 seal-again 結構即 F4 先例（見 A2）。
- ch1：錯誤歸因決定下一組球＝憲章五「可分辨誤差特徵」的正嫡，通過；與 E4 錯誤結論駁回契約的接線施工時對表。

### A5 第三章試點能否驗證假說？

**能，但要防位置效應。**C3-1 在章末，玩家帶著「終於要收尾」的情緒，任何加長內容的容忍度都偏高；試玩若回饋良好，可能是位置紅利而非機制效果。**建議 §12.3 加第六問：「你願意在章中段也遇到這種失敗嗎？」**另外 §10.2.6「重整／讀檔不重播失敗演出」在「不動 schema」約束下的實作邊界要先寫明：用現行 flags 機制（屬既有 state 結構，不算升 schema）記已播,可行,但要在試點 spec 明示,避免施工時被迫偷開新鍵。

## B 級結構建議（簡答）

1. **順序同意，加一級台階**：ch3 試點（F2 弧線）與 ch4 裂口（F4）之間證據跨度太大，建議 ch3 試點同批補 2–3 個 F1 反應枝（一至三拍、讀回一句），驗證最小尺寸的讀回是否已能改善體感——若 F1 就夠，F4 的成本可能根本不必付。
2. **撤換**：ch2 候選暫撤（A4 衝突），待 ADR-022 修正案；其餘保留。
3. **envelope 優先**（A3 時序糾纏論證），但兩案共同前置不變：跨章存檔遷移法源先立，負向 fixture 先建。
4. **裂口的純世界內替代案（若 C 案試玩失敗）**：ch4 可用「哈雷的錢」——玩家拒絕修復，哈雷自掏腰包救場（史實本就如此），玩家全程看著他付錢。損失由玩家在乎的人承擔，比時間回捲更痛，且零世界觀成本。建議寫進第二階段的 B 計畫。
5. **缺可失敗條件**：branch-lifetime 診斷需負向 fixture（弧線退回一拍時診斷必須報差異）；「第二輪不原樣重播」需機檢（回捲後 first_action 必須異於首輪）；「錯路不設收藏獎勵」需反向測試（列舉錯路不得出現在任何完成度統計）。
6. **skill 補強評估**：branch-lifetime「只報結構不判真假」的克制正確；**Failure-consequence contract 建議併入 check-mechanics 的 evidence_judgment 結構**（後者已有承諾、操作、留痕、阻力、後果欄位，重疊度高），新增 F 級與 readback 欄即可，避免兩套契約漂移——這是 §14.2 唯一過度設計處。R4 強制路由正確且必要。
