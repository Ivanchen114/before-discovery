## 一、施工端主張

1. 正式證據圖已改為「中性底圖＋當局 state 投影」。`projectionOnly: true` 禁止固定結果層；`neutralBase: true` 只允許不含答案的底圖，不得放行預製路徑、數字、判讀或裁決。
2. 第一章 S1／S2、第二章 F1／S3／S4、第四章 K1 已換成版本化中性 raster；六張母版與 800×500 WebP 成品均已入庫。
3. K1 固定底圖不再冒充玩家軌跡；不同合法 state 應共用同一張中性底圖，但產生不同的 HTML／SVG 結果投影。
4. 暫扣、污染、修復共用一份 disposition；取得提示、證據縮圖、放大讀圖器與研究紀錄四個入口不得互相繞過。
5. 同一證據含多張原紙時，放大讀圖器逐張呈現，不再只讀第一張。
6. 史料、後世刊本與教學重建移到「歷史參考」，不寫入 `state.evidence`，也不進辯論選牌；縮圖、圖說、替代文字與讀圖器標題須揭露身分。
7. 第七章正式證據不得只靠敘事碼或舊存檔旗標取得；必須同時有引擎真實 lab 狀態與精確 marker event，sanitize 會重算驗證。
8. `GB-ADR-057`、跨章規格與治理 CURRENT 已記錄上述責任邊界。

## 二、三方分工

三方皆須先比對第七節 SHA；任一不符即停止把不同版本合成同一輪裁決。

### Claude：揭曉、暫扣與語意邊界

- 追查史料／教學重建是否仍能混入正式證據或辯論選牌。
- 檢查 `projectionOnly` 與 `neutralBase` 的語意是否在所有消費端一致，不能只看 registry 字串。
- 檢查玩家開啟、切換、關閉筆記前後 state 深度相等。

### Codex：runtime 路徑與負向變異

- 實際執行 acquisition、thumbnail、reader、research 四條路徑，不以 grep 代替行為。
- 對 disposition、第二張原紙、K1 state overlay、第七章證據授予與 sanitize 分別做可還原變異。
- 驗證不同 K1 state 會得到不同結果投影，且固定 raster 本身不含任何本局答案。
- 逐項區分控制組、變異組；控制組不合法時必須撤回。

### Gemini：44 項證據與視覺／認知負荷

- 實看六張新增中性底圖，確認沒有可讀假古文、固定數值、固定軌跡或暗示正解的圖形。
- 檢查 844×390 下縮圖與放大閱讀器；判斷重要訊息是否改由可讀 HTML，而非縮小烤在圖裡。
- 抽查多圖證據、歷史參考與正式證據是否在視覺上可辨識。

## 三、必跑攻擊路徑

1. **中性底圖／state 投影**：同一 K1 底圖餵入至少三個合法 state，卡面結果必須不同；移除 state renderer 或退回固定成品圖時契約須轉紅。
2. **固定答案掃描**：S1、S2、F1、S3、S4、K1 六張 raster 逐張實看；不得含本局數值、預測、殘差、軌道或裁決。
3. **暫扣四入口**：第七章 away 狀態不得從取得提示、縮圖、讀圖器或研究紀錄看到被扣原紙；合法修復後四處一致恢復，事故史仍保留。
4. **多圖讀圖器**：把合法多圖證據的第二張移除於 reader 消費端，測試必須轉紅；每張需有獨立 alt，整組另有短圖說與文字版。
5. **第七章防偽**：只塞 evidence code、只塞 marker、只塞 lab 旗標、或使用錯誤 marker event 都不得成立；合法 lab＋精確 marker 的控制組必須成立。
6. **歷史參考分層**：將任一 historical reference 誤塞進 `state.evidence` 或辯論牌，契約須轉紅；史料身分少任何一處揭露也須轉紅。
7. **唯讀**：同一合法 state 連續開啟三次筆記、展開多圖與歷史版本，前後深相等。
8. **資產完整性**：六張 WebP 必須 800×500 且可解碼，`sourceMaster` 必須可解析；禁止以空白路徑或自由文字歷史債假裝完成。
9. **小螢幕**：844×390 橫屏檢查 K1 長資料、關閉鈕、鍵盤 Tab／Enter、焦點返回與縱向捲動；不得只驗空白筆記。
