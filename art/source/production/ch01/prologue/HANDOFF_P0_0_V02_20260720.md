## 總監方向的落地判斷

1. **出發地明確為台北。** 101 不是裝飾，它讓「低緯度極光」立刻成為玩家認得的異常，也讓 1590 年的斷裂更大。
2. **時間固定為故事時間 00:49。** 不再抓玩家系統時間。固定深夜美術若遇到玩家早上開遊戲，真實時間會拆穿場景；00:49 直接排入平板畫面，字幕只寫「凌晨。台北。」
3. **平板內容是完整美術成品。** 斜塔文章與突發新聞的文字、圖片、時間、版面、透視與光線全部合成進圖；程式不再疊文章卡、推播框、通知堆、斜塔 placeholder 或動態時鐘。
4. **繁中不是交給生圖模型猜。** 房間、城市與異象由生圖完成；精確繁中以 Heiti TC／Songti TC 在美術製作階段排入同一張圖，runtime 看見的仍是一張完整圖片。
5. **手機可讀性由字幕兜底。** 小螢幕不要求讀完平板內文；字幕至少重述文章問題與新聞主標，螢幕閱讀器另有隱藏完整文字。視覺層不再出現可見 HTML 方框。
