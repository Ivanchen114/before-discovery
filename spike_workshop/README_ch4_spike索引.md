**設計意義**:三組配對都成立,中間選項不是唯一正解(A-5);而**輕微錯配產生橢圓**——玩家在 1679 年就親手畫出橢圓,五年後哈雷帶著「橢圓?」的問題進門時,那個字他已經見過。

## 總監裁決(2026-07-28)|D2-1 操作與用語

1. **拖曳不採,只留轉鍵**。理由:pointer 事件的無障礙與橫屏問題(Sol B-10),且手震會混進方向判斷。轉鍵=主操作,鍵盤 ←→ 等價。
2. **轉鍵位置在圖正下方**,不在頁面下方——否則按的時候看不到動畫。
3. **「拍」必須先被定義**。牛頓親口:「月亮是一路連著走的,可是筆不能一路連著算。我把它切成一小段、一小段——每一小段,叫一拍。」
4. **「原本跑多快」不是裸旋鈕**。它的意義=玩家要先假定初速,因為「同樣一扳,對慢的來說太重,對快的來說太輕」。牛頓親口說明,寫在欄位裡。
6. **誘答鍵必須有餌,而且要點名**。誘答只能在玩家真的有動機時才亮;按鈕文字要寫出「改的是哪一條、改成什麼、換到什麼好處」。「微調一點,讓它更漂亮」這種寫法一律不合格。
7. 三個欄位一律改成問句:「一拍之內,把它的方向往哪扳?」「這顆月亮,原本跑多快?」「每一拍,方向扳多少?」
